## 확보한 자료

- 2026Q1:21,188행·1,564상권,2026Q2:21,133행·1,566상권.
- 총128,053행·62제공업종·6분기. 준비파일46,190,017바이트.
- 공식 다운로드가 요청 필터를 무시하고2025년까지 반환해 전체128,053행과 실제 추가 대상42,321행을 구분했다. 키는 분기+상권+업종이다.
- 원본 CSV SHA256 `74c0462ce5765b3a4acbbf1fc93a52bb6cd4125ce5f739bb2f5c2ac3347d0e0c`, 준비 JSON SHA256 `c1553f8c704232ce6b964270ce13faaec9caea9ba2b6df7661cab2ac9eb5dc99`.

원본은 불변 캐시 `data/raw/commerce/market-sales-2026-public-download.csv`에 보존했다. GitHub Pages에는 public의 준비 파일만 포함하며 원본 캐시나 키를 올리지 않는다. `scripts/extend-market-sales-2026.py --download`는 공식 전체 다운로드 폼을 사용하고 기존 원본이 바뀌면 덮어쓰지 않는다. `--check`는 오프라인 재생성 바이트 일치를 검사한다. 기존 prepare-market-areas 실행도 manifest가 있으면2026확장을 다시 적용한다.

## 독립 원문·공간 감사

[독립 데이터 감사](market-sales-2026-audit.md)에서 모든 준비 수치128,053행을 공식 CSV/ZIP과 대조했고 기존2025 스냅샷 불변, 중복0·잘못된 타입0·음수0·미연결 코드0을 확인했다. 이번 CSV에 빈값이 없어 null이0개였으며 빈값을0으로 보정한 것은 아니다. 없는 관측은 여전히 자료 없음이다.

2026Q1에는86개, Q2에는84개 보유 경계에 해당 분기 매출 행이 없다.2026에 새로 관측된3코드는 모두 기존 경계에 있어 새 도형을 만들지 않았다. 원본/경계 명칭 차이3개, 구/동의2026소속 미확인, 원본과 준비 경계 모두 자기교차6개를 별도로 기록했다. 코드 연결 통과를2026형상·면적 동일성 통과라고 표현하지 않는다.

공식 표 미리보기와 다운로드 CSV는 같은 키에서도 값이 다르다. 전체CSV를 수치 기준으로 유지했고 미리보기 값으로 수정하지 않았다. 제공처 원인과 어느 표출 경로의 오류인지는 확인하지 못했다. 출처 팝오버에 CSV 기준·이 차이·2023대표 명칭/구동·형상 한계를 표시했다.2026-07-03 공지의 날짜/본문도 공식 원문과 확인했으며 공지와 경계형상 보증을 혼동하지 않는다.
