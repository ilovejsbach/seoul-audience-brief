# 전체화면 지도 배치 검증 (2026-11-14)

상단 제목·자료 선택을 같은 행에 배치하고 지역 단위·확대/축소를 한 행에 묶었다. 색상 조건은 가로로 배치하고 범례·시간 조절 여백을 줄였다. 남은 가운데 행을 지도에 배정하며, 확대 전 전체 경계가 보이는 자동 맞춤을 유지한다. 구 지역명17px, 동15px 기준으로 확대하고 기존 확대 배율 보정을 유지했다. 일반 화면의 기본 글자 크기는 유지한다.

Chrome 실제1800×905에서 색상 여유 옵션을 펼친 구 지도의 SVG 상단182px, 높이593px. 기존 전체화면은 더 높은1800×961에서도 상단419.5px,높이331.2px였다. 16개 마포구 동 지도 높이571.3px, 모든 지역명 경계가 SVG 안에 있음을 확인했다. 다른 해상도는 미검증.

기존 E2E4개 시나리오 통과: fullscreen-dataset, pointer-controls, map-popup-drilldown, presentation-journey. 전체화면 열기/닫기, 자료 전환, 확대/축소/초기화, 실제 포인터 툴팁·휠·드래그, 구→동 상세 진입, 시연3장 이동을 확인했다. 생활이동 전체화면도 지도·지역명이 확대되며 잘림 없는 것을 확인했다. TypeScript·프로덕션 빌드 및 git diff --check 통과.
