## 목적과 변경 경계

광고 입지 분석자가 지도를 가리지 않는 곳에 조건창을 놓고 지역·시점·대상을 연속해서 바꾸는 작업을 돕는다. 창의 이동·크기·배치는 조회 조건이 아니며 데이터·후보·색상 범위를 바꾸지 않는다. 기간 선택은 해당 통계가 실제 제공하는 날짜·연도·분기 안에서만 허용한다.

최신 요청으로 폐기되는 전제는 **지도 작업 영역과 내부 스크롤 부모 안에만 플로팅 조회창을 가두는 것**이다. 브라우저 화면 안의 접근 가능한 제목·접기·크기 조절은 유지한다. 의미 툴팁·범례·축 설정·비교 카드를 무조건 전역 이동창으로 바꾸는 요구는 아니다.

## 창 배치 수용 기준

1. 일반 분석과 상권 양쪽에서 창 제목을 드래그/방향키로 옮겨 `창.left < 지도.left` 또는 `창.right > 지도.right`가 되는 위치에 둘 수 있다. 지도와 겹치지 않는 영역까지 이동하되 창은 브라우저 화면에 남는다.
2. 지도·순위·시간대를 누르는 정상 분석 작업 때문에 창이 조용히 닫히지 않는다. 명시적인 접기/조회 옵션 토글/Esc로 닫고 다시 열면 조건과 결과가 남는다.
3. 기본 창은 제목/작업 버튼과 최소 한 줄 이상의 입력에 접근할 수 있다. 300/560/900px 너비 및 낮은 높이에서 조건 그룹이 왼쪽부터 채워지고 과도한 빈 열·가로 넘침·버튼 겹침이 없다. 넓어지면 라벨-입력의 의미 관계를 유지하며 압축한다.
4. 전역 창을 접어도 지도는 계속 조작할 수 있고, 창 root가 화면 전체의 포인터 입력을 가로막지 않는다. 창 내부의 스크롤만 필요한 경우에 스크롤한다.
5. 원래 지도 안의 컨테이너에서 분리해도 mode-analysis/mode-presentation 글자 규칙, 선택 대비, container query에 의한 열 수, 버튼 최소 크기가 유지된다. 상권과 일반 지도의 wrapper가 서로의 강한 CSS를 물려받아 빈 지도나 거대 높이를 만들지 않는다.
6. 창 내부 설명/범례의 Esc는 설명만 닫고, 다음 Esc는 조회창을 닫는다. 창 밖 범례·팝업을 누를 때 관계 없는 예전 지도창이 닫히거나 다시 열리지 않는다.
7. 실제 전체화면에서는 포털이 전체화면 요소 안으로 들어가 보이고 클릭된다. 전체화면 종료 후 body 포털로 돌아오며 창 복제가 생기지 않는다. 브라우저 전체화면 실패 시 대체 레이어도 같은 기준이다.
8. 히어로 복귀·주제 탭 전환·상권 진입/이전 화면·시연 1/2/3장 전환 뒤 비활성 지도의 포털은 시각 화면과 접근성 트리에 남지 않는다. 다시 돌아왔을 때 상태 보존 정책이 일관된다.
9. 브라우저 크기·줌·스크롤을 바꾸어도 제목과 접기 버튼이 화면 밖으로 사라지지 않는다. 위치·크기 초기화와 전체 배치 초기화는 각각 의도한 배치만 바꾼다.

## 기간 선택 수용 기준

1. 생활인구 월 선택은 실제 index의 월만 표시한다. 월을 바꾸면 유효한 기준일을 선택하고, 이전일/다음일은 월 경계를 넘어 실제 index의 이웃 날짜로 이동한다. 첫날/마지막날 이동은 비활성 또는 명확한 제한이다.
2. “월 선택”은 특정 날짜를 찾는 범위 좁히기이며 월평균·기간 합산으로 오인되지 않도록 기준일을 결과 옆에 유지한다. 기간별 평균을 원하면 별도의 요일·월 구간 분석으로 이어진다.
3. Jan–Sep gzip 파일과 October 기존 JSON의 해제 후 데이터 계약은 같다. 압축 해제는 원값을 반올림·보간하지 않고 비공개를 0으로 바꾸지 않는다. 파일 수·달력 날짜·427동×24시간의 완전성 및 원자료 해시/독립 표본 값을 대조한다.
4. 실제 공개 호스팅에서 gzip의 `Content-Encoding` 처리 유무와 관계없이 올바르게 읽는지 확인한다. 지원하지 않는 해제·잘린 응답·통신 오류는 오류/재시도 경로로 이어지고 예전 날짜 값이 새 날짜 제목 밑에 남지 않는다.
5. 월을 빠르게 연속 변경한 뒤 마지막 선택 날짜의 값만 표시한다. 읽기 중에는 현재 날짜와 이전 원값이 섞이지 않고 후보·지도 미리보기·숫자·추이·CSV의 날짜와 값이 같다.
6. 날짜를 변경해도 시간·구/동·성별·연령의 유효한 선택은 유지한다. 원자료의 실제 행정동 코드가 없는 경우에는 회색/자료 없음으로 처리하며 임의 대체하지 않는다.
7. 생활이동은 확보한 일자, 전출입은 연도, 상권은 분기라는 실제 단위를 유지한다. 생활인구의 월 선택을 모든 자료에 모양만 복제하지 않는다.
8. ResidentContext의 주민등록 기준연도와 새 생활인구 선택일의 차이를 구체적으로 유지한다. “생활인구 2026년 10월”로 고정된 설명은 현행 UI에서 일반화하고, 자료 간 차이를 외부 유입이나 광고 효과로 해석하지 않는다.
9. 시연 모드와 전체화면 지도에서도 기간 선택이 존재하거나 같은 상태에 접근할 수 있다. 별도 상태를 복제하지 않는다. 기존 조회 조건 저장·복원은 현재 날짜와 월 표시가 함께 복구된다.

## 완료 판정과 증거

위 목록은 독립 수용 기준이다. 문서를 작성했다는 이유로 통과 처리하지 않는다. 부모가 실제 Chrome의 일반/시연/상권/전체화면을 확인하고, 최소 Jan1·Feb말·월 경계·Oct31의 실데이터 의미와 오류/복귀를 검사해 새 실행 보고에 기록한다. 모든 날짜×지역×업종 조합을 전수 실행했다고 과장하지 않는다. 정본·설계·현재 자료 설명·공개 배포 결과가 일치해야 완료다.

## 구현 후 독립 소스 검토 — 2026-11-15 1차

실제 Chrome 조작은 부모가 진행한다. 아래는 당시 파일을 읽어 확인한 소스 판정이며 실행 통과를 의미하지 않는다.

- 화면 전역 좌표: `useFloatingPanel`의 `viewport:true`는 host/스크롤 부모 경계를 제거하고 viewport로 제한한다. 이동·크기·초기화가 같은 clamp를 사용하며 방향키 이벤트는 헤더 자신에게 초점이 있을 때만 이동한다.
- 포털 수명: `FloatingQueryLayer`는 활성 host의 `getClientRects()`와 조상 class/style/hidden 변화를 관찰한다. `document.fullscreenElement || document.body`에 조회창을 붙이고 원래 앱의 mode/data/CSS 변수를 복사한다. 비활성 화면·시연 장면 전환은 실제 브라우저에서 별도 확인해야 한다.
- 기간: 월→유효 기준일 유지/월말 대체와 이전·다음 날짜는 index에 기반한다. gzip magic bytes를 검사해 CDN에서 이미 해제된 JSON도 처리한다. 응답의 active 가드는 늦게 온 응답이 마지막 선택을 덮는 것을 방지한다.
- 1차 지적의 현행 상태 — 독립 소스 재확인 완료:
  - 날짜 응답은 `{date,data}`로 보관하고 `populationResponse.date===date`인 경우에만 `pop`으로 소비한다. 응답 active 가드도 유지되어 첫 렌더의 이전 날짜 값 노출과 늦은 응답 덮어쓰기 두 경로를 막는다.
  - `DataMeaning`의 툴팁 포털 대상은 `document.fullscreenElement || document.body`로 수정됐다. 조회창과 설명의 전체화면 호스트가 일치하는 소스 경로를 확인했다.
  - `MapPanel`은 `floatingOpenRef`로 실제 열림 여부를 확인하고, Esc 후 화면에 존재하는 조회 옵션 버튼으로 초점을 돌린다. 숨겨진 주제 버튼으로 초점을 옮기지 않도록 가시성 조건도 확인했다.
- 부모가 실행해 보고한 범위는 자유 이동 5경로, 날짜 4경로, 다섯 조회창 크기 행렬, 색상 범위 4경로, 핵심 분석 5경로다. 이 문서 작성자는 브라우저를 직접 실행하지 않았으며 최종 실제 증거는 부모 실행 보고를 따른다.
- 남은 실행 한계: 현재 브라우저에서는 `requestFullscreen`이 대체 전체화면 경로로 전환되어 **네이티브 전체화면 top layer 경로는 미실행**이다. 소스의 전체화면 포털 대상 확인과 대체 전체화면 통과를 네이티브 전체화면 실행 통과로 표현하지 않는다.
