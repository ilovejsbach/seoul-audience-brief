# 전체화면 조회 유지와 보조 화면 공간 정리

2026-11-16 · 구현 ab3bba2, 글자 크기 정본 적용 d52ab5c · 공개 Pages aa2b410eee5523bd1264a91cfe8a5ef9e2e78fb9.

## 목적과 적용 범위

지도·그래프를 읽는 공간을 늘리되 조회 조건, 비교 기준, 미제공 이유와 복귀 동작을 유지한다. R03/R05/R06/R20 기준으로 자료 탐색/후보 비교/두 시점 비교/요일·월 구간/상권 전용 화면을 구분했다. 서로 다른 목적의 제목을 일괄 삭제하지 않았다.

|화면|문제|변경|
|---|---|---|
|네 자료의 전체화면 지도|자료 선택 시 MapPanel과 상위 선택 함수가 각각 exitFullscreen을 호출. 개별 지도 패널을 브라우저 전체화면 대상으로 삼아 자료 전환으로 패널이 숨겨짐|명시적 종료 호출을 제거하고 안정된 공통 앱을 브라우저 전체화면 호스트로 사용. 활성 지도에 확장 상태를 이어주며 사이트 확장 화면도 자료 전환 시 전달.|
|전체화면의 상세·후보 전환|공통 호스트가 앱 전체이면 실제 지도를 떠나는 이동의 판정이 달라짐|Navigation이 실제 활성 지도 패널 범위를 기준으로 명시적 이동 시 종료. 구→동 지도 탐색은 유지, 동 상세 추이는 종료. 시작 화면·상권 전용 진입도 종료 보호. 브라우저 전체화면의 배경 메뉴는 숨겨 초점 대상에서 제외.|
|네 자료의 후보 카드|지역명과 ‘이 지역 상세’ 버튼이 각각 행을 차지하고 기간 조건이 카드마다 반복|지역명 자체를 상세 이동 버튼으로 합침. 공통 기간·타깃을 비교 영역에 한 번 표시. 구/동 단위, 지역별 전입·전출·공개 시각, 미지원 사유는 유지.|
|두 시점 비교|긴 창 제목·설정 버튼·조건·기준 선택이 여러 행을 차지. 동일 조건 설명 중복|창 제목·설정·닫기를 묶고 조건/기준 선택을 같은 행에 배치 가능하게 조정. 중복 해석은 설명 툴팁으로 합침. 기준0 이하·결측 주의와 세 수치 카드·정확값은 유지.|
|요일·월 구간|접기 제목·본문·그래프 제목이 중복|접기 동작명과 분석 제목을 구분하고 ‘시간대별 하루 평균’을 보조 표기로 축소. 월·시각·유효일수는 유지.|
|상권 전용 지도|상위 제목 아래 결과 제목·상태·도구·복구 버튼이 행을 추가 차지|상위 제목은 작업 목적, 중앙 제목은 지표라는 서로 다른 역할 유지. 결과 제목·관측/결측·도구를 묶고 조건/범위 복구를 다음 줄에 배치. 줌 도구는 세로3행에서 가로1행. 글자 크기는 기존 정본 변수를 사용.|

## 실제 검증과 한계

- 로컬: 네 자료×지도/상세/후보×분석/시연=24개 여정. 후보 지역명 버튼의 후속 상세 이동도 확인했다.
- 전체화면 연속 조회: 진입→생활이동→전출입→추정매출→생활인구→12시 조건과 강남구869,946명 실제 지도값→구에서 동 지도→동 상세 추이 종료까지8개 검사. 확장된 활성 지도는 항상1개이며 viewport와 같은 크기다.
- 작은 PC1366×768의 두 시점 비교: 상단52px, 하단502px, 조건/기준 선택 헤더43px로 화면 안에 표시. 기준 선택으로 실제 세 값 변경 확인. 상권 구 이동은 마포구77곳 확인.
- 빌드 성공, 기존 단위 검사70개 통과. 원자료·집계식·비교식은 변경하지 않았다. 독립 소스 검토에서 공통 전체화면 호스트의 상세 이동 판정과 배경 초점 위험을 찾아 보완했다.

**브라우저 자체 전체화면과 사이트 확장 화면은 구분한다.** 이번 Chrome 자동화 환경에서는 DOM 클릭과 실제 UI 클릭 모두 브라우저 전체화면 요청이 사이트의 대체 확장 화면으로 전환됐다. 실제 E2E의 `native:false`, `fallback:true`를 보존한다. 네이티브 분기는 소스 검토·보완했지만 OS 수준의 Tab/Esc와 브라우저 자체 전체화면 상태 유지까지 실제 통과했다고 주장하지 않는다.

공개 배포 뒤 검사는 [증거 폴더](evidence/fullscreen-compact/)에 별도로 저장한다. 과거52화면 방문 결과를 새 버전의 모든 데이터 조합 통과로 소급하지 않는다.
