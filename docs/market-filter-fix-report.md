# 상권 검색·유형 조회 점검 (2026-11-14)

공개 화면에서 이름 검색과 상권 유형 자체는 원자료의 도형을 거르고 있었다. 1,650개→홍대10개→홍대+골목상권4개였다. 다만 조회 개수·조건이 지도에 없고, 같은 이름이 여러 구에 있어 결과가 화면 한쪽에 작아졌다. 홍대 골목상권4개 중 홍대부중은 성북구이고 나머지3개는 마포구다. 투영 범위 계산 오류가 아니라 실제 서로 떨어진 결과를 함께 보여 준 것이다. 앞뒤/단어 사이 공백은 기존 문자열 검색에서 누락을 만들었다.

수정: NFKC·공백 무시 검색, 현재 조회/관측값/자료없음 개수, 적용 지역·검색·유형 요약, 여러 구일 때 구별 결과 수와 좁히기, 무결과 AND 조건 안내와 해제, 검색어 지우기, 공간 조건 초기화, 조회 범위 맞춤을 추가했다. 검색 결과 순위에 구·동·유형을 표시하고 선택 시 해당 상권으로 확대한다. 집중/맞춤은 원값과 현재 필터의 색상 범위를 바꾸지 않는다. 검색어 지우기 버튼은 입력 라벨 밖에 두어 입력 접근성 이름이 바뀌지 않도록 했다. 확대 버튼은 실제 지도 영역에 고정해 조건 줄 수에 따라 잘리지 않게 했다.
