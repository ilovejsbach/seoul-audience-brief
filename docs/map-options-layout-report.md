# 지도 중심 영역과 조회 옵션 전환

2026-11-14 · R05/R06/R10/R20 · 일반 분석·시연의 MapPanel 적용. 별도 상권 지도 중심 조회 화면은 기존 구조를 유지한다.

- 상단에는 주제, 왼쪽에는 조회 조건과 지도 표시 도구, 중앙에는 지도, 오른쪽에는 순위를 배치했다. 기존 상단 조건 행을 제거하고 지도의 기본 높이를 늘렸다.
- 기본 지도/순위 비중75:25. 옵션220px 기본,180–300px 조절. 경계선 드래그·방향키 또는 화면 배치의 슬라이더를 사용할 수 있다. 지도 높이도 별도 선택한다.
- 패널 너비에서 옵션 너비를 뺀 공간이540px 미만이면 옵션을 플로팅 메뉴로 전환한다. 글자를 줄이지 않는다. 접기·Esc·바깥 클릭으로 닫고 같은 조건·결과를 유지한다. 전체화면에서도 조회 조건을 펼칠 수 있다.

## 실제 검사

Chrome 실제1512×724에서 `tests/map-options-layout-e2e.mjs` 7경로 통과. 결과는 `tests/map-options-layout-results.json`에 기록했다. 기본 지도780.5×420px, 옵션220→230px 키보드 조절,55% 배치에서 플로팅 전환, 연령/성별 적용→Esc→조건 유지, 초기화, 전체화면 펼침/복귀, 전입전출 순이동을 검사했다. 가로 넘침 없음, 구명25개 유지.

독립 원자료 기대값과 화면의 강남구20–39세 여성146,038명 및2025 순이동−1,728명이 일치했다. 시연 글자4종(14/18/24/36), 분석6종(12/14/16/20/28/36) 확인.

이 검사는 변경된 영역과 전환 경로 검사다. 모든 과거 E2E 전체 재실행 또는 모든 해상도 검사로 해석하지 않는다. 낮은 화면에서는 범례·시간 조작까지 보려면 세로 스크롤이 필요할 수 있다. 지도 높이 선택/옵션 접기/전체화면으로 작업 공간을 확보할 수 있다.
