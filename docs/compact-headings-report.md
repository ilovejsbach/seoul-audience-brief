# 제목·설명·단위 압축과 상권 구 라벨 개선

2026-11-15 · R01/R04/R05/R06/R07/R10/R14/R18/R20.

## 조사와 적용
[독립 소스 감사](compact-market-title-review.md)는22개 주요 화면 계열을 분류했다. 모든 정보를 한 줄로 강제하지 않고 같은 결과의 제목·현재 조건은 묶고, 선택에 필요한 정보와 통계 해석 경고는 남겼다.

- 상권 지도: 제목·설명 버튼·분기/집단·짧은 주의를 한 행으로 묶고 반복 지표명을 제거했다. 검색 결과·무결과·초기화는 역할이 달라 별도 짧은 행으로 유지한다.
- 상권 목록/선택 상세: 구·동·유형은 위치 정보 툴팁으로 옮겼다. 순위/상권명·값·선택 기능은 유지한다.
- 고정 조건창: ‘분석 조건/자료·지역·시간·지표’ 반복 제목을 제거했다. 띄운 창은 이동 대상을 구분할 ‘조회 옵션’ 제목을 유지한다. 우측 반복 ‘지역 상세/선택 근거·추이·후보 비교’ 머리말도 제거하며 영역 이름과 상세 여닫기는 유지한다.
- 공통 추이: 긴 목적문은 제목 옆 설명 툴팁으로 옮겼다. 시점별 추계/일 고유 방문자 아님, 연도1개/변화 비교 불가, 일계와 시간 추이 차이처럼 필수 주의는 짧게 남긴다. 상권 분기 그래프의 유지 안내도 헤더 한 묶음으로 압축했다.
- 대상 비교·요일 특성·이동 상대지역·두 시점 비교: 제목과 현재 범위를 같은 줄 우선으로 묶는다. 분포 지도도 제목/설명/조건을 한 묶음으로, 거주지 구성은 제목/설명/원자료 링크로 정리했다.
- 시작 자료 카드, 독립 핵심 수치, 체류·거주 통계의 서로 다른 기준시점 경고, 전체화면의 독립 조회 도구는 목적이 달라 유지했다. 좁으면 줄바꿈하며 글자를 축소·절단하지 않는다.

## 단위와 의미
상권 유동인구 화면의 반복 ‘명(원본 추정치)’는 ‘명’으로 줄이고, 눈금은 숫자만 표시한다. 단위는 현재값·축 설명·툴팁에서 확인한다. 분기 추정치이며 하루 고유 방문자 수가 아니라는 설명은 해당 화면에 한 번 표시하고, 상권 추이를 열면 배경 지도의 중복 주의는 숨긴다. 계산·원값·CSV 원자료 단위 설명은 유지한다.

## 구 이름
원인은 색뿐 아니라 구 라벨을 상권 도형보다 먼저 그려 가려지는 순서였다. 구 배경→상권→구 라벨 전용 최상위층으로 분리했다. 짙은 남색#142d49+불투명 흰 윤곽을 사용하고 포인터를 가로채지 않는다. 카메라와 SVG 비율을 함께 상쇄해 화면상14px를 유지한다.

## 이번 실제 실행
Chrome 로컬1800×905의 동일 중앙 지도774px에서 상단180.39→95px, 실제 지도498.61→584px로 약85px를 반환했다. 제목·조건·주의 행 자체는28px 한 줄이었다. 구 라벨25개가 마지막 층에 있고 확대1→1.4배에서도 화면상14px를 유지하며 도형 클릭이 가능했다.

위치 툴팁 열기/읽기/Esc/선택, 숫자 눈금·짧은 단위·추정치 주의 유지, 그래프 목적 툴팁, 고정/띄움/접기/재열기를5개 여정으로 검사했다.1366×768에서 한줄/줄바꿈 가능성과 가로 넘침, 매출 자료 전환1개도 확인했다. 시연 보조 화면11개와 상권 검색·유형·무결과·후보·정확값·복귀7개를 재검사해 총24개 여정이 통과했다. 계산21개와 타입·프로덕션 빌드도 통과했다.

독립 원본 CSV `data/raw/commerce/market-population-public-download.csv`에서20262/상권3001494의 총유동인구8,284,977을 확인했고 선택 화면의 정확값8,284,977명과 대조했다. 원본 이름의 인코딩 표기와 화면의 경계 명칭은 구분했다. [현재 실행 결과](../tests/compact-headings-results.json)를 보관한다.
