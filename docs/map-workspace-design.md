# 지도 탐색 작업 공간 설계

확인일: 2026-11-14. 목적은 광고업체가 확보된 실제 자료에서 지역과 시간을 바꾸며 광고주에게 설명할 근거를 찾는 것이다. 숫자의 장식보다 지도 선택 → 지역 내역 → 추이 → 후보 비교의 후속 행동을 분명히 한다.

## 공식 레퍼런스 확인

| 레퍼런스 | 공식 페이지에서 확인한 내용 | 이번 설계에 반영할 부분 |
|---|---|---|
| [Kepler 지도 레이어](https://docs.kepler.gl/docs/user-guides/c-types-of-layers), [필터](https://docs.kepler.gl/docs/user-guides/e-filters) | GeoJSON 도형 레이어와 자료의 필드를 이용한 필터를 구분한다. 필터 값 변경은 지도에 즉시 반영된다. | 자료·필터·지도 표현을 분리한다. 이번 서비스에서 조건을 왼쪽에 모으는 것은 별도의 설계 판단이다. |
| [서울시 상권분석 서비스](https://golmok.seoul.go.kr/commercialArea/commercialArea.do) | 행정동과 상권 탐색을 전환하고 점포수·매출·유동인구·주거인구를 선택한다. 상세조건에서 기간·업종·인구 조건 등을 조정한다. | 지역 단위와 통계 지표를 서로 다른 조작으로 제공한다. 상세 옵션은 필요할 때 펼치고, 적용 조건은 지도에도 남긴다. |
| [Felt 지도 대시보드](https://felt.com/platform/dashboards), [인터페이스 안내](https://help.felt.com/getting-started/tour-the-interface) | 지도와 필터·통계·시계열 구성 요소를 함께 다룬다. 선택된 대상의 상세 패널을 제공하고 지도를 드래그·확대해 탐색한다. | 지도 위치를 유지한 채 조건과 선택 지역의 상세만 갱신한다. 자료와 상세 패널을 독립적으로 접어 지도 공간을 확보한다. |

요청된 Felt 주소 `https://felt.com/dashboards`는 웹 도구에서 직접 열리지 않았다. 검색으로 확인한 공식 현행 주소 `/platform/dashboards`와 공식 도움말로 대체 확인했다. 위 사이트의 기능을 모두 구현한다는 뜻은 아니며, 현재 확보된 파일과 지표만 연결한다. 화면 자동 조작 검증이 아니라 공식 페이지·문서 내용 확인에 근거한 설계다.

## 작업 방식과 진입

기존 분석용·시연용 모드를 유지한다. 분석용에 **지도 탐색** 작업 방식을 추가한다. 분석용의 기존 대시보드 보기와 지도 탐색을 선택할 수 있고, 시연용 3장 구성은 그대로 남긴다. 지도 탐색을 닫으면 이전 화면으로 복귀한다. 돌아갈 때 자료·지역·시간·지표·후보 선택을 초기화하지 않는다.

지도 탐색은 별도 전체화면 창이나 팝업이 아니다. 같은 앱 안에서 중앙 지도가 고정된 작업 공간을 사용한다.

## PC 와이어프레임

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│ [☰ 메뉴/조건]  지도 탐색 · 현재 자료 제목      [상세 접기] [이전 화면으로]    │
├─────────────────┬───────────────────────────────────────┬───────────────────┤
│ 분석 조건       │ 현재 적용 조건 · 자료일 · 단위        │ 선택 지역         │
│                 │                                       │ 지역 이름/기준    │
│ 자료            │                                       │ 실제 지표         │
│ └ 생활/이동/…   │             고정 지도                 │                   │
│ 지역 단위       │ 구·동 경계 / hover / 선택 / 확대      │ 지역별 상세 내역  │
│ └ 구/동         │                                       │ 이동 상대지역     │
│ 지역 선택       │                                       │                   │
│ 시간 기준/기간  │                                       │ [추이 확인]       │
│ 지표            │                                       │ [후보에 추가]     │
│ 인구 조건 등    │                                       │ 후보 최대 3곳     │
│ 상세조건 펼치기 │                                       │ [비교] [저장]     │
├─────────────────┼───────────────────────────────────────┼───────────────────┤
│ 출처/제공범위   │ [이전] [재생/정지] 시간 선택 [다음]   │ 같은 조건 기준    │
└─────────────────┴───────────────────────────────────────┴───────────────────┘
```

권장 PC 폭 1440px: 조건 280px, 상세 320px, 나머지를 지도에 배분한다. 좌우 패널은 각각 스크롤하고 중앙 지도는 페이지 스크롤에 밀리지 않는다. 메뉴를 접으면 왼쪽 폭만 제거한다. 상세를 접으면 오른쪽 폭을 지도에 돌려준다. 좁은 화면은 한 열로 전환하고 조건·상세를 펼침 방식으로 제공한다.

IBM Plex Sans KR을 공통으로 사용한다. 제목 24px·본문 16px·보조 13~14px, 제목과 핵심 수치 600·본문 400·버튼 500을 따른다. 파란색은 지도 수치, 주황색은 선택·주요 행동에 사용한다. 색만으로 선택 상태를 표현하지 않고 테두리·지역명·단위도 남긴다.

## 버튼 목적과 후속 행동 계약

| 조작 | 목적 | 결과와 다음 행동 |
|---|---|---|
| 메뉴/조건 | 지도 공간과 조건 편집을 오가기 | 조건 패널만 접는다. 조건 값은 보존한다. 다시 열면 같은 값이다. |
| 자료 선택 | 서로 다른 통계의 의미를 분리 | 해당 자료에 지원되는 기간·단위·옵션을 표시하고 지도·상세·범례를 함께 갱신한다. 지원하지 않는 조건을 조용히 적용하지 않는다. |
| 구/동 단위 | 공간 해상도 변경 | 실제 경계가 있을 때만 동 지도로 전환한다. 생활이동은 구 단위만 지원한다고 안내한다. |
| 지역 선택/지도 클릭 | 분석 대상을 지정 | 선택 지역을 강조하고 우측 지표·내역을 갱신한다. 처음 구를 고르면 제공되는 동 내역을 보여준다. 같은 대상을 다시 상세 선택하면 추이로 이동한다. |
| 시간·기간·지표 선택 | 같은 공간에서 조건을 바꾸기 | 원본 파일을 읽은 뒤 같은 적용 조건을 지도·우측 상세·범례에 표시한다. 출발/도착 기준, 시간대/누적/원본 일계의 차이를 분리한다. |
| 시간 이전/다음/재생 | 시간에 따른 변화를 관찰 | 중앙 지도와 선택 지역 값을 같은 시점으로 바꾼다. 작업 공간을 벗어나면 재생을 멈춘다. |
| 상세 접기/보기 | 지도를 넓게 보거나 선택 근거를 읽기 | 우측 패널만 접는다. 선택 지역·후보는 보존한다. |
| 추이 확인 | 선택 지역의 변화 근거 찾기 | 같은 자료·지역·조건으로 추이를 보여준다. 추이에서 지도 복귀와 후보 비교가 가능해야 한다. |
| 후보에 추가/해제 | 광고주 브리핑 후보 구성 | 실제 연결된 지역만 최대 3곳 담는다. 선택 여부와 제한 이유를 표시한다. |
| 후보 비교 | 공통 기준으로 판단 | 단위·기간·대상·집계 방식을 함께 보여준다. 다른 조건으로 저장한 후보는 조건 차이를 명시한다. |
| 저장/표 내려받기 | 근거를 보존 | 실제 값·자료일·시간 기준·조건·출처를 함께 보존한다. 현재 내역과 다른 범위를 저장한다면 버튼에 범위를 명시한다. |
| 이전 화면으로 | 기존 분석/시연 흐름 복귀 | 작업 공간을 닫고 이전 보기를 연다. 현재 분석 상태는 상위 컴포넌트가 보존한다. |

## 빈 상태와 오류

- 지역 미선택: 지도는 전체 범위, 상세는 ‘지역을 선택하면 근거를 확인할 수 있습니다’와 구 선택 안내를 제공한다.
- 경계는 있지만 통계 키가 없음: 회색과 ‘현재 통계 연결 없음’을 표시하고 상세·후보 추가를 막는다. 닫기·전체 복귀는 유지한다.
- 실제 키가 있지만 비공개·결측: 자료 없음으로 표시한다. 0으로 바꾸지 않고, 실제 지역의 다른 시점 탐색은 허용한다.
- 로딩·실패: 이전 값을 새 조건의 값처럼 보여주지 않는다. 로딩 상태·같은 조건 재시도·내려받기 비활성화를 제공한다.
- 지원 범위 밖: ‘해당 연도의 동 자료 없음’ 등 구체적인 이유를 표시하고 공식 구 합계 또는 지원 기간 선택으로 이어간다.
- 상대지역 없음: 선택 조건의 기록 없음과 집계 기준을 표시한다. 상대지역을 임의 생성하지 않는다.
- 후보 없음: ‘지역 선택 → 후보에 추가’ 행동으로 되돌아갈 수 있게 한다.

## 범용 셸과 데이터 컴포넌트의 경계

이번 `MapWorkspace`는 배치와 패널 열기/닫기만 담당한다. 기간·지역·후보·지도 선택·집계·재생 상태는 상위 `MarketExplorer`가 소유한다.

```tsx
<MapWorkspace
  title="지도 탐색"
  controls={<자료와지역시간지표옵션 />}
  details={<선택지역상세와후보비교 />}
  onClose={이전화면복귀}
>
  <div className="mapWorkspaceMap">{실제지도}</div>
  <div className="mapWorkspaceTimeline">{시간선택과재생}</div>
</MapWorkspace>
```

Props는 `children`, `controls`, `details`, `title`, `onClose`다. 가운데 `children`은 부모가 지도와 하단 시간 컨트롤을 배치하는 자리다. 셸 자체는 작동하지 않는 가짜 시간 버튼이나 예시 수치를 만들지 않는다. 좌우 패널을 접어도 React 노드를 제거하지 않아 입력 상태를 보존한다.

## 통합 검증 기준

1. 자료·지역·기간·지표를 각각 바꿀 때 지도·현재 조건·우측 상세가 같은 값을 표시한다.
2. 구 선택→동 선택→재선택→추이→후보 비교→지도 복귀가 막히지 않는다.
3. 도착/출발 및 시간대/누적/일계 조건이 저장·복원·CSV에서 일치한다.
4. 메뉴·상세를 접고 다시 열어도 조건이 유지되고, 실제 지도 크기만 조정된다.
5. 시연용 3장 및 기존 분석용 동작이 유지된다. 지도 탐색 진입·복귀 때 데이터가 임의로 초기화되지 않는다.
6. 지도 키보드 조작, 포커스 표시, 버튼의 펼침 상태, 비공개·미연결 지역 차단을 확인한다.
