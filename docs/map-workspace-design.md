# 지도 탐색 작업 공간 설계

현행 요건 갱신: 2026-11-16. 상권 조회 계층과 자치구 탐색 계약을 갱신했다. 이번 전수 실화면 결과는 부모의 별도 실행 보고를 따르며 문서 갱신으로 통과를 주장하지 않는다. 목적은 광고업체가 확보된 실제 자료에서 지역과 시간을 바꾸며 광고주에게 설명할 근거를 찾는 것이다. 숫자의 장식보다 지도 선택 → 지역 내역 → 추이 → 후보 비교의 후속 행동을 분명히 한다. 아래는 설계 계약이며 현재 구현·실행 검수 상태는 [조회 개선 실행 보고](focused-query-report.md)를 따른다. 생활인구 우선13개 여정의 두 PC 크기 검수는 앞선 버전의 기록이다. 현재 상권 갱신은 소스969bf87·공개 배포d6041 이후 부모가 실화면 검수 중이며, 배포 성공을 전체 기능 통과로 간주하지 않는다. 문서 갱신을 모든 자료·배치 조합의 검수 완료로 간주하지 않는다.

## 작업 방식과 진입

기존 분석용·시연용 모드를 유지한다. 분석용에 **지도 탐색** 작업 방식을 추가한다. 분석용의 기존 대시보드 보기와 지도 탐색을 선택할 수 있고, 자료 종류와 지도/상세 분석/후보 비교의 두 선택 축을 구분한다. 시연은 순서가 없는 집중 보기로 제공한다. 지도 탐색을 닫으면 이전 화면으로 복귀한다. 돌아갈 때 자료·지역·시간·지표·후보 선택을 초기화하지 않는다.

지도 탐색은 별도 전체화면 창이나 팝업이 아니다. 같은 앱 안에서 중앙 지도가 고정된 작업 공간을 사용한다.

## PC 와이어프레임

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│ [메뉴·조건] 지도 탐색 · 현재 자료 제목        [상세 접기] [이전 화면으로]   │
├─────────────────┬───────────────────────────────────────┬───────────────────┤
│ 조회 옵션       │ 현재 적용 조건 · 자료일 · 단위        │ 선택 지역         │
│ [창 설정][접기] │ [조건 칩 → 해당 편집 화면 직접 열기] │ 실제 지표·내역    │
│                 │                                       │                   │
│ 자료·기간  ›    │                지도                   │ [추이 확인]       │
│ 지역·상권  ›    │ 구 배경/구 이름 → 구 필터·경계 맞춤  │ [후보에 추가]     │
│ 분석 대상  ›    │ 상권 도형 → 상권 값·상세 선택        │ 후보 최대 3곳     │
│ └ 현재값 요약   │ [서울 전체 지도] [지도 표시]         │                   │
│                 │                                       │                   │
│ 항목 선택 시    │ 짧은 색상막대·[범례]                 │ 같은 조건 비교    │
│ 해당 편집만 표시│ 색상·범위는 조회 필터와 분리          │                   │
│ [조회 항목으로] │                                       │                   │
└─────────────────┴───────────────────────────────────────┴───────────────────┘
```

상권 조회는 세 상위 항목과 한 하위 편집 화면으로 나눈다. 자료·기간은 자료/분기, 지역·상권은 구/동/이름/유형, 분석 대상은 업종과 한 가지 비교·세부 기준을 편집한다. ‘조회 항목으로’ 돌아가 다른 항목을 자유롭게 선택하며 조건·후보를 보존한다. 현재 조건 칩은 관련 하위 화면을 직접 열고 해당 입력으로 이어진다. 하위 화면 안은 한 열이며 다른 하위 화면의 입력을 함께 펼치지 않는다.

상권 작업공간 기본값은 조건280px·상세320px이고 나머지를 지도에 배분한다. 조건은220–360px, 상세는260–520px 범위에서 경계선 드래그·방향키로 조절하며 중앙 지도 최소 작업 공간을 우선한다. 일반 MapCanvas 분석은 지도/보조75:25 기본,55–85% 비율 조절과 조회 기본280px·조절260–360px를 사용한다. 플로팅 조회는 기본360×560px이며 기간 → 지역 → 분석 대상/기준의 한 열 순서를 유지한다. 이전180–300px·기본220px 및 너비별 자동 다중 열은 과거 셸의 이력이다. 단위가 다르므로 같은 수치 범위로 혼동하지 않는다. 좌우 패널은 각각 스크롤한다. 접은 패널의 공간은 지도에 돌려준다.

일반 지도와 상권 작업공간은 고정 패널을 제외한 지도 공간이540px 미만이면 조건을 플로팅으로 전환한다. 사용자가 ‘띄우기’를 직접 고를 수도 있다. 플로팅은 제목 드래그·방향키로 이동, 모서리 드래그·방향키로 가로·세로 크기를 조절한다. 지도 작업 영역 밖으로도 옮길 수 있도록 화면 안에만 제한하고 위치·크기 초기화와 전체 배치 초기화를 제공한다. 이동·접기·초기화는 조건·후보·원값을 바꾸지 않는다.

조회 옵션·선택 정보·순위는 제목 드래그로 떼어내고 좌우 가장자리56px에서 고정 위치를 예고한다. 놓을 때 고정하고 취소 이벤트는 확정하지 않는다. 명시적 좌측/우측/띄우기 버튼과 고정 폭/플로팅 가로세로 조절도 제공한다. 같은 쪽 창의 중첩과 지도 최소공간을 검사하고, 공간이 부족하면 플로팅으로 유지한다. 플로팅 배경만50–100%(기본100%)로 조절하며 도킹은100%·분리 시 이전값 복원으로 처리한다. 글자·버튼의 불투명도는 낮추지 않는다. 범례·정의 툴팁은 자석 배치 대상이 아니다.

IBM Plex Sans KR을 공통으로 사용한다. 글자 크기는 [정본 R07](DASHBOARD_DEVELOPMENT_RULES.md)의 분석12/14/16/20/28/36, 시연14/18/24/36으로 제한한다. 기본 파랑과 청록·자주 팔레트 선택은 지도와 범례에 함께 반영한다. 규모는 순차색, 증감은0 중심 대조색과 부호로 읽으며 설명을 특정 선택색에 고정하지 않는다. 색만으로 선택 상태를 표현하지 않고 테두리·지역명·단위도 남긴다.

긴 금액은 조/억/만 단위의 읽기 쉬운 주정보로 표시하며 원단위 정확값은 펼친 상세·툴팁·표·CSV에 남긴다. 두 시점 비교는 제목·조건을 전체행, 기준/선택/차이를 동일 너비3칸으로 분리한다. 긴 상권명은 정해진 폭 안에서 문장 단위로 줄바꿈하고 숫자가 이름 영역을 밀어내지 않게 한다. 의도한 정확값 표의 가로 스크롤과 페이지 전체의 넘침을 구분한다.

지도 범례는 일반·두 시점·증감·상권 모두 짧은 색상 막대와 ‘범례’ 버튼으로 시작한다. 구간·정확값·단위·결측·범위 밖 포화 의미는 마우스 오버/클릭/키보드로 여는 가벼운 툴팁에서 읽는다. 이전 상권 이동형 범례를 계속 유지하지 않으며, 조회 옵션의 이동/크기 조절과 범례 읽기를 분리한다. 의미 설명 DataMeaning 팝오버와 같은 읽기·Esc·포커스 규칙을 따르고, 다른 툴팁과 겹치지 않는다.

색상 범위 설정은 원자료 단위의 최솟값·최댓값 입력, 폭−20%/+20%, 초기화를 접힌 설정 안에 둔다. 두 시점은 같은 범위, 증감·순이동은0 중심 대칭으로 적용한다. 직접 범위는 시간 변경에서 유지하되 적용 상태를 알리고, 범위 밖 하한/상한 개수는 관측값 수로 표시한다. 값은 끝 색에 포화해도 실제 통계·순위·후보·CSV는 변하지 않는다. 상권의 직접 범위는 같은 값 간격으로 표시하고 자동 분위 분류와 구분한다. 입력·계산·포화 수용 기준은 [독립 색상 범위 기준](map-range-acceptance.md)을 따른다.

시계열 ‘축 설정’은 기본 접힘으로 제공하며 지수는100 중심·최대편차에20% 여유를 기본으로10/20/30%를 고른다. 최소 반경±1포인트, 실제값/증감의 기존 축 선택은 유지한다. 표시·축·속도·계산 설명은 독립 그래프 옵션에서 조절하고, 현재 기준·축 주의는 그래프에 남긴다.

## 버튼 목적과 후속 행동 계약

| 조작 | 목적 | 결과와 다음 행동 |
|---|---|---|
| 메뉴/조건 | 지도 공간과 조건 편집을 오가기 | 조건 패널만 접는다. 조건 값은 보존한다. 다시 열면 같은 값이다. |
| 자료 선택 | 서로 다른 통계의 의미를 분리 | 해당 자료에 지원되는 기간·단위·옵션을 표시하고 지도·상세·범례를 함께 갱신한다. 지원하지 않는 조건을 조용히 적용하지 않는다. |
| 구/동 단위 | 공간 해상도 변경 | 실제 경계가 있을 때만 동 지도로 전환한다. 생활이동은 구 단위만 지원한다고 안내한다. |
| 일반 지도 지역 선택 | 분석 대상을 지정 | 선택 지역을 강조하고 우측 지표·내역을 갱신한다. 처음 구를 고르면 제공되는 동 내역을 보여준다. 지역 옵션·작은 핵심 지표·추세를 동기화하되 현재 지도 단위·카메라를 유지한다. 명시적 상세에서만 동 지도 또는 연령별 구성 분석으로 진입한다. |
| 상권 지도 구 배경·구 이름 | 해당 구의 상권을 탐색 | 클릭/키보드 실행으로 구 필터를 적용하고 동·현재 상권 선택을 해제해 해당 구 경계에 맞춘다. 기간·검색/유형·분석 기준·후보는 유지한다. |
| 서울 전체 지도 | 구 탐색에서 전체 범위로 복귀 | 구/동 제한·현재 상권 선택을 해제하고 서울 경계에 맞춘다. 검색/유형이 남아 있으면 전체 서울 중 해당 조건의 결과이며 후보는 보존한다. |
| 상권 도형 선택 | 개별 상권의 근거 확인 | 선택 상권 값·상세·추이를 연결한다. 구 배경 탐색과 달리 카메라를 자동으로 맞추지 않는다. |
| 시간·기간·지표 선택 | 같은 공간에서 조건을 바꾸기 | 원본 파일을 읽은 뒤 같은 적용 조건을 지도·우측 상세·범례에 표시한다. 출발/도착 기준, 시간대/누적/원본 일계의 차이를 분리한다. |
| 시간 이전/다음/재생 | 시간에 따른 변화를 관찰 | 중앙 지도와 선택 지역 값을 같은 시점으로 바꾼다. 작업 공간을 벗어나면 재생을 멈춘다. |
| 지역 상세 단일 토글 | 지도를 넓게 보거나 선택 근거를 읽기 | 우측 패널만 접는다. 중복 접기 버튼은 두지 않는다. 선택 지역·후보는 보존한다. 새 상권 선택 시 상세를 다시 열고 내용 처음으로 이동한다. |
| 경계선 조절·띄우기·이동·크기 조절·초기화 | 지도와 옵션의 작업 공간을 조절 | 포인터·방향키 모두 제공한다. 지도 밖 화면 전역 이동을 허용하되 화면 안으로 제한하고 현재 조건·결과를 보존한다. |
| 범례 | 지도 공간을 유지하며 정확한 색상 경계 해석 | 모든 지도는 작은 버튼·색상 막대에서 툴팁으로 읽는다. 오버/클릭/초점·내부 읽기·Esc·외부 클릭과 현재 조건 동기화를 검사한다. |
| 색상 범위 | 작은 시점 차이를 공통 기준으로 강조 | 원단위min/max·폭±20%·자동 초기화. 두 시점 공통/증감0대칭·포화 개수·오류 복구·원값 불변을 함께 확인한다. |
| 추이 확인 | 선택 지역의 변화 근거 찾기 | 같은 자료·지역·조건으로 추이를 보여준다. 추이에서 지도 복귀와 후보 비교가 가능해야 한다. |
| 후보에 추가/해제 | 광고주 브리핑 후보 구성 | 실제 연결된 지역만 최대 3곳 담는다. 선택 여부와 제한 이유를 표시한다. |
| 후보 비교 | 공통 기준으로 판단 | 단위·기간·대상·집계 방식을 함께 보여준다. 다른 조건으로 저장한 후보는 조건 차이를 명시한다. |
| 저장/표 내려받기 | 근거를 보존 | 실제 값·자료일·시간 기준·조건·출처를 함께 보존한다. 현재 내역과 다른 범위를 저장한다면 버튼에 범위를 명시한다. |
| 이전 화면으로 | 기존 분석/시연 흐름 복귀 | 작업 공간을 닫고 이전 보기를 연다. 현재 분석 상태는 상위 컴포넌트가 보존한다. |

## 빈 상태와 오류

- 지역 미선택: 지도는 전체 범위, 상세는 ‘지역을 선택하면 근거를 확인할 수 있습니다’와 구 선택 안내를 제공한다.
- 경계는 있지만 통계 키가 없음: 회색과 ‘현재 통계 연결 없음’을 표시하고 상세·후보 추가를 막는다. 닫기·전체 복귀는 유지한다.
- 실제 키가 있지만 비공개·결측: 자료 없음으로 표시한다. 0으로 바꾸지 않고, 실제 지역의 다른 시점 탐색은 허용한다.
- 로딩·실패: 이전 값을 새 조건의 값처럼 보여주지 않는다. 로딩 상태·같은 조건 재시도·내려받기 비활성화를 제공한다.
- 지원 범위 밖: ‘해당 연도의 동 자료 없음’ 등 구체적인 이유를 표시하고 공식 구 합계 또는 지원 기간 선택으로 이어간다.
- 상대지역 없음: 선택 조건의 기록 없음과 집계 기준을 표시한다. 상대지역을 임의 생성하지 않는다.
- 후보 없음: ‘지역 선택 → 후보에 추가’ 행동으로 되돌아갈 수 있게 한다.

## 범용 셸과 데이터 컴포넌트의 경계

이번 `MapWorkspace`는 배치와 패널 열기/닫기만 담당한다. 기간·지역·후보·지도 선택·집계·재생 상태는 상위 `MarketExplorer`가 소유한다.

```tsx
<MapWorkspace
  title="지도 탐색"
  controls={<자료와지역시간지표옵션 />}
  details={<선택지역상세와후보비교 />}
  onClose={이전화면복귀}
>
  <div className="mapWorkspaceMap">{실제지도}</div>
  <div className="mapWorkspaceTimeline">{시간선택과재생}</div>
</MapWorkspace>
```

Props는 `children`, `controls`, `details`, `title`, `onClose`, 선택적인 `revealDetails`다. `revealDetails` 변경은 새 선택 지역의 상세를 다시 여는 신호이며 조회 자료를 변경하는 별도 상태가 아니다. 가운데 `children`은 부모가 지도와 그 지도에 필요한 탐색·표시 도구를 배치하는 자리다. 생활인구의 긴 하단 시간 행을 기본으로 넣지 않는다. 셸 자체는 작동하지 않는 가짜 시간 버튼이나 예시 수치를 만들지 않는다. 좌우 패널을 접어도 React 노드를 제거하지 않아 입력 상태를 보존한다.

## 통합 검증 기준

1. 자료·지역·기간·지표를 각각 바꿀 때 지도·현재 조건·우측 상세가 같은 값을 표시한다.
2. 구 선택→동 선택→재선택→추이→후보 비교→지도 복귀가 막히지 않는다.
3. 도착/출발 및 시간대/누적/일계 조건이 저장·복원·CSV에서 일치한다.
4. 메뉴·상세를 접고 다시 열어도 조건이 유지되고, 실제 지도 크기만 조정된다.
5. 시연용의 세 보기와 기존 분석용 동작이 같은 자료·조건에서 유지된다. 지도 탐색 진입·복귀 때 데이터가 임의로 초기화되지 않는다.
6. 지도 키보드 조작, 포커스 표시, 버튼의 펼침 상태, 비공개·미연결 지역 차단을 확인한다.
7. 좌우 자석 예고·놓기·취소·충돌·지도540px 보장, 도킹100%/분리 시 배경 설정 복원, 지도/보조 경계 조절, 고정/플로팅 전환, 가로·세로 크기 조절, 화면 전역 이동·화면 경계 제한, 초기화와 재열기를 일반 지도와 상권 작업공간 모두에서 확인한다.
8. 실제 최대 매출·긴 상권명·음수·0·결측으로 지도·팝업·추이·후보·저장 비교를 열고 수치·제목·단위 잘림을 확인한다. 원값과 축약 표시를 독립 대조한다.
9. 일반·두 시점·증감·상권의 작은 범례 버튼/툴팁과 색상min/max·±20%·초기화를 실제 화면에서 검사한다. 직접 범위는 같은 눈금으로 유지되고 포화 개수·원값·단위가 맞아야 한다. 상세 단일 토글, 왼쪽 네 그룹, 축 설정 접힘/기준100 여유도 변경 영향에 따라 검사한다.

조회 조건 칩·관련 검색·단일 상세 편집과 현재 변경 범위는 [조회 옵션 현행 설계](tableau-query-options-plan.md)를 따른다. 자석 배치가 자료 필터나 지도 카메라를 뜻하지 않으며, 현재 실행 통과는 [독립 수용 기준](tableau-query-acceptance.md)의 실제 결과와 별도로 확인한다.

생활인구는 기간 → 지역 → 분석 대상의 한 열에서 날짜·시각·구·동·연령·성별을 고른다. 기준일 달력은 제공 기간 전체를 다루므로 별도 월 선택을 반복하지 않는다. 시간 슬라이더·이전/다음 시간은 기간 묶음 안의 접힌 ‘시간 빠르게 이동’에 둔다. 정확 시각 선택과 현재 조건 칩을 유지하고 지도 아래 전체폭 시간 옵션 행을 제거한다. 상권의 분기·시간 구간은 해당 자료의 조회 기준을 따르며 생활인구의 시간별 이동과 혼동하지 않는다.
