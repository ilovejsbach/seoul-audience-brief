# 색상표 선택과 공통 페이지 폭

2026-11-15 · R04/R05/R07/R10/R11/R20.

## 사용자 확인과 변경
메뉴 위치를 바꾸는 요청이 아니라 최상단과 본문·그래프의 바깥 폭을 맞추는 요청으로 확인했다. 공통 페이지 여백을 하나로 사용하고, 본문에만 있던 좁은 최대 폭과 시연 그래프의 별도 여백을 통일했다. 메뉴·현재 화면 제목·그래프 제목의 위치는 유지한다.

‘기본 범례와 선택 범례’는 수치의 자동/수동 범위를 비교하는 뜻이 아니라 그라데이션 색상표를 선택하는 뜻으로 확인했다. 기본 파랑/청록/자주 선택기를 기존 색상·표시 설정에 넣었다. 일반 지도, 상권 지도, 두 시점 나란히·증감 지도가 같은 선택을 공유하며 브라우저에 기억한다. 기본값은 파랑이고 기존 파랑의 연속색·5구간·증감색을 보존했다.

옵션과 범례 툴팁에서 기본/선택 그라데이션을 작은 막대로 비교한다. 바깥 범례의 크기를 늘리지 않는다. 팔레트 변경은 원값·분류 경계·최솟값/최댓값·후보를 변경하지 않는다. 양수 규모는 밝음→짙음, 증감은0중심 중립색과 양·음의 서로 다른 색 계열을 사용한다. 안내도 선택된 색 이름에 맞게 갱신한다.

선택 위치: 일반 지도 ‘색상·표시 설정’, 상권 ‘보기 설정’, 분포 비교 ‘색상·표시 설정’ 안의 ‘지도 색상 팔레트’. 큰 조회 조건 제목을 다시 만들지 않았다.

## 현재 실제 실행
- 팔레트 5개 여정: 일반 지도의 세 색상 선택·기본색 정확 복귀·값과 범위 불변·범례 미리보기, 전체화면 변경과 복귀, 상권과 공유, 두 지도 공통 범위, 세 색상의 0 중립색·대칭, 화면·모드 변경 후 유지를 확인했다.
- 폭 정렬은 1800 화면의 상권·분석·시연 3개와 1366×768의 같은 3개를 검사했다. 상단 내용 시작선과 본문·주패널의 좌우 차이는 2px 이내였다. 1800에서는 공통 여백이 75.6px이며 상권 주영역은 기존 중앙 1376px 대신 1648.81px를 사용한다. 세로 스크롤바가 생기면 그 너비를 제외한 같은 기준을 쓴다.
- 1366×768의 네 자료 그래프도 패널 566px·실제 플롯 345.41px 높이로 화면 안에 들어갔고 가로 넘침이 없었다.
- 시연 보조 화면 11개와 상권 7개 회귀까지 합해 현재 33개 여정을 통과했다. 색상 4개를 포함한 계산 25개, 타입·프로덕션 빌드도 통과했다.

[실행 결과](../tests/palette-and-alignment-results.json). 모든 과거 E2E·모든 지역과 기간을 다시 실행한 것은 아니다. 전체화면은 자동화 환경의 앱 대체 경로이며 네이티브 전체화면을 전수 검사했다고 주장하지 않는다.
