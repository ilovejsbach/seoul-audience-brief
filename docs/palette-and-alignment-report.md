# 색상표 선택과 공통 페이지 폭

2026-11-15 · R04/R05/R07/R10/R11/R20.

## 사용자 확인과 변경
메뉴 위치를 바꾸는 요청이 아니라 최상단과 본문·그래프의 바깥 폭을 맞추는 요청으로 확인했다. 공통 페이지 여백을 하나로 사용하고, 본문에만 있던 좁은 최대 폭과 시연 그래프의 별도 여백을 통일했다. 메뉴·현재 화면 제목·그래프 제목의 위치는 유지한다.

‘기본 범례와 선택 범례’는 수치의 자동/수동 범위를 비교하는 뜻이 아니라 그라데이션 색상표를 선택하는 뜻으로 확인했다. 기본 파랑/청록/자주 선택기를 기존 색상·표시 설정에 넣었다. 일반 지도, 상권 지도, 두 시점 나란히·증감 지도가 같은 선택을 공유하며 브라우저에 기억한다. 기본값은 파랑이고 기존 파랑의 연속색·5구간·증감색을 보존했다.

옵션과 범례 툴팁에서 기본/선택 그라데이션을 작은 막대로 비교한다. 바깥 범례의 크기를 늘리지 않는다. 팔레트 변경은 원값·분류 경계·최솟값/최댓값·후보를 변경하지 않는다. 양수 규모는 밝음→짙음, 증감은0중심 중립색과 양·음의 서로 다른 색 계열을 사용한다. 안내도 선택된 색 이름에 맞게 갱신한다.

선택 위치: 일반 지도 ‘색상·표시 설정’, 상권 ‘보기 설정’, 분포 비교 ‘색상·표시 설정’ 안의 ‘지도 색상 팔레트’. 큰 조회 조건 제목을 다시 만들지 않았다.

## 현재 실제 실행
- 팔레트5개 여정: 일반 지도의3색 선택/기본색 정확복귀/값·범위 불변/범례 미리보기; 전체화면 진입·변경·복귀; 상권과공유/도메인보존; 두지도공통범위/3색모두0중립/대칭; 화면·모드변경후유지.
- 폭 정렬은1800화면의상권/분석/시연3개와1366×768의같은3개를 검사했다. 상단 내용 시작과본문/주패널의좌우차이는2px이내였다.1800에서는공통여백75.6px이며기존중앙1376px대신상권주영역1648.81px를사용한다. 세로스크롤바가생기는분석화면은그너비를제외한동일기준을사용한다.
- 1366×768의4자료그래프도566px패널/345.41px실제플롯높이로화면안에들어갔고가로넘침은없었다.
- 시연보조화면11개와상권7개회귀까지합해현재33개여정을통과했다.색상4개를포함한계산25개,타입·프로덕션빌드도통과했다.

[실행 결과](../tests/palette-and-alignment-results.json). 모든과거E2E·모든지역/기간을재실행한것은아니다.전체화면은자동화환경의앱대체경로이며네이티브전체화면을전수검사했다고주장하지않는다.
