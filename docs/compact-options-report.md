# 조회·보기 옵션 전수 점검과 개선

2026-11-15. R05·R06·R07·R10·R11·R20. 독립 Codex 에이전트 두 명이 원인과 옵션 계열을 조사하고, 구현 담당이 실제 Chrome에서 확인했다.

## 발견과 수정
1. 생활인구의 묶음이 기본 flex-end 정렬을 물려받아 오른쪽의 좁은 열로 축소됐다. 공통 조회창의 정렬을 stretch로 고쳤다. 고정형 조회창에도 적용한다.
2. 이동·전출입·매출·상권은 창을 넓혀도 한 열만 유지했다. **창 자체 너비** 520px 미만 1열, 520–799px 2열, 800px 이상 3열로 재배치한다. 자료·지역·분석 대상의 의미 묶음은 보존하며 고급 옵션을 임의로 펼치지 않는다.
3. 제목과 작업 버튼을 각각 전체 행으로 강제하던 규칙을 바꿨다. 좁으면 자연스럽게 줄바꿈하고 넓으면 한 줄로 배치한다. 이동·크기 안내는 제목의 도움말로 옮겨 상시 안내 행을 없앴다.
4. 시연 모드에 기준일·연령·성별이 두 번 나오는 중복을 정리했다. 전체화면 지도의 독립 조건 및 전출입에만 있는 성별·연령 상세는 유지한다.
5. 시연 영역 내부 스크롤 때 창 제목이 잘리는 현상을 재현했다. 창 좌표 제한이 브라우저뿐 아니라 스크롤·잘림 부모의 가시 영역도 고려하도록 공통 이동/크기 조절을 고쳤다.
6. 화면 배치 팝업은 남은 화면 높이 안에서 내부 스크롤한다. 초기화 버튼까지 접근할 수 있다. 좁은 상권 추세의 표시 버튼과 요일 비교 버튼은 묶음 내부에서도 줄바꿈한다.

## 옵션 계열별 판정

| 계열 | 실제 확인 | 적용 판단 |
|---|---|---|
| 생활인구 기본 조회 | 300/560/900px·낮은 창·재열기 | 우측 쏠림 및 재배치 수정 |
| 유입·유출 기본 조회 | 같은 크기 행렬·지역 연결 | 1/2/3열 수정, 시간 기준 의미 유지 |
| 전입·전출 기본 조회 | 같은 크기 행렬 | 1/2/3열 수정 |
| 구·동 매출 기본 조회 | 같은 크기 행렬 | 1/2/3열 수정 |
| 지도 구·동·확대 | 창 조작·전체화면·후속 경로 | 넓은 창에서 버튼과 확대 도구를 병렬 배치 |
| 지도 색상 범위 | 공통 범위·증감·전체화면·상권 4경로 | 접힘 유지, 수치와 버튼 묶음 보존 |
| 전출입 인구 집단 | 성별→여성·순이동→연령 실제 전환 | 넓은 창에서 필터 병렬화, 지원 단위 제한 유지 |
| 상권 자료·기간 | 크기 행렬 및 실제 자료 선택 | 묶음을 열로 재배치 |
| 상권 검색·유형 | 검색·필터·없음·초기화 | 의미 단위 유지, 그룹 재배치 |
| 상권 세부·보기 | 세부 자료·색상·분기·후보·복귀 | 접힘 유지, 그룹 재배치 |
| 두 시점 지도 | 나란히/증감·시간·범위 | 기존 공통 눈금과 줄바꿈 유지 |
| 추세·축·재생 | 축 범위·초기화·기준100·시점 후속동작 | 좁은 표시 버튼 그룹 줄바꿈 보완 |
| 두 시점 숫자·대상 A/B | 긴 숫자 회귀 및 연령/성별 실제 선택 | 비교 카드 유지, 조회창에 통합하지 않음 |
| 요일·월 구간 | 5개 실제 평균·시간·축·결측 경로 | 내부 버튼 줄바꿈 보완, 조건 단위 유지 |
| 화면 배치 | 1366×650/500에서 실제 팝업·초기화 | 최대 높이 및 내부 스크롤 수정 |

## 실행 증거와 한계
- 기본 Chrome 1800×961에서 다섯 조회창을 각각 300/560/900px로 검사했다. 가로 넘침 0px, 넓은 창 제목 46px(좁은 창 81px), 높이 300px일 때 본문 252px였다. 상권·기존 지도 창의 이동·가로세로 조절·초기화도 통과했다.
- 시연용 너비 900px에서 제목 51px, 3열, 중복 없는 기본 조건 5개와 보기 옵션 1개를 확인했다. 제목·닫기는 시연 스크롤 영역 안에 있었다.
- 화면 배치 팝업은 높이 500px 화면에서 하단 488px, 내부 스크롤로 초기화에 접근했다.
- 추가 영향 회귀 23경로: 핵심 분석 5, 상권 7, 기간 특성 5, 색상 범위 4, 영역 조절 2. 실제 원값 대조를 포함한다. 대상 A/B와 전출입 세분 전환도 수동 확인했다.
- [실행 JSON](../tests/compact-options-results.json), [크기 행렬 테스트](../tests/compact-options-e2e.mjs), [독립 소스 전수 감사](option-layout-source-audit.md).
- 전수 범위는 화면에 존재하는 옵션 **계열**이다. 모든 날짜·지역·업종 조합을 전부 검사했다는 뜻은 아니다. 자료표·히트맵의 의도적 가로 스크롤과 옵션창 넘침은 구분했다. 범례·출처 툴팁은 기존 의도를 유지한다.
