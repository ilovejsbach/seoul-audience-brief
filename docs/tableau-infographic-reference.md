# Tableau 인포그래픽 참조 검토

검토일: 2026-11-15. 범위: 일반 구·동 지도, 두 시점 비교 지도, 상권 지도, 상세 추이 그래프. 적용 규칙: R01, R06, R11, R13, R14, R17, R19, R20.

이 문서는 공식 문서와 현재 소스의 독립 검토다. 현재 브라우저 실행·원자료 수치 대조·공개 화면 검증은 수행하지 않았다. 제안은 구현 완료를 뜻하지 않는다. Tableau 제품으로 이전하거나 기능 전체를 복제하는 제안이 아니다.

## 참조 원칙과 현재 상태

- Tableau의 강조는 관심 표식을 두드러지게 하고 나머지를 흐리게 한다. 범례도 강조의 입력으로 사용할 수 있다. 필터 동작은 선택한 필드 값을 대상 화면의 조회 필터로 전달한다. 두 동작은 수치와 모집단에 미치는 영향이 다르다. [강조 동작](https://help.tableau.com/current/pro/desktop/en-us/actions_highlight.htm), [필터 동작](https://help.tableau.com/current/pro/desktop/en-us/actions_filter.htm)
- Tableau의 툴팁 속 시각화는 가리킨 표식에 해당하는 별도 시각화를 보여주어 본문의 공간을 보존한다. 이 제품에서는 가리키기는 설명, 클릭은 명시적인 상세 행동으로 나누는 것이 적절하다. [툴팁 속 시각화](https://help.tableau.com/current/pro/desktop/en-us/viz_in_tooltip.htm)
- Tableau의 기준선은 상수 또는 계산값을 연속축에 표시한다. 조건부 영역은 선택 등 상태에 따라 심화 정보를 드러낸다. 본 제품에서는 기준 100·증감 0의 의미를 그래프 가까이에 유지하고, 부가 분석은 요청했을 때 여는 방향으로 적용한다. [기준선](https://help.tableau.com/current/pro/desktop/en-us/reference_lines.htm), [조건부 영역 표시](https://help.tableau.com/current/pro/desktop/en-us/dynamic_zone_visibility.htm)

소스에는 이미 공통 3종 팔레트, 작은 범례 버튼·툴팁, 직접 색상 범위, 음수와 0 중심 설명, 자료 없음 구분, 두 지도 공통 눈금, 추이 그래프의 기준 100·기준선·축 조정이 있다. 따라서 큰 범례나 새 설정 패널을 추가하는 것은 우선순위가 아니다.

## 즉시 확인·보완할 세 가지

### 1. 범례를 현재 결과의 설명서로 일치시킨다

목적은 ‘지금 이 색이 어떤 수치를 뜻하는지’ 판단하는 것이다. 팔레트 선택, 범위, 지표, 시점, 대상이 바뀔 때 범례의 숫자·단위·부호·설명을 함께 갱신한다. 이미 있는 범례 계산을 재사용하며 별도 설명 상태를 만들지 않는다.

| 화면 | 반드시 맞아야 하는 설명 |
|---|---|
| 구·동 지도 | 현재 지표·단위, 관측 범위와 적용 색상 범위, 선택 팔레트, 범위 밖 포화, 자료 없음 |
| 두 시점 지도 | 두 지도 공통 범위와 같은 색의 동일 의미. 증감 지도는 비교−기준, 0 중심, 음·양 색상 방향 |
| 상권 지도 | 현재 필터·단위, 분위/등간격 구분과 실제 경계, 수동 범위, 자료 없음 |
| 추이 그래프 | 실제값/차이/기준 100, 기준 시점, 적용 세로축, 축 밖 값의 존재 |

수용 사례: 전입→전출→순이동을 바꾸면 순이동에서만 부호와 0 중심 설명이 나타난다. 성별·연령·업종을 바꾸면 원래 집단의 경계나 단위가 남지 않는다. 팔레트만 바꾼 뒤 원값·순위·조건·내려받기 값은 그대로다. 수동 범위 밖 값은 극단 색으로 보이고 포화 개수가 설명된다. 일반·전체화면·시연에서 같은 상태의 범례가 같다.

### 2. ‘선택’, ‘강조’, ‘조회’를 혼동하지 않게 한다

현재 범례 항목은 읽기용이다. 범례 클릭으로 조회가 바뀌는 것처럼 꾸미지 않는다. 관심 구간 찾기가 실제로 필요해지면 ‘구간 강조’라는 별도 행동을 제공할 수 있다. 이때 다른 지역을 흐리게 보여도 합계·순위·원자료·조회 조건은 바뀌지 않아야 한다. 실제 모집단을 줄이는 기능은 ‘이 구간만 조회’로 구분하고 독립적으로 설계한다.

당장 중요한 것은 지도 클릭 후 선택 지역의 상세와 비교 행동이 같은 조건으로 이어지는 것이다. 조건 요약에는 조회 범위와 선택 지역을 따로 표시한다. 선택 해제는 선택만 지우고 검색·기간·대상은 보존한다.

수용 사례: 서울 전체 조회에서 서초구를 누르면 ‘조회: 서울 전체 / 선택: 서초구’로 구분된다. 서초구 상세는 같은 연도·연령·방향을 사용한다. 선택 해제 후 지도 전체 수치와 순위는 클릭 전과 같다. 필터를 바꾸어 선택 지역이 결과에서 빠지면 이전 상세 수치를 새 결과처럼 남기지 않는다.

### 3. 설명과 상세는 문맥을 유지하며 필요할 때 연다

지도 툴팁은 지역·적용 시점/집단·값·단위와 다음 행동을 보여준다. 증감은 기준값→비교값, 증감 방향을 함께 설명한다. 긴 출처·추정 방법은 공통 설명으로 묶는다. 상세 화면에 들어가도 선택 조건을 유지하고 돌아올 대상을 알 수 있어야 한다.

그래프의 기준 100·차이 0과 선택 기준 시점은 항상 짧게 보인다. 자세한 해석은 설명 툴팁으로 제공한다. 부가적인 두 시점 비교·집단 구성은 화면 전환이나 선택적 패널로 열며 본문 아래에 모두 펼치지 않는다.

수용 사례: 두 시점 지도에서 같은 동을 가리키면 두 원값과 차이가 모두 맞는다. 한쪽이 결측이면 차이를 0으로 만들지 않는다. 그래프 기준 시점을 바꾸면 지수·기준선 설명·선택값이 함께 바뀐다. 상세→지도 복귀 시 지역·기간·대상과 사용자가 정한 색상 범위가 유지된다. 툴팁은 마우스뿐 아니라 키보드로 읽고 닫을 수 있다.

## 뒤로 미룰 항목

- 툴팁 안의 작은 추이 그래프: 충분한 실제 시계열과 명확한 질문이 있는 지표부터 검토한다. 현재 조건 연동과 상세 진입을 먼저 검증한다.
- 범례 구간 강조: 현재 읽기용 범례를 유지한다. 도입 시 강조가 필터가 아니라는 표시와 해제 경로를 함께 설계한다.
- 평균·목표선·참조 구간: 비교 모집단·가중 방식·목표의 근거가 없으면 추가하지 않는다. 현재 기준 100·증감 0과 중복되는 장식선을 늘리지 않는다.

## 검증 인계

R20에 따라 위 수용 사례를 실제 화면과 독립 원자료로 별도 검증해야 한다. 이 문서의 확인 근거는 소스 구조이며 E2E 통과 보고가 아니다. 현재 편집 중인 조회 조건 요약·선택 상태 변경은 구현 담당자가 최신 결과에 대조한다.
