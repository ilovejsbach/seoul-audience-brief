# 광고주 판단 목적에 따른 화면별 UX 조사

조사일: 2026-11-14. 공개 버전 85860c3 기준 Chrome 1800×905에서 실제 조작·스크린샷·화면 문구를 확인했다. 22개 화면/상태를 기록하고 기존 기능 E2E 13개를 실행했다. 작은 화면·모든 업종·모든 연도 조합·스크린리더 사용자 실험은 범위에 포함하지 않았다. 기능 통과와 사용성 적합은 별도로 판정한다. 새 타깃 비교·전입전출 세분 자료는 이번 조사 중 추가 구현 중이며, 아래 기초 평가는 추가 전 버전이다.

## 판단의 출발점

이용자는 데이터를 구경하려는 사람이 아니라 광고주에게 입지·대상·시간의 근거를 설명하는 광고업체 담당자다. 핵심 여정은 **목적 선택 → 같은 조건의 지역 후보 발견 → 대상·시간 비교 → 차이 해석 → 후보 유지 → 근거를 담아 브리핑**이다. 데이터가 많거나 버튼이 작동하는 것만으로 이 여정이 성립하지 않는다.

사용자가 별도로 요청한 생활인구 두 타깃 비교, 전입전출 세분 자료·지도 옵션·구성 그래프, 체류/거주 기반 구분은 이번 조사와 함께 구현·검증한다. 후보 보존·첫 화면 개편·상권 추이 재배치 등 나머지는 위 수용 기준에 따라 별도 작업 항목으로 남긴다.
