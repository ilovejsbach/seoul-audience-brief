# 지도 선택과 핵심 지표 연결

2026-11-15 · R01/R02/R05/R06/R18/R20. 구현 담당 소스·자료 확인 기록이며 브라우저 실행은 부모 검수 기록을 따른다.

## 효용과 결정
전입·전출·순이동의 세 수치는 선택 지역에서 유입과 이탈이 동시에 얼마나 발생하는지 판단하는 자료다. 단일 순이동만으로는 큰 전입과 전출이 상쇄된 지역을 읽을 수 없으므로 유지한다. 다만 팝업에만 숨기지 않고, 지도 바로 다음에 작은 선택 지역 요약으로 놓는다. 현재 지도 지표를 첫 숫자로 보여주고 나머지 두 관련 값을 함께 제공한다. 생활인구의 현재 규모·최대 시간·직전 변화와 매출의 현재/직전/증감도 같은 요약 규칙을 따른다.

## 원인과 동작
기존 main/ExtraDashboard의 지도 `onPreview`는 팝업만 열었으며 집계의 district/dong은 그대로였다. 따라서 서초구를 눌러도 숫자는 서울 합계였다.

이제 클릭/키보드 선택은 지역 상태를 즉시 바꾸며 왼쪽 자치구/동, 숫자, 추세, 저장·CSV가 동일한 상태를 사용한다. 마우스 올리기는 미리보기만 한다. 구 지도에서 구를 클릭해도 지도 단위와 카메라는 유지하고, 상세 분석·선택 구 동 지도에서만 동 지도로 확대한다. 동 클릭도 현재 지도를 유지한다. 닫기와 후보 담기는 선택 범위를 원복하지 않는다.

큰 숫자 세 칸은 작은 공통 요약으로 줄이고, 그 위에 선택 지역·기간·연령/성별·지표/시간 기준을 명시했다. 현재 적용 조건에도 지역 이름을 추가했다. 연령별 전출입은 동 자료가 없으므로 상세 분석에서 선택 구의 연령·성별 구성으로 실제 이동한다. 순이동이 양수일 때는 첫 요약 값에도 + 부호를 표시한다. 팝업의 '지역 미리보기'는 '선택 지역 정보'로 바꾸고 출처·심화·후보 경로를 유지했다.

## 연령별 심화와 지도 단위의 분리
연령별 심화는 구성 분석 진입이며 동 지도 확대가 아니다. 팝업에 `districtDrilldown` 목적을 명시해 연령별·생활이동 상세는 동 확대 이벤트를 보내지 않는다. 따라서 연령별 상세를 연 뒤 성별 보기로 전환해도 구 지도를 유지하고, 성별 상세의 명시적 확대에서만 동 지도로 들어간다.

연령별처럼 구 단위로 제한된 필터를 성별·전체로 바꾸는 경우, 제한 해제 첫 렌더부터 구 지도를 유지하여 잠깐 동 지도로 바뀌거나 카메라가 초기화되지 않게 한다. 단 저장한 조건이 특정 동을 명시적으로 복원하면 해당 동 지도를 우선한다.
