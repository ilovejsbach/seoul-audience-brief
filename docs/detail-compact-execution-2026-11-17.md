# 상세 분석 공간 정리 실행 기록 · 2026-11-17

## 목적과 변경

R02–07/R14–20에 따라 생활인구·생활이동·전입전출 상세에서 그래프를 먼저 읽고 필요한 근거로 이동하도록 정리했다. 분석/시연은 같은 계산·상태·팝업/본문 틀을 쓴다.

- 추이 제목·선택 시점/값·그래프 도구를 한 행 우선으로 통합했다. 공통 상세 콤보와 겹치는 내부 지도 이동·보조 메뉴를 제거했다. 기존 ‘두 시점 분포 지도’는 공통 콤보에 추가해 기능을 보존했다.
- 설명은 가까운 설명 창으로 모으되 지역·기간·대상·단위·비교 기준·0 제외/범위 밖 경고는 남겼다. 표의 조작 설명도 ⓘ로 옮겼다.
- 요일/구성/체류·거주/두 시점/후보/저장 조건 비교의 제목·도구·요약을 압축했다. 서로 다른 시점의 거주/체류 경고, 유효일수·분모·결측과 원값·저장/적용·삭제는 유지했다.
- 공통 상세의 바깥 크기는 유지하고 헤더/본문 여백을 줄였다. 세로축은 렌더된 글자 폭으로 여백을 계산하며, 생활이동 축에서 반복 단위를 생략하되 현재값/축 안내에 단위를 남긴다.

## 발견·수정한 회귀

1. 시연 두 시점 분포지도의 범례/주의 잘림: 지도 최소 높이 대신 남은 grid행을 사용했다. 첫 수정에서 공통 표시 규칙이 grid를 덮어 SVG0이 된 회귀를 실제 화면에서 발견해 우선순위를 정정했다. 최종 팝업 지도 SVG383px, 범례 아래662px·주의 아래723px가 창 아래744px 안에 있다. 본문도 지도285px·주의 아래739px가 창 아래760px 안에 있다.
2. 시연 생활이동 최대Y눈금 잘림: 숫자만 표시하고 실제 글자 폭을 측정했다. 최종 모든 눈금의 왼쪽 경계가 SVG 안45.6px 이상이다.
3. 비교 기준 라벨 줄바꿈: nowrap과 선택기 너비를 지정했다. 최종 분석34px·시연36.875px 한 줄이다.
4. 저장 적용 피드백 대비: 공통 밝은 배경에서 짙은 보조색을 사용했다.

독립 디자이너는 before6장/after40장 및 수정 후 이미지를 따로 읽었다. 수치 기대값은 별도 에이전트가 준비 데이터에서 독립 계산했다. 구현자의 자체 선언만으로 통과하지 않았다. 감사: [독립 검토](detail-compact-audit-2026-11-17.md).

## 이어진 상권 요청

제목을 ‘상권 지도 · 유동인구와 매출’로 바꿨다. 공통 최상단에 지역 정보 열기/닫기1개·창 배치 아이콘·지역 분석 지도 전환을 모았다. 정보창 안의 중복 접기·창 설정을 없애고, 도킹·투명도·초기화는 상단 배치 메뉴에서 제공한다. 일반 화면에도 ‘상권 지도’ 전환을 최상단에 하나만 두며, 상권 복귀는 현재 모드·자료 상태를 유지한 지역 분석 지도로 간다.

상권의 구 경로·단위·집계·상세/도구는 한 행 우선이며, 세부 관측/결측은 지표ⓘ와 상태 접근성 이름에 보존했다. 필터 해제는 지도 도구로 이동했고 무결과 복구는 남겼다. 실제 성북구76곳/자료없음6, 지도 도구 행44.86px·공통헤더52px를 확인했다. 토글·플로팅·배치메뉴Esc·지역 지도 복귀와 비활성 화면의 잔류 창0개를 확인했다. 분기 필드를220px 확보하고 ‘2025년4분기’ 전체 판독을 재확인했다.
