| 항목 | 판정 |
|---|---|
| 상권 매출·인구 | 선택 상권·분기·업종·주변분포의 원자료 열과 지도·상세·추이의 값이 같은가 |
| 세부 기준 | 시간 6·성별 2·연령 6·요일 7 항목을 각각 조회해 올바른 원자료 열을 쓰는가 |

| 서울 밖 | 여러 외부 지역을 한 덩어리로 집계한 값을 단일 자치구처럼 탐색하지 않는가 |
| 생활인구 | 실제 성·연령 교차 열의 합계를 사용하고, 시점 인구 차이를 실제 입장/퇴장 또는 고유 방문자로 바꾸지 않는가 |
| 부분 공개 | 공개 16/24시간에서만 최대를 찾고, 비공개 시간은 null을 유지하는가 |

| 설명 | 의미·해석·주의를 구분하고, 조회 옵션 변경에 따라 설명의 시각·누적·방향·연도·분기가 함께 바뀌는가 |

상권 자료는 성별·연령·시간·요일의 **각각의 주변분포**여서 이를 곱해 여성 20대 금요일 매출을 만들 수 없다. 반면 생활인구 원본에는 성·연령 교차 열이 있어 여성 20–39세 합계를 직접 계산할 수 있다. 두 자료에 같은 제한을 기계적으로 적용하지 않았다.

공덕역의 예시로 2025Q4 한식 17–21시 매출 **4,393,912,588원**, 2026Q2 여성 유동인구 지표 **675,008명(원본 추정치)**를 화면·지도·추이·CSV에서 확인했다. 이 둘의 기간·단위·모집단은 다르므로 나누어 전환율로 계산하지 않는다.

## 발견하여 수정한 문제

1. **범례 경계의 의미 오차:** 실제 등간격 경계 `7,799,541,536.8원`을 설명에서는 `7,799,541,537원`으로 반올림했다. 경계의 원값을 보존하고 정확한 범위 설명을 추가했다. 화면 축약 단위와 실제 분류 경계를 구분한다.
2. **긴 설명창의 Esc 재열림:** 예상 높이로 배치한 설명창이 버튼을 덮어, 닫힌 직후 마우스 진입으로 다시 열릴 수 있었다. 실측 높이로 배치하고 의도적인 재진입과 닫기 직후의 재진입을 구분했다.
3. **설명 내용을 클릭하면 닫힘:** 설명창을 눌러 읽을 때 버튼의 초점이 빠져 창이 닫혔다. 창 내부의 포인터·초점 이동과 외부 이동을 구분했다. 내용 클릭 후 읽기와 Esc 닫기를 재검증했다.

비공개 시간에는 차트의 클릭 가능한 점이 없으므로 검사에서 시간 슬라이더로 조회한다. 옵션 선택기의 `{label:...}` 객체를 문자열로 바꾼 검사 코드도 수정했다. 이 두 건은 제품 결함으로 계산하지 않았다.

## 툴팁 적용 위치

생활인구 요약·공개 시간대 최대·직전 차이, 이동 유입/유출/순이동·상대 지역 비중, 거주지 전입/전출/순이동, 분기 매출·전분기 변화, 상권 인구·매출·주변분포, 지도 색상 구간과 정확한 범례, 두 시점 분포·증감, 세로축·기준 지수·두 시점 차이에 작은 **설명** 버튼을 붙였다. 마우스 오버·포커스·클릭으로 열고 Esc/외부 클릭으로 닫는다. 여러 설명창을 겹쳐 띄우지 않는다.

## 범위와 한계

이 검사는 사전에 명시한 데이터 정의·원자료·허용/금지 해석에 대한 판정이다. 모든 지역×분기×필터 조합의 전수 실행이나 광고 성과의 타당성을 증명한 것은 아니다. 상권의 모든 세부 항목과 62업종은 공덕역을 기준으로 실행했고, 다른 지역·결측·부분 공개·OD 사례를 별도로 포함했다. 준비 자료의 원본 전행 대조와 경계 코드 검증은 별도 보고를 따른다.

실제 화면은 Chrome **1800×905**다. 작은 화면·다른 브라우저의 실측은 완료로 표시하지 않는다. 상권 인구의 일평균 환산식, 통계 시점과 같은 경계 형상, 개인 고유 방문자와 광고 효과는 확인한 범위를 넘겨 단정하지 않는다.
