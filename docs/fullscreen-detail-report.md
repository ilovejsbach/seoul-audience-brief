# 전체화면 상세 분석 전환 수정 (2026-11-14)

원인: 선택 지역·추이 포커스는 바뀌었지만 전체화면 지도가 남아 외부 추이 화면을 가렸다. 시연용은 페이지 변경과 내부 스크롤 이동 순서가 겹쳐 추이 제목이 화면 위로 숨었다.

변경: 구 상세 분석은 전체화면 안에서 동 지도로 진입한다. 동 상세 분석(생활이동은 구)은 전체화면을 해제하고 선택 지역의 추이로 이동한다. 브라우저 전체화면과 대체 오버레이 모두 해제하도록 공통 이동을 정리했다. 시연용은 화면 배치 후 내부 스크롤을 추이 시작에 맞추고 포커스를 준다.

Chrome 실제1800×905에서 신규E2E5개 확인: 생활인구 구→동→서교동 추이, 생활이동 마포구 추이, 전입전출 서교동 추이, 추정매출 서교동 추이, 시연용 전체화면→서교동 시간 흐름 비교. 전체화면 해제·팝업 닫힘·선택 제목·추이 포커스·화면 위치를 확인했다. 서교동 생활인구122,660명 확인. 시연용 추이 상단325.29px와 내부화면 상단325.5px 일치.

기존E2E3개 map-popup-drilldown/fullscreen-dataset/presentation-journey 통과. TypeScript/빌드 및 변경 검사 통과. tests/fullscreen-detail-results.json에 실행 결과 기록. 대체 오버레이 해제 경로는 코드 검토, 브라우저 전체화면 경로는 실제 실행 검증.
