## 정적 검토에서 확인한 압축 후보

1. `TrendExplorer`는 긴 제목의 지역·날짜·대상과 상단 조회를 반복한다. 지역/지표를 짧게 유지하고 날짜·대상은 실제 조회 입력에 맡길 수 있다. 단 모달이 전역 조회를 가리는 경우 비교 문맥을 대체할 짧은 표시가 필요하다.
2. 추이 도구와 현재값, 별도 축 설명행은 플롯 앞에 높이를 누적한다. 동작 도구를 한 묶음으로, 현재값을 결과 근처 한 줄로 압축하는 것이 후보이며 폰트를 임의 축소하는 방식은 피한다.
3. `MigrationDemographics`는 제목·별도 분포 문장·탭·범례·하단 주의와 행마다 적용 버튼이 있다. 탭/범례의 역할은 보존하고 반복 문구·버튼의 화면 점유를 검토한다. 행 선택+단일 적용은 선택 상태가 명확할 때만 대안이다.
4. `ResidentContext`의 요약·제목·주의·지역·카드별 설명은 중복 가능성이 있다. 다만 서로 다른 기준시점과 타깃 무관 전체인구라는 의미는 삭제하면 안 된다. 두 수치를 직접 비교 가능한 동일 분모 그래프로 바꾸는 것도 부적절하다.

상단 전역 조회와 상세의 비교 기준 시점/그룹은 서로 다른 역할이다. 비슷한 선택창이라는 이유로 합치거나 삭제하지 않는다.

## 이번 변경의 수용 기준

- 같은 자료/모드의 상세 전환에서 바깥 틀 크기와 상단 콤보/복귀 위치가 일정하다. 자료 내용 길이 때문에 틀이 늘어나거나 페이지 하단으로 이동하지 않는다.
- 기본 PC1365×768에서 주 그래프·축·시간/연도 라벨·현재값·재생행이 잘림 없이 첫 화면에 보인다. 상단 관리 행은 실제 필요한 내용만 차지하며 플롯 높이는 변경 전보다 줄어들지 않는다.
- 전역 조회 입력은 한 벌이고 현재 조건 표시를 겸한다. 별도 조건 요약을 반복하지 않는다. 상세 비교 기준은 별도 역할로 남긴다.
- 실제/증감/기준100 전환 때 단위·기준시점·0제외 축 경고가 해석 가능하다. 수동 범위 밖 값·결측을 정상0이나 관측값처럼 보이게 하지 않는다.
- 시연4종/분석6종 글자 규칙을 유지하되 축과 설명을 작게 줄여 공간을 확보하지 않는다. 긴 지역명·긴 수치·음수·긴 연령값을 실제 데이터로 확인한다.
- 모달↔본문↔지도와 상세 콤보 전환 후 조건·선택 지역·확대 위치·그래프 설정이 유지된다. 설명/옵션은 닫기·Esc·복귀가 예측 가능하고 다른 장면에 불필요하게 남지 않는다.
- 생활이동의 시간 해석과 집계 방식, 주민등록과 생활인구의 다른 시점, 연령별 제공 단위 제한은 압축 후에도 오해하지 않게 남긴다.
