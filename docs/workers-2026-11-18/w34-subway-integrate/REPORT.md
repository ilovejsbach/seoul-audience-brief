## 4. 모드 처리 근거

- **지역과 같은 mode 상태를 공유**합니다. 근거: 정본 R03(시연용은 분석용에서 파생, 같은 계산·조회·상세·복귀)과 w31에서 교통도 두 모드를 지원하기로 한 점, 모드 상태를 둘로 나누면 서비스를 왕복할 때 모드가 어긋난다는 점입니다. 단 두 서비스가 같은 값을 쓰도록 `mode`는 main의 한 곳에서만 쓰고 교통은 prop으로 읽기만 합니다.
- **I04 유지:** 루트 클래스는 `region`·`transport`만 mode를 따르고 `market`은 항상 analysis입니다. 상권에는 모드 전환 버튼이 없습니다. 교통에서 시연용으로 둔 채 상권으로 가도 상권은 시연 글자를 받지 않음을 E2E로 확인했습니다. 기존 I04 양방향 검사도 그대로 통과합니다.
- 시연용은 교통 첫 진입에서만 좌측을 접는 w31 동작(결정 a)을 유지했습니다.
