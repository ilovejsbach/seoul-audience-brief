# w47 지하철 역별 상세: 추이와 기간 차이

작성 2026-11-18 · 창5 · 메인 트리(커밋·배포 안 함) · E2E 미실행 · 외부 요청 없음(원본은 읽기만).

## 1. 결론 3줄

- 좌측 "보기"에 역별 상세 4개를 추가했습니다: 선택 역 추이(일·월·계절·연), 두 기간 비교(차이와 증감률), 연도별 같은 시기, 후보 역 비교. 비교 기준은 **하루 평균**(관측일만으로 계산, 관측일 수 표시), 합계는 선택입니다.
- 2026은 1~10월뿐이라 연 비교는 "같은 1~10월끼리"만 허용하고(2025도 1~10월로 맞춤), 부분연도는 "2026(1~10월)"로 표시합니다. 계절은 12월을 다음 해 겨울에 넣고 3개월이 없으면 "일부 달"입니다.
- 원본 대조 3건이 모두 일치하고, build·단위 시험 105/105·validate-subway 통과입니다.

## 2. 추가한 상세 목록 (좌측 보기에 등록)

| 항목 | 내용 |
|---|---|
| 선택 역 추이 | 단위 일/월/계절/연, 기준 하루 평균/합계. 지표(승차·하차·합계)와 요일은 위 조회 바를 따름. **일 단위는 조회 기간 끝에서 최대 366일만** 그림(긴 기간은 월 단위 사용, 판단 근거: 수백 개 점은 읽기 어렵고 월 단위가 같은 정보를 줌). 값 표(관측일·일부 기간 표시)와 CSV |
| 두 기간 비교 | 단위 월↔월/계절↔계절/연↔연(이름 "두 달/두 계절/두 연도 비교"). 기본값 최신 기간 vs 전년 같은 기간. 하루 평균 2개, 차이(건, +부호), 증감률(%, 기준 0 이하면 "계산 불가"), 관측일. 연·같은 계절은 서로 있는 달만 맞춰 비교하고 안내 |
| 연도별 같은 시기 | 같은 달(1~12월) 또는 같은 계절을 2023~2026에 걸쳐 막대로 나란히. 일부 달 기간은 주황, 직전 해 대비 표 |
| 후보 역 비교 | 후보 최대 3곳의 월/계절/연 추이를 겹쳐 보여 줌(같은 단위·기준), 표와 CSV |

- 공통: 숫자(카드·표)는 `ExactValue`로 정확한 값 툴팁, CSV 내려받기(기존 버튼), 환승역은 "이 호선 행만 집계, 다른 호선·다른 노선 구간 미포함" 문구, 시연용은 표를 숨기고 큰 글자만(글자 종류 기존 토큰), 6호선은 이름 기준 연결과 무관하게 역 번호로 값을 읽어 영향 없음(w46 순서 검사 통과).
- **기존 체계와 다른 점:** 이 지하철 작업공간은 "좌측 보기 메뉴 → 중앙 본문 교체" 방식이라 같은 방식으로 등록했습니다. 지역 분석의 상세 팝업↔본문 전환(`DetailNavigation`/`AnalysisDetailModal`)은 쓰지 않았습니다(지하철 화면이 아직 그 체계를 쓰지 않음, 연결은 후속).
