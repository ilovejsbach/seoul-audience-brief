화면 구성
상단에 탭 3개를 둔다. 탭을 누르면 각 시안이 1365×768 크기의 PC 화면 틀 안에 나온다.

1. 현재
   지금 실제 메뉴를 그대로 재현한다.
   - 시작 화면
   - 지역 분석 헤더: 브랜드, 자료 4탭, 지도/상세 분석, 상권 지도, 배치, 분석용/시연용, 더보기
   - 상권 헤더
   - w16 문제 지점(I02, I03, I04, I08, I09, I11)에 번호 표시를 달고, 마우스를 올리면 설명이 나오게 한다.

2. 안 1 (우선 권고)
   현재 틀은 유지하고 경계만 명확히 한다.
   - 시작 화면에 두 서비스("서울 구·동 지역 분석" / "상권 분석")를 같은 위계로 나란히 보여 준다. 기존 바로가기와 이어보기는 유지한다.
   - 지역 분석 헤더
     - 서비스 이름을 표시한다.
     - 자료 탭: 생활인구 / 생활이동 / 거주지 이동 / 행정동 매출
     - 분석용/시연용은 지역 분석에만 둔다.
   - 상권 헤더
     - 서비스 이름을 표시한다.
     - 자료: 상권 매출 / 상권 유동인구
     - 모드 버튼은 없다.
     - "지역 분석으로" 복귀 버튼을 둔다.
   - 더보기 메뉴 설명을 실제 항목과 일치시킨다.
   - 생활인구 기간은 "2026.01.01–11.12"로 쓴다.

3. 안 2 (수평 확장 대비)
   주제 선택 구조를 둔다.
   - 최상위에 주제 선택을 둔다: 지역 분석 / 상권 분석 / 교통(예정) / 부동산(예정)
   - 예정 항목은 비활성으로 표시하고 "자료 확보 후"라고 적는다.
   - 교통을 고르면 하위에 지하철역 / 버스 정류장·노선이 어떻게 붙는지 회색 시안으로 보여 준다.
   - 자료가 7개 이상일 때 탭이 넘치지 않는 형태를 보여 준다. 예: 주제별로 묶은 2단 구성이나 드롭다운.
   - 예시 숫자나 가짜 데이터 값은 넣지 않는다. 지도 자리는 회색 박스와 "지도 영역" 글자로 대체한다.

각 시안 아래에는 쉬운 한국어로 짧은 설명을 붙인다.
- 장점과 단점을 각각 2~3줄로 쓴다.
- 바뀌는 점을 목록으로 쓴다.

품질 기준
- 같은 위계의 버튼과 탭은 크기와 높이를 같게 한다.
- 글자 대비는 4.5:1 이상으로 한다.
- 1365×768 틀 안에서 메뉴가 잘리거나 줄바꿈되지 않게 한다.
- 다 만든 뒤 Playwright로 세 탭을 각각 1365×900에서 캡처한다. 결과물: mockup-current.png, mockup-plan1.png, mockup-plan2.png
- 캡처를 직접 보고 잘림, 겹침, 대비 문제를 고친다.
