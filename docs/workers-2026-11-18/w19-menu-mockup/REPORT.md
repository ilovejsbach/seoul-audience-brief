# 메뉴 구성 목업

## 만든 것

[mockup.html](mockup.html) 하나에 CSS·JS를 넣었습니다. 외부 라이브러리·폰트·네트워크 요청 없이 파일을 열어 볼 수 있습니다.

- **현재 / 안 1 / 안 2**를 비교하고, 각 안의 **시작 화면 / 지역 분석 헤더 / 상권 헤더**를 오갈 수 있습니다.
- 현재의 I02·I03·I04·I08·I09·I11은 번호에 마우스를 올리거나 키보드 초점을 두면 설명이 나옵니다. 안 1은 두 서비스와 매출 이름을 구분하고 지역에만 모드를 둡니다.
- 안 2는 주제→자료 선택으로 긴 탭 행을 피합니다. 교통·부동산은 ‘자료 확보 후’ 비활성이며, 별도 **교통 하위 구성 미리보기**로 회색 구조만 보여줍니다. 각 시안 아래에 장점·단점·변경 목록을 붙였습니다.

Playwright의 **1365×900** 화면에서 캡처했습니다. 내부 PC 틀은 **1365×768**입니다.

| [mockup-current.png](mockup-current.png) | [mockup-plan1.png](mockup-plan1.png) | [mockup-plan2.png](mockup-plan2.png) |

지역·상권 보조 캡처는 `mockup-*-region.png`, `mockup-*-market.png`, 교통 구조는 [mockup-plan2-transport.png](mockup-plan2-transport.png)입니다. 캡처를 직접 보고 선택 탭의 대비, I08 위치, I04 설명의 위쪽 펼침, 자료 바로가기 크기를 보완했습니다.

[검사 결과](playwright-results.json): 20상태에서 메뉴 경계 이탈·가로 잘림 없음, 설명 6개 모두 틀 안에 표시, 글자 대비 최저 **4.79:1**, 외부 요청·JS 오류 0건. 안 1의 지역/상권 자료 바로가기 6개는 모두 **135.375×36px**입니다. 제안 시연 화면은 14·18·24px 세 종류이며, 상권은 지역 시연을 거쳐 들어와도 기본 글자 크기를 유지합니다. [독립 검토](REVIEW.md)도 마쳤습니다.

## 실제와 다르게 단순화한 부분

- 실제 지도·통계값·그래프는 회색 자리로 바꿨습니다. 조회 계산·조건 저장/복원·인쇄·내려받기·창 이동은 연결하지 않았으며, 해당 도구에는 목업 안내를 띄웁니다. ‘이어보기’는 이동 위치를 보여주는 동작이고, 안 1의 ‘이전 상권 이어보기’는 새 버튼 제안입니다.
- ‘현재’는 w16 시점의 메뉴 이름과 배치를 재현합니다. 전체 UI의 픽셀 복제는 아니며, 시연 시작의 자료 선택은 카드가 펼쳐진 형태로 단순화했습니다. I11의 관측된 폭 차이와 I04의 글자 상속은 현재 시안에만 의도적으로 남겼습니다.
- 외부 폰트를 받지 않고 설치된 한글 글꼴을 사용합니다. 날짜 입력 표기는 브라우저 환경에 따라 `11/12/2026`처럼 보일 수 있습니다. 시안 아래 설명은 스크롤해서 읽습니다.

산출물은 이 폴더 안에만 만들었습니다. `src/`, `public/`, 기존 문서는 수정하지 않았고 커밋·푸시·배포하지 않았습니다.
