- 버스의 현재 고유 정류장·노선·행 수, 파일 완전성, 실제 압축률·성능, 좌표계·ID 연결은 미확인이다. 위치 설명의 WGS84/EPSG-5179 혼재, ARS 앞자리0·A/B 예외, TPSS 마스터 차이를 검증해야 한다.

- 용량은 W24 REPORT의 출처 표를 따른다. 일별 승하차 한 달140.85MB, OD 월ZIP251.47MB는 **목록 표기**이지 내려받은 실측이 아니다. 기존 dist555,347,631B는 W18 과거 측정이다. 사이트1GB와 현 Git 경로의 파일100MiB 차단을 구분하고 별도 Pages 단일 파일 한도로 단정하지 않는다.

## 5. 이어받을 때의 요령

- 작업 위치는 `/Users/koscom/workspace2/seoul human`이다. 공백이 있어 셸 경로를 따옴표로 감싼다. NEXT-SESSION → AGENTS → 최신 브리프와 연결 보고를 먼저 읽는다. NEXT-SESSION의 배포 식별자도 과거 기준일 수 있어 현재 상태를 재확인한다.
- W24는 문서 작업이라 빌드·단위검사·Playwright를 새로 실행하지 않았다. 숫자 산식·상대 링크·요구 절을 확인했고 Codex 검토 둘의 지적을 반영했다. 성연령 문구·노선당 양방향 정류장 수·계절 비교 기간 보완은 최종 REPORT에 반영돼 있다. 뒤늦게 도착한 하위 검토 메시지는 수정 전 초안을 가리킬 수 있다.
- 제품 변경 시 기본 명령은 `npm run build`, `node --test tests/*.test.mjs`, `python3 scripts/validate-data.py`, `npm run test:e2e`다. 실행 전 최신 package.json·브리프를 확인하고 증거 출력은 자기 작업 폴더에 둔다. 현재 인계에는 실행하지 않았다.
- 목업 검사 방법은 W19/W20의 `capture.mjs`와 각 결과 JSON을 따른다. 목업 통과를 실제 통계·서비스 통과로 확대하지 않는다. 실제 PC 검수는 요청한 창 크기와 CSS 뷰포트가 일치하는지도 확인한다.
- 사용자에게는 쉬운 한국어로 핵심 세 가지와 짧은 결론을 전한다. 사용자 지시로 Codex 위임을 선호하지만, 새 작업자의 제공자·역할 변경은 감독자가 정한다. 관련 없는 세션·서버는 건드리지 않는다.
- 이 인계 작성 중에는 외부 요청·Git 쓰기·배포를 하지 않았으며 다른 파일을 수정하지 않았다.
