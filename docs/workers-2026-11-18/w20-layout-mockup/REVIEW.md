# 배치 목업 독립 검토

2026-11-18 · 구현자와 별도 Codex 검토. 브리프 전체, w19 목업·보고·검토, w16 IA 보고, 개발규칙 R04/R06/R07/R08과 실제 서비스 색 토큰을 읽고 w20 소스·캡처·검사 결과를 대조했다. 검토자는 이 문서 외의 파일을 수정하지 않았다.

## 확인한 결과

- 시작은 두 서비스 카드와 이어보기 하나이며 자료 목록을 펼치지 않는다. 비교용 화면 탭은 없어졌고 안내만 틀 밖에 있다. 좌측은 자료·보기 탐색, 중앙 상단은 단일 조회 바, 결과 안은 표시 설정·범례, 우측은 지표·최대3후보·해석/출처로 역할이 나뉜다. 지역 상세 25항목을 w16과 대조했으며 두 시간/두 연도/두 분기처럼 기간을 드러내는 이름이 맞다.
- 1365와1920의 시작·지역 분석·시연·상권·좌우 접힘 캡처, 시연 좌측 펼침·긴 조회값, 출처/표시설정 팝오버를 직접 확인했다. 시연의 좌측 기본 접힘·큰 주정보·간소한 우측과 상권의 모드 없음이 구분된다. 메뉴 접힘 뒤에도 펼치기 경로가 남고 중앙 폭이 넓어진다. 숫자 자리는 대시이며 가짜 통계값이 없다.
- 구현자의 최종 Playwright 기록은116상태 통과,15여정 통과, 페이지 오류·외부 요청·선택값 잘림·동위 크기 불일치 기록0건이다. 명목 최저 대비는4.62:1이다. 시연 글자는14/18/24/36px 네 종류다. 독립 검토에서 발견한 시연 시각 선택값의 마지막 숫자 잘림은 선택 화살표와 여백을 보완한 뒤 새 캡처 및 선택문자 실측으로 해소됐음을 확인했다.

## 한계

가장 긴 생활인구 보기 목록도 최종1365 분석 기본값은 내부 높이/내용579px, 시연에서 좌측을 수동으로 펼친 경우는581px로 각각 같아 추가 스크롤 없이 들어간다. 초기 시연 펼침의6px 초과는 하단 안내 여백을 줄인 뒤 새 캡처와 실측으로 해소했다. 시연 기본은 좌측 접힘이다. 이 관측을 미검사 화면 크기·브라우저 글자 확대까지 확대하지 않는다.

목업은 배치·메뉴·대표 선택·후보 상태를 확인하는 자료다. 실제 원자료 연결·계산·지도/그래프·인쇄·지속 저장·공개 배포 품질을 검수한 것은 아니다. 조회 선택지는 대표값으로 제한되어 있으며 실제 사용자 과업 검사는 하지 않았다.

## 히어로 후속 검토 — w20-2

`brief-hero.txt` 전체와 변경 소스·숫자 산출 스크립트를 읽고 갱신된 [1365 시작](1365-start.png), [1920 시작](1920-start.png), [스크롤 뒤 고정 메뉴](1365-sticky-menu.png)를 직접 확인했다. 두 카드 대신 한 줄 제목·부제, 같은 크기의 두 진입 버튼, 비활성 이어보기, 단색 서울 실루엣과 작은 범위 지표로 바뀌었다. 첫 화면의 주제는 모두 미선택이며 예정 주제와 상단 메뉴가 남는다. 두 PC에서 잘림·겹침·의도하지 않은 줄바꿈이나 시작 본문의 추가 스크롤 문제는 찾지 못했다. 지역 화면을 아래로 내린 캡처에서도 주제 메뉴가 화면 위에 붙어 있다.

숫자는 구현자가 만든 요약을 그대로 믿지 않고 원본에서 따로 셌다.

| 표시 | 독립 확인 |
|---|---|
| 생활인구316일 | `public/data/population/index.json`의 고유 날짜316개, 2026-01-01~11-12이며 중복·누락0개 |
| 생활인구427동 | `regions.json` 등록430코드 중 `activePopulation=false`인 과거3코드 제외. 최신 생활인구 gzip의 고유 동 코드427개와 **코드 집합도 일치** |
| 보유 상권 경계1,650곳 | `market-sales.json`의 `areas` 고유 코드1,650개. 최신 매출 관측1,566곳과 구분하는 라벨·주석을 확인 |
| 행정동·상권 매출6분기 | `commerce.json`과 `market-sales.json`의 기간 목록이 모두2025Q1~2026Q2의 동일6분기 |

상권 유동인구는 별도로22분기·최신1,648곳이므로 모든 지표에1,650곳이 관측된다는 해석을 하지 않았다. 인라인 SVG는 `districts.geojson`의25개 구 코드와 연결된25경로이며 모든 구의 채움색이 동일하다. 범위 지표의 숫자를 지도 색으로 표현하지 않는다. 숫자 근거에 적힌6개 원본 파일의 SHA256도 현재 파일과 모두 일치한다.

최신 [Playwright 기록](playwright-results.json)은116상태·18여정 모두 통과이며 페이지 오류·외부 요청·경계 이탈·글자 잘림·동위 크기 오류 기록이 없다. 두 시작 화면 모두 제목·부제가 한 줄이고, 주 버튼 크기가 같고,25경로의 채움색도 한 가지다. 최저 글자 대비는 **4.79:1**이다. 시작 함수 외 기존 JS 함수의 해시도 변경 전 기록과 모두 같아 히어로 외 기능을 바꾸지 않았다는 근거와 일치한다. 상단 `sticky`는 이번 추가 요구에 따른 공통 CSS 변경이다.

앞 절의15여정·최저4.62:1은 히어로 수정 전 배치 검토 결과이며 이 후속 절이 현재 목업 판정이다. 원자료를 히어로의 범위 확인에 읽은 것과 실제 분석 결과에 데이터를 연결한 것은 구분한다. 실제 서비스 구현·배포나 사용자 이해도 검사는 이번 검토 범위가 아니다.
