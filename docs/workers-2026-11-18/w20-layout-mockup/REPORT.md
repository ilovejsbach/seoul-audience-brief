# 상단·좌측 메뉴와 분석 작업공간 목업

## 만든 것

[mockup.html](mockup.html) 하나에 CSS·JS를 넣었습니다. 외부 라이브러리·폰트·요청 없이 로컬 파일로 열 수 있습니다.

- 시작은 서비스 카드 2개와 이어보기 하나로 줄였습니다. 상단은 큰 주제, 좌측은 자료·보기, 중앙은 조회·분석, 우측은 선택 대상의 보조정보입니다. 비교용 화면 버튼은 없습니다.
- 지역 분석의 분석용·시연용, 상권 분석, 좌·우 접기와 복원을 실제로 누를 수 있습니다. 시연용은 좌측을 기본으로 접고 큰 글자와 간결한 우측 정보를 씁니다. 상권에는 모드 버튼·시연 글자 상속이 없습니다.
- w16의 지역 상세 25항목을 유지하면서 ‘두 시간 비교 / 두 연도 비교 / 두 분기 비교’로 기간을 밝혔습니다. 조건 변경·보기 이동·서비스 왕복, 후보 최대 3곳, 표시 설정·범례·더보기도 확인할 수 있습니다.

각 화면 아래에는 목적·변경점·장점 2줄·주의점 2줄과 현재 폭을 표시합니다. 설명은 페이지를 아래로 스크롤하면 읽을 수 있습니다.

## 폭 계산

좌측 기본 **200px**, 접힘 **64px**, 우측 기본 **300px**, 접힘 **0px**입니다. 좌·우 구분선은 이 폭 안에 포함하며 열 사이 별도 간격은 없습니다.

**지도·그래프 내용 폭 = 화면 폭 − 좌측 − 우측 − 중앙 좌우 여백 32px − 결과창 경계 2px**입니다.

| 배치 | 좌 / 우 | 중앙 열: 1365 / 1920 | 실제 지도·그래프: 1365 / 1920 |
|---|---|---|---|
| 양쪽 열림 | 200 / 300px | 865 / 1,420px | **831 / 1,386px** |
| 좌측 접힘·시연 기본 | 64 / 300px | 1,001 / 1,556px | **967 / 1,522px** |
| 우측 접힘 | 200 / 0px | 1,165 / 1,720px | **1,131 / 1,686px** |
| 양쪽 접힘 | 64 / 0px | 1,301 / 1,856px | **1,267 / 1,822px** |

모두 DOM 실측과 일치합니다. 1365에서 양쪽을 열어도 지도 내용 폭은 831px지만, 실제 지도 라벨·비교 그래프가 들어오면 다시 읽기 검수가 필요합니다. 접기/복원 버튼을 항상 남겼으며 시연에서 좌측을 다시 펼쳐도 메뉴를 사용할 수 있습니다.

## 실제와 다르게 단순화한 부분

- 지도·그래프는 회색 자리이며 통계값은 모두 **—**입니다. 후보 이름은 선택한 실제 지역명·상권명이고, 수치와 분석 결과는 만들지 않았습니다.
- 날짜·시간·분기·지역 선택지는 배치를 확인할 일부 항목만 넣었습니다. 원자료 조회, 모든 지원 조합 검증, 공간 탐색·CSV·실제 인쇄·표시 옵션의 도형 반영은 연결하지 않았습니다.
- 현재 탭 안의 JavaScript 상태로 조건·보기·후보·접힘을 유지합니다. 새로고침 뒤 복원·계정 저장 기능은 없습니다. 첫 방문의 이어보기는 비활성이며 서비스를 연 뒤 활성화됩니다.
- 별도 폰트를 받지 않아 설치된 한글 글꼴로 표시됩니다. 모바일·태블릿·실제 사용자 과업 검사는 범위 밖입니다.

이 폴더 밖의 파일은 만들거나 수정하지 않았습니다. `src/`, `public/`, 기존 문서는 그대로이며 커밋·푸시·배포하지 않았습니다.

## 히어로 수정

앞 절의 시작 카드 2개는 수정 전 기록입니다. 현재 시작 화면은 큰 제목 한 줄·짧은 부제 한 줄·서울 실루엣·범위 요약으로 바꿨습니다. 같은 크기인 **지역 분석 시작 / 상권 분석 시작** 버튼(184×46px)과 첫 방문에 비활성인 **이어보기**를 뒀습니다. 본문의 교통·부동산 안내는 빼고 상단 예정 메뉴만 남겼습니다.

상단 메뉴는 히어로에서도 모두 보이며 어느 주제도 선택되지 않습니다. 공유 헤더에 `position:sticky; top:0`을 적용했습니다. 히어로 외 분석 함수는 바꾸지 않았고 기존 분석 상태의 폭·글자·조회값도 수정 전과 일치합니다.

### 숫자 출처

| 표시 | 읽은 파일·센 방법 |
|---|---|
| 생활인구 **316일** | `public/data/population/index.json`의 서로 다른 날짜 316개. 2026.01.01~11.12 사이 중복·누락 없음 |
| 생활인구 분석 대상 **427동** | `public/data/regions.json`의 430코드 중 `activePopulation:false`인 과거 코드 3개 제외. 최신 생활인구 gzip의 서로 다른 동 코드 427개와도 대조 |
| 보유 상권 경계 **1,650곳** | `public/data/market-sales.json`의 `areas` 1,650개·고유 코드 1,650개. 분기별 매출 관측 상권 수를 뜻하지 않음 |
| 행정동·상권 매출 **6분기** | `public/data/commerce.json`과 `market-sales.json`의 `periods`가 모두 2025Q1~2026Q2의 같은 6개 분기 |

`market-population.json`의 유동인구 기간도 2021Q1~2026Q2, 22분기로 확인했으나 요약을 네 지표로 제한해 별도로 표시하지 않았습니다. 최신 매출 관측 상권 1,566곳·유동인구 1,648곳은 보유 경계 1,650곳과 구분합니다.

서울 실루엣은 읽기 전용 `public/data/districts.geojson`의 **25개 구 도형을 25개 인라인 SVG 경로**로 단순화했습니다. 모든 구는 같은 색이며 통계값에 따른 채색·가짜 값은 없습니다. [숫자·원본 해시·SVG 생성 근거](hero-data-sources.json), [생성 스크립트](hero-build.py)를 남겼습니다.

### 검사 결과

- [1365 시작](1365-start.png), [1920 시작](1920-start.png)을 갱신하고 직접 확인했습니다. 제목·부제가 한 줄이며 히어로 본문과 네 지표가 스크롤 없이 각 화면 안에 들어갑니다. 아래의 설계 설명은 기존처럼 스크롤해서 읽습니다.
- [상단 메뉴 고정 캡처](1365-sticky-menu.png): 지역 분석 화면을 **195px** 아래로 스크롤해도 헤더 상단은 **0px**이며 주제 4개가 모두 보입니다.
- 기존 `capture.mjs` 전체 검사 **116상태 통과**, 히어로·sticky를 더한 **18여정 통과**입니다. 같은 위계 버튼 크기, 잘림·겹침·의도하지 않은 줄바꿈, 선택값, 대비를 다시 검사했고 최저 대비는 **4.79:1**입니다. JS 오류·외부 요청은 0건입니다.
- 히어로 외 함수 해시와 기존 분석 상태의 폭·글자·조회값 차이 **0건**, 읽은 원본 파일 해시 변경 **0건**입니다. [회귀 대조](hero-regression.json)와 [독립 검토](REVIEW.md)에 근거를 남겼습니다. 커밋·배포는 하지 않았습니다.
