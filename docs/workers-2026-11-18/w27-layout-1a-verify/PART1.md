## 5. 미리 알아둔 어긋남

- NEXT-SESSION의 "공개 JS `index-DtotdIpr.js`, CSS `index-7CTjbMjC.css`"와 실제 공개 자산 `index-CobtncSk.js`/`index-C4FDrChi.css`가 다르다. 이후 배포가 있었는지, 문서가 낡았는지는 미확인이다. 이 불일치는 B5(NEXT-SESSION 정리) 범위에서 구현자가 다루는지 본다.
- 요청한 창 크기와 실제 CSS 뷰포트가 다르다(768→591, 1080→772). 2부 측정 때도 `documentElement.clientWidth/innerHeight`를 기록한다. 계획서 6절의 1365 기준 폭 계산은 clientWidth(1365) 기준이라 영향이 없지만 높이 관련 판정은 주의한다.
