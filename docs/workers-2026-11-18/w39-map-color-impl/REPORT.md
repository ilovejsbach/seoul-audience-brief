## 3. 최종 팔레트 값과 대비표

**연속 채움 규칙:** `blendPaletteColor(colors[0], colors[4], t)`. 감독자 결정 (a)에 따라 5단계 값(범례·분포 지도)을 이 직선 위로 보정했고, 단위 시험이 "5단계 = 직선의 0·¼·½·¾·1 지점"을 확인합니다. 브리프의 파랑 값 `#94aec7 #6a8dad #416b94`는 직선 위 값 `#94afc7 #6a8dae #416c94`로 1칸 이내로 바뀌었습니다(JS 반올림 기준).

- 끝색, 증감 0 근처 중립색(`#f2f5f8`, 단계 중립 `#f1f1ed`), 양수 파랑 단계는 바꾸지 않았습니다. 청록·자주의 양수 단계는 원래 같은 배열이어서 새 5단계를 따라갑니다. 기본 파랑의 양수 단계(`#dce9f5…`)는 목록에 없어 그대로입니다.

## 4. 결측 무늬 측정 (c, d)

- 무늬: 바탕 `#d7dee6` + 사선 `#5b6b80`, 줄 간격 6px, 굵기 1.5px. 범례 견본도 같은 색·간격·방향의 CSS 그라데이션입니다.
- **화면 고정 크기:** 무늬 크기를 `6px × (SVG 사용자 단위/화면 px)`로 계산합니다. 구·동 지도를 100%→274%로 확대해도 줄 간격 화면 6px 그대로이고(사용자 단위 9.00→3.28), E2E가 확인합니다. 상권 지도와 분포 지도도 각자의 배율로 같은 계산을 합니다.
- 대비: 줄무늬↔바탕 4.01, 줄무늬↔가장 낮은 값 색 3.43(파랑·청록·자주 모두 3.43~3.44), 줄무늬↔페이지 배경 5.16, 줄무늬↔상권 지도 구역 바탕(`#dfe7ee`) 4.35. 무늬 평균 밝기는 가장 낮은 값 색과 비슷(1.15)해서 구분은 색이 아니라 **줄무늬 모양**이 맡습니다. 즉 모양 구분이 목적이며 색 구분은 아닙니다.
- 실제 결측 화면(d): 생활인구 · 남성 · 00시 · 중구 동 지도에서 원자료 기준 5개 동(소공·명동·필동·광희·을지로동)이 자료 없음이며 5개 모두 무늬, 나머지 10개는 값 색. 상권 지도(2026Q2)는 "자료 없음 84"와 무늬 84곳이 같습니다. 가정한 픽스처는 필요 없었습니다. null은 0으로 바뀌지 않으며(단위 시험: 결측 위치는 항상 결측 색, 0은 가장 낮은 색) 값·순위·KPI는 변경 전과 같습니다.
- 두 시점 분포 지도는 이전에 null을 별도 회색(`#d9dedc`)으로 칠하던 경로를 무늬로 통일했습니다(값 색이 아니므로 0으로 읽히지 않는 점은 이전과 같음). 이 화면에서 실제 결측이 나오는 조건은 찾지 못해 무늬가 실제로 칠린 장면은 확인하지 못했습니다(범례 견본과 5단계 값은 E2E로 확인).
