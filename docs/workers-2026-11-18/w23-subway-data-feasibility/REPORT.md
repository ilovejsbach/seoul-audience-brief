# 지하철 자료 가능성 조사

확인일: 2026-11-18 (공식 공개 페이지와 인증키 없는 파일만 확인)

## 1. 핵심 결론 3줄

- 역·호선별 승하차는 시간대·일·월 단위 자료가 있어 지도와 시간 분석이 가능합니다. 승하차 건수는 고유 방문자 수가 아닙니다.
- 혼잡도도 30분 단위로 가능하지만, 승하차 수와 다른 지표이며 1~8호선 중심입니다. 연령은 일부 권종·승객유형만 가능하고 성별은 역별 자료에서 확인하지 못했습니다.
- 출발역→도착역은 코레일의 연간 역간 자료와 신청·키 발급형 교통카드 OD가 있습니다. 서울 전체를 같은 기준으로 묶은 공개 시간대 OD는 이번 조사에서 확인하지 못했습니다.

## 2. 요구별 가능성 판정

| 요구 | 판정 | 근거와 조건 |
|---|---|---|
| a. 역별 시간대별 승하차(유동인구) | 가능 | OA-12252는 월별 역·호선, 04시~다음날 04시 시간대별 승·하차 인원. 서울교통공사 OA-12921은 1~8호선 일·역·시간대 자료. 카드 태그 승하차 건수로 표시하며 사람 수·체류·광고 노출로 바꾸어 부르지 않음. |
| b. 일별 | 가능 | OA-12914는 서울교통공사·코레일·공항철도·9호선 등 카드 승하차를 일자·노선·역으로 제공. 공개 파일은 월 단위 CSV(표본 2026년 10월). OA-12921은 1~8호선의 일별 시간대 자료. |
| c. 월별 | 가능 | OA-12252가 월별 시간대 합계를 제공. OA-12914는 일자료를 월로 합산 가능. 월별 집계 시 일별 파일의 기간과 합계 정의를 유지. |
| d. 계절별 | 조건부 가능 | 월별 값을 봄(3~5월)·여름(6~8월)·가을(9~11월)·겨울(12~2월)로 묶을 수 있음. 한 해는 그 해 계절의 기술통계뿐임. 전년 같은 계절 비교는 2개 완전 연도, 통상적인 계절성 판단은 행사·공사·기상 등 연도별 요인을 살필 수 있도록 3년 이상을 권장. 이는 분석 권고이지 원자료 제공 기준은 아님. |
| e. 혼잡도 | 조건부 가능 | OA-12928은 1~8호선, 요일구분·역·방향·30분별 평균 열차 혼잡도(%). 2024년부터 분기 자료. 좌석만 찬 상태를 34%로 둔 정원 대비 비율. 서울 9호선 자료 OA-22197은 별도 제공처·정의·기간이므로 검증 전 한 시계열로 합치지 않음. 승하차 수로 혼잡도를 추정하지 않음. |
| f. 연령별 | 조건부 가능 | 공공데이터포털의 승객유형 자료는 일반·어린이·중고생·청소년·우대권별 일·시간대 승하차. 권종/승객유형이지 생년 기반 실제 나이가 아님. 우대권에 노인·장애인·국가유공자가 함께 포함되어 연령으로 분리할 수 없음. 모든 운영기관을 포괄하는 연령표는 미확인. |
| g. 성별 | 미확인 | 이번에 확인한 서울 역별 승하차·혼잡·권종 파일에는 성별 항목이 없음. 성별 자료를 추정하거나 다른 통계의 비율을 곱하지 않음. STCIS 원자료 차원·공개 범위도 확인 전. |
| h. 출발역→도착역 OD | 조건부 가능 | 코레일 수도권 전철 역간 연간 파일은 출발·도착역과 인원을 제공(244,244행)하나 연간 합계이며 범위·환승·운영기관 결합은 확인 필요. KTDB는 여객 OD를 신청 후 제공하고 STCIS는 도시철도 OD 지표 및 인증키 신청을 안내함. 시간대·역 코드·이용 조건·비용은 미확인. |
| i. 역 위치와 행정동·상권 연결 | 조건부 가능 | 서울교통공사 1~8호선 좌표 파일은 외부역코드·역명·위경도를 제공. 좌표 점을 행정동/상권 경계와 공간 결합할 수 있지만, 모든 운영기관·역 출구 좌표와 코드·이름 대응표가 필요함. 출구별 위경도는 확인하지 못함. 단일 역점이 상권의 대표 위치나 실제 도보권을 뜻하지 않음. |

### 원문과 간단 집계 대조

승하차 집계는 같은 날짜·노선·역으로 묶은 다음 승차와 하차를 각각 더했습니다. 세 대표 원문 행의 합계가 다음과 같이 재계산됩니다.

| 날짜·노선·역 | 원문 승차 | 원문 하차 | 합계 |
|---|---:|---:|---:|
| 2026-10-01 · 중앙선 · 아신 | 626 | 623 | 1,249 |
| 2026-10-01 · 1호선 · 서울역 | 88,198 | 85,260 | 173,458 |
| 2026-10-31 · 중앙선 · 회기 | 28,514 | 25,137 | 53,651 |

월자료에서 날짜·노선·역 키 중복은 0건이었습니다. `서울역`은 여러 노선에 나타날 수 있으므로 역명만으로 합치면 안 됩니다. 환승객이 카드 정산에서 어떤 방식으로 포함되는지 원문 정의를 추가 확인하기 전까지는 ‘환승 포함’ 여부를 단정하지 않습니다.

혼잡도 XLSX의 직접 셀 대조: 평일·1호선·역번호 150·서울역·상선의 `08:00~08:30` 값은 원문 `73.774675690919338%`입니다. 같은 역·구간의 하선 값은 `39.769987309644669%`입니다. 이 값은 열차 통과 혼잡도이고 승하차 인원으로 더할 수 없습니다. 시트 이름은 요일유형이지 관측 날짜별 기록이 아닙니다.

### 표본에서 확인한 한계

- CSV의 빈 마지막 열은 값이 없는 형식 잔여 열입니다. 정제 시 제거할 수 있지만 원본 CSV는 그대로 보존합니다.
- 같은 역명은 노선마다 반복될 수 있고, 표본은 코드가 없습니다. 반면 혼잡도·좌표 자료에는 역번호/외부역코드가 있으므로 노선+역코드 연결표를 만들고, 역명 단독 연결은 피해야 합니다.
- 월별 일자료와 혼잡도는 시간·모집단·정의가 다릅니다. 표본만으로 혼잡도를 승차 인원에서 재현할 수 없습니다.
- 두 표본의 이름 있는 데이터 열에서는 결측을 확인하지 못했지만, 월 CSV에는 비어 있는 미명명 마지막 열이 있습니다. 이 표본 결과를 전체 기간·모든 파일에 일반화할 수 없으며 다른 날짜·분기·노선은 미검사입니다.

### w20 작업공간 배치

- **상단 주제:** `지하철` 선택을 표시하고 `역 이용`과 `혼잡도`를 자료 유형으로 전환. 현재 자료·기간·단위를 한 줄에서 식별.
- **좌측 자료·보기:** 자료(승하차/혼잡도/승객유형/OD), 노선·역 검색, 기간·요일을 선택. 보기(지도/추이/달력/OD)는 자료 선택과 분리.
- **중앙:** 지도 점을 기본으로, 역 선택 뒤 시간 곡선·달력·계절 비교·OD 흐름 중 하나를 본다. 지도→상세→다른 역→지도 복귀를 유지.
- **우측:** 현재 역의 노선·역코드·좌표·관측기간·결측/제공범위 및 가까운 원문 출처 링크. 값마다 승하차 건수인지 혼잡도 %인지 표시.

### 크기와 배포

실측한 OA-12914 월 파일은 1.23MB/19,088행이며, 31일 기준 하루 약 616행입니다. 이 속도를 단순 연장하면 622개 노선-역×365일은 약 227천 행/년, CSV 약 15MB/년, 10년 약 150MB입니다(최근 월 표본의 행 밀도·바이트/행이 유지된다는 추정). 실제로 전체 노선이 매일 모두 관측되는지와 CSV 압축률은 미확인입니다. OA-12921 연도 파일은 24~31MB 수준이므로 10년 원본을 한 파일로 만들지 말고 연도별/월별 분할이 안전합니다.

분석용 사전 집계는 월×노선×역×시간대 또는 연도×역×시간대 단위로 나누고, 한 화면은 필요한 기간 조각만 가져오도록 설계합니다. 혼잡도 분기 파일은 약 0.4~0.7MB로 작습니다. 표본 파일 크기만 보면 개별 100MiB 제한은 여유가 있지만, 프로젝트 W18 보고서상 현재 사이트가 약 555.35MB이므로 1GB 전체 한도 안에서 다른 주제의 증가량도 함께 계산해야 합니다. 10년 일자료 추정 150MB는 정적 배포 전에 gzip 실측·실제 build 용량으로 다시 확인해야 합니다. 기간·차원 인덱스를 포함한 JSON 크기는 아직 미측정입니다.

### 해석 주의

- 승·하차 집계는 카드 태그 건수이며 반복 이용자를 구분하지 않으므로 고유 방문자 수가 아닙니다.
- 한 역의 승차와 하차를 합산하면 이용 횟수 합이지 역에 머문 사람 수가 아닙니다.
- 혼잡도는 30분 동안 역을 통과한 열차의 평균 정원 대비 승차율이며 승하차 인원과 다릅니다. 좌석 혼잡 기준이 34%입니다.
- 환승 통행의 승·하차 집계 포함 방식과 운영기관 간 합산 범위는 자료별 확인이 필요합니다. ‘환승 포함/제외’라고 추정해 쓰지 않습니다.
- 승객유형·우대권은 실제 연령·성별과 다릅니다. 서로 다른 주변분포를 곱해 성·연령 교차 대상을 만들지 않습니다.
- 지하철 혼잡도·승하차량은 광고판 시야, 노출, 주목, 전환 수치를 직접 나타내지 않습니다.
- 역점과 동/상권 경계 교차는 공간상 위치 연결입니다. 실제 출구 동선·역세권·도보 이용권과 같지 않습니다.

## 6. 사용자가 할 일

1. 시간대별 승하차는 OA-12252 또는 OA-12921 중 원하는 범위(1~9호선 전체 vs 1~8호선 관할·더 긴 일별 시간자료)를 선택합니다. API 자동 갱신을 원하면 열린데이터광장에서 인증키를 신청합니다. 이번 조사는 키를 사용하지 않았습니다.
2. 연령 성격의 분석이 필요하면 공공데이터포털의 15099330 승객유형 파일을 요청 범위로 확인하고, 화면 명칭을 권종/승객유형으로 승인합니다. 성별은 별도 공식 자료가 확보될 때까지 보류합니다.
3. OD가 우선이면 코레일 2024 연간 OD의 운영범위와 역 코드 정의를 먼저 확인합니다. 시간대/서울 전체 OD가 필요하면 KTDB의 여객 OD 자료 신청 또는 STCIS Open API 인증키 신청에서 제공 주기·공간 코드·이용 허락·비용을 확인합니다. 이번 작업에서는 신청·로그인·키 발급을 하지 않았습니다.
4. 역 지도에는 서울교통공사 1~8호선 좌표 276역을 우선 사용할 수 있습니다. 나머지 노선 좌표와 행정동·상권 경계 결합은 코드 대조 후 별도 승인합니다.

## 7. 한계와 미확인

- 확인 날짜 현재 공개 페이지의 파일 목록을 조사했지만, 모든 기간 파일을 받거나 과거 전체 기간의 품질을 검증하지 않았습니다. 표본은 월 1개와 분기 혼잡도 1개뿐입니다.
- 좌표 276역은 1~8호선 범위이며 공사 관할 좌표가 다른 공식 좌표와 미세하게 다를 수 있습니다. 모든 사업자에 걸친 공통 station ID, 좌표계, 출구 좌표, 역별 행정동·상권 연결은 미확인입니다.
- Open API 키 발급·일일 호출 제한·요금·상업적 이용 세부 조건은 페이지에서 확인 가능한 범위를 넘으면 미확인으로 남겼습니다. 인증키 API는 호출하지 않았습니다.
- STCIS와 KTDB의 OD 지표/자료신청 경로는 확인했지만, 상세 OD 단위·시간대·기간·비용·다운로드 파일·상업 이용 조건은 미확인입니다. KOTSA 원시 카드 기록은 일반 다운로드 가능한 파일로 확인되지 않았으며, KTDB 보고서는 교통카드 태그 및 하차 태그 추정 절차를 설명할 뿐 원시 기록의 공개 허가를 뜻하지 않습니다.
- 월/연도 파일의 크기는 출처 페이지 표기값 또는 실제 받은 표본값입니다. 기간 전체의 정확한 용량·gzip 크기·정적 사이트 build 크기는 미측정입니다.
- 본 보고서는 자료 가능성 조사이며 소스·public 데이터·기존 문서는 수정하지 않았습니다. 커밋·배포 및 화면 구현은 하지 않았습니다.
