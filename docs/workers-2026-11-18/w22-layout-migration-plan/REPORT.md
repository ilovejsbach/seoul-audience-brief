# W22 결과

확정 w20 구조를 실제 서비스로 옮기는 [계획서](../../layout-migration-plan.md)를 작성했다.
지역 상세25개·상권 상세3개와 조회·후보·복귀·전체화면·인쇄·CSV 보존 조건을 정리했다.
I01 선수리, 상권 모드 독립, 실제831px 가독성 및 독립 검증을 단계별 관문으로 두었다.

| 단계 | 내용 | 예상 파일 / 난이도 |
|---|---|---|
| 0 | 결정·요구서/규칙 개정안 | 본문1+보조 / 낮음 |
| 1a | 현행 문서 동기화·표시설정 I01 수리 | 7–12 / 중간 |
| 1b | 공통 셸·주제·히어로·상권 모드 상속 차단 | 10–16 / 높음 |
| 2 | 지역 왼쪽 자료·보기·시연 기본 접힘 | 8–13 / 높음 |
| 3 | 지역 오른쪽300px·후보·접기 | 9–15 / 높음 |
| 4 | 상권 작업공간을 같은 셸에 연결 | 10–17 / 매우 높음 |
| 5 | 문구·균등 크기·잘림·인쇄·최종 감사 | 5–10 / 중상 |
| L | 선로딩 중단: 레이아웃과 별도 커밋 | 5–9 / 중상 |

파일 수는 단계별 중복 포함 추정이다. 구현·독립 검증 역할과 단계별 검사·공개 확인·되돌리기는 본문에 적었다. 기존 PC16의 누락된 행정동 매출과 상권 모드 기대값을 확인해 새 지역16+상권2=PC18 및 추가 여정으로 이식하도록 했다.

사용자가 정할 세부 질문:

- 시연 전환 때마다 왼쪽을 접을지, 첫 기본 접힘 이후 수동 선택을 유지할지? 권고는 후자다.
- 고급 비율·도킹을 장기적으로 유지할지? 이번 이전은 더보기 안에 보존하며, 제거는 별도 결정 대상으로 남겼다.

별도 Codex가 독립 문서 검토했고 실행 명령·증거 보존·중간 단계 접근·소스 줄·폭 검사 적용 단계·집계 도구 영향을 보완했다. [검토 기록](independent-plan-review.md), [소스 대응 근거](source-mapping-notes.md), [문서 검사](document-checks.json)를 함께 남겼다.

계획만 작성했다. 이번 작업자의 쓰기는 새 계획서와 W22 폴더 안으로 제한했다. 기존 소스·데이터·테스트·문서는 수정하지 않았고 git 쓰기·외부 요청·빌드/E2E·배포도 하지 않았다. 실제 서비스와 공개 화면의 합격 여부는 미검사다.
