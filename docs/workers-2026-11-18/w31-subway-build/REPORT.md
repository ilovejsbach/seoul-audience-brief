## 3. 승객 유형 대응표와 근거

화면은 "연령"이 아니라 **일반 / 청소년 / 우대 / 기타(어린이 등)** 로 씁니다. 성별은 "자료 없음"입니다.

| 화면 | 원문 승객유형 | 근거 |
|---|---|---|
| 일반 | 일반 | 파일 설명 |
| 청소년 | 청소년, 중고생 | 서울교통공사 여객운송약관은 운임을 어른·청소년(만 13~18세, 재학 중 24세까지)·어린이 세 종류만 두고 중고생 별도 운임이 없습니다. 그래서 중고생을 청소년 요금 대상으로 합쳤습니다. 약관 문구가 권종 코드의 정의까지 보장하는 것은 아니라는 점은 미확인으로 남깁니다. |
| 우대 | 우대권 | 파일 설명: 노인·장애인·국가유공자가 섞여 있음 → 화면에 주의 문구 |
| 기타(어린이 등) | 어린이, 직원, 영어·중국어·일어 일반/어린이 | 3그룹에 안 들어가 버리지 않고 따로 표시. 외국어 안내 권종은 일반 요금으로 보이나 정의를 확인하지 못해 기타에 둠 |

원문 12개 유형의 승차 합계는 준비 파일에서도 그대로 보존(`rawTypeTotals`)됩니다. 이 화면의 합계는 월 합이며 요일 구분을 적용하지 않습니다(화면에 명시).

- 용량 한도(전체 30MB/파일 10MB)는 검증기가 확인합니다.

## 5. 독립 대조 결과 (`scripts/validate-subway.py`, 종료 코드 0, 8건 통과)

준비 코드를 쓰지 않고 원본 CSV·XLSX를 다시 읽어 비교했습니다.

1. 매니페스트 필수 항목·파일 해시·용량 한도 통과.
2. 원본 55개 해시 = 수집 MANIFEST(원본 불변).
3. **역 하루 합**: 무작위 40건(고정 시드)이 원본 행과 정확히 일치.
4. **환승역**: 서울역 2026-10-16 — 1호선 승차 99,466·하차 97,013 + 4호선 16,002·27,003 = 승차 115,468·하차 124,016, 화면 일별 파일과 일치. 묶음 안 먼 쌍 없음.
5. **시간대 합**: 서울역 2025-03 평일(21일), 강남 2024-10(23일), 어린이대공원 2023-06(22일)의 20개 시간대 합이 원본과 일치.
6. 월 합 = 일별 합: 12,650개 역-월 전부 일치.
7. 승객유형: 서울역 2026-03 승차 그룹 합이 원본과 일치(일반 2,058,093·청소년 44,363·우대 293,375·기타 33,250), 12개 유형 전체 합과 4그룹 합 일치.
8. 혼잡도 셀 3,159개 원본 XLSX와 일치.

**결측·행 수:** 일별 원본 860,468행 중 좌표가 있는 역 383,131행을 연결, 나머지 477,337행은 좌표 없는 노선(코레일 등·9호선)입니다. 빈 칸(null) 셀은 일별 0, 시간대 0, 유형 0, 혼잡도 0건이었고 결측 처리 코드(null 유지)는 단위 시험으로 고정했습니다. 12914의 같은 날·노선·역 중복 키 0건. 좌표 없어 못 붙인 1~8호선 역 10개: 불암산, 굴포천, 까치울, 부천시청, 부평구청, 삼산체육관, 상동, 신중동, 춘의(7호선 부천 구간), 암사역사공원 (코레일/타 기관 관할). 역명이 바뀐 2역(7호선 이수=총신대입구 2738, 자양=뚝섬유원지 2730)은 코드로 확인한 별칭으로 연결했습니다.

## 8. OD 판정: 이번에는 만들지 않음 (화면 "준비 중")

OA-21222 2026-10 표본(31일 파일, 10-01·10-05 두 날은 헤더만 있음)을 검사했습니다.
- 열: 기준날짜, 승차 ID, 하차 ID, 승객 수, 시간대별 승객 수. **수단 코드 열이 없습니다.** 4자리 ID는 지하철 외부역코드와 같은 값이고 9자리 ID는 정류장으로 보이나 문서화된 규칙이 아닙니다.
- 역 코드 대응: 4자리 ID 768개 중 271개가 좌표 파일(1~8호선 276역)과 일치. 승차·하차 합계가 OA-12914와 거의 같음(강남 승차 93,649 vs 93,679, 하차 93,260 vs 93,260; 홍대입구 하차 85,103 vs 85,104). 하차 ID가 "-"(하차 태그 없음)인 행이 있음.
- 환승 처리: 한 통행인지 구간별인지 문서로 확인하지 못했고 파일만으로도 가릴 수 없습니다.
→ 3가지 기준(수단 코드, 환승 처리, 역 코드 대응) 중 역 코드 대응만 통과. 나머지가 확인되기 전에는 OD를 만들지 않습니다.
