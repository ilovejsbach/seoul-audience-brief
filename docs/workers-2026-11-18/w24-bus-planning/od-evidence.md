# 버스 OD·혼잡·성연령 공개 설명 독립 확인

확인일: 2026-11-18. w24 기획의 보조 근거다. 공식 목록·설명·공개 분석 화면만 읽었다. 파일 다운로드, 데이터 API 호출, 인증키 사용, 로그인은 하지 않았다. 자료 존재·명세 확인과 실제 데이터 확보·검증을 구분한다. 아래 미확인은 이번 허용 범위에서 확인하지 못했다는 뜻이다.

## 핵심 판정

- 교통카드 기반 OD 공개 통계와 API 설명은 존재한다. **정류장/역사별 수단 OD 파일 목록(OA-21222)도 확인했다.** 다만 읍면동 OD·통합 OD와 구분해야 하며, 버스만 추출하는 정확한 수단코드와 출도착 연결 컬럼·완전성은 파일을 읽지 않아 미확인이다.
- 버스 노선 혼잡도 API 설명도 존재한다. 공식 혼잡도 산식·차량 정원·응답 세부 필드는 추가 확인이 필요하다. 승하차 합계를 차내 혼잡률로 이름만 바꾸면 안 된다.
- 교통카드 OD 명세에서 성별·연령을 확인하지 못했다. 기후동행카드 등록자 연령과 통신 기반 생활이동은 별도 자료이므로 버스 승객 성연령으로 대체할 수 없다.

## 해석과 규모에서 지켜야 할 경계

1. **승하차:** 정류장에서 타고 내린 이용 건수다. 같은 사람이 여러 번 타거나 환승하면 반복될 수 있다. 승차+하차는 고유 인원수가 아니다.
2. **OD:** 출발과 도착을 연결한 통행이다. 환승 전후를 하나로 연결하는지, 수단별 구간으로 나누는지에 따라 값이 다르다. 통합 OD를 버스 OD라고 표시하지 않는다.
3. **차내 혼잡:** 차 안에 남아 있는 재차인원·정원 또는 공식 등급 정의가 필요하다. 승하차량이 큰 정류장과 차 안이 붐비는 구간이 반드시 같지는 않다.
4. **거리 유동인구·생활인구·생활이동:** 주변 체류·이동의 추정 대상이다. 버스 승객과 겹칠 수 있고 분모도 다르다. 버스 이용량과 단순 합산하거나 ‘도보 유동인구’로 이름을 바꾸지 않는다.

OD 규모는 모든 출발지×모든 도착지×시간 구간×일 수로 커질 수 있다. OA-21222의 위 ZIP 용량은 **공식 목록의 압축파일 표기**이며 버스만 남긴 크기·풀었을 때 크기·화면용 JSON 크기가 아니다. 실제 희소 행 수와 누락·비공개 처리 기준이 미확인이므로 서울 정류장 OD 행 수를 제시하지 않는다. 지역 수를 N으로 가정한 최대 조합은 N²×96×일수이나, 이는 15분 지역 OD의 **이론적 조합 상한**이며 실제 제공 행 수 예측이 아니다. 행정동 자료와 법정동 자료의 코드 연결도 별도 검증이 필요하다.

OA-21222 목록에는 2022년 일부 월이0.01MB, 2024-12가25.49MB로 표기되어 다른 월보다 작다. 원인은 미확인이므로 해당 월을 완전 자료로 가정하지 않는다. 목록 본문의 메타 갱신일2026-08-24와 최신 파일 수정일11/17도 구분한다. 페이지 말미에 일반 종료·URL오류 안내 문구가 함께 파싱되지만 정상 제목·설명·최신 목록이 있으므로 이 문구만으로 서비스 종료를 판정하지 않는다.

계절 비교를 구현하려면 여러 달의 연속 제공과 결측·휴일·운행 변경을 먼저 확인해야 한다. 월 합계를 바로 계절 평균으로 더하지 말고 유효 관측일 기준의 합계/일평균을 구분한다. 정류장 인근 생활인구의 연령 비율을 승객 연령으로 배분하는 방식은 별도의 추정모델이며 관측값으로 표시할 수 없다.

## 구현 전 남은 확인

- 최신 지원 기간, 서울 포함 범위, 수단 분리 가능 여부, OD 환승 정의, 법정동/행정동 연결, 누락 하차·미태그 처리.
- 혼잡도 공식 산식·단위·등급과 시간 범위, 노선 변경 이력, 실제 응답의 행 수·바이트. 성연령 자료의 모집단과 교차표 가용성.
- 각 API 키 승인·쿼터, 정적 재배포 조건, 자료 갱신 지연. 이번에는 승인 신청·기관 문의·호출을 하지 않았다.

이번 확인은 목록·설명 단계다. 실제 파일 확보, 데이터값 의미 대조, 브라우저 구현·화면 검사·배포는 수행하지 않았다.
