# 브리핑 메뉴·선택 지표·그래프 조작 재설계

2026-11-15. 목적: 광고주가 지금 **어떤 자료를, 어느 지역·대상 조건으로, 어떤 방식으로** 보고 있는지 혼동하지 않고 판단하도록 한다.

## 1. 메뉴는 시나리오 순서가 아니라 두 선택 축이다

| 위계 | 선택 | 바뀌는 것 | 보존하는 것 |
|---|---|---|---|
| 1차 자료 | 생활인구 / 생활이동 / 거주지 이동 / 추정매출 | 모집단·단위·지원 기간·적용 옵션 | 현재 지도/상세/후보 보기 |
| 2차 보기 | 지도 / 상세 분석 / 후보 비교 | 자료를 읽는 화면 또는 이동 위치 | 선택 자료·그 자료의 조건·후보 |
| 작업 설정 | 조회 옵션 / 그래프 옵션 / 화면 배치 | 조건 또는 표현·작업 공간 | 각 설정의 역할 밖 데이터 |

시연은 선택한 보기에 집중하고, 분석은 전체 도구를 유지하면서 해당 영역으로 이동한다. 그래서 분석용에는 ‘이동’, 시연용에는 ‘보기’로 표시한다. 상세 분석은 시간 추이만 뜻하지 않는다. 연령·성별 구성, 요일·월중 특성, 거주 기반 비교 등 제공 자료에 맞는 근거도 포함한다. 단일 연도 구성 자료를 시계열이라고 설명하지 않는다.

상단의 단계 번호·이전/다음·1/3 표시를 제거했다. 번호 없는 3개 보기로 직접 이동하며, 자료를 바꾸어도 현재 보기를 유지한다. H1에 현재 자료와 시연 보기를 표시한다. Hero의 실제 행동이 중복됐던 목적별 버튼과 번호 여정을 없앴다. 시연 시작도 생활인구로 조용히 고정하지 않고 자료 4종 중 명시적으로 선택한다.

전역의 중복 시작 복귀 버튼은 하나로 합쳤다. 일반 지도 안의 중복 자료 선택기는 숨기고, 상단 메뉴가 없는 전체화면에서만 제공한다. 별도 상권 경계 탐색은 ‘상권 단위 분석’으로 이름을 밝혔고, 출처·상세표를 표시하는 토글은 ‘근거 정보’로 구분했다. 그래프의 작은 지도 복귀는 깊은 분석에서 바로 되돌아오는 맥락 행동이므로 헤더에 작게 유지한다.

## 2. 숫자는 선택 지역의 판단 요약으로 유지한다

전입·전출·순이동은 총량과 방향을 함께 판단하는 값이므로 삭제하거나 팝업에만 숨기지 않았다. 큰 카드 대신 작은 선택 지역 요약으로 재배치하고 지역·기간·연령/성별·시각·집계 기준을 표시한다. 기간 반복 문구는 줄이고 순이동 수식은 해당 값 아래에만 둔다. 순이동을 지도 지표로 골라도 나머지 두 칸은 전입·전출을 보여주며 중복 숫자를 만들지 않는다.

원인은 지도 클릭이 `popup`만 바꾸고 실제 지역 조건은 그대로였기 때문이다. 이제 클릭은 지역 옵션·KPI·추세·후보 기준·CSV에 같은 지역을 적용한다. 마우스 오버는 미리보기만 한다. 선택만으로 구 지도와 카메라를 바꾸지 않는다. 명시적 상세에서 동 지도로 내려가며, 동 자료가 없는 연령별 전출입은 구성 분석으로 실제 연결한다. 연령 제한 해제만으로 동 지도로 자동 전환하지 않는다. 동을 명시한 저장 조건 복원은 동 지도를 우선한다.

오른쪽 비교 목록과 선택 요약의 범위는 다를 수 있다. 따라서 목록을 ‘서울 자치구 비교’ 또는 ‘선택 구 행정동 비교’로 밝히고 해당 행을 강조한다. 팝업은 출처·심화·후보 행동을 보조하며 요약 숫자의 조건을 별도로 만들지 않는다.

[ArcGIS의 지도 선택→지표 필터 동작](https://doc.arcgis.com/en/dashboards/latest/create-and-share/configuring-actions-on-dashboard-elements.htm), [Tableau의 선택 필터 동작](https://help.tableau.com/current/pro/desktop/en-gb/actions_filter.htm)을 참고했다. 이를 토대로 이 대시보드에서는 핵심 요약은 상시 작게, 출처·심화는 필요할 때 열도록 판단했다.

## 3. 그래프에는 해석과 최소 조작만 남긴다

표시 방식·비교 기준·축·재생 속도·계산 설명은 헤더의 ‘그래프 옵션’에서 독립 창으로 연다. 창에는 설정 대상 자료·지역·대상을 명시하며 이동·가로세로 크기 조절·초기화를 제공한다. 옵션을 열어도 그래프 높이나 값이 바뀌지 않는다.

본문에는 현재 표시 방식, 실제 비교 기준 시점, 축 범위와 0 제외·범위 밖 주의를 남긴다. 이전·재생·다음은 32px 버튼의 한 줄이고 큰 하단 복귀 행은 없다. 복귀와 후보 행동은 작은 헤더 버튼이며 이미 담김·상한 상태를 구분한다. Esc는 초점을 가진 창 하나만 닫고, 다른 지도 전체화면에서는 그 지도에 속하지 않은 그래프 옵션을 숨긴다.

## 4. 실제 검수 결과

Chrome 기본 1800×961의 로컬 화면에서 다음 25개 시나리오가 통과했다.
- 메뉴·보기·옵션·재생·Hero 진입 6개.
- 좁은 상권 그래프 옵션과 호스트 닫기 1개: 280×470px 창에서 본문263px, 스크롤폭263px로 가로 넘침 없음.
- 지도 클릭·인구 집단·구/동 상세·생활인구·생활이동·매출 연동 5개.
- 좌측 지역 선택 후 연령→성별 제한 해제와 순이동 3값·카메라 보존 1개.
- 축·음수 기준 지수·상세 복귀·두 시점·상대 이동 회귀 5개.
- 상권 자료·검색·무결과·색상·후보·추이·복귀 회귀 7개.

계산 검사21개, 타입·프로덕션 빌드·변경 형식 검사도 통과했다. 서초구 2025년30대는 공식 원본에서 **전입13,705 / 전출13,007 / 순이동+698명**, 서울25구 합계는308,182 /326,912 /−18,730명으로 독립 대조했다. 실제 화면에서30대→40대→성별·순이동 변경이 같은 지역에 반영되는지 확인했다.

개선 전 공개 화면의 메뉴 두 영역은59+55=114px, 그래프 하단은재생61+복귀47=108px였다. 새 메뉴는55px, 재생 하단은38px다. 같은 기본 그래프의 높이는약835px에서503px로 줄었다. 본문 주의를 없애서 수치를 왜곡한 것이 아니라 조작·설명을 옵션으로 이동한 결과다.

실제 텍스트 크기 집합은 시연 **14/18/24/36px**, 분석 **12/14/16/20/28/36px**로 각각4/6종이었다. [실행 결과](../tests/briefing-refinement-results.json), [메뉴 전략](navigation-strategy-review.md), [독립 그래프 기준](compact-chart-acceptance.md), [선택 연동·원본 대조](selected-region-acceptance.md)를 함께 확인한다.

현재 변경 영향 경로를 실행했으며 과거의 전체 E2E나 모든 날짜·지역·업종 조합을 모두 실행했다고 주장하지 않는다. 네이티브 Fullscreen API가 활성화되지 않는 자동화 환경에서는 앱의 전체화면 대체 경로를 검사했고 실제 최상위 레이어 경로는 소스 검토와 구분한다.
