# 지도 눈금·범례·기간 분석 실행 보고

2026-11-15. 실제 Chrome 1800×961 화면으로 검사했다.

## 반영 범위
- 행정구·동 지도, 두 시점 분포·증감 지도, 상권 지도에 색상 최솟값·최댓값 및 범위 ±20% 조절을 제공한다. 두 지도는 공통 눈금, 증감·순유입은 0 대칭을 유지한다. 범위를 벗어난 관측치는 끝 색으로 표시하고 개수를 안내한다. 원자료·다운로드 값은 변하지 않는다.
- 범례는 작은 색 막대와 버튼으로 줄였다. 마우스·초점·클릭으로 구간과 해석을 보고 Escape로 닫는다. 상권 범례 툴팁은 최대 350×340px, 긴 내용은 내부 스크롤로 확인한다.
- 생활인구 원자료 2026년 1–10월 304일, 3,115,392행을 확보·검증했다. 120개의 월·연령·성별 요약 파일을 필요할 때 읽는다. 요일 및 월초(1–10일)·월중(11–20일)·월말(21일 이후)의 시간대별 하루 평균을 비교한다.
- **기존 일자별 상세 지도는 2026년 10월이다.** 1–10월은 새 요일·월 구간 분석에서 선택한다. 기간 범위를 혼동하지 않도록 시작 화면과 분석 설명에 표시했다.

## 의미와 결측 처리
같은 날짜·지역·시간·대상 집단을 먼저 합산한 후 유효한 날짜 수로 나눈다. 비공개 구성값이 있으면 해당 지역·날짜를 평균 분모에서 제외하며 0으로 채우지 않는다. 유효/전체 날짜 수와 실제 날짜를 펼쳐 확인한다. 공휴일을 별도 분리하지 않았으며 월초·월말 차이를 인과 효과로 해석하지 않는다. 서로 다른 생산 방식의 구·신 자료를 자동 연결하지 않는다.

## 검사 결과
- 계산 검사 27개 통과. 독립 Decimal 원자료 대조 11건 및 요약 평균 13,046,400칸 검증 포함.
- 신규 화면 시나리오 9개 통과: 지도 범위·툴팁 4개, 기간 분석 5개.
- 영향 범위 회귀 28개 통과: 기존 지도 6개, 상권 7개, 의미 판정 8개, 핵심 흐름 5개, 영역·플로팅 조절 2개.
- 공항동 12시 7,676.14명 → 18시 7,779.34명에 공통 범위 7,600–7,900을 적용하면 색 구간이 2→3으로 변한다. 원값은 유지되며 범위 밖 관측치는 아래 35개·위 3개다.
- 공항동 2026년 10월 청년 남성 월요일 12시 평균 8,877.50명(4/4일), 월초 8,596.61명(10일), 월말 8,954.30명(11일)을 확인했다.
- 창신1동 여성 월초 00시 평균은 2,527.96명(유효 4/10일)으로 비공개 날짜를 제외한 원자료 계산과 일치했다.
