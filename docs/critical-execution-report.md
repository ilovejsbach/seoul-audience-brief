# 지도 중심 조회·인포그래픽 개선 실행 보고

2026-11-14. 정적 감사·원자료 대조·실제 Chrome 조작을 구분해 수행했다. 이전 보고의 기능 통과만으로 상세 여정이 충분하다고 보지 않고, 같은 지역 반복 선택과 다음 행동을 추가 검증했다.

## 주요 변경

- 상단 왼쪽 **지도 중심 조회**: 조건 패널·중앙 지도·선택 상권 상세를 한 화면에서 조회한다. 기존 분석/시연도 유지한다. 지도 위치·입력 조건을 보존하고 실제 이전 화면으로 돌아간다.
- 상권 실제 자료: 유동인구 2021Q1–2026Q2 36,281행·1,650상권, 매출 2025년 85,732행·62업종, 경계 1,650개. 자료·분기·구/동·상권 검색·유형·업종·한 가지 주변분포를 조회한다. 개인별·세부 교차값은 만들지 않는다.
- 같은 구/동 상세 재선택은 추이로 연결한다. 지도·추이·후보·상대 지역의 후속 행동을 연결하고, 접힌 상세는 새 선택 시 열고 핵심 값이 있는 상단으로 이동한다. 상권 지도 포인터 캡처 때문에 클릭이 전달되지 않던 문제도 수정했다.
- 세로축 0 포함·변화 확대·직접 지정 및 초기화. 잘못된 입력, 0 제외, 범위 밖 점을 안내한다. 음수·0 기준 지수는 막고 값의 차이로 비교한다. 표시 전환 시 축을 초기화한다.
- 생활인구 두 시점 분포/증감 지도는 같은 영역·같은 색상 눈금으로 비교한다. 생활이동은 실제 OD 상대 지역과 각 방향의 전체 합계를 분모로 하는 비중을 보여준다. 서울 밖은 여러 지역의 통합값으로 구분한다.
- 장식 KPI 대신 유입·유출·차이, 직전 분기·차이, 공개 시간대 중 최대·공개 개수·직전 차이를 표시한다. 부분 결측에서 하루 전체 최대라고 단정하지 않는다.
- 흰 바탕·남색 글자 중심으로 전환했다. 규모 지도는 큰 값이 짙은 파랑으로 일관되게 표시하고 증감은 주황–파랑이다. 상권은 순위별 구간/같은 값 간격을 선택하며 실제 범례를 같이 바꾼다. 범례는 억·만으로 축약하고 상세/CSV는 원값을 유지한다.

## 참고 후 설계한 근거

- [서울시 상권분석 실제 화면](https://golmok.seoul.go.kr/commercialArea/commercialArea.do): Chrome에서 좌측 조건·지표·순위와 지도·도구의 배치를 직접 확인했다. 외부 페이지 일부 버튼은 자동 조작이 완료되지 않아 그 세부 동작을 검증했다고 주장하지 않는다.
- [Kepler 공식 레이어 안내](https://docs.kepler.gl/docs/user-guides/c-types-of-layers): 공개 문서의 지도와 레이어 역할을 확인했다. 실제 도구 세션을 사용한 것으로 표현하지 않는다.
- [ColorBrewer 색상 유형](https://colorbrewer2.org/learnmore/schemes_full.html), [Datawrapper 지도 안내](https://www.datawrapper.de/blog/choroplethmaps): 규모와 증감의 색상 목적을 분리했다.
- 상세 설계와 와이어프레임: [map-workspace-design.md](map-workspace-design.md). 색상 대비 계산: [color-readability.md](color-readability.md). 현행 요구·영향 기준: [interaction-design.md](interaction-design.md).

## 실측 범위와 남은 한계

- 실제 화면은 **1800×905**, 가로 넘침 없음. 1440/1280 크기 변경 요청이 브라우저에 적용되지 않아 작은 PC 화면 통과로 계산하지 않았다. 모바일·작은 화면은 별도 실측이 필요하다.
- 새 상권 화면은 정적 공개 파일을 읽는다. 최초 내려받기 크기와 로딩 상태를 고려해야 한다. 지속 갱신·별도 백엔드는 도입하지 않았다.
- 유동인구 원본을 서비스 화면의 일평균으로 바꾸는 환산식은 미확정이다. '분기 제공 지표·명(원본 추정치)'로 제한한다. 개인의 고유 방문자 수·상권 간 OD·광고 효과로 해석하지 않는다.
- 상권 경계 2023년과 통계 기준 시점의 형상 일치는 미검증이다. 원본 도형 오류 6개·자료 없는 상권을 임의 보정/0 처리하지 않았다.
- 현재 색상 조합의 모든 시각 장애 조건을 사용자 실험으로 검증한 것은 아니다. 지도에 범례·숫자·선택 윤곽과 텍스트를 병행한다.
