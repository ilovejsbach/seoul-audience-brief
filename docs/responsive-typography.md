# 기기별 글자와 정보량 기준

2026-11-16 · 현행 R07 · 브라우저 기본16px 기준. 숫자는 제품의 역할 규격이며 모든 사용자에게 편한 유일한 크기라는 주장은 하지 않는다.

## 화면 폭과 글자 역할

| 모드 | 역할 순서 | 모바일 ≤767px | 태블릿 768–1199px | PC ≥1200px |
|---|---|---|---|---|
| 분석 | 메타 / 조건 / 본문 / 패널 / 화면 제목 / 핵심 수치 |12 /14 /16 /18 /20 /28|12 /14 /16 /20 /24 /32|12 /14 /16 /20 /28 /36|
| 시연 | 보조 / 본문 / 제목 / 핵심 수치 |14 /16 /20 /28|14 /16 /24 /32|14 /18 /24 /36|

같은 역할은 화면 크기에 따라 지정된 한 값만 사용한다. 입력·선택창은 모바일·태블릿16px, PC 분석14px·시연18px다. 본문을 작게 줄여 더 많은 정보를 밀어 넣지 않는다. 12px는 분석용 출처·축 등 짧은 메타 정보에 한정한다.

행간은 본문1.6–1.65, 제목1.35–1.45, 핵심 수치1.3을 기준으로 한다. IBM Plex Sans KR와 고정폭 숫자 정렬을 유지한다. 정보의 중요도는 크기 외에도 굵기·정렬·간격·접힘으로 나타낸다.

## 영역별 네 역할과 공통 상태

기기별 표는 허용 크기 집합이고, 아래 표는 각 영역에 어떤 크기·색·굵기를 배정할지 정한다. 창마다 새 크기를 만들지 않는다.

| 역할 | 크기 배정 | 기본 색·굵기 | 강조 원칙 |
|---|---|---|---|
| 기능 폰트 | 항목명=조건/보조, 입력·선택=control | 동작은 파랑 #24558b·500, 항목명은 #53677c·500 | 선택은 배경·테두리·선택 상태를 함께 표시, 비활성은 상태를 분명히 표시 |
| 정보 폰트 | 본문=body, 대표값=key | 본문 #142d49·400, 값·지역명600 | 대표값과 비교값을 구분, 금액은 축약+정확값 펼침 |
| 인포그래픽 부가 폰트 | 축·범례·출처=meta | #53677c·400 | 짧은 맥락에 한정. 판단을 바꾸는 해석·주의는 본문 크기로 승격 |
| 창 구성 폰트 | 창 제목=panel, 그룹명=조건/본문 | #142d49·600, 그룹명500 | 위치·구획·간격으로 구조를 표시하며 제목을 중복하지 않음 |

설명창 본문은 옵션보다 읽기 중심이다. PC 분석16px·시연18px, 모바일/태블릿16px로 읽고 출처만 보조 크기로 둔다. 설명창 제목은 panel 역할을 재사용한다.

상태는 다섯 번째 글자 크기 체계가 아니라 네 역할에 공통으로 적용하는 규칙이다. 선택·오류·비활성·처리 중·자료 없음은 색만으로 구분하지 않고 문구·아이콘·테두리를 함께 쓴다. 증가/감소의 파랑/주황은 선택 색의 의미와 구분하며 부호·기준값을 유지한다. 자료 없음은 회색이고 0으로 바꾸지 않는다.

표현 기준은 CSS 토큰, 역할 배정은 공통 구성 요소, 수치·상태 의미는 데이터와 화면 상태가 맡는다. 변경 기준·공통 부품·긴 제목/큰 수치/결측을 확인하는 검사용 화면을 순서대로 정비하는 디자인 시스템 방식을 권한다. 별도 부품 전시 도구 도입은 후속 선택사항이며 이번 변경에 새 패키지를 추가하지 않는다.

## 정보량과 조작

| 화면 | 기본 노출 | 추가 정보와 옵션 |
|---|---|---|
| 모바일 | 지도 또는 현재 그래프 한 가지 | 조회·상세를 요청할 때 연다. 상권 첫 진입의 플로팅 창은 접는다. 지도 선택은 해당 상세를 연다. 긴 금액은 축약하며 정확값은 펼쳐 확인한다. |
| 태블릿 | 주영역 우선, 가능한 보조창 한 개 | 사용할 공간이 부족하면 창을 겹쳐 두지 않고 요청한 창으로 전환한다. 가로/세로 방향에 따라 폭 기준을 다시 적용한다. |
| PC | 지도와 필요한 좌우 조건·정보 | 폭이 허용하는 범위에서 동시에 표시하고 사용자가 조절한다. |

작은 화면 조작 높이44px는 이 제품의 터치 편의 기준이다. 글자와 버튼을 같은 비율로 무조건 축소하지 않는다. 그래프는 실제 영역에 맞춰 눈금 개수를 줄이고 축의 글자 크기는 보존한다. 지도 라벨은 도형 확대와 반대로 크기를 보정한다.

## 근거와 판단 범위

- [Carbon Typography](https://www.carbondesignsystem.com/building-blocks/foundations/typography/overview)는 역할별 타입 토큰과 업무용/표현용 위계를 구분한다. 이 제품에서는 한글 지도 브리핑에 맞춰 모드별 단계 수를 제한한다.
- [WCAG Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)와 [Resize Text](https://www.w3.org/WAI/WCAG21/Understanding/resize-text)는 좁은 폭과 확대에서도 내용·기능을 잃지 않도록 요구한다. 위 기기별 숫자를 WCAG가 지정하는 것은 아니다.
- 화면 폭은 장치 모델을 뜻하지 않는다. 태블릿의 분할 화면은 모바일 규격으로, 큰 가로 화면은 PC 규격으로 바뀔 수 있다.

## 변경 영향과 소유 기준

| 변경 | 직접 영향 | 간접 영향 | 유지하는 것 | 확인 방법 |

데이터 파일·집계 계산·백엔드는 영향 없음. 과거 날짜별 감사 보고는 이력으로 남긴다. 독립 와이어프레임 파일 대신 현재 실행 가능한 웹 화면을 갱신한다. 실제 휴대폰·태블릿의 터치/키보드·기본 글자 설정 및 보조기기 검사는 브라우저 폭 모의 검사와 구분한다.

## 수용 기준

- 분석은 여섯 종류 이하, 시연은 네 종류 이하. PC·태블릿·모바일에서 각각 검사한다.
- 좁은 화면에서 입력16px 이상, 지도·그래프의 주요 제목·수치·축이 잘리지 않는다.
- 조회·상세는 버튼으로 열고 닫을 수 있으며 조건과 선택 값이 유지된다.
- 767/768·1199/1200px 경계에서 토큰만 전환되고 값·모드는 바뀌지 않는다.
- 실제 브라우저 결과와 미검사 실기 범위는 별도 실행 기록에 남긴다.
