2026-11-16 · 독립 읽기 전용 소스·원자료 검토. **이 문서는 공개 브라우저 실행 통과 기록이 아니다.** 배포와 실제 Chrome 조작은 부모 에이전트가 수행하고 별도 실행 기록에 남긴다.

## 소스 판정

현재 검토 범위는 `MapPanel`, `MapCanvas`, `QueryControls`, `ExtraDashboard`, `MarketExplorer`, `MapWorkspace` 및 생활인구 상위 상태이다. R06(조회·표시·상세·의미 역할), R13(동일 상태·조건 연동), R20(동작·수치·실화면의 독립 판정)을 적용했다. 추가 중대 배포 차단 회귀는 발견하지 못했다.

- 생활인구 기본 조회는 기간 → 지역 → 대상의6필드이며, 같은 날짜·시각·지역·연령·성별 상태가 지도·요약·추이·후보를 생산한다. 응답 날짜와 현재 선택 날짜가 같을 때만 `pop`을 사용하고 이전 요청은 active 플래그로 차단한다.
- 단일 검색 선택기는 같은 입력ID에서 현재값·검색·선택·0건 복구를 제공한다. 실제 팝업은 dialog이며 `aria-haspopup="dialog"`로 맞는다. 일부 native select가 버튼형 combobox로 바뀌어 기존 selectOption 자동화는 새 클릭·검색 흐름을 사용해야 한다.
- focused 조회창은 지도 탐색·표시 포털을 받지 않는다. `MapCanvas` 지도 도구 JSX는 하나이고 표시범위·팔레트가 원자료 수치 계산에 개입하지 않는다.
- 전출입 세분 지원은 성별2021–2025 구·동, 연령2025 구를 유지한다. 생활이동 일계에서는 시각 입력을 비활성화하고 이유를 표시한다.
- 상권은 지역·이름·유형의 교집합, 관련 선택지 건수, 개별 상권 선택을 구분한다. 분할선 key는 `split-controls`/`split-details`로 패널 key와 분리되어 이전 중복 원인 후보가 소스상 해소됐다.
- 정적 요청은 상대 BASE_URL을 사용하고 Vite base는 `./`다. GitHub Pages 하위 경로에서 HTML·JS·CSS뿐 아니라 실제 자료 요청도 확인해야 한다.

## 공개 실제 실행 관문

- [ ] 배포 완료 상태와 별도로 공개 HTML이 새 JS/CSS를 참조하는지 확인한다. 캐시된 이전 목록·기존 로컬 페이지를 새 공개 실행으로 간주하지 않는다.
- [ ] 공개 주소를 새 탭에서 열고 자료 로딩 완료 후 생활인구 기본6필드·한 열·닫힘 요약·긴 슬라이더 제거를 확인한다.
- [ ] 서교동 남성20–39세18→12를 실제 입력하고 지도 선택/색·요약·그래프 값·현재 조건이 같은 대상을 가리키는지 위 기대값과 대조한다.
- [ ] 상세 시연에서 조건을 열어 같은 입력 하나에 초점이 가고, 보기를 지도 쪽으로 바꾸지 않은 채 그래프가 갱신되는지 확인한다.
- [ ] 검색0건 복구·긴 종로1·2·3·4가동·첫Esc 검색만 닫기·다음Esc 조회 닫기/초점복귀를 확인한다.
- [ ] 다른 날짜를 실제 적용해 새 자료가 로딩되는지 확인한다. 로딩 중 이전 값과 새 날짜가 섞이지 않아야 한다.
- [ ] 생활이동의 출발/도착 기준과 한시간/일계, 전출입 지표3종·세분, 추정매출 시간 구간의 지도/그래프/설명을 확인한다.
- [ ] 상권 교집합2곳과 후보/추이 연결, 도킹/플로팅/재열기 뒤 입력창1개·중복ID0개를 확인한다.
- [ ] 팔레트는 색만 바꾸고 로딩 완료된 원값은 유지한다. 색 변경 전후 로딩 단계가 다르면 불변 검증으로 사용하지 않는다.
- [ ] 1800×905와1366×768에서 실제 가로 넘침·선택값 잘림·조회창 내부 스크롤·주정보 면적을 확인한다.
- [ ] 실제 실행 버전·URL·크기·기대/실제값·스크린샷·미검사 범위를 최종 보고에 기록한다.

## 판정의 한계

소스 검토와 자료 재계산은 공개 페이지 실행을 대신하지 않는다. native 전체화면, 모든 드래그/충돌/투명도 조합, 실제 사용자 성공률은 이번 독립 검토에서 수행하지 않았다. 부모가 대체 전체화면을 검사했다면 native 전체화면 통과로 바꾸어 쓰지 않는다. 수정이 필요하면 관련 소스·자료 의미·공개 실행을 다시 확인한다.
