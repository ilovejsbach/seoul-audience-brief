# 실제 크롬 전체화면 검증 — 2026-11-16

## 검증 대상과 방법

배포된 GitHub Pages의 소스 `4e6a4d9`를 macOS의 실제 Google Chrome에서 확인했다. 브라우저 디버거를 연결하지 않고 네이티브 창의 버튼·선택창·메뉴를 조작했다. Chrome의 보기 메뉴에서 **전체 화면 종료**가 활성화되는 것을 각 자료 전환 뒤 확인했다. CSS로만 화면을 확대한 결과와 구분한다.

이전 검증 기록에서 실제 전체화면을 확인하지 못했다고 남긴 내용은 당시 실행의 한계다. 이번에는 아래 여정을 실제 크롬 자체 전체화면에서 완료했다. 다른 운영체제나 모든 브라우저까지 검증했다는 뜻은 아니다.

## 발견한 문제와 수정

상세 그래프에서 열었던 그래프 옵션이 지도 복귀 후에도 남아 실제 전체화면 지도 위에 겹쳤다.

- `FloatingQueryLayer.tsx`: 전체화면의 표시 대상은 현재 지도 패널로 한정하고, 표시 위치의 기준은 안정적인 앱 전체화면 요소로 유지했다. 다른 화면의 옵션이 끼어들지 않는다.
- `TrendExplorer.tsx`: 다른 분석 장면으로 이동하면 이전 그래프 옵션을 닫는다. 선택한 값이나 축 설정은 바꾸지 않는다.

수정 커밋: `4e6a4d9`. 빌드 성공, 테스트 70개 통과. Pages 배포 실행 `43805740165` 성공 후 배포본에서 다시 확인했다. 배포 자산은 `index-O0QtizYU.js`, `index-BEqKZe0a.css`다.

## 배포본의 실제 확인 결과

| 여정 | 결과 |
|---|---|
| 분석용에서 생활인구·생활이동·거주지 전입전출·상권 추정매출 전환 | 네 자료 모두 제목·내용이 바뀌고 실제 전체화면 유지 |
| 시연용에서 같은 네 자료 전환 | 실제 전체화면 유지 |
| 생활인구 시간·연령·성별 변경 | 적용 조건과 지도 값이 함께 변경되고 전체화면 유지 |
| 강남구 상세 → 행정동 지도 | 전체화면 유지 |
| 역삼1동 상세 → 생활인구 추이 | 올바른 지역의 그래프로 이동하고 지도 전체화면 정상 종료 |
| 추이 → 지도 복귀 → 전체화면 재진입 | 분석용·시연용 모두 정상 |
| Esc | 전체화면 종료 후 지도 화면 사용 가능 |
| 범례 열기·닫기 | 표시와 해석 내용 확인, 전체화면 유지 |
| 그래프 옵션 → 지도 복귀 → 전체화면 | 이전 그래프 옵션이 남지 않음 |
