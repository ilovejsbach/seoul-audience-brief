# 시연 그래프 집중과 화면 전환

2026-11-15 · R03/R05/R06/R07/R19/R20.

시연 상세의 주정보는 추이 그래프 하나다. 현재 지역·추이 버튼을 반복하던 큰 상자는 제거하고, 지역·조건은 제목에서 표시한다. 패널과 SVG의 실제 플롯이 메뉴 아래 남은 가로·세로를 채운다. 글자와 도형을 임의로 늘리지 않고 좌표를 다시 계산한다.

생활인구의 요일·월중, 체류·거주 기반, 연령·성별, 두 시점 분포는 ‘보조 분석’에서 선택한다. 생활이동 상대지역·거주지 이동 구성도 동일하다. 선택한 분석 한 개가 화면을 교체하고 상단 ‘추이 그래프’로 복귀한다. 긴 페이지의 아래로 이동하지 않는다. 한 분석 안의 긴 표에는 내부 스크롤을 허용한다.

두 시점 비교는 기본 숨김이며 그래프 버튼으로 여닫는 보조창이다. 기준 변경·정확값·차이·분모 의미는 유지한다. 분석용은 기존 본문 비교와 상세 조회를 유지한다.

실제 Chrome 로컬에서11개 여정,1366×768의4자료 크기 검사, 계산21개, 타입·프로덕션 빌드를 통과했다.1800×961에서 패널1744×759px, 실제 SVG1702×538.41px였다.1366×768의4자료 모두 패널566px·SVG345.41px 높이이며 가로 넘침은 없었다. 글자는14/18/24/36px 네 종류였다.

검사: 기본 비교 숨김, 큰 지역 상자 제거, 가용 공간 채움, SVG 종횡비, 비교 열기/닫기/Esc/재열기/기준 변경과 원그래프 값·높이 불변, 지수 표시. 생활인구4보조 화면의 주패널1개·스크롤0·조건 유지·복귀, 대상B 지도 적용 후20–39세 여성 그래프 반영, 이동 상대지역·거주지 구성 화면 교체, 자료/지도/모드 전환 창 정리도 확인했다.

매출2025년3→4분기 차이는 정확값+1,110,613,770,150원, 기준을2분기로 바꾸면+1,782,675,618,541원이었다. [실행 결과](../tests/presentation-focus-results.json), [독립 기준](presentation-graph-acceptance.md)을 보관한다.

모든 과거 E2E와 모든 지역·기간 조합을 다시 검사한 것은 아니다. 네이티브 전체화면·모바일 전체 경로는 이번 실행 범위 밖이다.
