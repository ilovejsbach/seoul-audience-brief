# 분석용 생활인구 상세 조회 정리

2026-11-16. R06 역할 분리, R20 실제 동작 검수 적용.

- 상세 분석 콤보에서 보조 분석 네 항목·후보 지역 비교·조회 조건 비교를 단일 모달로 연다. 분석용 본문 아래로 이동하는 중복 버튼과 조건 비교 작업대는 모달로 옮긴다. 시연용 기존 전환은 유지한다.
- 후보 지역 비교는 같은 조건의 지역 비교, 조회 조건 비교는 저장한 서로 다른 조건의 조회값 비교다. 계산 의미를 합치지 않고 진입점만 통합한다. 기존 옵션과 저장 상태를 유지한다.
- 공통 추이 그래프의 실제값·증감 기본 축과 초기화는 변화 확대 자동 맞춤이다. 기준100 보기는 기존 100 중심 편차 범위를 유지한다. 축 변경은 원자료에 영향을 주지 않으며 0 제외 안내를 표시한다.
- 화면 배치·그래프 옵션·상권 지도 표시·일반 지도 표시 설정은 분석용에서 설명 툴팁이 있는 작은 아이콘으로 제공한다. 주요 조회 조건은 이 변경의 대상이 아니다.

## 현재 검수

로컬 크롬에서 상세 콤보 여섯 항목, 한 번에 한 모달, Esc 복귀, 추이 자동 맞춤과 초기화, 그래프 옵션 열기를 확인했다. 후보 한 곳의 표시와 조건 두 개 저장·모달을 닫은 뒤 유지·기준안 재적용 후 지도 복귀도 확인했다.

서울 전체 18시 11,370,664명, 12시 11,366,460명, 기준 대비 차이 −4,204명으로 연결되었다. 빌드 및 단위 검사 70개가 통과했다.

이번 변경의 공개 배포, 브라우저 전체화면, 시연 모드 회귀는 아직 확인하지 않았다. 다른 자료의 상세 화면을 일괄 모달로 변경하지 않았다.
