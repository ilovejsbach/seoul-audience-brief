# 생활인구·상권 실제 화면 재점검과 전후 시안

2026-11-16 · **G0 실화면 표본 재점검 / G1 전후 동작 시안 / 운영 코드·배포 미변경**

## 1. 실제로 다시 본 화면

Chrome에서 공개 사이트를 열어 생활인구 분석·시연, 상권 구/상권 선택·조회·추이를 조작했다. 공개 자산은 `index-BSZ-nqvv.js`였다. 이전 보고의 통과를 이번 검사로 대체하지 않았다.

|---|---|---|
| 생활인구 분석,10/31 18시 전체, 강남구 선택 | 서비스 상단·자료/보기·지도 제목·조건칩·후보·지도 단위/확대가 위에 쌓인다. 첫 기본 진입에서 지도SVG는 y356·615.7×420px, 추이는 y1357로 떨어져 있다 | 기존 지도/추이/비교의 목적은 유지. 제목·상태를 압축하고 단일 주영역에서 선택 지역 추이로 전환. 반복 조회 입력과 선택 정보는 좌우에 역할 구분 |

[현행 측정·관찰](evidence/paired-design/live-checks.json). 계층 조회·범례 접힘·그래프 옵션·상권 확대는 이미 존재한다. 시안의 개선점은 이 기능을 새로 붙이는 것이 아니라 기본 배치·정보 위계·조작과 근거의 연결을 정돈하는 데 있다.

시안 안에서 ‘개선 전·실화면 / 개선 후·동작 시안’을 같은 표시 영역에서 교대로 본다. before는 기준 조건의 정지 캡처이고 after는 변경 가능하다. **after를 변경한 상태까지 같은 조건의 전후라고 하지 않는다.** 초기 비교 조건은 생활인구10/31 18시 전체·강남구, 상권2026Q2 전체·종로3가역이다.

현재 캡처의 원본은1366×768 또는1351×760, 모형 실제 측정 폭은1484/1647px였다. 같은 물리 viewport의 정밀 면적 비교까지 완료하지 않았으므로 면적 증가율·업무시간 개선율을 주장하지 않는다. 새 시안의 핵심은 상단 중복을 줄이고 같은 결과 영역에서 보기를 바꾸는 구조, 역할별 읽기와 실제 연결 동작이다.

## 3. 실제 자료와 의미 대조

- 생활인구는2일·25구·24시간·6집단,10/31 강남22동과 실제 경계. 구×시각에서 선택 열/동 중 하나라도 결측이면 전체를 null로 유지한다. 모형은 운영의 모든 월·연령 구간·동을 지원하지 않는다.
- 상권은 종로구74곳의6분기 유동인구·4분기 매출·59개 관련 업종, 성별 또는 시간 한 가지 주변분포. 서울 전체1,650곳 탐색은 이번 시안 범위 밖이다. 매출 결측6곳을0으로 채우지 않는다.
- 강남구18시 전체841,342.84명, 역삼1동99,775.96명. 구와 동 후보를 각각의 코드로 조회하며 범위가 중복될 수 있어 합산하지 않는다.
- 종로3가역 여성2026Q2 2,678,264명,2026Q1 2,562,184명. Q2를 협의 기준으로 Q1 검토 시 −116,080명·−4.3%, 반대 방향의 전분기 증가율은+4.5%로 분모가 다름을 유지한다.
- 종로3가역2025Q4 매출331,319,763,982원은 주정보에서3,313.2억원으로 읽고 정확값에 원단위를 보존한다. 생활인구를 매출로 나눠 전환율을 만들지 않는다.

[독립 자료 검사·출처 해시·기대값](evidence/paired-design/data-check.json) · [시안 데이터](prototypes/paired-review-data.json). 원본/기존 운영 집계는 변경하지 않았다. 과거 구조 모형의 부분 결측 합산 방식은 새 시안에서 그대로 재사용하지 않았다.

## 4. 실제 조작 확인과 독립 검토 반영

- 공개 화면: 생활인구 성/연령 변경과 지도 반영, 강남구 선택·시연 상세, 상권 자료 전환·종로구74곳·종로3가역5,792,307명·추이·부모 복귀 확인.
- 새 생활인구: 성/연령→역삼1동 상세→지도/비교 전환, 구·동 후보 각각 저장·독립 값, 협의12시 변경→상세→현재 조건 복귀→명시적 기준안 복원, 종로구 여성 전체 결측이0 아닌자료 없음임을 확인.
- 새 상권: 없는 이름0건→검색·유형 해제, 선택 상권·성별→상세→지도, 매출 전환·원값/축약값, 여성 기준안 교체→다른 분기 검토→상세 왕복→기준안 복원, 상세 안 조회 입력 열기 확인.
- 실제 before 이미지가 모형 안에서 로드되는지 두 시안 모두 확인. 새 시안 PC 분석은12/14/16/20/28px(5종), 협의는14/18/24/36px(4종), 검사한 영역의 가로 넘침 없음.
- 최종 실무 조회창은260px로 맞추고 상권 시안에서 실제260px·가로 넘침 없음을 재확인했다. 가용 폭1104px 미만은 조회창을 여는 동안 보조 정보창을 숨겨 주영역을 확보하며 접으면 다시 표시한다. 상세·빠른 조회 입력은 동시에 복제하지 않는다. 검수 캡처에는 진행 중 상태가 포함되므로 최종 동작 정의는 연결된 HTML 시안을 따른다.
- 독립 검토에서 발견한 동 후보의 구 코드 저장, 후보 비교에 다른 시간 증감 혼입, 상세에서 보기/조회 버튼의 무반응, 협의h3 글자5종, 빠른/상세 입력 중복을 수정하고 관련 동작을 재확인했다.

[모형 검수 기록](evidence/paired-design/prototype-checks.json). 좁은 폭390px 요청은 실제 모형 폭에 적용되지 않아 모바일 통과로 판정하지 않는다. 원본 캡처와 모형의 배율도 다르므로 CSS 글자 집합이 실제 발표 거리의 가독성을 검증한 것은 아니다.

## 5. 남은 범위와 다음 단계

이번 결과는 전후 **동작 시안**이다. 운영 코드·배포를 바꾸지 않았다. 실제 사용자와의 업무시간/오해/합의 효과, 모든 자료 조합, 모바일·태블릿 실기, 브라우저 전체화면, 휠/드래그·도킹·투명도, 임의 min/max 입력, CSV 내용, 장기 저장은 이번 새 시안에서 검증하지 않았다. 기존 운영 기능을 삭제하자는 뜻이 아니다.

G1 후속은 같은 물리 viewport 전후 측정과 실제 과업 평가다. 특히 실무 조건창 반복 조작과 현장 협의의 질문·대안·근거·판단 유보를 사용자와 확인한 뒤, 확정한 공통 변경만 G2에서 운영 화면에 적용한다. 새 허브·전체 메뉴 개편을 선행하지 않는다.
