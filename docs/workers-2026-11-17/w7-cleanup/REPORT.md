# 개인 경로 쓰기 제거 및 검사 시각 변경 검토

실행일: 2026-11-17T02:18:38.284265+00:00

## 수정 결과

- AGENTS.md와 지정 brief.txt를 끝까지 읽었다. `scripts/prepare-paired-design.py`에서 개인 절대경로 변수와 해당 경로에 HTML을 쓰는 구문, 총2줄을 제거했다.
- 출력은 스크립트 위치로 찾은 저장소의 `docs/prototypes/`로만 간다. 템플릿·자료 선택·직렬화·치환 방식은 바꾸지 않았다.
- 실제 기존 HTML을 덮어쓰지 않도록 임시 폴더에 수정된 스크립트와 입력6파일(총7파일)을 복사하고, 그 폴더에서 스크립트를 실행했다. 외부 요청은 없었다. 임시 폴더는 검사 후 정리됐다.

## 실제 생성 비교

명령: 임시 저장소에서 `python3 scripts/prepare-paired-design.py`. 종료코드0. 원본과 생성 결과의 바이트를 직접 비교했다.

| 대상 | 생성 크기(B) | 기존 파일과 바이트 동일 | 생성/기존 SHA256 |
|---|---:|---|---|
| `docs/prototypes/paired-population.html` | 487,980 | 예 | `d94279f18cecacd00d47b9b644ba17f85bc2a7e6e48b68956e1dbc482e07950c` |
| `docs/prototypes/paired-market.html` | 652,630 | 예 | `7f23c74187c13f69d07f97b4be7fcc6ebe96c74c3924c139f527a16ba784b3cb` |

기존 HTML2개와 검사 JSON의 실행 전후 SHA256도 같았다. 템플릿 파일 자체는 생성 대상이 아니며 읽기만 했다.

## validatedAt만 바뀐 변경의 판단

- `git diff` 원문과 HEAD/작업 파일의 JSON을 비교했다. 달라진 키는 `validatedAt` 하나뿐이다.
- HEAD: `2026-11-14T10:12:10.033345+00:00` / 작업 파일: `2026-11-16T12:47:54.234010+00:00`.
- 판단: 이번 정리에서는 이 날짜 변경을 채택하지 않고, 담당자가 당시 실행 근거를 연결하지 못한다면 원래 값으로 되돌리는 편을 권한다. 날짜만 바뀐 diff로는 같은 자료·같은 명령의 재실행을 확인할 수 없고, 현재2026 확장 자료의 검사 증거로도 사용할 수 없기 때문이다. 새 검증은 별도 실행 기록으로 보존하는 편이 명확하다.
- 실제 되돌리기는 하지 않았다. 기존 JSON의 날짜·내용·상태를 모두 그대로 유지했다.

## 범위와 한계

- 수정한 기존 작업 파일은 생성 스크립트1개뿐이고, 지정 산출물인 이 REPORT.md를 추가 작성했다. 임시 비교 파일 외 다른 프로젝트 파일은 수정하지 않았다.
- git commit/push, 외부 요청, pkill은 실행하지 않았다. 다른 작업자의 package 파일·Playwright 관련 변경은 건드리지 않았다.
- 수행한 것은 스크립트의 실제 생성·바이트/해시 비교·JSON diff 확인이다. 앱 브라우저/E2E·빌드·전체 자료 검증은 이번 범위가 아니므로 실행하지 않았다. 과거 passed를 현재 통과로 재판정하지 않았다.

결론: 개인 경로 쓰기는 제거했고 출력2종은 기존과 바이트 동일하다. 검사 날짜 변경은 판단 근거만 남기고 유지했다.
