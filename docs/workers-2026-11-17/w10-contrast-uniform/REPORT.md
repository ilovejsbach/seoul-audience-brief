# W10 PC 대비·동위 크기 검증 보고서

## 실행 범위

- 실행일: 2026-11-17
- 실행: `PLAYWRIGHT_EVIDENCE_DIR=docs/workers-2026-11-17/w10-contrast-uniform npm run test:e2e -- --project=desktop-1365 --project=desktop-1920`
- 범위: 분석용/시연용 × 생활인구/생활이동/전입전출/상권, 총 16개 여정. 모바일은 제외했다.
- 결과: 16개 여정 모두 실패(exit 1). 실행 차단은 0건이며, 모두 대비 규칙 g의 신뢰 가능한 결함 때문에 실패했다. a–f 및 h의 집계 판정은 통과했다.
- `src/`, `public/`은 수정하지 않았다. 커밋·배포도 하지 않았다.

## 수정한 검사기

1. 대비 배경은 요소 자신의 `computed background-color`부터 사용하고, 투명한 경우에만 조상 배경으로 이동한다. 반투명 색과 조상 `opacity`를 합성한다.
2. 이미지·그라데이션·SVG 텍스트는 `page.screenshot()`을 캔버스에 올려 글자 주변 픽셀을 표본화한다. SVG 글자에는 흰색 윤곽선과 지도 채움이 함께 있어 글자색·윤곽·바탕을 나눌 수 없는 경우 판정 불가로 둔다. `aria-hidden` 장식 로고도 텍스트 대비 결함에서 제외했다.
3. 키보드 `Tab`으로 실제 초점 상태를 만들었다. 초점 윤곽 인접 픽셀의 확정 대비는 측정하지 못해 판정 불가에 포함했다.
4. 결과 집계기가 `PLAYWRIGHT_EVIDENCE_DIR`의 `results.json`과 측정 파일을 읽도록 복구했다.

기존 선택 모드·지도 버튼에서 보였던 1.09:1은 버튼 자신의 배경색을 반영하지 않은 오판이었다. 최종 실행에서는 이 값이 사라졌고, 화면에서 확인된 결함은 아래 4.34:1 두 조작이다.

## 정본의 동위 묶음 및 크기 결과

R04는 같은 위계 및 같은 목적의 선택 요소를 같은 크기로 두고 선택 상태가 크기를 바꾸지 않도록 한다. R20 시각 E2E는 동위 폭·높이·기준선을 확인한다. 이에 따라 자료 탭 4개(폭·높이), 분석용/시연용 선택(높이), 상권 확대/축소(높이)만 측정했다. 지도와 상세 콤보, 역할이 다른 행의 버튼을 임의로 묶지 않았다.

- 16개 화면 여정에서 28개 동위 묶음을 측정했고 28개 모두 통과했다. 자료 탭 폭·높이, 모드 선택 높이, 상권 확대/축소 높이의 최대 오차는 모두 허용치 ±1 CSS px 이내였다.

## 신뢰 가능한 제품 결함

WCAG 기준은 일반 글자 4.5:1을 적용했다. 아래 두 조작의 대비는 4.34:1로 4.5:1보다 낮다. 각 결함은 desktop-1365와 desktop-1920, 분석용/시연용에서 재현됐다(표본에 따라 총 24건).

| 화면 요소 | 전경 / 배경 | 실측 | 기준 | 재현 범위 |
|---|---|---:|---:|---|
| “선택 구 동 지도” 버튼 | `rgb(97,114,135)` / `rgb(237,241,245)` | 4.34:1 | 4.5:1 | 두 PC 크기, 분석용·시연용, 생활인구·생활이동·전입전출 |
| “−” 지도 축소 버튼 | `rgb(97,114,135)` / `rgb(237,241,245)` | 4.34:1 | 4.5:1 | 두 PC 크기, 분석용·시연용, 생활인구·생활이동·전입전출 |

두 요소는 각 결함을 12회씩 측정했다. 실패 시점 화면은 `test-results/` 아래 `failure-*.png`와 Playwright의 `test-failed-1.png`로 보존했다.

## 판정 불가

- 지도 SVG 지역명: 400건. 캡처의 글자 주변 픽셀은 표본화했지만, 글자 안쪽 색·흰 윤곽선·지역별 지도색을 분리할 수 없어 대비비를 확정하지 않았다.
- 키보드 초점 윤곽: 16건. 초점 윤곽은 `rgb(184,91,26)`, 두께 3px로 확인했으나 인접 배경 픽셀을 신뢰성 있게 샘플링하지 못해 대비비는 판정 불가다.
- `aria-hidden` 장식 브랜드 표시 `▦`: 16건. 검사기는 부모 배경을 잘못 연결해 낮은 값으로 보고했지만, 장식용이며 접근성 트리에서 숨겨져 있어 텍스트 대비 제품 결함으로 세지 않았다.

## 통과 및 실패 집계

- 대비 표본: 신뢰 가능한 통과 1,220건, 신뢰 가능한 결함 24건, 판정 불가 432건(지도 SVG 400 + 초점 16 + 장식 표시 16).
- 동위 크기: 28개 묶음 모두 통과.
- 기존 a–f 측정: a 200, b 272, c 200, d 184, e 32, f 200개 판정이 통과했다.
- Playwright 여정은 g의 결함으로 16/16 실패했다. 나머지 통과를 전체 여정 통과로 표시하지 않는다.
- `summary.json`, `RESULTS.md`, `results.json`, 화면 PNG 및 각 여정의 `measurements.json`에 원 결과를 보존했다.

## 한계

현재 자동 픽셀 표본만으로는 윤곽이 있는 지도 글자와 초점 링 대비를 확정할 수 없다. 이 둘은 실패로 몰아넣지 않고 판정 불가로 분리했으며, 판정 기준을 낮추지 않았다. 제품 결함 두 항목의 수치와 h의 크기 판정은 이번 PC 실행에서 재현됐다.
