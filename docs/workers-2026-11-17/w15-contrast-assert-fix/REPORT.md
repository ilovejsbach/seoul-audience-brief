## 대조 실험

1. 시작 시 `src/readability.css` 전체 바이트·SHA256과 `git diff`를 저장했다.
2. 지정된22줄의 일반 disabled 버튼 글자색만 `#5b6b80` → `#8a99ab`으로 임시 변경했다. 나머지 두 선언은 유지했다.
3. 1365px 생활인구 분석 여정을 실제 실행했다. **종료1**, g가 신뢰 가능한 미달2건으로 실패했다.

4. 실험의 finally에서 원래 바이트로 복원했다. 최종 실행 후에도 다시 대조했으며 시작 바이트·diff 모두 같았다. 남은 CSS diff는 W14의 **세 선언 변경만**이다. SHA256은 `fcadbbc9112afbb983782502b637e467eb3d26e1852a12b89195e5704fa36fb7`이다.

## 판정 불가와 장식 제외

| 구분 | 수 | 처리 |
|---|---:|---|
| 윤곽선이 있는 지도 SVG 글자 | 400 | 글자 칠·윤곽·지도 배경을 픽셀로 신뢰성 있게 분리하지 못해 판정 불가 |
| 초점 테두리 | 16 | 인접 픽셀의 별도 대비 판정이 필요해 판정 불가 |
| **판정 불가 합계** | **416** | g 단언에서는 제외하되 요약·상세 내역 유지 |
| aria-hidden 장식 텍스트 | **36** | 로고16개와 선택기 화살표20개. 판정 불가와 별도 excluded 목록 유지 |

최종 `summary.json`의 `contrastAudit.indeterminate`와 `contrastAudit.decorativeExcluded`에 각 항목이 남아 있다. 규칙 단언 자체의 판정 불가0과 텍스트/초점 샘플의 판정 불가416은 다른 수치다. 수정된 보고서도 이 차이를 설명한다.

## 한계

- 이번 통과는 지정 PC 두 크기의 현재 로컬 Chromium 검사다. 공개 배포·사용자 Chrome·모바일·패드·실물 기기·인쇄·모든 설정/툴팁·모든 조회 조합·전체 WCAG 인증을 뜻하지 않는다.
- g는 기본 지도 진입 장면에서 측정한다. 위416개 항목의 실제 대비가 충분하다고 승인하지 않았으며 별도 시각/픽셀 검토가 필요하다.
- 색 파서는 쉼표형 rgb/rgba를 지원한다. 지원하지 않는 computed 글자색은 판정 불가로 보고한다. 이미지·그라데이션·윤곽선 등 복잡한 화면의 자동 추정 한계도 남아 있다.
- aria-hidden이 올바르게 장식에 부여됐다는 제품 의미는 별도 접근성 검토 범위다. 이번에는 지정된 장식 제외 정책을 적용했고, 클래스명 예외가 실제 글자를 숨기지 않는지 별도로 대조했다.
- src에는 대조 실험의 임시 색 변경만 했고 반드시 원복했다. 외부 요청·배포·git commit/push/reset/checkout/clean은 수행하지 않았다.

결론: 장식 오탐은 해소했고 실제 대비 미달은 계속 잡는다. 요청한 전체 명령은 종료0이며, 판정 불가416건은 후속 검토할 수 있도록 그대로 남겼다.
