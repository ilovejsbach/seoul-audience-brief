## 4. 실제 화면 1365×768 분석·시연

새 날짜 전용 검사는 원자료 독립 계산 JSON을 기대값으로 사용했다. 브라우저의 외부 요청을 차단했고 두 모드에서 외부 요청/페이지 오류는 0이었다. 실제 `innerWidth=1365`, `innerHeight=768`, `visualViewport.scale=1`, 보이는 날짜 입력1개를 기록했다.

- 기본일 2026-11-12, 선택기 min2026-01-01/max2026-11-12를 확인했다. 일별 인덱스는 `?v=daily-20260101-20261112`, 패턴 인덱스는 `?v=20261112`로 실제 요청됐다.
- 11/12 12시 서울 전체 원값 **11,887,067.79명**이 화면에서는 **11,887,068명**으로 반올림됐다. 청운효자동 `11110515` 원값 **27,454.80명**은 **27,455명**이며 실제 다운로드 CSV에는 원수치가 남았다.
- 요일·월구간 화면에서 ‘2026년11월 · 12일까지12일 관측’ 안내를 확인했다. 요일 기본 두 그룹의 1/1일, 월초 평균11,587,662.52명/10일, 월말 자료 없음/0일이 독립 계산과 맞았다. 월말을 0명으로 표시하지 않았다.
- 10/31→11/01 전환 후 청운효자동12시 원값18,309.23명/화면18,309명을 확인했다. 10/31은 기존 HEAD와 바이트 동일한 파일로 복귀했다가 다시 새 월로 전환하는 여정이다.
- 추이 팝업→본문에서 날짜를11/12로 변경→지도 복귀 후 날짜11/12·12시·청운효자동·원값이 유지됐다. 별도의 카메라 변형은 이번 여정에 넣지 않았다.
- 최신 서울/동 지도, 요일 화면, 월 구간 화면, 복귀 화면을 각 모드로 촬영했다. 그중 서울 지도·월 구간·동 지도 대표4장을 실제로 열어 기간·단위·자료 없음 표기를 확인했다.

전용 검사 명령:

```sh
npm run test:e2e -- --config docs/workers-2026-11-17/w13-verify-population/new-date.config.mjs
```

최종 증거: `new-date-final-results.json`, `new-date-final-artifacts/`의 모드별 PNG·`dong-raw.csv`·`observations.json`.

최초 전용 검사에서는 상세 호스트가 이미 자동으로 열어 준 native details의 숨겨진 summary를 다시 클릭하려 해 진행이 멈췄다. 평가자가 그 실행만 Ctrl-C로 중단하고(종료130, 분석1건 중단·시연1건 미실행), 검사 스크립트를 ‘이미 open인지 확인’하는 방식으로 바꿨다. 제품 소스는 바꾸지 않았다. 이전 `new-date-results.json`/`new-date-artifacts/`는 중단 이력으로 보존하고, 최종 2/2와 구분한다.

## 5. 코드 리뷰·심각도

이번 현재 자료와 소스에서 P0/P1은 발견하지 못했다. 별도 Codex 읽기 전용 검토도 같은 결론이다. 다음 두 건은 **후속 갱신·재생성의 P2 위험**이며 현재11/01–12 수치 불일치는 아니다.

| 심각도 | 위치 | 위험·후속 권고 |
|---|---|---|
| P2 | `src/PopulationPatterns.tsx:22` | 프로필 파일 URL과 메모리 캐시 키가 `file.path`뿐이다. 인덱스만 새 버전을 써도 다음11월 확장 시 동일 `202611-*.json`의 이전12일 응답이 남을 수 있다. 프로필 URL/메모리 키에 자료 버전·해시를 함께 반영하는 것이 좋다. 이번11월은 신규 경로이므로 기존 공개10월 자료와 충돌하지 않아 현재 배포 차단은 아니다. |
| P2 | `scripts/prepare-population-patterns.py:96` | 기존 요약을 temporary.replace로 교체하며, daily 생성기처럼 기존 파일과 달라질 때 거부하는 보호 장치는 없다. 이번120개 기존 요약 불변은 HEAD 대조로 확인했지만, 다음 재실행의 잘못된 월 선택·원문 변경까지 자동 보호하는 것은 아니다. 기존 범위 가드 또는 명시적 교체 정책이 필요하다. |

그 외 검토: 기본일은 정렬된 인덱스 마지막 날짜에서 정해지고, 날짜 변경 시 이전 응답의 날짜와 현재 날짜를 비교해 오래된 값을 새 제목 아래 표시하지 않는다. 부분월 분모는 `dates`의 실제 그룹 날짜만 사용하고, 구/서울 합산의 결측 전파와 평균의 유효일 제외는 독립 전수 계산과 맞았다. 수집기는 네트워크 모드가 명시적이고 원본 덮어쓰기를 거부하며 오프라인 검사를 제공한다. 이번 평가에서 수집기의 외부 요청 모드는 실행하지 않았다.

## 범위·최종 인계

이번 생활인구12일 추가에 한해 배포 가능하다고 평가한다. P2 두 건은 후속 위험으로 남기며 다음11월 자료 갱신 전 우선 검토를 권고한다. g/h는 별도 담당·감독자가 판단할 기록이다. 모바일·태블릿·인쇄·공개 서비스·모든 조합·전체화면/카메라 변형·전체 합성색 대비는 이번 독립 검수의 완료 범위가 아니다. 공개 배포 후에는 새 날짜 선택지·자료/자산 버전·대표 원값을 별도로 확인해야 한다.

소스·데이터 수정, 커밋·푸시·배포, 외부 요청, pkill은 하지 않았다. 지정 산출물 폴더에만 평가 코드·JSON·스크린샷·로그를 작성했으며, 요청된 build가 만든 dist/빌드 캐시는 검사 산출물이다. 최종 대상35파일의 시작/종료 해시는 동일하다.
