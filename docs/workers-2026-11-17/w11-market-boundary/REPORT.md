# 작업자11 — OA-15560 상권 경계 최신 파일 확보·동일 확인

2026-11-17. 작업 시작 HEAD `5565929`, main. **공식 최신 내려받기 ZIP이 기존 2023 원본과 바이트까지 동일하므로 운영 경계와 소스를 반영·변경하지 않았다.** 최신 페이지 갱신일을 최신 형상 제작일로 취급하지 않는다.

## 방법·작업 범위

AGENTS/NEXT-SESSION, R13/R18/R19/R20, 개발 요구사항, 상권 매출 독립 감사, 기존 prepare/collect 코드를 읽었다. 기존 코드/키·값·null·형상은 그대로 유지하는 조건으로, 공식 파일 확보→원본/준비 형상 비교→연결/유효성 재측정→현재 검사 실행을 수행했다.

### PC 실패를 분리한 결과

이번 검사 작업본은 다른 작업자가 추가한 g(대비)/h(도구 크기)를 포함한다. 과거 PC 16/16 통과 기록과 같은 검사 묶음이라고 간주하지 않는다.

1. **g 대비 실패 16여정 — 검사 계산 오류 확인.** contrast 함수가 자식→조상 순서로 배경을 합성하여 불투명한 버튼 배경을 body 색으로 덮는다. 결과는 흰 글자/밝은 body 배경 비율 1.09로 보고되지만, 실제 선택 모드 버튼과 ‘지역 분석 지도’ 버튼의 computed background는 `rgb(36,85,139)`, foreground는 `rgb(255,255,255)`였다. 해당 두 버튼에 대해 보고된 1.09 판정은 실제 버튼 배경을 사용하지 않은 검사 오류다. `screen-failure-diagnosis.json`에 DOM 조상색까지 저장했다. 전체 UI 대비를 통과 판정한 것은 아니다.
2. **h 도구 크기 실패 4개 상권 여정 — 실제 차이·검사 위계 검토 필요.** 화면에서 상세 select 33px, 지도 표시 36px, 출처/내려받기 30px, 줌 버튼 28px를 측정했다. 검사기는 다른 역할/행의 이 항목들을 하나의 동위 그룹으로 비교한다. 이 그룹 범위가 R04 동위 기준에 맞는지와 실제 크기 불균등의 처리 범위는 담당자가 검토해야 한다. 이번 경계 동일 확인으로 생긴 회귀라고 볼 근거는 없으며, 통과로 덮지 않았다.
3. **초기 1920 여정 3개 execution-context 중단 — 재실행에서 미재현.** analysis/market, presentation/market, presentation/population에서 페이지 navigation으로 context가 사라졌다. 원인은 확정하지 않았다. 같은 3개를 별도 출력 폴더로 재실행하니 navigation 중단은 없었고 g/h만 남았다. 최초 중단 이후 미실행 구간과 재검사 결과를 구분해 보존했다.

최초16건의 실패 rule 수는 g16/h4/context3이다. g/h는 soft assertion이라 가능한 후속 여정은 계속 실행했다. 최초 실행에서 a175/f175/b236/c175/e28/d157개 체크가 통과했으나, 이것을 전체 E2E 통과로 부르지 않는다. 재검사 3건에서도 g/h 외의 실행된 규칙은 통과했다. 허용 범위 밖인 제품 스타일·기능·tests/e2e 소스를 고치거나 실패 기준을 완화하지 않았다.

증거: `pc-e2e-results.json`, `pc-e2e-summary.json`, `pc-e2e-artifacts/`의 측정/실패 PNG/trace, `pc-navigation-recheck-results.json`, `pc-navigation-recheck-summary.json`, `pc-navigation-recheck-artifacts/`, `screen-failure-diagnosis.json`. 모바일은 사용자 지시로 보류했고 실행하지 않았다.

## 5. 변경 파일과 감독자 통합 제안

**운영 파일 변경 없음.** 새로 쓴 것은 raw의 신규 ZIP 한 개와 지정 산출물 폴더의 수집/감사/검증 증거·보조 스크립트·보고서뿐이다. `scripts/prepare-market-areas.py`, `public/data/market-areas.geojson`, src, README, NEXT-SESSION은 수정하지 않았다. 커밋·푸시·배포·pkill을 하지 않았다.

README에 제안할 문구:

> 2026-11-17 공식 OA-15560 최신 내려받기 ZIP을 다시 확인했으며 기존 2023 파일과 바이트·1,650개 코드/형상이 동일했습니다. 따라서 경계는 교체하지 않았고, 자기교차 6건·원문 명칭 차이 3건과 2026 실제 형상/소속 미검증 한계는 유지합니다.

NEXT-SESSION에 제안할 문구:

> OA-15560 최신 파일 재확보 결과 기존 2023 원본과 동일하여 운영 반영 없음. w11 보고서의 해시·좌표·연결 검증을 참고한다. PC 최신 회귀는 g 대비 계산 및 h 도구 그룹/크기 검토가 남아 전체 통과가 아니며, 모바일은 보류한다.

## 한계·최종 판정

**경계는 ‘동일 확인’, 자료 검사는 통과, 현재 PC 전체 회귀는 실패 상태로 보고한다.** 공식 최신 파일이라는 사실만으로 2026 경계 형상 최신성을 보증하지 않는다. 기존 결함 도형을 임의 수선하지 않았고, 경계 변경이 없으므로 화면의 2023 기준도 유지했다. PC 실패 항목은 담당 작업자/감독자가 별도 처리해야 한다. 공개 서비스에는 이번 작업을 배포하지 않았다.
