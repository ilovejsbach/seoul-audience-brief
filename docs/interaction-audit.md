# 상호작용 독립 감사 기록

2026-11-14 현재 소스와 실제 데이터 파일을 대조한 기록이다. 브라우저의 최종 검증은 별도로 진행한다. 이 문서의 발견 항목은 작성 시점 코드 기준이며, 아래 검증 기준을 충족하기 전에는 수정 완료로 표시하지 않는다. Hero는 별도 작업 중이므로 감사 대상에서 제외했다. 감사 중 UI 소스는 수정하지 않았다.

## 발견 사항과 수정 검증 기준

### P2 — 과거 연도 구 자료가 있어도 CSV 저장이 비활성화됨

- 재현: 거주지 전입·전출 → 2001~2014년 → 자치구 선택.
- 근거: `ExtraDashboard`는 `selected`/`activeStats`에 공식 구 자료를 가져오지만 `stats`는 해당 구의 동 자료를 필터한다. 이 기간의 동 자료는 없어 `stats.length=0`이고 CSV 버튼은 이 값으로 비활성화된다.
- 기대: 실제 내보낼 `activeStats`가 있으면 저장 가능해야 한다. 2010년 마포구 선택 시 구 1행을 저장하고, 2015년 이후 동 선택은 해당 동 1행을 저장하는지 확인한다. 결측은 빈 값으로 유지한다.

### P2 — 시연 단계에서 후보 비교 바로가기 무반응

- 재현: 시연용 → 1단계 지역 살펴보기 또는 2단계 시간 흐름 비교 → 퍼널의 후보 비교 n/3 클릭.
- 근거: 호출부는 `scrollIntoView`만 실행하지만 해당 단계 CSS에서 `.compare`가 `display:none`이다.
- 기대: 후보지 브리핑 단계로 전환한 후 현재 탭의 비교 영역으로 이동한다. 분석용에서는 현재 페이지의 후보 영역으로 이동하고, 후보가 없을 때도 비어 있는 상태와 돌아가는 방법이 보여야 한다.

### P2 — 음수 지도 수치의 범례가 0~양수만 표시됨

- 재현: 생활이동 또는 거주지 이동 → 지도 지표 순이동 → 음수 지역이 있는 기간 선택.
- 근거: 음수 지역은 주황으로 표시하지만 `MapCanvas` 범례는 0과 절댓값 최댓값만 표시한다. 색으로 표현한 음수 범위를 수치로 확인할 수 없다.
- 기대: 음수·0·양수의 방향과 범위를 함께 읽을 수 있어야 한다. 양수 지표는 순차 범례를 사용한다. 음수 값을 0으로 바꾸거나 음수의 절댓값을 양수 값으로 읽게 해서는 안 된다.

### P2 — 분석용의 지역 선택 돌아가기 버튼 무반응

- 재현: 분석용 → 비교 후보가 없는 상태 → 후보 영역의 “지역 선택 화면으로 →” 버튼 클릭.
- 근거: main의 버튼과 ExtraDashboard의 이벤트는 `presentationStep=0`만 설정한다. 분석용에서는 이 상태가 화면 배치를 바꾸지 않으며 지역/지도 영역으로 스크롤하지 않는다.
- 기대: 분석용에서는 현재 탭의 지역 필터 또는 지도/순위로 이동한다. 시연용에서는 첫 단계로 전환한 뒤 해당 영역을 보이게 한다. 분석용과 시연용 모두 키보드로 작동하는지 확인한다.

## 기존 주요 계산 항목 재확인

- 생활인구 날짜 변경 시 원본 상태 초기화와 로딩/오류 시 CSV 비활성화가 추가되어 이전 날짜 수치를 새 날짜로 저장하던 위험이 줄었다.
- 성별·연령 선택은 실제 컬럼과 대응하며 일부 값이 결측이면 합계도 결측으로 처리한다.
- 거주지 이동은 공식 구 총계와 동 값을 level로 구분한다. 한쪽 전입·전출이 결측이면 순이동도 결측이다.
- 상권 구 선택 시 기간 추이는 구 단위 집계에서 값을 찾도록 수정되어, 동 코드와 구 코드 비교 때문에 전부 결측이 되던 문제는 현재 코드에서 해결되었다.
- 생활이동은 구내 이동을 제외하고 출발시각 기준으로 계산·설명한다. 원본의 구내 포함 여부와 화면 집계 기준을 구별한다.
- 생활인구 CSV는 선택 동과 성·연령 조건을 반영한다. 다른 자료 CSV에도 출발시간/매출 시간구간이 포함된다.
- 두 시점 비교는 결측을 전파하고 단순 차이만 계산한다. 모집단이 다른 지표 간 비율이나 광고 전환율을 만들지 않는다.

## 남은 브라우저 확인

전체화면 진입·종료, 데이터 종류 변경 후 포커스, 지도 드래그 직후 오클릭 방지, 팝업 Esc·닫기·상세·후보 추가/해제, 동 경계 결측 안내, 두 시점 비교와 CSV 값 일치, 시연 단계 이동 및 인쇄 범위를 실제 화면으로 확인한다. 숨긴 탭이나 단계의 버튼을 소스상 연결된 것만 보고 통과시키지 않는다.
