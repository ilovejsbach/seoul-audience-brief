## 발견하여 수정한 문제

1. **지도 드래그 후 전체 화면이 사라짐**: 포인터 종료 후 비워진 이동 기준을 읽는 문제. 이동 기준을 먼저 복사하고 포인터 종료·취소를 정리했다. 실제 마우스 드래그와 휠로 재검사했다.
2. **자료가 없는 과거 동에 상세/비교 진입 가능**: 미연결 경계의 행동을 제한했다. 모든 시간이 결측인 후보는 임의의 “최대 00:00” 대신 자료 없음으로 표시한다.
3. **자료 요청 실패 시 기술적인 오류만 표시**: 한글 안내와 같은 조건 재시도 버튼을 추가했다. 실패 중 이전 값과 내보내기가 남지 않는지 검사했다.
4. **인쇄에서 출처 누락**: 인쇄 중 현재 자료 설명만 펼치고 인쇄 종료 후 접힘 상태를 복원한다. 시연 장별 숨김 규칙도 수정했다.

## 실행 자료와 범위

- `tests/cua-e2e.mjs`: 문서화된 CUA Chrome Tab을 전달해 사용하는 시나리오 실행기.
- `tests/e2e-fixtures.json`: 실제 자료에서 독립 계산한 기대값 21건.
- `tests/e2e-artifacts/results.json`: 최종 브라우저 실행 기록.
- `tests/e2e-artifacts/data-validation.json`: 독립 자료 검증 결과.
- `docs/e2e-audit-findings.md`: 수정 전 독립 정적 감사 기록.

브라우저 실행은 `createSuite(tab)` 이후 `suite.run(id)`를 순차 호출한다. `network-failure`는 **검사용 dist 복사본에서만** 20261030 생활인구 파일을 잠시 제외한 뒤 실행하고 반드시 복원한다. 운영 파일을 변경하지 않는다. 인쇄는 실제 PDF 미리보기까지 확인했으며 종이 인쇄는 실행하지 않았다. 모든 브라우저·모든 해상도·모든 가능한 조건 조합을 보증하는 전수 검사는 아니다. 현재 제공 기능의 대표 정상·경계·오류·복귀 경로를 검사했다. 초기 잘못된 대기 조건에 의한 검사 실패는 로딩 완료 대기로 수정했으며 제품 결함 수에는 포함하지 않았다.
