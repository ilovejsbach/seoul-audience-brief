# 지도 중심 조회와 브리핑의 현재 설계 기준

이 문서는 현행 조작 계약이다. 개선의 우선순위와 두 트랙 단계 설계는 [작업공간 설계 v2](expansion-workspace-design.md)를 따른다. 현재 화면의 공간·가독성·연동 개선보다 새 IA 개편을 앞세우지 않는다.

2026-11-15 개정. 구현 여부는 실행 검증 보고와 구분한다. 이전 문서의 '2013년 경계·동 지도 미지원·출발시간만 제공' 전제는 폐기한다. 현재 공식 구·동 경계와 출발/도착 생활이동을 지원하되 자료별 시점·단위의 한계를 유지한다.

## 목적과 화면 방식

광고주가 **어느 지역과 시간대를 추가 조사할지** 근거를 가지고 비교하도록 돕는다. 인구가 많다는 이유만으로 광고 도달·매출·전환율이 높다고 결론 내리지 않는다.

- 지도 중심 조회: 왼쪽 조회 메뉴는 ‘자료·기간 / 지역·상권 / 분석 대상’의 현재값 요약으로 시작한다. 항목 하나를 고르면 해당 하위 편집 화면 하나만 보이고 ‘조회 항목으로’ 돌아가 다른 항목을 자유롭게 고른다. 순서나 단계 완료는 없다. 기간·구/동·검색·유형·업종·세부 기준은 같은 상태를 유지하며 중앙 지도·상세·후보 비교에 적용한다. 왼쪽 조건/오른쪽 상세는 기본 배치이고 사용자가 좌우 고정·플로팅으로 조절한다. 상권 추이는 지도 중앙 창에서 확인하고 닫으면 같은 지도 위치로 돌아온다.
- 분석용: 기존 구·동 인구·생활이동·거주지 이동·행정동 매출의 상세 도구를 유지한다. 지도·추이·후보 간 직접 행동을 제공한다.
- 시연용: 자료 종류를 먼저 선택하고 같은 조건·계산을 지도/상세 분석/후보 비교로 자유롭게 본다. 순서나 진도는 부여하지 않는다. 상세 분석에는 시간 추이뿐 아니라 구성·요일·거주 기반 비교도 포함한다. 시작 화면·분석 화면·지도 조회 사이 복귀는 실제 이전 화면을 기준으로 한다.

## 각 도표가 답하는 질문

| 도표 | 판단 질문 | 의미와 범위 | 후속 행동 |
|---|---|---|---|
| 생활인구 지도 | 선택 시간에 어느 지역에 많이 머무는가? | 내국인 시점별 추계 명, 고유 방문자 아님 | 구→동, 동→추이, 후보 비교 |
| 두 시점 분포/증감 지도 | 두 시간 사이 어느 지역이 늘고 줄었는가? | 같은 날짜·성별·연령, 공통 색상 눈금, 결측 증감 미계산 | 시간 변경, 지역 선택 |
| 생활이동 지도·상대지역 | 언제 어느 지역에서 오고 어디로 가는가? | 출발/도착 시각, 시간대/누적/원본일계, 추정 이동 건수, 구내 이동 제외 | 선택 구 추이, 상대 구 탐색·후보 |
| 거주지 전입·전출 | 거주지 이동의 장기 방향은 무엇인가? | 구/동 연간 전입·전출·순이동, 행정구역 변경 주의 | 연도/지역 변경, 두 시점 차이 |
| 행정동 매출 | 동일 제공 업종의 분기·시간구간 매출이 어떻게 변했는가? | 분기 원 단위 추정매출, 개별 점포 회계매출 아님 | 동 선택, 전분기 비교 |
| 상권 지도 | 어느 상권의 유동인구 지표·소비 지표가 큰가? | 상권 경계, 선택 자료/분기/업종/한 가지 주변분포 | 상권 선택, 분기 추이, 후보·CSV |
| 시계열 | 어느 시점의 규모·변화가 비교할 만한가? | 원값/차이/양수 기준 100, 결측 비연결 | 시점 선택·재생, 지도 복귀·후보 |

## 수치와 축의 계약

1. 장식용 상태 숫자(분기·후보 0 등)를 주요 KPI로 쓰지 않는다. 인구는 현재 값·공개 시점 중 최대·직전 차이, 이동은 유입·유출·차이, 매출은 현재·직전 분기·차이로 판단 근거를 제시한다.
2. 공개값이 일부 없으면 '하루 최대'라고 단정하지 않는다. 공개된 시점 개수와 그 범위 내 최대를 표시한다.
3. 세로축은 0 포함(기본), 변화 확대(관측 범위+여유), 직접 지정으로 나눈다. 0 제외와 범위 밖 점 수를 공개한다. 축 변경은 원자료·지도·CSV 값을 바꾸지 않는다. 단위가 바뀌는 표시 전환은 축을 초기화한다.
4. 기준 100은 기준값이 양수일 때만 계산한다. 음수 순이동은 값의 차이로 비교한다. 0 이하 기준에서 증감률을 만들지 않는다.
5. 마우스 미리보기와 실제 선택 시점을 구분한다. 마우스 오버는 조회 조건을 바꾸지 않고, 일반 지도 클릭은 지역 옵션·작은 핵심 지표·추세·CSV를 같은 지역으로 바꾼다. 일반 구 지도와 카메라는 유지하고 명시적 상세 동작에서만 공간 단위를 확대한다. 상권 지도에서는 상권 도형 클릭이 선택 상권 경계 확대와 정보 연동이고, 자치구 배경·구 이름 클릭은 구 필터와 경계 맞춤을 실행한다. 상위 지도 복귀는 이전 범위를 복원하며 기간·검색/유형·분석 기준·후보를 유지한다.
6. 상권 인구의 일평균 환산식은 확정하지 못했다. 공개 CSV는 '분기 제공 유동인구 지표·명(원본 추정치)'로 제시하고 하루 고유 방문자라 부르지 않는다. 성별·연령·시간·요일은 주변분포이므로 교차 비율을 만들어내지 않는다.
7. 상권 경계는 2023년, 매출은 2025년, 인구는 2021Q1–2026Q2다. 코드 연결은 확인했지만 통계 시점의 동일 형상은 미검증이다. 원본 도형 오류 6개를 보정한 것처럼 표현하지 않는다. 겹칠 수 있는 상권 전체를 서울 총계로 합산하지 않는다.

## 의미 설명과 판정

주요 지표의 설명 버튼은 의미·해석·주의와 필요한 출처를 보여준다. 선택한 시간 기준·누적/일계·방향·연도·분기가 설명에도 반영되어야 한다. 마우스·키보드로 열고 닫으며 화면/부모 영역에 잘리지 않아야 한다. 값의 출현만으로 통과시키지 않고 원자료의 같은 범위·단위·열·전분기·분모·결측 정책까지 검사한다. [의미 판정 기준](semantic-acceptance.md)과 [실제 결과](semantic-e2e-report.md)를 따른다.

## 색과 가독성

흰색·연회색 표면, 짙은 남색 글자, 하나의 남색 강조색을 기본으로 한다. 지도는 기본 파랑 또는 선택한 청록·자주 팔레트로 값의 크기를 나타내며, 증감은0 중심 대조색·부호·중립색을 보존하고 자료 없음은 별도 회색이다. 선택·결측·증감을 색만으로 구분하지 않으며 제목·수치·윤곽·범례를 같이 제공한다. 긴 금액은 범례에서 억/만으로 축약하되 상세와 CSV에 원값을 보존한다. IBM Plex Sans KR를 유지하며 [기기별·역할별 폰트 규칙](responsive-typography.md)을 적용한다. 옵션은 조작 크기, 설명창은 읽기 크기를 사용하고 출처·각주만 보조 크기로 둔다.

### 지도 색상 시작값 조정 (2026-11-14)
- 기본 지도에 ‘0 포함 · 규모 비교’와 ‘관측 최솟값 아래 · 차이 강조’를 제공한다. 후자는 현재 표시 지역의 최솟값 − (최댓값 − 최솟값) × 여유율(기본10%, 입력0–100%)을 하한으로 쓰며 비음수 자료는0 아래로 내리지 않는다.
- 구·동·시간·타깃 변경시 표시 지역 전체로 다시 계산한다. 지도 확대·이동은 범위를 바꾸지 않는다. 색상·범례만 변하며 원수치·순위·내려받기는 변하지 않는다. 두 시점 나란히 비교의 공통 눈금은 유지한다.
- 음수가 포함되면0 중심 대칭 범위를 유지한다. 결측은 회색이며 최솟값 계산에서 제외한다. 같은 값만 있으면 유한한 여유 구간을 적용한다. 범례 및 도움말에 적용 범위와 계산 의미를 표시한다.

## 조회 조건과 배치의 동작 계약

현재 조건은 짧은 칩에서 읽고 수정하며 해당 항목만 해제한다. 상권 칩은 해당 자료·기간/지역·상권/분석 대상 하위 편집 화면을 바로 열고 실제 입력으로 이어진다. 상위 항목 목록과 하위 편집을 동시에 길게 펼치지 않으며 같은 입력을 복제하지 않는다. 항목 복귀·다른 항목 진입·창 이동은 조회 조건을 초기화하지 않는다. 지역·검색·상권 유형의 해제는 후보·기간·표시 설정을 지우지 않는다. 검색 선택지는 현재 다른 조건에 관련된 값과 건수를 제공하고 현재 선택한0건은 해제 가능하게 남긴다. 미지원 성별·연령·기간 조합은 실제 확보 범위만 선택한다.

상세/후보 화면의 조건 편집은 원래 입력 하나를 외부 조회창으로 열어 현재 보기를 유지한다. 입력 ID를 복제하거나 숨긴 지도 화면으로 스크롤하지 않는다. 분석은 고정 조회 기본, 시연은 접힌 조회 기본이며 필요시 같은 입력을 연다. 생활인구 조회는 기간 → 지역 → 분석 대상의 한 열로 읽으며 기본은 날짜·시각·구·동·연령·성별 여섯 항목이다. 기준일 달력에서 제공 기간을 바로 선택하고 별도 월 선택은 두지 않는다. 시간 슬라이더·이전/다음 시간은 기간 안의 ‘시간 빠르게 이동’을 펼쳤을 때만 제공한다. 정확 시각 선택과 현재 시각 칩은 유지한다. 검색은 별도 버튼 없이 하나의 검색 내장 선택기에서 시작한다.

조회·선택 정보·순위 창은 충분한 지도 공간에서 좌우에 붙이고 떼어내 이동·크기를 조절한다. 플로팅 배경 불투명도50–100%는 표현 설정이다. 글자·버튼은 유지하고 붙으면100%, 다시 떼면 앞선 값으로 돌아온다. 범례/의미 툴팁은 다른 역할이므로 같은 큰 창으로 바꾸지 않는다.

조회·표시·창 설정·결과 작업은 서로 다른 역할이다. 상권 조회의 세 상위 항목은 원값을 바꾸는 조건만 담당한다. 색상·범위는 지도 표시, 좌우 고정·분리·불투명도·위치/크기 초기화는 창 설정으로 분리한다. 조회창 기본280px·조절260–360px, 플로팅360×560px에서 한 열 순서를 유지한다. 지도 탐색·색상/범위는 지도 가까이에, 축은 그래프 옵션에, 내려받기는 결과 도구에 둔다. 창 제목의 ‘창 설정’ 안에 배치·투명도·위치/크기 초기화를 모은다.

생활인구의13개 조회 여정은 당시 Chrome1800×905와1366×768에서 각각 부모가 실행 확인했고, 전체화면 대체 화면의 단일 조회 입력도 확인했다. 상권의 계층 조회와 구 지도 탐색은2026-11-16 갱신 계약이며 이번 전수 실화면 결과는 부모의 별도 실행 보고로 확인한다. 이 문서 갱신 자체가 전수 실행 통과를 뜻하지 않는다. 현재 상권 갱신은 소스969bf87·공개 배포d6041 이후 부모가 공개 실화면 검수 중이다. 배포 성공과 전체 기능 통과는 별개다.
