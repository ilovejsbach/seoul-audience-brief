# 분석용 상세 조회 모달 통합

2026-11-16. R01 목적 보존, R05 공간, R06 역할 분리, R20 실제 실행 기준을 적용했다.

## 화면별 적용

| 화면 | 상세 분석 콤보 | 지도에 남긴 정보 |
|---|---|---|
| 생활인구 | 요일·월중 특성, 체류·거주 기반, 연령·성별 비교, 추이, 후보, 조회 조건 비교 | 지도·순위·선택 지표 |
| 생활이동 | 시간대별 추이, 이동 상대지역, 지역 상세표, 후보, 조회 조건 비교 | 출발/도착·집계 기준과 지도·순위·선택 이동량 |
| 전입·전출 | 기간별 추이, 연령·성별 구성, 지역 상세표, 후보, 조회 조건 비교 | 연도·인구 세분·전입/전출/순이동 선택과 지도 |
| 행정구역 추정매출 | 기간별 추이, 지역 상세표, 후보, 조회 조건 비교 | 분기·시간 구간과 지도·선택 매출 |
| 상권 지도 | 선택 상권 추이, 후보 상권 비교 | 상권 선택 정보·순위·지도 탐색·후보 담기 |

상권 지도에는 기존에 없는 조건 스냅샷 기능을 새로 만들지 않았다. 후보 담기·지도 복귀·지도 적용처럼 결과를 실제 작업에 연결하는 문맥 동작은 유지했다. 분석용 상세·후보의 독립 상단 버튼과 아래로 펼쳐지는 상세 영역은 콤보와 모달로 통합했다. 시연용의 기존 장면 전환은 보존한다.

기존 컴포넌트를 한 벌만 유지하는 포털로 조회 상태·옵션·저장안을 보존한다. 모달은 배경 조작을 막고 닫기/Esc/초점 복귀를 제공한다. 모달 간 교체의 스크롤 잠금을 공통 관리하고, 그래프 옵션·설명·아이콘 툴팁도 열린 모달 안으로 연결한다. 닫힌 추이는 재생을 중지한다.

## 로컬 크롬 실행

배포용 빌드의 PC 화면에서 다음을 실행했다.

- 생활이동: 마포구 지도→시간 추이→그래프 옵션 기준100→Esc로 옵션만 닫기→19시 선택→지도 19시 반영. 상대지역 모달에 같은 시간대 합계 표시. 출발 기준 18시 유입47,799/유출45,604/차2,195건, 도착 기준 유입59,832/유출52,526/차7,306건으로 독립 fixtures와 일치했다. 조건 두 안 저장 후 기준안 적용으로 지도 복귀했다. 상세표도 같은 범위였다.
- 전입·전출: 마포2025 전입49,402/전출53,428/순이동−4,026명 일치. 구성 모달에서30대 적용→지도−1,673명(전입13,407/전출15,080) 연결. 연령 자료1개년 제한 안내 확인. 전체 인구 추이에서2024 선택→지도 연도2024 반영. 추이→구성 모달 교체 시 열린 모달1개와 배경 잠금 유지. 조건안 재열기 후 저장 유지.
- 행정구역 매출: 마포2025Q4 1.08조 원(원값1,079,338,758,575원) 확인. 추이에서Q3 선택→지도 분기20253 반영. 상세표 긴 매출은 억/조 축약 및 정확값을 유지하며 후보·조건 비교 모달도 확인했다.
- 상권 지도: 종로구 클릭→구 확대→종로3가역 선택→후보 담기→추이 모달. Q4 3,313.2억 원(원값331,319,763,982원) 확인. 기준100 옵션·Q3 선택→닫기 후 같은 카메라와 선택 상권/조회 분기 유지. 후보 모달의 지도에서 보기→모달 닫힘·해당 상권 표시.
- 시연 회귀: 전입전출 상세 장면과 두 시점 비교 창 열기/닫기 확인. 지도 전체화면 대체 보기에서 모달 열기/닫기 확인. 브라우저 네이티브 전체화면과 모든 시연 장면을 전수 검사했다고 주장하지 않는다.
