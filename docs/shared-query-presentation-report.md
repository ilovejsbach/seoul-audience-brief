# 조회 통합·공통 상세 실행 기록

기록일: 2026-11-16. 소스·로컬 Chrome 검수와 공개 배포 후 검수를 완료했다. 확인 범위는 아래 표와 배포 절을 따른다. 과거 랩업은 당시 스냅샷으로 보존한다.

## 반영

- 생활인구·생활이동·전입전출·행정동 매출은 상단 실제 입력 한 벌이 현재 조건 표시를 겸한다. 상권도 같은 원칙으로 핵심 입력과 작은 부가 옵션을 사용한다.
- 분석/시연은 같은 상세 콤보·팝업/본문·지도 복귀를 쓴다. 본문은 아래로 이어붙이지 않고 중앙을 교체한다.
- 추이 SVG의 높이를 실제 그래프 컨테이너에 맞췄다. 두 줄 조회 바에서도 축과 재생행이 함께 보이도록 내부 최소 높이와 여백을 조정했다.
- 시연 플로팅 그래프 옵션이 예전 장면 숨김 규칙에 가려지던 문제를 수정했다.
- 시간대·인구 세분·매출 구간의 선택값 폭을 확보했다. 상권 검색의 0px 폭 문제를 고쳤으며 선택 입력의 불필요한 상권 접두사·건수 반복을 줄였다. 건수는 선택 목록과 조회 결과에 남긴다.
- 상권 본문 상세 동안 중복된 우측 선택 정보창을 잠시 접어 플롯이 작업 폭을 사용한다. 복귀하면 원래 정보창 배치·폭을 유지한다.

## 실제 Chrome 검수

실제 CSS 뷰포트 1365×768에서 확인했다. 큰 화면 및 Chrome 자체 전체화면의 관찰은 별도로 기록한다.

48상태 순회는 프레임·선택기·현재 조회 가시성 검사다. 모든 데이터 값과 옵션 조합을 전수 대조했다는 뜻이 아니다. 의미 검사는 위 사례 및 기존 독립 원자료 검증을 따로 수행했다.

## 검사와 증거

- `npm run build`: 성공. 최종 로컬 JS `index-FcMxdg-3.js`, CSS `index-CoTHcdhM.css`.
- `node --test tests/*.test.mjs`: 70/70 통과.
- `python3 scripts/validate-data.py`, `python3 scripts/validate-market-data.py`: 통과, 상권 mismatch0.
- `git diff --check`: 통과.
- [독립 시각 감사](uiux-designer-audit.md). 증거는 `docs/evidence/shared-query-presentation/verified-*`, `frame-matrix.json`, `extra-frame-matrix.json`, `fullscreen-matrix.json`, `typography-map.json`, `chrome-fullscreen-menu.txt`.
- `before`, `preaudit`, 이전 `final-*` 캡처는 중간 실패를 포함하므로 현재 통과 증거로 사용하지 않는다.

## 배포 상태

- 런타임 소스: `98591c4` · main 푸시 완료.
- Pages: `a0ec4b93fc170c3d34dad70f9508860edfa1cfe2` · GitHub Pages build `built` 확인.
- 공개 URL: https://ilovejsbach.github.io/seoul-audience-brief/
- 공개 Chrome이 최종 JS `index-FcMxdg-3.js`를 읽는 것을 확인했다. 실제 공개 뷰포트1229×691 및1366×768에서 검수했다.
- 생활인구 분석 본문18→19시, 시연 마포18시20–39세여성125,106명, 지수 설정·형제 상세·팝업/본문 왕복·조건·140% 확대 transform 보존을 확인했다.
- 공개 생활이동 마포 도착19시52,335건, 전입전출 구성의30대 지도적용−1,673명, 매출17–21시3,188.84억원을 확인했다. 보이는 조회 입력은 한 벌이며 상세 복귀가 작동했다.
- 상권 홍대 검색과 발달상권 교집합4개, 서울→종로구→종로3가역, Q3매출3,156.42억원의 상세/지도/우측 연동을 확인했다. 본문에서 우측 중복창은 숨고 지도 복귀 후320px로 복원됐다.
- 공개 상권 인구도 여성 조건으로 조회하고 본문에서2026Q1로 바꾼 뒤2,562,184명과 조건·선택 경로를 확인했다. 확대 transform `translate(0 0) scale(1.4)`는 상세 왕복 후 같았고 잔류 플로팅은0개였다.
- 공개 조작 범위에서 브라우저 오류 로그0개. 증거: `public-analysis-trend.jpg`, `public-presentation-trend.jpg`, `public-commerce-trend.jpg`, `public-market-trend.jpg`, `public-market-return.jpg`.
- Chrome 자체 전체화면 검사는 로컬 동일 런타임에서 수행했다. 공개 검수와 수행 위치를 구분한다.

## 남은 범위

이번 검수는 PC의 위 조건·자료·전환 범위다. 모바일/패드 전수, 인쇄, 모든 지표·날짜·업종의 조합과 모든 합성색 대비는 별도 관문이다. 이를 전체 품질 완료로 표현하지 않는다.

## 후속 수정: 생활이동 집계 설명

별도 ‘시각 기준·집계 방식 / 집계 기준·날짜 해석’ 박스를 제거하고, 상단 조회의 집계 방식 옆 ⓘ 툴팁으로 통합했다. 선택 한 시간·누적·원본 일자 전체와 출발/도착 기준에 따라 설명이 바뀐다. 반복 이동·구내 이동 제외·고유 방문자/체류 인원과의 차이·원본 일자·자정 이후 날짜 보정 미확인을 보존했다. 도착 자료 미확보 경고는 상태 안내로 유지한다.

로컬 Chrome 분석/시연에서 한 시간·누적·일자 전체 및 출발/도착 설명을 확인했고, 일자 전체에서 시간 선택 비활성·기존 안내 박스0개를 확인했다. 빌드·변경 형식 검사 통과. 공개 배포 확인은 후속 기록으로 갱신한다.
