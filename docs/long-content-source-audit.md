## 수정 원칙

1. 숫자를 작게 줄여서 해결하지 않는다. 주정보는 조/억/만 단위 표시, 실제값은 원단위로 보존한다. 축약표시는 반올림이며 같은 화면 비교가 가능하도록 단위 기준을 통일한다.
2. 제목·조건은 결과 카드와 다른 행을 사용한다. 결과 세 칸은 `repeat(3,minmax(0,1fr))`처럼 내용의 최소폭으로 서로 밀리지 않게 하고, 각 카드에도 min-width0을 준다. 긴 제목은 문장단위 줄바꿈을 허용한다.
3. 실제 큰값·음수·0·자료없음·긴명칭으로 검사한다. `scrollWidth > clientWidth` 측정은 의도한 표스크롤·설정내부스크롤과 실제페이지침범을 구분한다. 숨김화면이나SVGtext의명목크기만으로 통과판정하지 않는다.
4. 기능E2E가 끝나도 실제스크린샷에서 제목읽힘·숫자크기·단위·영역균형을 독립 확인한다. 최소 분석/시연, 기본/전체화면, 지도/추이/후보/작업대/상권상세를 포함한다. 검수한 실제뷰포트와 미검사범위를 기록한다.
