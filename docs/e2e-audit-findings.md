# E2E 상태 전이 독립 감사

확인일: 2026-11-14. `main.tsx`, `ExtraDashboard.tsx`, `Navigation.tsx`, `MapCanvas.tsx`, `TrendExplorer.tsx`, `TimeComparison.tsx`, 조건 작업대 및 관련 CSS를 읽고 실제 경계·지역·통계 파일과 대조했다. **정적 감사이며 실제 브라우저 통과 보고가 아니다.** UI 소스는 변경하지 않았다. 최신 Hero는 별도 작업 중이라 전환 계약만 확인했다.

## P2: 미연결 동을 후보로 저장하면 없는 피크 시간 생성

### 재현 조건

생활인구 → 동대문구 선택 → 동 지도에서 회색 **용신동** 클릭 → “후보 비교”.

### 근거와 영향

- 현재 경계에는 과거 용신동 코드 `11230536`이 있지만 2026 생활인구는 용두동·신설동으로 나누어져 해당 코드의 값이 없다. `regions.json`도 이 코드의 `activePopulation=false`를 표시한다.
- 지도 팝업은 결측을 보여 주지만 비교 추가는 허용한다. main의 후보 계산은 `rank.find` 실패로 이름 대신 코드가 표시되며 시간별 값도 모두 null이다.
- 피크 표시는 `hourly.indexOf(Math.max(...hourly.map(x=>x??-1)))`이므로 모든 값이 null이면 0번, 즉 **“최대 00:00”**을 만든다. 실제 관측된 피크가 아니다.
- 같은 팝업의 상세 분석은 드롭다운에 없는 동을 선택하며, CSV는 선택 코드와 일치하는 순위가 없어 헤더만 저장한다. 내보내기 버튼은 pop 로딩 상태만 보므로 활성화되어 있다.

### 수정 검증 기준

미연결 지역은 후보 추가·상세 행동을 제한하거나, 명시적인 자료 없음 상태로 관리한다. 모든 시점이 결측이면 피크를 표시하지 않는다. 이름을 알고 있는 과거 코드가 원시 코드만 보이는 상태도 피한다. CSV 대상 행이 없으면 비활성화 또는 명확한 안내를 제공한다. 정상 동 후보와 결측 동 후보를 섞어도 정상 값이 바뀌지 않아야 한다.

## P2: 기본 접힘 출처·해석 기준이 인쇄에서 누락될 수 있음

### 재현 조건

출처의 “자료 설명·출처·해석 기준”을 열지 않은 상태로 분석 또는 시연 화면의 “브리핑 인쇄” 실행.

### 근거와 영향

- 출처 내용은 `<details className="dataNotes">` 내부에 있으며 초기 `open`이 없다.
- 인쇄 CSS는 `.source` 색·표시 등을 조절하지만 닫힌 details의 내용까지 명시적으로 펼치지 않는다.
- 시연 모드의 `.mode-presentation .dataNotes{display:none}`도 별도로 인쇄에서 복원하지 않는다. 부모가 숨겨지면 자식 `.source`만 표시해도 출처가 나오지 않는다.
- 출력된 통계의 제공처·내국인 범위·결측 처리·경계 한계가 빠질 수 있다. 브리핑 근거를 재확인하기 어려워진다.

### 수정 검증 기준

인쇄 전용 출처 블록 또는 beforeprint/afterprint의 안전한 펼침·복원 등으로 실제 PDF에 현재 탭의 출처와 해석 기준이 보이게 한다. 화면의 접힘 상태는 인쇄 후 복원한다. 분석용과 시연용 각각, details를 열지 않은 상태에서 PDF 텍스트·레이아웃을 확인한다. 브라우저별 details 인쇄 동작은 실제 출력으로 확인해야 한다.

## 이번 감사에서 새로 발견하지 않은 사항

기존 과거 연도 구 CSV 비활성화는 현재 `activeStats.length` 기준으로 바뀌었다. 공통 지도 범례는 음수 최솟값·0·양수 최댓값을 구분한다. 빈 후보에서 지역 선택 돌아가기는 `navigateSection`으로 단계 변경과 해당 지도 스크롤을 요청한다. 기존 생활인구 성·연령, 구·동 중복 합산 방지, 상권 구별 시계열 계산에서 새 P1 오류는 확인하지 못했다.

## 테스트 실행자에게 넘길 확인 항목

fullscreen 상태에서 전체화면 닫기·Esc·자료 전환, 지도를 드래그한 직후 오클릭, 정보창 포커스 복원, 시연 단계에 숨겨진 버튼으로 스크롤하는 문제, 조건 복원과 비동기 날짜 로딩, 화면을 떠난 뒤 재생 중지, 활성 탭만 인쇄되는지를 실제 UI로 확인한다. 정적 코드상 연결과 사용자에게 보이는 작동을 구분한다.
