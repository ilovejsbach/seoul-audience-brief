# 광고 입지 대시보드 개발 규칙

정본 규칙 · 2026-11-14 제정 · 2026-11-15 개정 · 2026-11-15 현행 요건 갱신 · 적용 대상: 분석용, 시연용, 지도 중심 상권 조회, 일반·전체화면 지도, 상세·보조 분석, 표·내려받기·인쇄.

이 문서는 사용자가 처음부터 지적한 사항을 **반복해서 지켜야 할 개발 원칙과 수용 기준**으로 바꾼 것이다. 새 기능·새 자료·화면 수정은 이 규칙에 대조한다. 과거 보고서의 ‘통과’는 그 보고서의 버전·화면·조건에만 유효하다. 현재 작업 중인 변경을 검증 완료로 간주하지 않는다.

## 1. 판단 목적을 먼저 정한다 — 목적 계약

**R01. 모든 화면·도표·주요 수치는 하나의 판단 질문을 가져야 한다.**

구현 전에 다음 다섯 항목을 기록한다. 하나라도 답하지 못하면 새 패널을 만들거나 장식용 수치를 추가하지 않는다.

1. 누가 왜 이 화면을 보는가?
2. 어떤 결정을 하려는가?
3. 어느 자료·기간·공간 단위·모집단이 필요한가?
4. 어떤 조작으로 결과가 바뀌는가?
5. 결과를 읽은 뒤 어떤 다음 행동을 할 수 있는가?

| 업무 목적 | 화면의 주정보 | 보조 분석 | 다음 행동 |
|---|---|---|---|
| 후보 지역 발견 | 같은 조건의 공간 분포와 지역 순위 | 후보별 규모·조건 비교 | 구→동/상권, 후보 담기 |
| 타깃 접촉 가능 시간 검토 | 선택 지역·대상의 시간별 체류 추계 | 두 타깃의 규모·구성비, 두 시점 차이 | 시간·대상 변경, 지도 복귀 |
| 이동 수요 검토 | 출발/도착 기준의 유입·유출 이동 건수 | 상대 지역·시간대 분포 | 방향·집계 비교, 상대 지역 탐색 |
| 거주 기반 검토 | 주민등록인구의 기준시점·규모 | 연간 전입·전출·집단별 순이동 | 연도·집단 비교 |
| 소비 수요 검토 | 같은 업종·분기의 상권 추정매출 | 분기 추세·한 가지 주변분포 | 상권 후보 비교·원자료 확인 |
| 광고주 브리핑 | 선택된 근거 한 가지와 그 의미 | 꼭 필요한 조건·한계 | 다음 장·상세·시작 화면 |

**R02. 제목은 질문과 결과 범위를 설명한다.** ‘실제 데이터’, 의미 없는 상태 숫자, 불필요한 영어로 시선을 분산하지 않는다. 자료·지표·대상이 바뀌면 제목·조건 요약·단위·설명도 함께 바뀐다. ‘지역별 퍼널’처럼 현재 과제에 필요 없는 구조는 의무적으로 유지하지 않는다.

**R03. 시연용은 분석용 계산과 선택 상태에서 파생한다.** 두 모드에 별도 수치 계산을 만들지 않는다. 시연용은 같은 근거를 지역·시간·후보의 명확한 장면으로 줄이고 더 크게 읽히게 한다. 분석용 도구를 단순히 숨겨 작동을 막지 않는다. 시연에서도 필요한 조건·상세·복귀 경로는 남긴다.

## 2. 영역과 정렬을 규격으로 다룬다 — 공간 계약

**R04. 같은 위계는 같은 크기를 사용한다.** 주제 탭 4개, 시연 단계 3개, 동일 목적의 선택 버튼은 글자 수가 아니라 정해진 격자로 배치한다. 선택되었다고 폭·높이·글꼴 크기를 바꾸지 않는다. 긴 이름은 남는 공백·행 높이·줄바꿈 규칙으로 처리하며 임의의 폭 확장이나 말줄임으로 뜻을 숨기지 않는다.

**R05. 주정보와 보조정보의 역할·비율을 먼저 정한다.**

| 영역 | 기본 역할 | PC 기준 | 조정 규칙 |
|---|---|---|---|
| 주영역 | 중앙 지도·현재 비교 결과 | 지도/보조 75:25를 기본 기준으로 사용 | 지도 중심75, 균형형67, 비교 중심55; 지도 기준 비율55–85% 조절, 지도/보조 경계선 드래그·방향키도 같은 상태 사용 |
| 보조영역 | 순위·선택 근거·후보 | 최소 너비280px | 최소 너비 때문에 실제 비율이 제한될 수 있음. 내용 잘림보다 최소 너비를 우선 |
| 조회 조건 | 왼쪽에서 무엇을 볼지 결정 | 기본 너비220px, 조절 범위180–300px | 지도에 남는 너비가540px 미만이면 고정 영역 대신 ‘조회 옵션’ 펼침 메뉴로 전환 |
| 부가 설명 | 출처·경계·주의·방법 | 주정보 뒤의 접힘 영역 | 필요시 펼침. 결과 해석에 필수인 단위·기준시점은 접지 않음 |
| 전체화면 지도 | 공간 분포 집중 | 상단 조건은 내용 높이, 지도는 남은 높이 | 일반 화면의 비율 조정과 분리. 도형 전체 맞춤 제공 |

- PC 기본 배치는 상단 주제 메뉴, 왼쪽 조회 조건, 중앙 지도, 오른쪽 순위·상세 정보로 나눈다. 상단에 조회 조건을 여러 줄 쌓아 지도 높이를 줄이지 않는다.
- 조회 조건을 좁혀 글자를 축소하지 않는다. 지도 패널 너비에서 옵션 너비를 뺀 값이540px 미만이면 같은 조건을 플로팅 메뉴로 전환하며, 현재 적용 조건은 지도 옆에 남긴다. 전체화면에서도 조회 옵션은 필요할 때 펼친다.
- 상권 지도 중심 조회에도 지도/보조 경계 조절과 조회 옵션 띄우기를 적용한다. 일반 분석은 지도 비율55–85%, 상권 작업공간은 좌우 패널의 픽셀 너비로 조절하되 중앙 지도 최소 작업 공간과 패널 최소 너비를 우선한다. 서로 다른 단위를 하나의 비율로 보고하지 않는다.
- 위 비율은 이 제품의 작업 목적에 맞춘 기본값이다. 사람에게 보편적으로 최적인 비율·황금비라는 주장을 하지 않는다.
- 한 화면의 직사각형·행·여백은 공통 규칙을 쓴다. 기본 간격 단위는4px, 같은 위계 간격은8/12/16/24px 중 지정한 값으로 통일한다.
- 같은 화면 안의 패널은 동일한 안쪽 여백과 제목 기준선을 사용한다. 보조 패널이 많다는 이유로 각자 다른 여백·반경·폰트 체계를 만들지 않는다.
- 분석 첫 진입과 시연 지역 장면은 지도·범례·현재 조건을 우선한다. 합계·저장·긴 안내가 그 앞을 밀어내지 않게 한다.
- 화면 배치 옵션은 미리 정한 범위에서만 조절한다. 배치 초기화(지도75%, 옵션220px), 현재 선택 상태, 좁은 화면의 한 열 전환과 조회 옵션의 플로팅 전환을 제공한다. 비율 조절은 데이터·후보·색상 범위를 바꾸지 않는다.
- 시각적 순서를 바꾸면 DOM·키보드 순서도 맞춘다. CSS `order`만으로 주·보조 순서를 바꾼 채 완료하지 않는다.

**수용 기준:** 같은 위계 버튼의 실제 너비·높이 오차는 반올림에 따른1px 이내. 실제 검사 화면에서 가로 넘침이 없고, 기본 배치에서 주제·조건·지도·범례가 읽힌다. 화면 크기는 기록하며 미검사 해상도까지 통과했다고 쓰지 않는다.

## 3. 창과 옵션의 역할을 통폐합한다 — 정보 계층 계약

**R06. 창을 기능별로 늘리지 않고 네 역할로 구분한다.**

| 역할 | 포함할 것 | 기본 노출 | 통합·분리 기준 |
|---|---|---|---|
| 조회 조건 | 자료, 지역, 기준기간, 시간 기준, 지표, 제공되는 성별·연령·업종 | 현재 결과 가까이 | 같은 결과를 바꾸는 조건은 한 묶음. 같은 상태를 따로 복제하지 않음 |
| 표시 설정 | 색상 범위, 축 범위, 실제값/차이/지수, 배치 | 필요한 때 펼침 | 원값을 바꾸지 않는 도구는 조회 조건과 구분. 기본 화면을 압도하지 않음 |
| 상세·보조 분석 | 선택 지역의 추이, 두 타깃, 집단 구성, 후보 비교 | 명시적 진입 후 | 다른 판단 질문을 답할 때만 분리. 제목과 복귀 대상 유지 |
| 의미·출처 | 정의, 해석, 주의, 수집기간, 경계, 원본 링크 | 짧은 설명 버튼·접힘 주석 | 동일 설명은 한 곳에서 관리. 단위·적용 조건·자료 없음 이유는 결과 옆에도 표시 |

- 일반 화면에서 조회 조건이 보이면 지도에 같은 조건을 중복 노출하지 않는다. 전체화면·시연에서 외부 조건이 숨겨지면 필요한 조건을 지도 안에 제공한다.
- 플로팅 조회 옵션은 고정 조회 영역과 같은 상태를 사용한다. ‘조회 옵션’ 버튼의 펼침 상태를 표시하고, 접기 버튼·Esc로 닫을 수 있게 한다. 닫아도 선택 조건·현재 결과는 유지한다. 메뉴 안쪽은 필요할 때만 스크롤한다. 고정/띄우기를 직접 선택할 수 있고, 띄운 창은 제목 영역 드래그·방향키로 이동, 모서리 드래그·방향키로 가로·세로 크기를 조절한다. 지도를 벗어나 화면 전역으로 이동할 수 있게 하되 화면 경계를 넘지 않게 제한하고 위치·크기 초기화를 제공한다. 창 이동·크기 변경이 조회 조건·후보·원값을 바꾸면 안 된다.
- 왼쪽 상권 조건은 ‘자료·기간 / 지역 / 세부 분석 / 보기 설정’으로 묶고, 자료·기간과 지역을 우선 노출하며 세부 분석·보기 설정은 필요할 때 펼친다. 일반 지도도 같은 역할 구분을 따르되 자료별 필요한 조건만 제공한다.
- 우측 상세 패널은 하나의 펼침/접힘 토글로 제어한다. 같은 패널의 중복 접기 버튼을 여러 곳에 두지 않는다. 토글의 접근 가능한 이름·펼침 상태는 현재 상태와 일치하며, 지도에서 상권을 새로 선택하면 상세가 다시 보이고 선택 근거로 이동한다.
- 형식 설정과 상세 분석을 같은 모양의 팝업으로 혼합하지 않는다. 사용자가 설정 변경인지, 자료 조회인지, 다른 화면 이동인지 예측할 수 있어야 한다.
- 깊은 분석으로 진입할수록 한 번에 보이는 정보는 줄여도 근거·현재 지역·조회 조건은 잃지 않는다.
- 무결과·미지원·읽기 실패는 서로 다른 상태다. 각 상태에는 이유와 실제 가능한 복구 행동을 붙인다.

**수용 기준:** 같은 목적의 선택기는 한 문맥에 하나의 보이는 진입점을 갖는다. 설정을 접어도 현재 적용 결과·기준은 읽힌다. 표시 설정을 펼쳐도 입력·적용·오류·초기화가 끊기지 않는다.

## 4. 글자와 색은 의미와 대비로 통제한다 — 가독성 계약

**R07. 같은 역할에는 같은 글자 규격을 쓴다.** 한국어를 기본으로 하고 신뢰할 수 있는 한글 서체(현재 IBM Plex Sans KR)를 유지한다. 역할별 공통 토큰으로 관리한다. 패널마다 글자 수에 맞춰 임의로 축소하지 않는다.

- 시연은 **14/18/24/36px 네 단계 이하**, 분석은 **12/14/16/20/28/36px 여섯 단계 이하**로 제한한다. 제목·수치·조작·설명은 아래 역할표에 배정하고 글자 수에 맞춰 일곱 번째·다섯 번째 크기를 만들지 않는다.

| 모드 | 단계와 역할 | 지도 지역명 |
|---|---|---|
| 시연 |14 보조·조작·축 /18 본문·선택 /24 제목 /36 핵심 수치 | 일반14, 전체화면18px |
| 분석 |12 메타·축 /14 조건·보조 /16 본문·목록 /20 패널 제목 /28 페이지 제목 /36 핵심 수치 | 일반14, 전체화면16px |

- 이 조합은 제품의 제한된 타입 토큰이다. 공식 디자인 시스템의 역할별 토큰·반복 읽기 검증 원칙을 참고했으며, 한글 사용자 모두에게 편한 유일한 최적값으로 주장하지 않는다. [공식 근거와 적용 판단](presentation-typography-rationale.md)을 따른다. 몸통 글자·단위·포털 툴팁도 모드별 집합에 포함한다.
- 행간은 본문1.6–1.65, 제목1.35–1.45, 핵심 수치1.3을 출발점으로 실제 문구에서 검사한다. 글자가 길거나 좁은 화면이라는 이유로 `clamp()`로 계속 다른 폰트 크기를 만들지 않는다. 레이아웃·줄바꿈을 바꾸되 브라우저 글자 확대는 막지 않는다.
- 주요 수치는 일반 본문보다 분명히 크고, 숫자는 고정폭 숫자 정렬을 사용한다. 시연은 설명량을 줄여 핵심 수치를 키운다.
- 긴 금액은 주정보에서 조/억/만 단위로 축약하고 정확값은 펼친 상세·툴팁·표·CSV에 보존한다. 계산·정렬·색상·증감률은 축약 문자열이 아니라 원값으로 수행한다. 단위·부호·자릿수는 잘라서는 안 된다.
- 두 시점 비교의 제목·현재 조건은 결과 카드와 별도 전체 행에 둔다. 결과 세 칸은 `repeat(3,minmax(0,1fr))`와 자식 최소 너비0으로 구성해 긴 숫자가 제목 열을 밀어내지 못하게 한다. 글자 축소 대신 단위와 배치를 조정한다.
- 같은 역할의 기존 화면이 위 기준과 다르면 공통 토큰으로 이관할 작업 항목을 남긴다. 한 선택자에만 임의 폰트를 덧씌우는 방식으로 끝내지 않는다.

**R08. 선택 상태는 색만으로, 또는 낮은 투명도로 표현하지 않는다.** 기본 표면은 흰색·연회색, 본문은 짙은 남색이다. 선택된 주제는 남색 배경+흰 글자, 순서 번호는 따뜻한 보색 배지로 구분한다. 번호도 정보이므로 글자·배경의 불투명도를 낮춰 사라지게 하지 않는다. 선택 상태에는 `aria-selected`/`aria-pressed`/`aria-current`와 시각적 상태가 일치해야 한다.

| 의미 | 색 사용 규칙 | 색 이외의 표현 |
|---|---|---|
| 선택된 주제 | 남색#173e69, 흰 글자 | 동일 크기, 선택 상태 속성 |
| 선택 순서 번호 | 밝은 주황빛#ffd28a 바탕, 남색 숫자 | 불투명도1, 고정 크기 배지 |
| 비선택 정보 | 밝은 표면, 짙은 글자 | 경계·구획 |
| 값의 규모 | 작음→큼의 순차 파랑 | 실제 범례 값·단위 |
| 증감/순이동 | 음수 주황, 양수 파랑,0 중립 | 부호·0선·‘순유입/순유출’ 문구 |
| 결측 | 회색 | ‘자료 없음’과 이유 |
| 키보드 초점 | 주변과 구분되는 윤곽 | 선택 상태와 별도 |

일반 텍스트의 대비4.5:1 이상, 큰 글자·핵심 도형/초점 표시는3:1 이상을 프로젝트 검사 기준으로 둔다. 실제 최종 색과 불투명도를 합성해 계산한다. 선택 번호 예시 색 조합의 명목 대비는 약7.69:1, 흰 글자/남색은 약10.88:1이다. 이 수치가 모든 화면의 실제 측정 결과를 대신하지 않는다.

**R09. 숫자를 일괄적으로 보색으로 칠하지 않는다.** 번호의 강조색과 통계 증감색을 구분한다. 정상/선택/마우스 오버/키보드 초점/비활성 상태를 모두 검사한다. 단순한 카드 장식에 경고색을 쓰지 않는다.

## 5. 지도는 읽을 수 있는 공간 분석 도구다 — 지도 계약

**R10. 도형·지역명·선택·미리보기는 별도 층으로 그린다.** 지역명은 모든 도형을 그린 뒤 최상위 라벨 층에 표시한다. 다음 지역 도형이 이전 지역명을 덮어서는 안 된다. 흰색 윤곽과 충분한 대비를 제공하고 라벨은 포인터 입력을 가로채지 않는다.

- 전체 맞춤 상태에서 구·동·상권의 도형·지역명이 SVG/부모 영역에 잘리지 않는지 검사한다. 라벨이 좁은 도형을 벗어나면 도형만의 문제가 아니라 충돌·위치·최대 줄 수·보조 라벨 처리를 검토한다.
- 구/동 전환, 선택 수치 추가, 긴 지역명, 확대·축소 후 라벨과 수치가 서로 겹치는지 확인한다. 도형 확대 배율과 SVG 뷰박스의 화면 배율을 함께 상쇄해 지정한 화면 픽셀 글자 크기와 윤곽을 유지한다. SVG의 명목 CSS크기만 검사해서는 안 된다.
- 화면 확대·축소는 **− / 배율 / + / 원래 범위** 순서를 기본으로 한다. 배율을 제공하지 않는 경우에도 −가 +보다 먼저 온다. 모든 지도에서 같은 원칙을 적용한다.
- 휠 확대와 드래그 이동은 클릭 선택과 구분한다. 드래그 직후 상세가 잘못 열리지 않아야 한다.
- 일반 지도도 조회 옵션을 왼쪽에 배치하거나 플로팅으로 전환해 세로 공간을 확보한다. 옵션을 접으면 지도에 공간이 반환되어야 하며, 지도·지역명 글자는 축소하지 않는다.
- 전체화면은 제목·핵심 조건을 압축하고 지도가 남은 공간을 채운다. 기존 기본 지도를 단순히 고정 높이로 확대하지 않는다.
- 지도 후보 추가 후에는 전체화면 안에서도 후보 수·담긴 이름·해제·비교 열기가 보여야 한다.

**R11. 색상 범위는 수치와 별도다.** 0 포함 규모 비교, 관측 최솟값 아래 여유율 차이 강조, 직접 지정 범위를 구분한다. 자동 여유 하한은 `최솟값 − (최댓값−최솟값)×여유율`이며 비음수 자료는0 아래로 내리지 않는다. 음수가 포함되거나 증감·순이동 지표이면0 중심 대칭 범위와 부호를 유지한다. 두 시점 나란히 비교는 두 시점 값의 합집합으로 하나의 공통 눈금을 사용한다. 확대·이동·선택 집중은 원값·범례 범위를 바꾸지 않는다.

- 일반 지도·두 시점 분포·증감·상권의 색상 최솟값·최댓값을 접힌 표시 설정에서 직접 조절한다. 입력은 원래 단위로 받고, 값의 축약은 요약 표시에만 사용한다. 최솟값<최댓값·유한수·비음수 규모의 하한≥0을 검사한다. 증감은 한쪽 입력을 바꾸면 반대쪽도 같은 절댓값으로 맞춘다.
- ‘범위 좁히기 −20% / 넓히기 +20%’는 현재 범위 폭을0.8/1.2배로 바꾼다. 가능한 동안 중심을 유지하고, 양수 범위의 하한이0에 닿으면 상한을 조정해 폭을 유지한다. 증감은0 중심 반경을 조절한다. 자동·직접 상태와 현재 범위를 가까이에 표시하며 초기화를 제공한다.
- 시간·비교 시점 변경에서 직접 범위는 고정해 같은 색의 의미를 유지한다. 공간 단위·지원 차원·지표의 부호 체계가 달라 범위를 초기화해야 한다면 그 전환 규칙을 소비자별로 명확히 정한다. 잘못된 입력은 마지막 유효 범위를 바꾸지 않으며 이유와 복구 경로를 표시한다.
- 범위 밖 값은 끝 색으로 포화시키되 원값·차이·순위·후보·CSV를 바꾸거나 해당 지역을 제거하지 않는다. 하한 미만/상한 초과 관측값 개수를 알리고 툴팁에 끝 색의 의미를 설명한다. 두 지도에 같은 지역의 값이 두 번 있으면 ‘지역 수’가 아니라 ‘관측값 수’로 세며 null/비공개/미연결은0·최저색으로 대체하지 않는다.
- 상권의 자동 분위 분류와 직접 값 범위는 다른 분류다. 직접 범위에서 같은 값 간격을 사용하면 선택 상태·범례·설명도 ‘직접 범위 · 같은 값 간격’으로 표시한다. 초기화는 선택된 자동 분류와 일치해야 한다.
- **최신 범례 기본형은 짧은 색상 막대+‘범례’ 버튼이다.** 일반·두 시점·증감·상권의 정확 구간·단위·0·결측·포화 의미는 가벼운 툴팁으로 읽는다. 상시 큰 범례와 범례용 이동·크기 조절 창은 지도 공간을 차지하므로 사용하지 않는다. 이전 이동형 상권 범례는 과거 구현 이력이며 이 규칙으로 대체한다. 마우스 오버·클릭·키보드 초점으로 열고 Esc/외부 클릭으로 닫는다. 내부 읽기·스크롤은 유지하고 다른 의미 설명과 겹치지 않게 한다.

**R12. 검색·유형·지역 필터의 교집합을 설명한다.** 입력 공백을 정규화하되 원래 상권명·코드는 보존한다. 조회 개수·적용 조건·자료 없음 개수·무결과 복구를 표시한다. 동명이름이 여러 구에 있으면 구별 위치를 안내한다. 결과 선택은 상세와 지도 집중으로 이어지고 ‘조회 범위 맞춤’으로 필터 결과 전체에 돌아온다.

## 6. 조작의 결과는 끝까지 연결한다 — 상호작용 계약

**R13. 조회 조건은 하나의 상태 원천을 공유한다.** 조건을 바꾸면 지도 도형/색/값, KPI, 순위, 상세, 보조 그래프, 추이, 툴팁, CSV의 같은 범위가 함께 바뀐다. 현재 조건만 바뀌고 결과가 그대로이거나, 값만 바뀌고 단위·설명이 남는 상태를 허용하지 않는다.

**R14. 버튼은 결과를 예고하고 결과까지 도달한다.** ‘상세 분석’처럼 목적지가 여러 개인 경우 ‘동별 분포 보기’, ‘시간 추이 보기’처럼 다음 결과를 이름에 드러낸다. 활성 버튼을 눌렀는데 변경·안내·이동이 하나도 없으면 결함이다. 상한·중복·자료 없음은 비활성 또는 명확한 대안으로 처리한다.

**R15. 화면 여정에는 복귀가 있다.** 지역 지도→구 상세→동 추이→후보→시작 화면의 경로를 끊지 않는다. 전체화면 밖 상세로 이동할 때는 전체화면을 해제한 뒤 목적지가 실제 보이도록 한다. 시연은 장면 전환·배치 완료 후 내부 스크롤과 포커스를 맞춘다. 히어로 복귀와 이어보기는 선택 조건·후보에 미치는 영향을 명확히 한다.

**R16. 후보와 조회 조건 저장은 다른 도구다.**

- 후보는 조사 중인 지역 목록이다. 다른 구/동 탐색, 조건 변경, 시나리오 재적용으로 조용히 지우지 않는다. 제거는 ‘후보 해제/비우기’처럼 명시한다.
- 최대3개 후보의 상한은 모든 진입점에서 동일하다. 가득 찼으면 비교 화면 열기 또는 해제 안내를 제공한다.
- 혼합 구·동 후보를 허용하면 현재 지도 범위가 아니라 각 후보의 원자료 코드로 독립 조회한다. 이름에는 소속 구·동을 구분하고 같은 자료·기간·타깃으로 비교한다.
- 조건 저장은 서로 다른 가설의 스냅샷이다. 현재 후보 목록과 혼동되지 않게 이름·보관 기간·기준안 변경을 설명한다.
- 빈 후보 장면은 현재 보이지 않는 ‘오른쪽 순위’를 지시하지 않는다. 실제 후보를 담는 장면으로 한 번에 복귀시킨다.

**R17. 툴팁은 값+의미+해석+주의를 제공한다.** 마우스 오버·키보드 초점·클릭으로 읽고 Esc·외부 클릭으로 닫을 수 있어야 한다. 툴팁 내부를 눌러 읽을 때 닫히지 않고, 닫은 직후 자동으로 재열리지 않는다. 화면 경계와 스크롤 부모에 잘리지 않으며 한 번에 여러 설명창이 겹치지 않는다.

## 7. 데이터 정의를 화면 계약으로 지킨다

**R18. 모집단·시점·단위·공간 단위를 데이터와 함께 다룬다.** 준비 파일에는 출처, 수집일, 기준기간, 공간 단위, 지원 차원, 코드 연결, 결측 정책을 남긴다. 정적 파일로 시연하는 동안에도 원자료와 준비 파일을 구분하고 개인 키는 공개 파일에 넣지 않는다. 장기 데이터가 쌓이면 별도 백엔드 구조로 확장하되 화면 계산의 정의를 바꾸지 않는다.

| 자료 | 허용되는 의미 | 금지되는 치환 |
|---|---|---|
| 생활인구 | 특정 시점에 머무는 내국인 추계 인구 | 하루 고유 방문자·광고 순도달 |
| 생활이동 | 출발/도착 기준의 이동 건수 | 중복 제거 유입 인원 |
| 주민등록인구 | 행정 등록 거주 기반 | 해당 시각 실제 상주 인원 |
| 전입·전출 | 연간 주소 이동과 전입−전출 | 현재 거주민 수·당일 상권 방문 |
| 추정매출 | 제공 업종·분기의 추정 소비 지표 | 회계 매출·광고 기여 매출 |

- 생활인구−주민등록인구를 외부 방문자로, 시간별 이동 합계를 하루 고유 인원으로, 서로 다른 기간의 매출/인구를 구매전환율로 표시하지 않는다.
- 성별·연령·요일·시간의 주변분포를 곱해 교차 타깃을 만들지 않는다. 생활인구처럼 원본에 성·연령 교차 열이 있는 경우에만 직접 집계한다.
- 전입전출 성별은 현재2021–2025 구·동, 연령별은2025 자치구9구간이다. 미지원 연도·동별 연령은 총계로 몰래 대체하지 않는다. 특정 말일이 확인되지 않은2025 주민등록 자료에는 임의의12월31일을 붙이지 않는다.
- 원값 null/비공개/미연결은0과 다르다. 부분 결측이면 정해진 집계 정책에 따라 자료 없음으로 유지한다. 경계가 없는 동을 임의 분할·추정 도형으로 채우지 않는다.
- 수도권·관광객·직업 등 아직 확보되지 않은 범위는 실제 자료 확보 후 제공한다. 서울 자료를 광역 자료처럼 보이게 하는 선택지를 만들지 않는다.

**R19. 보조 그래프는 지도와 다른 질문에 답한다.** 지도는 ‘어디’, 구성 막대는 ‘어느 집단’, 추이는 ‘언제’, 후보 비교는 ‘어느 대안’을 답한다. 동일 정보를 큰 카드로 반복하지 않는다. 자료가1개년뿐이면 장기 추세처럼 보이는 그래프를 만들지 않고 비교 불가 범위를 설명한다. 축·색상·지수 변경은 해석을 바꾸므로 그 결과를 도표 가까이 명시한다.

- 시계열의 ‘축 설정’은 기본 접힘으로 두되 실제값/증감/기준100 선택과 현재 축 범위·해석 주의는 그래프 가까이에 남긴다. 기준100 지수는 기본적으로100을 가운데 둔다. 반경은 `max(1, max(abs(지수−100)) × (1+여유율))`, 범위는 `100±반경`이며 기본 여유20%, 선택10/20/30%를 제공한다. 상수 시계열은 최소±1포인트로 표시한다. 실제값·증감의0 포함/자동/직접 지정은 유지한다. 축 선택·초기화는 현재 보기와 일치해야 하며 원값·기준시점·재생 상태를 바꾸지 않는다.
- 모든 팝업을 움직이는 창으로 바꾸지 않는다. 의미·해석 설명은 기존 가벼운 팝오버를 유지하고, 지도 작업을 계속하면서 오래 참고할 조회 옵션에만 이동/크기 조절을 적용한다. 범례는 R11의 가벼운 툴팁으로 읽는다. 정확값 표의 원단위·의도적 가로 스크롤과 시연3장 구조는 유지한다.

## 8. E2E와 시각 검수의 완료 조건

**R20. 버튼 작동·수치 의미·실제 화면을 모두 통과해야 완료다.** 아래 세 종류를 분리해 기록한다.

| 검수 | 반드시 확인할 것 | 통과 증거 |
|---|---|---|
| 기능 E2E | 조작→결과→후속 행동→복귀, 반복 선택, 키보드·포인터 | 실행 경로와 실제 상태 |
| 의미 E2E | 독립 원자료의 코드·열·기간·분모·단위·결측·순위·차이 | 화면/지도/그래프/CSV 동일 기대값 |
| 시각 E2E | 선택·오버·초점·비활성, 균등 폭높이, 대비, 숫자·라벨 잘림, 주정보 첫 노출 | 실제 뷰포트 크기·스크린샷·측정값 |

### 변경마다 실행할 최소 체크리스트

- [ ] 화면의 판단 질문·주정보·보조정보·다음 행동을 적었다.
- [ ] 동위 탭/버튼의 폭·높이·기준선이 글자 수와 무관하게 같다.
- [ ] 선택 번호와 글자에 낮은 불투명도가 남지 않는다. 대비는 최종 합성색으로 확인했다.
- [ ] 실제 보이는 글자의 계산된 크기 집합이 시연4종/분석6종 이하다. SVG 배율·본문 밖 포털·펼친 설정도 포함했다.
- [ ] 값·부호·단위·긴 지역명·축 글자·툴팁이 잘리거나 다른 도형에 덮이지 않는다.
- [ ] 기본 PC 화면에서 주정보·조건·범례가 함께 읽힌다. 전체화면도 별도로 검사했다.
- [ ] 레이아웃 비율55/67/75/85, 옵션 너비180/220/300px와 초기화(75%,220px)에서 최소 너비·가로 넘침·원값 불변을 검사했다.
- [ ] 지도 잔여 너비540px 전후의 고정/플로팅 전환, 조회 옵션 열기·접기·Esc, 조건 변경 후 결과 유지와 글자 크기 불변을 검사했다.
- [ ] 플로팅 조회 옵션을 이동/가로세로 크기 조절하고, 경계 제한·초기화·Esc·재열기 후 상태 보존을 검사했다. 범례는 이동형 창과 구분했다.
- [ ] 지도 색상 최솟값/최댓값 적용·±20%·초기화·오류 복구, 시간 변경 시 직접 범위 유지와 두 지도 공통 눈금을 검사했다. 증감·순이동은0 중심 대칭이며 원값·부호가 유지된다.
- [ ] 범위 밖 하한/상한 개수를 원자료로 대조했다. 결측은 포화값에 포함하지 않고, 두 시점 중복은 관측값 수로 알렸다.
- [ ] 일반/두 시점/증감/상권의 범례가 작은 막대·버튼으로 남고, 정확값·구간·단위·끝 색 의미는 툴팁에서 읽힌다. 열기/내부 읽기/Esc/외부 클릭/조건 동기화/잘림을 검사했다.
- [ ] 긴 매출14자리·긴 상권명·음수·0·결측을 분석/시연, 지도/추이/비교/조건 저장에서 열고 제목·수치·단위와 정확값 접근을 검사했다.
- [ ] 기준100 축의100 중앙·최대편차+10/20/30%·최소±1, 축 설정 접기/펼치기·초기화를 검사했다.
- [ ] 조회 조건과 표시 설정이 구분되고 중복 선택기가 한 문맥을 어지럽히지 않는다.
- [ ] 모든 조건 변경이 수치·지도·순위·상세·추이·CSV·설명에 같은 의미로 반영된다.
- [ ] 후보를 담고 다른 구/동을 조사해도 유지된다. 혼합 후보값은 독립 원자료와 같다.
- [ ] 활성 버튼에는 실제 결과가 있다. 상한·무결과·미지원·결측에서 복구할 수 있다.
- [ ] 지도→상세→추이→후보→시작 및 시연 장면 복귀가 실제 보이는 위치·포커스로 끝난다.
- [ ] 마우스 오버·드래그·휠·클릭·Esc·Tab 경로를 검사했다.
- [ ] 실제 검사항목·뷰포트·버전·미검사 범위를 보고서에 남겼다.
- [ ] TypeScript/빌드와 변경 파일 검사를 통과했다. 테스트는 변경 영향에 맞는 것을 실행했다.

**R21. 기능 통과를 UX 통과로 보고하지 않는다.** 원래 버튼이 작동했어도 결과 안내가 없으면 발견성 문제다. 도구 대기시간·캐시·자동화 선택자 오류는 제품 결함과 구분한다. 단발 관찰은 재현 가설로 표시한다. 실제 성공 시간·오류율을 수집하지 않았다면 개선 효과를 수치화하지 않는다.

## 9. 작업·검증 기록의 운영 규칙

- 구현자는 변경한 규칙ID와 영향 화면을 변경 설명에 적는다. 새 요구는 아래 추적표에 연결한다.
- 감사자는 소스 확인, 과거 실행 확인, 현재 실화면 확인을 구분한다. 작성자 자신의 ‘구현 완료’만으로 검증 완료를 표시하지 않는다.
- 공개 전에는 현재 산출물과 공개 페이지를 별도로 확인한다. 배포 성공만으로 공개 화면 확인을 대신하지 않는다.
- 재현 자료에는 허용된 공개 통계만 넣는다. 원본 요청·준비 파일·기대값·실행 결과를 구분한다.
- 불변 조건은 고치지 않는 한 계속 유지한다. 데이터 범위·단위·산식 변경은 설명·테스트·문서까지 함께 바꾼다.

## 부록 B. 근거 문서와 우선순위

1. 현재 문서: 앞으로 지킬 개발 규칙의 정본.
2. [목적 기반 UX 감사](ux-purpose-e2e-audit.md), [독립 소스 감사](ux-source-audit.md): 문제와 재현 가설·개선 우선순위. 당시 상태 기록을 현재 구현 상태로 오인하지 않는다.
3. [상호작용 설계](interaction-design.md), [지도 작업공간 설계](map-workspace-design.md): 화면 목적·데이터 계약의 상세 근거.

상충할 때 사용자 최신 요구를 우선하며, 데이터 원값·모집단·결측의 사실을 디자인 편의를 위해 바꾸지 않는다. 규칙의 예외가 필요하면 이유·영향 화면·대체 수용 기준을 기록하고 실제 화면으로 검증한다. 정당한 예외를 문서화하는 것과 검증을 생략하는 것은 다르다.

## 기간 특성 분석 추가 수용 기준
- 일자별 상세 조회 기간과 요일·월 구간 요약 제공 기간을 분리해서 표시한다.
- 요일·월초·월중·월말은 같은 시간·지역·인구 집단의 하루 평균으로 비교하고 유효/전체 날짜 수를 함께 제공한다.
- 결측·비공개 구성값을 0으로 대체하지 않는다. 월 전환 중 이전 월 값을 새 제목 아래 보여주지 않는다.
- 연령·성별 교차 통계는 실제 교차 원자료가 있을 때만 제공한다. 날짜와 모집단을 툴팁·접힌 상세에서 확인할 수 있어야 한다.
- 최신 실제 실행 범위와 제한은 [지도·기간 실행 보고](map-range-and-period-report.md)를 따른다.

## 플로팅 조회창 추가 규칙
- 조회창 너비와 내부 배치를 연결한다. 화면 전체 너비만 보고 열 수를 정하지 않는다. 520px 미만 1열, 520–799px 2열, 800px 이상 3열을 기본으로 하되 의미 묶음을 보존한다.
- 세로 flex의 교차축 정렬을 명시하고 그룹은 남은 너비를 채운다. 상위 flex-end 정렬에 의존하지 않는다.
- 제목·작업 버튼은 내용이 들어갈 때 한 행으로, 좁을 때 자연스럽게 줄바꿈한다. 도움말만을 위한 상시 전체 행은 만들지 않는다.
- 이동창은 지도·스크롤 부모 경계에 가두지 않고 화면 전역에서 배치한다. 화면 경계 안에서 제목·닫기와 최소 한 줄의 본문에 접근할 수 있어야 한다. 전체화면에서는 해당 전체화면 요소를 창의 포털 대상으로 사용한다.
- 조회창의 중복 조건을 제거할 때 전체화면의 독립 조건과 전출입 전용 세부 조건을 함께 숨기지 않는다.
- 새 옵션 계열 추가 시 [옵션 전수 감사](option-layout-source-audit.md)의 목록과 [실행 기록](compact-options-report.md)을 갱신한다.

## 독립 조회창·일자 기간 조회 현행 기준
- 플로팅 기본 560×360px·최소 높이220px. 지도 밖 클릭으로 자동 닫지 않는다. 접기/Esc·고정 복귀·초기화를 제공한다.
- 비활성 탭/장면/화면의 독립 창은 숨긴다. 이전 창이 다음 화면의 옵션이나 헤더를 덮어서는 안 된다.
- 생활인구 일자 조회는 2026년 1–10월304일을 제공한다. 월 선택과 일자 선택의 뜻을 구분하며 월 선택을 월 합계로 해석하지 않는다. 요일·월 구간 평균은 별도 분석이다.
- 응답 날짜가 현재 선택과 일치하기 전까지 값·내려받기·팝업을 노출하지 않는다. 이전 응답이 나중에 도착해도 새 조건을 덮지 않는다.
- 현행 실행과 제한은 [독립 조회창·기간 실행 보고](free-query-and-period-report.md)를 따른다. 과거 지도 내부 제한·10월만 제공한 보고는 당시 이력이다.
