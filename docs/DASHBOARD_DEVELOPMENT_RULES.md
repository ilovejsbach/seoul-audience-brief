# 광고 입지 대시보드 개발 규칙

정본 규칙 · 2026-11-14 제정 · 2026-11-15 개정 · 2026-11-16 상단 단일 조회·분석/시연 공통 상세 원칙 갱신 · 2026-11-17 상권 매출2026년1·2분기 확장 검수 기준 추가 · 적용 대상: 분석용, 시연용, 지도 중심 상권 조회, 일반·전체화면 지도, 상세·보조 분석, 표·내려받기·인쇄.

이 문서는 사용자가 처음부터 지적한 사항을 **반복해서 지켜야 할 개발 원칙과 수용 기준**으로 바꾼 것이다. 새 기능·새 자료·화면 수정은 이 규칙에 대조한다. 과거 보고서의 ‘통과’는 그 보고서의 버전·화면·조건에만 유효하다. 현재 작업 중인 변경을 검증 완료로 간주하지 않는다.

현재 개선 순서는 [단계별 설계 v2](expansion-workspace-design.md#11-단계별-설계적용과-영향-범위--v2-기준)를 따른다. 화면 재구성보다 공간·가독성·동작을 함께 개선한다. 분석자의 작업·조회와 시연·결론 도출은 같은 단계에서 각각 설계·검사하며, 한쪽 통과로 다른 쪽을 갈음하지 않는다.

### 최신 요구의 영향과 현재 판정

| 사용자 변경 | 직접·간접 영향 | 유지할 불변 조건 | 문서·검증 상태 |
|---|---|---|---|
| 조회 옵션·현재 조건을 상단 입력 하나로 통합 | 일반·상권 조회, 고정 바, 종속 선택지, 검색 팝오버, 전체화면 포털 | 한 벌의 ID·상태·원자료, 후보·표시 설정 보존 | R05/R06/R13/R20와 [조회 현행 설계](tableau-query-options-plan.md) 갱신. 코드·실화면은 별도 판정 |
| 시연을 분석용 원칙에 맞춤 | 주제 메뉴·상세 콤보·팝업/본문·복귀·시연 CSS | 같은 계산·조회 상태, 시연4/분석6단계 글자 | R03/R07/R15/R20 갱신. 이전 시연 장면 동작은 이력 |
| 상세에서도 현재 조회를 이어 편집하고 지도로 복귀 | 숨겨진 지도와 활성 입력의 가시성, 포털 재연결, 초점/카메라 | 표시 전환만으로 조건·축·지역·확대 위치를 초기화하지 않음 | 실제 전환·의미·가독성은 [공통 실행 기록](shared-query-presentation-report.md)에서 확인 |
| 공통 헤더와 자료/보기 메뉴를 PC 한 행으로 통합 | 브랜드·자료4개·상세 콤보·모드·부가 도구·잔여 높이 측정 | 자료 동위 폭, 현재 자료/모드 인지, 작은 화면의 조작 크기 | R04/R05/R07/R20 갱신. 좁은 폭·긴 제목 실측 필요 |
| 상단 조회 바의 선택형 플로팅/우측 도킹 | 단일 입력 호스트·자석 배치·최소 지도 폭·상단 복원 | 상태·ID·종속 조건·후보·원값 보존 | R05/R06/R20 갱신. 같은 호스트 이동·충돌·복귀 검수 필요 |
| 생활이동 해석 박스와 전체폭 출처 footer 압축 | 집계 옵션 옆 동적 툴팁·결과 가까운 출처/해석 도구 | 기간·단위·출발/도착·한시간/누적/일계·결측 설명 | R06/R17/R18/R20 갱신. 가독성·해석·키보드 검수 필요 |
| 공식 상권 매출2026Q1/Q2 추가 | 원문·정제 파일·기간/manifest·캐시·지도·추이·CSV·후보·전년동기 | 기존2025 값 불변, null·지원 차원·산식 보존, 코드 연결과 형상 동일성 분리 | R13/R18/R19/R20 및 REQ-21 갱신. 새 수치·연결 범위·현재 Chrome/공개 판정은 검증 전 완료로 쓰지 않음 |

이 표는 설계 정합화 기록이며 구현·공개 화면 검수 통과가 아니다. 과거 시안과 날짜별 실행 보고는 보호된 이력으로 남기고 새 UI의 증거로 소급하지 않는다.

## 1. 판단 목적을 먼저 정한다 — 목적 계약

**R01. 모든 화면·도표·주요 수치는 하나의 판단 질문을 가져야 한다.**

구현 전에 다음 다섯 항목을 기록한다. 하나라도 답하지 못하면 새 패널을 만들거나 장식용 수치를 추가하지 않는다.

1. 누가 왜 이 화면을 보는가?
2. 어떤 결정을 하려는가?
3. 어느 자료·기간·공간 단위·모집단이 필요한가?
4. 어떤 조작으로 결과가 바뀌는가?
5. 결과를 읽은 뒤 어떤 다음 행동을 할 수 있는가?

| 업무 목적 | 화면의 주정보 | 보조 분석 | 다음 행동 |
|---|---|---|---|
| 후보 지역 발견 | 같은 조건의 공간 분포와 지역 순위 | 후보별 규모·조건 비교 | 구→동/상권, 후보 담기 |
| 타깃 접촉 가능 시간 검토 | 선택 지역·대상의 시간별 체류 추계 | 두 타깃의 규모·구성비, 두 시점 차이 | 시간·대상 변경, 지도 복귀 |
| 이동 수요 검토 | 출발/도착 기준의 유입·유출 이동 건수 | 상대 지역·시간대 분포 | 방향·집계 비교, 상대 지역 탐색 |
| 거주 기반 검토 | 주민등록인구의 기준시점·규모 | 연간 전입·전출·집단별 순이동 | 연도·집단 비교 |
| 소비 수요 검토 | 같은 업종·분기의 상권 추정매출 | 분기 추세·한 가지 주변분포 | 상권 후보 비교·원자료 확인 |
| 광고주 브리핑 | 선택된 근거 한 가지와 그 의미 | 꼭 필요한 조건·한계 | 다음 장·상세·시작 화면 |

**R02. 제목은 질문과 결과 범위를 설명한다.** ‘실제 데이터’, 의미 없는 상태 숫자, 불필요한 영어로 시선을 분산하지 않는다. 자료·지표·대상이 바뀌면 제목·조건 요약·단위·설명도 함께 바뀐다. ‘지역별 퍼널’처럼 현재 과제에 필요 없는 구조는 의무적으로 유지하지 않는다.

**R03. 시연용은 분석용 계산·조회·상세·복귀 원칙에서 파생한다.** 두 모드에 별도 수치 계산이나 별도 메뉴·조회 경로를 만들지 않는다. 상단의 편집 가능한 단일 조회 바, 상세 콤보, 팝업↔본문 전환, 지도 복귀는 두 모드에서 같은 상태와 동작을 쓴다. 시연용의 차이는 주정보 강조·정보 밀도·글자 크기에 둔다. 시연은 네 단계, 분석은 여섯 단계 이하의 R07 글자 규격을 유지하며, 분석 도구를 숨겨 조회·상세·복귀를 막지 않는다. 예전 번호식 시연 장면·별도 상세 버튼은 현행 원칙이 아니라 과거 이력이다.

시연의 주목적은 광고주와 현장에서 조건·후보를 비교하며 결론을 만드는 협의다. 준비된 발표 순서를 강제하지 않는다. 판단 질문·현재 검토 조건·비교 근거·대안을 읽으며 필요한 상세를 왕복할 수 있어야 한다. 비교 기준안과 현재 검토 조건의 세부 동작은 [v2 설계 제안](expansion-workspace-design.md#b트랙의-중심-현장-비교협의)에서 정의하며 신규 저장·고정 발표자료 기능을 사용자 확정으로 가정하지 않는다.

## 2. 영역과 정렬을 규격으로 다룬다 — 공간 계약

**R04. 같은 위계는 같은 크기를 사용한다.** 자료 탭4개와 동일 목적의 선택 버튼은 글자 수가 아니라 정해진 격자로 배치한다. 지도와 상세 콤보는 서로 다른 역할이므로 옛 보기3개 버튼 격자를 유지하려고 후보 버튼을 반복하지 않는다. 선택되었다고 폭·높이·글꼴 크기를 바꾸지 않는다. 긴 이름은 남는 공백·행 높이·줄바꿈 규칙으로 처리하며 임의의 폭 확장이나 말줄임으로 뜻을 숨기지 않는다.

**R05. 주정보와 보조정보의 역할·비율을 먼저 정한다.**

| 영역 | 기본 역할 | PC 기준 | 조정 규칙 |
|---|---|---|---|
| 주영역 | 중앙 지도·현재 비교 결과 | 지도/보조 75:25를 기본 기준으로 사용 | 지도 중심75, 균형형67, 비교 중심55; 지도 기준 비율55–85% 조절, 지도/보조 경계선 드래그·방향키도 같은 상태 사용 |
| 보조영역 | 순위·선택 근거·후보 | 최소 너비280px | 최소 너비 때문에 실제 비율이 제한될 수 있음. 내용 잘림보다 최소 너비를 우선 |
| 조회 조건 | 무엇을 볼지 결정, 기본은 상단 고정 단일 입력 | 현재 값을 보여주는 실제 입력을 공통 메뉴 아래에 압축 배치 | 필요하면 같은 호스트를 플로팅/우측 도킹으로 이동하고 상단 복원. 동시 복제·읽기 전용 동일 요약 없음 |
| 부가 설명 | 출처·경계·주의·방법 | 관련 결과나 옵션 가까운 작은 설명 도구 | 상시 전체폭 footer를 두지 않음. 해석 필수 단위·기간·기준은 가까이 유지 |
| 전체화면 지도 | 공간 분포 집중 | 상단 조건은 내용 높이, 지도는 남은 높이 | 일반 화면의 비율 조정과 분리. 도형 전체 맞춤 제공 |

- PC 기본 배치는 상단 주제 메뉴와 고정 조회 바, 중앙 지도, 오른쪽 순위·상세 정보로 나눈다. 조회 바의 입력 자체가 현재 조건 표시를 겸한다. 왼쪽 조회 옵션·상단 조건 칩·본문 조건 요약으로 같은 정보를 반복하지 않는다. 짧은 입력은 한 행을 우선하고 필요한 부가 조건만 작은 설명 가능한 아이콘의 팝오버로 제공한다. 무리한 한 행 고정이나 지나친 입력 폭 확장으로 가독성을 해치지 않는다.
- PC에서는 기존 공통 헤더와 자료/보기 탐색을 한 행으로 통합한다. 브랜드·자료4개·상세 콤보·현재 모드를 읽을 수 있게 하고, 중복 부제/context·같은 자료의 큰 제목 행은 제거한다. 자료4개는 같은 위계의 폭·높이를 쓴다. 모드와 부가 도구는 현재 상태를 식별할 수 있는 작은 메뉴/더보기로 묶고, 표시 설정·출처를 헤더에 상시 나열하지 않는다. 공통 헤더는 고정하고 조회 바는 그 아래 같은 경계에 둔다. 작은 화면에서는 글자/터치 영역을 무리하게 줄여 한 행을 강제하지 않는다. 실제 헤더·조회 바 높이로 지도/본문의 잔여 높이와 이동 여백을 측정한다.
- 상권 작업공간도 제품 root 헤더와 작업공간 제목·주요 action의 중복 행을 PC 한 행으로 압축한다. 지도 지표·조회/관측/결측 개수·서울→구→상권 경로·결과 도구는 각 목적을 유지하며 짧게 묶는다. 복귀·현재 공간 범위·단위·무결과 복구를 무조건 지우거나 하나의 거대 옵션에 숨기지 않는다. 상권 조회 호스트의 이동은 일반4자료의 배치 구조와 기존 정보 패널·본문·우측 도킹 충돌을 검토하고, 범위별 실제 검수 뒤에 지원 상태를 판정한다. 구현 중인 상태를 상권 전면 지원으로 쓰지 않는다.
- 전체화면 지도에서 자료·시간·타깃 등 조회 조건을 바꿔도 전체화면을 유지한다. 브라우저 전체화면의 호스트는 자료 전환으로 숨겨지거나 교체되는 개별 지도보다 안정된 공통 영역을 쓴다. 상세 추이·후보로 전환하면 지도 전용 집중 레이어가 목적지를 가리지 않게 숨기고, 지도 복귀 시 원래 선택·확대 위치를 보존한다. 브라우저 자체 전체화면은 별도 상태로 유지한다. 전체화면에서 뒤쪽 메뉴가 키보드 초점에 끼어들지 않게 한다.
- 후보 카드의 지역명은 상세 이동 동작과 합치고, 같은 기간·타깃은 비교 영역에 한 번만 표시한다. 구/동 단위와 각 후보의 자료 제공 차이는 숨기지 않는다. 반복 해석 문구는 가까운 설명 도구로 모으되 기준값0·결측 같은 계산 주의는 해당 값 옆에 남긴다.
- 조회 조건을 좁혀 글자를 축소하지 않는다. 기본은 상단 바이고, 부가 입력은 팝오버로 연다. 사용자가 필요하면 같은 입력 호스트를 플로팅 또는 우측 자석 도킹으로 옮기고 상단으로 복원할 수 있다. 우측 도킹은 다른 정보창을 제외한 지도 작업 폭540px 이상을 남길 때만 허용하며, 공간이 부족하면 플로팅으로 유지한다. 도킹과 플로팅을 동시에 복제하지 않는다. 지도 전체화면에서도 동일한 입력 한 벌을 활성 화면으로 옮기며, 별도 ID·별도 상태의 선택기를 만들지 않는다.
- 상권 지도 중심 조회도 상단 단일 조회 바를 쓰고, 지도/보조 경계 조절은 유지한다. 일반 분석은 지도 비율55–85%, 상권 작업공간은 정보 패널의 픽셀 너비로 조절하되 중앙 지도 최소 작업 공간과 패널 최소 너비를 우선한다. 서로 다른 단위를 하나의 비율로 보고하지 않는다. 왼쪽 조회 패널을 없애 얻은 너비는 지도·그래프에 반환한다.
- 상권의 정보·부가 작업 플로팅 창은 기본적으로 상단 작업 바 아래의 좌우에 나누어 연다. 이동·크기 변경·화면 크기 변경 뒤에도 창 전체를 화면 경계 안에 둔다. 두 창을 나란히 표시할 공간이 없으면 마지막으로 요청한 창을 표시하며 다른 창의 조건·배치 상태는 보존한다. 상단 기본 조회 바와 그 입력 팝오버는 이 정보창 배치와 구분한다.
- 위 비율은 이 제품의 작업 목적에 맞춘 기본값이다. 사람에게 보편적으로 최적인 비율·황금비라는 주장을 하지 않는다.
- 한 화면의 직사각형·행·여백은 공통 규칙을 쓴다. 기본 간격 단위는4px, 같은 위계 간격은8/12/16/24px 중 지정한 값으로 통일한다.
- 같은 화면 안의 패널은 동일한 안쪽 여백과 제목 기준선을 사용한다. 보조 패널이 많다는 이유로 각자 다른 여백·반경·폰트 체계를 만들지 않는다.
- 분석·시연의 첫 지도 화면은 지도·범례·상단 조회 입력을 우선한다. 합계·저장·긴 안내가 그 앞을 밀어내지 않게 한다.
- 화면 배치 옵션은 미리 정한 범위에서만 조절한다. 배치 초기화(지도75%), 현재 선택 상태와 좁은 화면의 정보 패널 전환을 제공한다. 비율 조절은 데이터·후보·색상 범위를 바꾸지 않는다. 이전 일반 조회280px·260–360px 조절·360×560px 플로팅 수치는 레거시 조회창의 회귀 검사나 명시적으로 남긴 선택 정보·서식 창에만 적용하며, 현행 조회 바의 기본 폭으로 사용하지 않는다.
- 시각적 순서를 바꾸면 DOM·키보드 순서도 맞춘다. CSS `order`만으로 주·보조 순서를 바꾼 채 완료하지 않는다.
- 선택 정보·순위·명시적인 부가 작업창의 자석 배치는 좌우 가장자리56px에서 위치를 예고하고 놓을 때만 확정한다. 드래그 취소는 확정하지 않는다. 상단 조회 바도 사용자 선택으로 같은 호스트를 플로팅/우측 자석 도킹으로 이동할 수 있다. 드래그 대안으로 ‘상단/띄우기/우측 고정’ 같은 명시적 버튼과 키보드 조작을 제공한다. 정보창과의 충돌을 조정하며 지도540px를 남길 수 없으면 플로팅으로 유지한다. 이동·크기·배치 초기화는 조회 조건·표시 범위·후보·통계 원값을 바꾸지 않는다. 이전의 ‘상단 조회 바는 이동 대상이 아니다’라는 전제는 이 사용자 선택형 배치 요구로 대체한다.

**수용 기준:** 같은 위계 버튼의 실제 너비·높이 오차는 반올림에 따른1px 이내. 실제 검사 화면에서 가로 넘침이 없고, 기본 배치에서 주제·조건·지도·범례가 읽힌다. 화면 크기는 기록하며 미검사 해상도까지 통과했다고 쓰지 않는다.

## 3. 창과 옵션의 역할을 통폐합한다 — 정보 계층 계약

**R06. 창을 기능별로 늘리지 않고 네 역할로 구분한다.**

| 역할 | 포함할 것 | 기본 노출 | 통합·분리 기준 |
|---|---|---|---|
| 조회 조건 | 자료, 지역, 기준기간, 시간 기준, 지표, 제공되는 성별·연령·업종 | 공통 메뉴 아래 고정된 실제 입력 바 | 입력 자체가 현재 조건 표시. 같은 상태의 읽기 전용 요약·왼쪽 입력을 반복하지 않음 |
| 표시 설정 | 색상 범위, 축 범위, 실제값/차이/지수 | 해당 지도·그래프 가까이 필요한 때 펼침 | 원값을 바꾸지 않는 도구는 조회 조건과 구분. 기본 화면을 압도하지 않음 |
| 상세·보조 분석 | 선택 지역의 추이, 두 타깃, 집단 구성, 후보·조회 조건 비교 | 공통 상세 콤보로 명시적 진입 후 | 팝업 또는 중앙 본문을 교체. 같은 내용은 한 벌만 유지하고 제목·현재 조건·지도 복귀를 보존 |
| 의미·출처 | 정의, 해석, 주의, 수집기간, 경계, 원본 링크 | 짧은 설명 버튼·접힘 주석 | 동일 설명은 한 곳에서 관리. 단위·적용 조건·자료 없음 이유는 결과 옆에도 표시 |

- 일반·시연·상권 화면 모두 실제 조회 입력 하나가 현재 조건 표시를 겸한다. 그 입력이 보이면 같은 내용을 읽기 전용 칩이나 큰 본문 요약으로 다시 표시하지 않는다. 입력을 임시로 가리는 모달에는 결과를 해석하는 데 필요한 지역·기간·대상만 제목 가까이에 남긴다.
- 기본 조회는 상단 고정 바에서 즉시 수정한다. 사용자 선택으로 플로팅/우측 도킹한 경우에도 같은 입력과 상태를 사용하고 상단 복원을 제공한다. 조건이 많으면 주된 입력을 남기고 부가 조건은 작은 정사각형 아이콘과 툴팁이 있는 팝오버로 연다. 펼침 상태·현재값·해제 범위·Esc 후 초점 복귀를 제공한다. 팝오버를 닫아도 현재 결과는 유지하며, 열 때 숨겨진 왼쪽 조회창으로 이동시키지 않는다.
- 상권 조회는 자료·기간, 지역·상권, 분석 대상이라는 의미 구분을 유지하되 이를 별도의 큰 왼쪽 창과 상단 요약으로 이중 구현하지 않는다. 자료/분기·구/동/이름/유형 등 직접 수정할 항목을 상단에 제공하고, 업종·비교·세부 항목 등 부가 입력은 같은 바의 팝오버에 둔다. 같은 하위 입력을 별도 창이나 ID로 복제하지 않는다.
- 색상·범위는 지도 표시, 축·실제값/지수는 그래프 옵션, 도킹·투명도·위치/크기는 남아 있는 정보·작업창의 창 설정으로 분리한다. 조회 바의 부가 조건 아이콘과 표시 설정 아이콘은 툴팁·접근 가능한 이름으로 목적을 구분한다. 일반 지도는 자료별 필요한 조건과 미지원 이유를 유지한다.
- 우측 상세 패널은 하나의 펼침/접힘 토글로 제어한다. 같은 패널의 중복 접기 버튼을 여러 곳에 두지 않는다. 토글의 접근 가능한 이름·펼침 상태는 현재 상태와 일치하며, 지도에서 상권을 새로 선택하면 상세가 다시 보이고 선택 근거로 이동한다.
- 형식 설정과 상세 분석을 같은 모양의 팝업으로 혼합하지 않는다. 사용자가 설정 변경인지, 자료 조회인지, 다른 화면 이동인지 예측할 수 있어야 한다.
- 깊은 분석으로 진입할수록 한 번에 보이는 정보는 줄여도 근거·현재 지역·조회 조건은 잃지 않는다.
- 상세·후보·조회 조건 비교는 분석용과 시연용 모두 같은 콤보에서 연다. 팝업↔본문은 표시 방식만 바꾸며, 본문은 아래로 펼치지 않고 중앙 내용을 교체한다. 기존 지도·그래프를 다시 만들어 조회 조건·선택 지역·확대 위치·그래프 설정을 초기화하지 않는다. 본문에서도 상단의 같은 조회 입력을 사용할 수 있어야 한다. 모달에서는 배경 조회 입력을 조작하지 못하게 하며 기존의 명시적 ‘지도에 적용’ 동작은 유지한다.
- 본문 제목·팝업 전환·‘지도로 돌아가기’는 내부 스크롤 바깥의 고정 영역에 둔다. 팝업은 닫기/Esc로 복귀한다. 현재의 공유 조회 조건을 지도에 유지하는 동작과 진입 전 조건을 별도로 복원하는 스냅샷은 구분한다. 후자를 구현하지 않았다면 자동 복원하는 것처럼 안내하지 않는다. 다른 보조 분석을 거쳐도 최종 복귀의 위치와 초점을 보존하고, 닫힌 그래프 옵션·범례·이전 상세가 앞 화면에 남지 않게 한다.
- 무결과·미지원·읽기 실패는 서로 다른 상태다. 각 상태에는 이유와 실제 가능한 복구 행동을 붙인다.
- 상세/후보의 본문에서도 같은 상단 입력 한 벌을 유지한다. 일반 지도·본문·전체화면 사이에 입력 호스트를 옮길 때 원래 지도나 비활성 탭의 숨김 상태가 활성 입력·검색 팝오버를 함께 숨기지 않게 한다. 검색·부가 조건 팝오버의 Esc는 먼저 그 창만 닫고, 모달 닫기·지도 복귀와 중복 실행하지 않는다.
- 생활인구 기본 조회는 날짜·시각·자치구·행정동·연령·성별 여섯 항목이다. 기간 → 지역 → 분석 대상의 의미와 읽기 순서를 유지하면서 상단의 직접 편집 입력으로 압축한다. 기준일 달력은 제공 기간 전체를 다루므로 별도 월 선택을 반복하지 않는다. 시간 슬라이더·이전/다음은 부가 조회 팝오버 안의 ‘시간 빠르게 이동’ 도구로 두고 지도 아래 전체폭 행이나 동일한 현재 시각 칩을 반복하지 않는다.
- 검색과 선택은 하나의 입력으로 시작하고 별도 검색 버튼을 반복하지 않는다. 지도 탐색·색상/범위는 조회창 밖 해당 지도 가까이에, 내려받기는 결과 도구에 둔다. 창 제목의 ‘창 설정’에는 배치·투명도·위치/크기 초기화만 모으며 조회 항목과 구분한다.
- 생활이동의 별도 ‘기준/집계/날짜 해석’ 박스는 상시 배치하지 않는다. 상단 집계 옵션 가까운 설명 툴팁이 현재 출발/도착 기준과 한시간/누적/일계 선택에 맞게 내용을 바꾼다. 일계에서 시간 입력이 적용되지 않는 사실, 누적 범위, 날짜 해석의 한계와 이동 건수≠고유 인원이라는 주의는 접근 가능하게 유지한다.
- 자료 설명·출처·경계·방법을 위해 결과 아래 전체폭 footer나 긴 접힘 카드를 반복하지 않는다. 관련 지도/그래프/조회 옵션 가까운 작은 설명·출처 도구로 통합한다. 단위·기간·기준시점·분모·결측 사유처럼 당장 해석에 필수인 사실은 값 가까이에 유지하고, 원본 링크와 긴 설명은 키보드로 열고 읽을 수 있는 툴팁/팝오버에서 제공한다.

**수용 기준:** 실제 기본 조회 입력은 항목별 한 개이며, 입력 자체에서 현재값과 수정 동작을 모두 확인한다. 별도 왼쪽 입력·읽기 전용 현재 조건 칩·본문 조건 요약을 동시에 노출하지 않는다. 상단 조회→본문 상세→팝업→지도→전체화면 왕복에서도 같은 상태·ID·원값을 유지한다. 부가/표시 설정을 접어도 현재 결과·지원 범위는 읽히고, 펼치면 입력·적용·오류·초기화·초점 복귀가 끊기지 않는다.

## 4. 글자와 색은 의미와 대비로 통제한다 — 가독성 계약

**R07. 같은 역할에는 같은 글자 규격을 쓴다.** 한국어를 기본으로 하고 신뢰할 수 있는 한글 서체(현재 IBM Plex Sans KR)를 유지한다. 역할별 공통 토큰으로 관리한다. 패널마다 글자 수에 맞춰 임의로 축소하지 않는다.

- 기기 모델을 추정하지 않고 사용 가능한 화면 폭으로 타입 체계를 선택한다. **모바일 767px 이하 / 태블릿 768–1199px / PC 1200px 이상**을 기준으로 한다. 각 화면에서 시연은 네 단계, 분석은 여섯 단계 이하를 유지한다. 아래는 브라우저 기본 글자 크기16px일 때의 값이며 구현은 rem 토큰으로 사용한다.

| 모드·역할 | 모바일 | 태블릿 | PC |
|---|---:|---:|---:|
| 분석 메타·축 |12|12|12|
| 분석 조건·보조 |14|14|14|
| 분석 본문·목록 |16|16|16|
| 분석 패널 제목 |18|20|20|
| 분석 화면 제목 |20|24|28|
| 분석 핵심 수치 |28|32|36|
| 시연 보조·축 |14|14|14|
| 시연 본문·주요 조작 |16|16|18|
| 시연 제목 |20|24|24|
| 시연 핵심 수치 |28|32|36|

- 입력·선택창은 모바일/태블릿16px 이상, PC 분석14px·시연18px를 기본으로 한다. 해당 크기는 각 모드의 기존 단계에서 재사용한다. 작은 화면의 터치 조작 높이는44px를 제품 기준으로 하되 작은 아이콘은 주변 간격까지 별도 검사한다.
- 모바일은 본문을 줄여 PC 정보량을 유지하지 않는다. 지도/그래프 한 가지를 주영역으로 보여 주고 조회·상세는 명시적으로 연다. 상권 첫 진입의 플로팅 창은 접고 지도 선택 시 해당 상세만 연다. 태블릿은 보조창 하나씩, PC는 공간이 허용되는 좌우 창을 사용한다.
- 기기별 크기는 `responsive-type-tokens.css`, 역할 배정은 두 mode type-scale 파일을 정본으로 한다. 포털·툴팁·폼·SVG 축도 같은 토큰을 소비한다. SVG를 작게 그리면서 글자까지 축소하지 않으며 눈금 개수와 레이아웃을 줄인다. [기기별 기준과 변경 영향](responsive-typography.md)을 따른다.

- 이 조합은 제품의 제한된 타입 토큰이다. 공식 디자인 시스템의 역할별 토큰·반복 읽기 검증 원칙을 참고했으며, 한글 사용자 모두에게 편한 유일한 최적값으로 주장하지 않는다. [공식 근거와 적용 판단](presentation-typography-rationale.md)을 따른다. 몸통 글자·단위·포털 툴팁도 모드별 집합에 포함한다.
- 행간은 본문1.6–1.65, 제목1.35–1.45, 핵심 수치1.3을 출발점으로 실제 문구에서 검사한다. 글자가 길거나 좁은 화면이라는 이유로 `clamp()`로 계속 다른 폰트 크기를 만들지 않는다. 레이아웃·줄바꿈을 바꾸되 브라우저 글자 확대는 막지 않는다.
- 주요 수치는 일반 본문보다 분명히 크고, 숫자는 고정폭 숫자 정렬을 사용한다. 시연은 설명량을 줄여 핵심 수치를 키운다.
- 긴 금액은 주정보에서 조/억/만 단위로 축약하고 정확값은 펼친 상세·툴팁·표·CSV에 보존한다. 계산·정렬·색상·증감률은 축약 문자열이 아니라 원값으로 수행한다. 단위·부호·자릿수는 잘라서는 안 된다.
- 두 시점 비교의 제목·현재 조건은 결과 카드와 별도 전체 행에 둔다. 결과 세 칸은 `repeat(3,minmax(0,1fr))`와 자식 최소 너비0으로 구성해 긴 숫자가 제목 열을 밀어내지 못하게 한다. 글자 축소 대신 단위와 배치를 조정한다.
- 같은 역할의 기존 화면이 위 기준과 다르면 공통 토큰으로 이관할 작업 항목을 남긴다. 한 선택자에만 임의 폰트를 덧씌우는 방식으로 끝내지 않는다.

**R08. 선택 상태는 색만으로, 또는 낮은 투명도로 표현하지 않는다.** 기본 표면은 흰색·연회색, 본문은 짙은 남색이다. 선택된 주제는 남색 배경+흰 글자, 순서 번호는 따뜻한 보색 배지로 구분한다. 번호도 정보이므로 글자·배경의 불투명도를 낮춰 사라지게 하지 않는다. 선택 상태에는 `aria-selected`/`aria-pressed`/`aria-current`와 시각적 상태가 일치해야 한다.

| 의미 | 색 사용 규칙 | 색 이외의 표현 |
|---|---|---|
| 선택된 주제 | 남색#173e69, 흰 글자 | 동일 크기, 선택 상태 속성 |
| 선택 순서 번호 | 밝은 주황빛#ffd28a 바탕, 남색 숫자 | 불투명도1, 고정 크기 배지 |
| 비선택 정보 | 밝은 표면, 짙은 글자 | 경계·구획 |
| 값의 규모 | 작음→큼의 순차 파랑 | 실제 범례 값·단위 |
| 증감/순이동 | 음수 주황, 양수 파랑,0 중립 | 부호·0선·‘순유입/순유출’ 문구 |
| 결측 | 회색 | ‘자료 없음’과 이유 |
| 키보드 초점 | 주변과 구분되는 윤곽 | 선택 상태와 별도 |

일반 텍스트의 대비4.5:1 이상, 큰 글자·핵심 도형/초점 표시는3:1 이상을 프로젝트 검사 기준으로 둔다. 실제 최종 색과 불투명도를 합성해 계산한다. 선택 번호 예시 색 조합의 명목 대비는 약7.69:1, 흰 글자/남색은 약10.88:1이다. 이 수치가 모든 화면의 실제 측정 결과를 대신하지 않는다.

플로팅 창은 배경 불투명도50–100%(기본100%)를 선택할 수 있다. 글자·버튼·자식 전체의 opacity를 낮추지 않는다. 좌우 고정 시100%로 표시하고 다시 떼면 이전 플로팅 설정을 복원한다. 투명 배경 뒤에 지도 도형·라벨이 있는 실제 상태의 읽기 대비를 확인하며, 이 표현 설정으로 통계·조회 조건을 바꾸지 않는다.

**R09. 숫자를 일괄적으로 보색으로 칠하지 않는다.** 번호의 강조색과 통계 증감색을 구분한다. 정상/선택/마우스 오버/키보드 초점/비활성 상태를 모두 검사한다. 단순한 카드 장식에 경고색을 쓰지 않는다.

## 5. 지도는 읽을 수 있는 공간 분석 도구다 — 지도 계약

**R10. 도형·지역명·선택·미리보기는 별도 층으로 그린다.** 지역명은 모든 도형을 그린 뒤 최상위 라벨 층에 표시한다. 다음 지역 도형이 이전 지역명을 덮어서는 안 된다. 흰색 윤곽과 충분한 대비를 제공하고 라벨은 포인터 입력을 가로채지 않는다.

- 전체 맞춤 상태에서 구·동·상권의 도형·지역명이 SVG/부모 영역에 잘리지 않는지 검사한다. 라벨이 좁은 도형을 벗어나면 도형만의 문제가 아니라 충돌·위치·최대 줄 수·보조 라벨 처리를 검토한다.
- 구/동 전환, 선택 수치 추가, 긴 지역명, 확대·축소 후 라벨과 수치가 서로 겹치는지 확인한다. 도형 확대 배율과 SVG 뷰박스의 화면 배율을 함께 상쇄해 지정한 화면 픽셀 글자 크기와 윤곽을 유지한다. SVG의 명목 CSS크기만 검사해서는 안 된다.
- 화면 확대·축소는 **− / 배율 / + / 원래 범위** 순서를 기본으로 한다. 배율을 제공하지 않는 경우에도 −가 +보다 먼저 온다. 모든 지도에서 같은 원칙을 적용한다.
- 휠 확대와 드래그 이동은 클릭 선택과 구분한다. 드래그 직후 상세가 잘못 열리지 않아야 한다.
- 일반 지도도 조회 옵션을 왼쪽에 배치하거나 플로팅으로 전환해 세로 공간을 확보한다. 옵션을 접으면 지도에 공간이 반환되어야 하며, 지도·지역명 글자는 축소하지 않는다.
- 전체화면은 제목·핵심 조건을 압축하고 지도가 남은 공간을 채운다. 기존 기본 지도를 단순히 고정 높이로 확대하지 않는다.
- 지도 후보 추가 후에는 전체화면 안에서도 후보 수·담긴 이름·해제·비교 열기가 보여야 한다.
- 상권 지도는 서울 전체 → 구 → 선택 상권의 공간 탐색과 복귀를 제공한다. 상권 클릭은 도형 확대와 정보창의 선택 근거를 함께 바꾸며, 구 지도 복귀 시 기존 조회 조건과 지도 위치를 유지한다. 정보창은 현재 지도 수준에 맞춰 전체/구의 목록 또는 개별 상권 수치를 우선한다. 추이·후보 추가는 지도 탐색과 분리한 명시적 동작으로 제공한다.

**R11. 색상 범위는 수치와 별도다.** 0 포함 규모 비교, 관측 최솟값 아래 여유율 차이 강조, 직접 지정 범위를 구분한다. 자동 여유 하한은 `최솟값 − (최댓값−최솟값)×여유율`이며 비음수 자료는0 아래로 내리지 않는다. 음수가 포함되거나 증감·순이동 지표이면0 중심 대칭 범위와 부호를 유지한다. 두 시점 나란히 비교는 두 시점 값의 합집합으로 하나의 공통 눈금을 사용한다. 확대·이동·선택 집중은 원값·범례 범위를 바꾸지 않는다.

- 일반 지도·두 시점 분포·증감·상권의 색상 최솟값·최댓값을 접힌 표시 설정에서 직접 조절한다. 입력은 원래 단위로 받고, 값의 축약은 요약 표시에만 사용한다. 최솟값<최댓값·유한수·비음수 규모의 하한≥0을 검사한다. 증감은 한쪽 입력을 바꾸면 반대쪽도 같은 절댓값으로 맞춘다.
- ‘범위 좁히기 −20% / 넓히기 +20%’는 현재 범위 폭을0.8/1.2배로 바꾼다. 가능한 동안 중심을 유지하고, 양수 범위의 하한이0에 닿으면 상한을 조정해 폭을 유지한다. 증감은0 중심 반경을 조절한다. 자동·직접 상태와 현재 범위를 가까이에 표시하며 초기화를 제공한다.
- 시간·비교 시점 변경에서 직접 범위는 고정해 같은 색의 의미를 유지한다. 공간 단위·지원 차원·지표의 부호 체계가 달라 범위를 초기화해야 한다면 그 전환 규칙을 소비자별로 명확히 정한다. 잘못된 입력은 마지막 유효 범위를 바꾸지 않으며 이유와 복구 경로를 표시한다.
- 범위 밖 값은 끝 색으로 포화시키되 원값·차이·순위·후보·CSV를 바꾸거나 해당 지역을 제거하지 않는다. 하한 미만/상한 초과 관측값 개수를 알리고 툴팁에 끝 색의 의미를 설명한다. 두 지도에 같은 지역의 값이 두 번 있으면 ‘지역 수’가 아니라 ‘관측값 수’로 세며 null/비공개/미연결은0·최저색으로 대체하지 않는다.
- 상권의 자동 분위 분류와 직접 값 범위는 다른 분류다. 직접 범위에서 같은 값 간격을 사용하면 선택 상태·범례·설명도 ‘직접 범위 · 같은 값 간격’으로 표시한다. 초기화는 선택된 자동 분류와 일치해야 한다.
- **최신 범례 기본형은 짧은 색상 막대+‘범례’ 버튼이다.** 일반·두 시점·증감·상권의 정확 구간·단위·0·결측·포화 의미는 가벼운 툴팁으로 읽는다. 상시 큰 범례와 범례용 이동·크기 조절 창은 지도 공간을 차지하므로 사용하지 않는다. 이전 이동형 상권 범례는 과거 구현 이력이며 이 규칙으로 대체한다. 마우스 오버·클릭·키보드 초점으로 열고 Esc/외부 클릭으로 닫는다. 내부 읽기·스크롤은 유지하고 다른 의미 설명과 겹치지 않게 한다.

**R12. 검색·유형·지역 필터의 교집합을 설명한다.** 입력 공백을 정규화하되 원래 상권명·코드는 보존한다. 조회 개수·적용 조건·자료 없음 개수·무결과 복구를 표시한다. 동명이름이 여러 구에 있으면 구별 위치를 안내한다. 검색·유형 변경은 카메라를 자동 초기화하지 않는다. 상권 도형·순위 결과 선택은 R10에 따라 해당 경계로 확대하고 정보창을 연동한다. 구 지도 복귀는 기록한 부모 카메라·조회 조건을 복원하며 선택 강조는 유지하고 정보창은 구 목록으로 전환한다. ‘조회 범위 맞춤’은 별도 명시적 행동이다. 상권 지도의 자치구 배경 도형·구 이름은 지역 탐색 대상이며 클릭·키보드 실행으로 해당 구 필터를 적용하고 종속 동·현재 상권 선택을 해제해 구 경계에 맞춘다. ‘서울 전체 지도’는 구/동 제한과 현재 선택을 해제하되 기간·분석 기준·검색/유형·후보를 유지한다. 관련 선택지 건수는 나머지 조건의 교집합이며 구 변경이 종속 동을 해제하므로 구 건수는 구·동을 제외한 조건으로 계산한다.0건은 비활성으로 보이되 현재 선택은 해제할 수 있게 남기고 결측·미지원과 구분한다.

## 6. 조작의 결과는 끝까지 연결한다 — 상호작용 계약

**R13. 조회 조건은 하나의 상태 원천을 공유한다.** 조건을 바꾸면 지도 도형/색/값, KPI, 순위, 상세, 보조 그래프, 추이, 툴팁, CSV의 같은 범위가 함께 바뀐다. 현재 조건만 바뀌고 결과가 그대로이거나, 값만 바뀌고 단위·설명이 남는 상태를 허용하지 않는다.

**R14. 버튼은 결과를 예고하고 결과까지 도달한다.** ‘상세 분석’처럼 목적지가 여러 개인 경우 ‘동별 분포 보기’, ‘시간 추이 보기’처럼 다음 결과를 이름에 드러낸다. 활성 버튼을 눌렀는데 변경·안내·이동이 하나도 없으면 결함이다. 상한·중복·자료 없음은 비활성 또는 명확한 대안으로 처리한다.

**R15. 화면 여정에는 복귀가 있다.** 지역 지도→구 상세→동 추이→후보→시작 화면의 경로를 끊지 않는다. 분석·시연 모두 같은 상세 콤보와 팝업↔본문 전환을 쓴다. 본문은 중앙만 교체하고 상단 조회 바와 복귀 동작을 유지한다. 지도 집중 보기와 상세를 왕복할 때 목적지가 실제 보이고 원래 지도의 선택·확대 위치가 보존되어야 한다. 브라우저 자체 전체화면은 별개의 상태이며 자료·조회 조건 변경과 상세 왕복 때문에 해제하지 않는다. 표시 방식 전환은 조회 조건을 변경하지 않고, 상세에서 명시적으로 바꾼 공유 조건은 지도 복귀에도 유지한다. 여러 보조 분석을 거친 뒤에도 최초 진입 위치와 사용할 수 있는 초점으로 복귀한다. 히어로 복귀와 이어보기는 선택 조건·후보에 미치는 영향을 명확히 한다.

**R16. 후보와 조회 조건 저장은 다른 도구다.**

- 후보는 조사 중인 지역 목록이다. 다른 구/동 탐색, 조건 변경, 시나리오 재적용으로 조용히 지우지 않는다. 제거는 ‘후보 해제/비우기’처럼 명시한다.
- 최대3개 후보의 상한은 모든 진입점에서 동일하다. 가득 찼으면 비교 화면 열기 또는 해제 안내를 제공한다.
- 혼합 구·동 후보를 허용하면 현재 지도 범위가 아니라 각 후보의 원자료 코드로 독립 조회한다. 이름에는 소속 구·동을 구분하고 같은 자료·기간·타깃으로 비교한다.
- 조건 저장은 서로 다른 가설의 스냅샷이다. 현재 후보 목록과 혼동되지 않게 이름·보관 기간·기준안 변경을 설명한다.
- 빈 후보 장면은 현재 보이지 않는 ‘오른쪽 순위’를 지시하지 않는다. 실제 후보를 담는 장면으로 한 번에 복귀시킨다.

**R17. 툴팁은 값+의미+해석+주의를 제공한다.** 마우스 오버·키보드 초점·클릭으로 읽고 Esc·외부 클릭으로 닫을 수 있어야 한다. 툴팁 내부를 눌러 읽을 때 닫히지 않고, 닫은 직후 자동으로 재열리지 않는다. 화면 경계와 스크롤 부모에 잘리지 않으며 한 번에 여러 설명창이 겹치지 않는다.

## 7. 데이터 정의를 화면 계약으로 지킨다

**R18. 모집단·시점·단위·공간 단위를 데이터와 함께 다룬다.** 준비 파일에는 출처, 수집일, 기준기간, 공간 단위, 지원 차원, 코드 연결, 결측 정책을 남긴다. 정적 파일로 시연하는 동안에도 원자료와 준비 파일을 구분하고 개인 키는 공개 파일에 넣지 않는다. 장기 데이터가 쌓이면 별도 백엔드 구조로 확장하되 화면 계산의 정의를 바꾸지 않는다.

| 자료 | 허용되는 의미 | 금지되는 치환 |
|---|---|---|
| 생활인구 | 특정 시점에 머무는 내국인 추계 인구 | 하루 고유 방문자·광고 순도달 |
| 생활이동 | 출발/도착 기준의 이동 건수 | 중복 제거 유입 인원 |
| 주민등록인구 | 행정 등록 거주 기반 | 해당 시각 실제 상주 인원 |
| 전입·전출 | 연간 주소 이동과 전입−전출 | 현재 거주민 수·당일 상권 방문 |
| 추정매출 | 제공 업종·분기의 추정 소비 지표 | 회계 매출·광고 기여 매출 |

- 생활인구−주민등록인구를 외부 방문자로, 시간별 이동 합계를 하루 고유 인원으로, 서로 다른 기간의 매출/인구를 구매전환율로 표시하지 않는다.
- 성별·연령·요일·시간의 주변분포를 곱해 교차 타깃을 만들지 않는다. 생활인구처럼 원본에 성·연령 교차 열이 있는 경우에만 직접 집계한다.
- 전입전출 성별은 현재2021–2025 구·동, 연령별은2025 자치구9구간이다. 미지원 연도·동별 연령은 총계로 몰래 대체하지 않는다. 특정 말일이 확인되지 않은2025 주민등록 자료에는 임의의12월31일을 붙이지 않는다.
- 원값 null/비공개/미연결은0과 다르다. 부분 결측이면 정해진 집계 정책에 따라 자료 없음으로 유지한다. 경계가 없는 동을 임의 분할·추정 도형으로 채우지 않는다.
- 수도권·관광객·직업 등 아직 확보되지 않은 범위는 실제 자료 확보 후 제공한다. 서울 자료를 광역 자료처럼 보이게 하는 선택지를 만들지 않는다.

### 상권 매출2026년1·2분기 확장

- 기존2025 자료·값·기간·산식·기능을 보존하고 공식2026Q1/Q2 원문을 확보·독립 검증한 뒤 시계열을 추가한다. 새 기간을 선택지에 적거나 정제 파일을 만든 사실만으로 원문 확보·자료 검증·UI·공개 지원을 모두 완료로 쓰지 않는다. 새 수치·최종 연결 범위가 미확정이면 그대로 기록한다.
- 지원 기간은 실제 확보된 자료와 manifest에서 결정한다. 상권 단위 매출과 행정구역 단위 매출은 다른 준비 자료이므로 한쪽의2026 지원을 다른 쪽에 자동 적용하지 않는다. UI의 연도/분기 문구·기본 선택·자료 설명도 각 자료의 지원 기간과 일치해야 하며, 현재 문서의 일반 데이터 계약을2025만 지원한다는 고정 가정으로 구현하지 않는다.
- 공식 원문 출처·기준기간·수집시각·파일 식별/버전과 필요한 변환 내역을 보존한다. 독립 검토자가 원문에서 대표 상권 코드·업종·분기·값·합계·결측을 확인하고 준비 파일과 대조한다. 기존2025의 원값·레코드·합계·지원 차원을 회귀 확인하며 새 자료에 맞추려고 수정하지 않는다.
- 2026 통계의 상권 코드와 로컬 경계 코드의 연결률/미연결 목록을 확인한다. **코드 연결은2023년 로컬 경계가2026 통계와 동일 형상이라는 증거가 아니다.**2026-07-03 공식 공지의 원문·적용 범위·변경 설명과 로컬 형상 검증을 별개로 기록한다. 공지일을 경계 기준일로 임의 치환하거나 공지 확인만으로 동일 형상을 주장하지 않는다. 미검증 한계는 관련 지도·출처 설명에 남긴다.
- null·비공개·미연결은0과 다르다. 시간·요일·성별·연령 주변분포의 합계가 총계와 다르면 원문 차이와 집계 정의를 기록하고, 총계에 맞추기 위한 임의 배분·스케일 조정·행 추가를 하지 않는다. 주변분포를 곱해 미제공 교차 집계를 만들지 않는다.
- 새 기간을 배포할 때 manifest의 실제 지원 기간·파일/버전과 로더 캐시 키를 함께 검토한다. 오래된 목록·데이터가 새 분기 제목 아래 나타나지 않도록 응답 기간과 선택 기간을 대조한다. 로컬 검사만으로 브라우저/CDN 갱신을 추정하지 말고 공개 Pages의 선택지·자산 버전·값을 별도로 확인한다.

**R19. 보조 그래프는 지도와 다른 질문에 답한다.** 지도는 ‘어디’, 구성 막대는 ‘어느 집단’, 추이는 ‘언제’, 후보 비교는 ‘어느 대안’을 답한다. 동일 정보를 큰 카드로 반복하지 않는다. 자료가1개년뿐이면 장기 추세처럼 보이는 그래프를 만들지 않고 비교 불가 범위를 설명한다. 축·색상·지수 변경은 해석을 바꾸므로 그 결과를 도표 가까이 명시한다.

- 시계열의 표시 방식·축·재생 속도·계산 설명은 ‘그래프 옵션’에서 필요할 때 연다. 현재 표시 방식과 축 범위·해석 주의는 그래프 가까이에 남긴다. 재생 조작은 작은 한 줄로 유지하고 복귀·후보 동작은 헤더의 작은 버튼으로 제공한다. 기준100 지수는 기본적으로100을 가운데 둔다. 반경은 `max(1, max(abs(지수−100)) × (1+여유율))`, 범위는 `100±반경`이며 기본 여유20%, 선택10/20/30%를 제공한다. 상수 시계열은 최소±1포인트로 표시한다. 실제값·증감의0 포함/자동/직접 지정은 유지한다. 축 선택·초기화는 현재 보기와 일치해야 하며 원값·기준시점·재생 상태를 바꾸지 않는다.
- 모든 팝업을 움직이는 창으로 바꾸지 않는다. 의미·해석 설명은 기존 가벼운 팝오버를 유지하고, 지도·그래프 작업을 계속하면서 참고할 조회·그래프 설정에 이동/크기 조절을 적용한다. 범례는 R11의 가벼운 툴팁으로 읽는다. 정확값 표의 원단위·의도적 가로 스크롤과 자료별 지도/상세 분석/후보 비교 보기는 유지한다.
- 상권 매출 기간 확장 시 같은 자료·상권·업종·분석 기준의2025Q2를 기준으로2026Q2를 선택하는 전년동기 여정을 확인한다. 기준/선택 기간을 명시하고2026Q1→Q2 직전 분기 비교와 혼동하지 않는다. 차이·증감률·기준100은 기존 산식을 유지하고, 한쪽 null 또는 비율/지수 기준0의 계산 불가를 원값0으로 채우지 않는다. 기간 입력·지도·정보·그래프·CSV·후보는 같은 선택 상태를 사용한다.

## 8. E2E와 시각 검수의 완료 조건

**R20. 버튼 작동·수치 의미·실제 화면을 모두 통과해야 완료다.** 아래 세 종류를 분리해 기록한다.

| 검수 | 반드시 확인할 것 | 통과 증거 |
|---|---|---|
| 기능 E2E | 조작→결과→후속 행동→복귀, 반복 선택, 키보드·포인터 | 실행 경로와 실제 상태 |
| 의미 E2E | 독립 원자료의 코드·열·기간·분모·단위·결측·순위·차이 | 화면/지도/그래프/CSV 동일 기대값 |

- [ ] 상권 상단 입력과 부가 조건 팝오버가 자료·기간/지역·상권/분석 대상의 의미를 유지하고, 숨겨진 왼쪽 조회창을 여는 중복 경로 없이 같은 입력·현재값·후보를 유지한다.

- [ ] 현재 Chrome의 분석·시연에서2026Q1/Q2 기간 변경, 기준2025Q2→선택2026Q2, 지도/정보/추이/후보/CSV의 같은 코드·기간·단위·값과 복귀를 확인했다. 데이터/계산 검사와 실제 화면 검수는 별도로 기록했다.
- [ ] manifest·지원 기간 목록·파일/캐시 버전을 갱신하고 이전 응답의 새 분기 오표시를 검사했다. Pages 배포 후 공개 선택지·자산 버전·대표 실제 값도 별도 확인했으며,2025 과거 실행을 새 기간 검증으로 소급하지 않았다.
- [ ] 후보를 담고 다른 구/동을 조사해도 유지된다. 혼합 후보값은 독립 원자료와 같다.
- [ ] 활성 버튼에는 실제 결과가 있다. 상한·무결과·미지원·결측에서 복구할 수 있다.
- [ ] 지도→상세→추이→후보→시작 및 시연 장면 복귀가 실제 보이는 위치·포커스로 끝난다.
- [ ] 마우스 오버·드래그·휠·클릭·Esc·Tab 경로를 검사했다.
- [ ] 실제 검사항목·뷰포트·버전·미검사 범위를 보고서에 남겼다.
- [ ] TypeScript/빌드와 변경 파일 검사를 통과했다. 테스트는 변경 영향에 맞는 것을 실행했다.

**R21. 기능 통과를 UX 통과로 보고하지 않는다.** 원래 버튼이 작동했어도 결과 안내가 없으면 발견성 문제다. 도구 대기시간·캐시·자동화 선택자 오류는 제품 결함과 구분한다. 단발 관찰은 재현 가설로 표시한다. 실제 성공 시간·오류율을 수집하지 않았다면 개선 효과를 수치화하지 않는다.

## 9. 작업·검증 기록의 운영 규칙

- 구현자는 변경한 규칙ID와 영향 화면을 변경 설명에 적는다. 새 요구는 아래 추적표에 연결한다.
- 감사자는 소스 확인, 과거 실행 확인, 현재 실화면 확인을 구분한다. 작성자 자신의 ‘구현 완료’만으로 검증 완료를 표시하지 않는다.
- 공개 전에는 현재 산출물과 공개 페이지를 별도로 확인한다. 배포 성공만으로 공개 화면 확인을 대신하지 않는다.
- 재현 자료에는 허용된 공개 통계만 넣는다. 원본 요청·준비 파일·기대값·실행 결과를 구분한다.
- 불변 조건은 고치지 않는 한 계속 유지한다. 데이터 범위·단위·산식 변경은 설명·테스트·문서까지 함께 바꾼다.

- 연령·성별 교차 통계는 실제 교차 원자료가 있을 때만 제공한다. 날짜와 모집단을 툴팁·접힌 상세에서 확인할 수 있어야 한다.
- 최신 실제 실행 범위와 제한은 [지도·기간 실행 보고](map-range-and-period-report.md)를 따른다.

## 상단 조회 바·부가 팝오버 현행 기준
- 생활인구·생활이동·전입전출·행정구역 매출·상권 모두 상단의 실제 입력 한 벌로 조회와 현재 조건 표시를 통합한다. 기간 → 지역 → 분석 대상/기준의 의미·키보드 순서를 유지한다. 글자 크기를 줄여 과도한 항목을 한 행에 우겨 넣지 않고, 부가 항목만 설명 가능한 작은 아이콘의 팝오버로 제공한다.
- 상단 조회 바는 기본적으로 공통 메뉴 아래에 고정하며, 중앙 본문 교체로 숨겨지지 않는다. 사용자가 플로팅/우측 도킹을 고르면 같은 입력 호스트를 옮기고 상단 복원을 제공한다. 일반/본문/전체화면·배치 전환 사이에 조상 노드·가시성 기준·포털 대상을 갱신한다. 이전 지도에 붙어 있던 참조 때문에 활성 입력이나 팝오버가 사라지면 결함이다.
- 입력에는 현재값과 수정 기능을 함께 제공하고, 같은 값을 보여주기 위한 큰 제목·읽기 전용 칩·왼쪽 조회 패널을 반복하지 않는다. 팝오버의 항목 해제와 전체 조건 초기화는 범위를 구분한다.
- 부가 팝오버는 관련 입력 가까이 열고 화면·스크롤 부모 경계에 잘리지 않아야 한다. 전체화면에서는 해당 전체화면 요소를 포털 대상으로 사용한다. 모달 안의 옵션은 열린 모달 안에서 동작하고 배경의 같은 입력을 조작하지 않는다.
- 비활성 자료/화면의 바와 팝오버는 숨긴다. 이전 창이 다음 화면의 옵션이나 헤더를 덮지 않게 하되, 활성 입력이 숨겨진 원래 지도 노드의 가시성에 잘못 종속되지 않게 한다.
- 이전 조회창의 고정280px·260–360px 조절·플로팅360×560px·한 열 배치는 과거 구현 이력 또는 명시적으로 남긴 부가 작업창 회귀 기준이다. 이를 현행 기본 조회 구조로 되살리지 않는다. 최신 사용자 선택형 배치는 기본 상단 바의 동일 호스트를 이동하며, 우측 최소 지도540px·좁으면 플로팅·상단 복원·드래그 대안·상태 불변 계약으로 별도 검사한다. 선택 정보·순위·그래프 옵션의 이동/크기 조절 계약은 유지한다.
- 새 옵션 계열 추가 시 감사 목록과 현재 실행 기록을 함께 갱신한다. [옵션 전수 감사](option-layout-source-audit.md)와 [이전 실행 기록](compact-options-report.md)은 해당 버전의 이력이다.

## 일자 기간 조회와 상태 보존
- 생활인구 일자 조회는2026년1–10월304일을 제공한다. 기본 조회는 기준일 달력과 시각으로 제공하고 별도 월 선택을 반복하지 않는다. 요일·월 구간 평균의 월 선택은 별도 분석이며 일자 조회를 월 합계로 해석하지 않는다.
- 응답 날짜가 현재 선택과 일치하기 전까지 값·내려받기·팝업을 노출하지 않는다. 이전 응답이 나중에 도착해도 새 조건을 덮지 않는다.
- 현행 통합의 실행 범위·제한은 [공통 조회·시연 실행 기록](shared-query-presentation-report.md)에서 별도로 판정한다. [조회 개선 실행 보고](focused-query-report.md), [이전 독립 조회창·기간 실행](free-query-and-period-report.md), 과거 지도 내부 제한·10월만 제공한 보고는 해당 버전의 이력이다. 독립 원자료 기대값은 [생활인구 수용 기준](population-query-acceptance.md)을 따른다.
- 자료 목록 범위가 바뀌면 목록 요청 버전도 갱신한다. 새 화면이 브라우저/CDN의 이전 목록을 사용하지 않는지 공개 화면에서 확인한다. 창 경계는 스크롤바를 제외한 실제 화면 너비를 사용한다.

## 브리핑 위계·선택 동기화 현행 수용 기준
- 자료는 모집단을 고르는 1차 축이다. 지도는 기본 작업 화면, 상세 콤보는 추이·구성·후보·조건 비교를 고르는 진입점이며, 팝업/본문은 그 내용을 표시하는 방식이다. 번호·진도·이전/다음으로 강제 순서를 만들거나 후보 비교를 같은 위계의 독립 버튼으로 반복하지 않는다. 자료 전환은 자료별 조건·후보를 보존하고 해당 자료의 현재 결과를 일관되게 표시한다.
- 지도 클릭은 지역 옵션·작은 요약·추세·CSV를 같은 범위로 바꾼다. 마우스 오버와 구분한다. 선택이 지도 단위·카메라를 뜻하지 않으며 명시적 상세에서만 확대한다. 미지원 연령 동 상세는 구성 분석으로 연결한다.
- 비교 목록과 선택 요약의 범위를 제목으로 구분한다. 반복 기간 문구는 헤더로 합치고 수식·주의는 관련 값에 붙인다.
- 그래프 옵션은 본문 높이를 밀지 않는 비모달 창으로 제공한다. 현재 표시·실제 기준 시점·축 주의는 본문에 유지하고 재생 조작은 32px 버튼의 한 줄로 제공한다. 여러 옵션이 열려도 Esc 하나는 한 창만 닫는다.
- 현행 실행과 한계는 [브리핑 위계·연동 보고](briefing-hierarchy-report.md)를 따른다. 과거 단계식 메뉴·미리보기만 갱신하던 기록은 당시 이력이다.

## 분석·시연 공통 상세와 시연 집중 기준
- R03/R05/R06/R19: 기본 추이 그래프와 실제 SVG 플롯은 메뉴 아래 남은 가로·세로를 채운다. 지역·조건은 제목에 두고 큰 안내 상자를 반복하지 않는다.
- 분석·시연 모두 같은 상세 콤보에서 해당 내용 하나를 팝업 또는 중앙 본문으로 연다. 긴 페이지 아래로 이동하지 않는다. 본문에서는 상단 조회 바를 유지하고, 팝업에서는 배경 조작을 막는다. 같은 하위 컴포넌트를 옮겨 쓰며 조회 조건·그래프 설정을 별도로 복제하지 않는다.
- 두 시점 비교 등 보조 내용의 표시와 계산은 모드 간 같은 정책을 쓴다. 시연에만 별도 열기 버튼·장면 조건을 남겨 무반응이나 숨김이 생기지 않게 한다. 비활성 자료·보기·보조 화면에 이전 창이 남지 않아야 한다.
- 차이는 시연의 정보 밀도·R07 네 단계 글자·핵심 결과 강조에 둔다. [시연 그래프 집중 보고](presentation-focus-report.md)의 별도 장면/창 동작은 과거 이력이며, 현재 수용 판정은 [공통 조회·시연 실행 기록](shared-query-presentation-report.md)을 따른다.

## 제목·조건·단위 압축 기준
- 같은 결과의 제목·현재 범위·짧은 주의는 한 줄 우선으로 묶되 좁은 영역은 자연스럽게 줄바꿈한다. 글자를 줄이거나 뜻을 자르며 형식만 맞추지 않는다.
- 일반적 조작·목적 설명과 상권 구/동/유형 등 부정보는 접근 가능한 툴팁으로 제공한다. 시간 기준·분모·결측·통계 간 기준시점 차이 같은 해석에 필수인 정보는 가까이에 남긴다.
- 화면 단위에 ‘원본 추정치’ 같은 장문 수식어를 숫자마다 반복하지 않는다. 짧은 단위와 한 번의 의미 설명을 사용하고 원값·CSV 설명은 보존한다.
- 출처·경계·방법의 전체폭 footer와 생활이동 기준/집계의 독립 해석 박스는 가까운 작은 설명 도구로 통합한다. 현재 선택에 따라 설명을 갱신하고 필수 단위·기간·분모·결측 사실을 삭제하지 않는다.
- 고정 옵션의 내용과 반복되는 제목·부제를 제거할 수 있다. 이동 가능한 창은 소유·이동 대상을 구분할 짧은 제목과 닫기·초기화를 유지한다.
- 상권 구 라벨도 상권 도형 뒤 최상위층·짙은 글자와 흰 윤곽·화면상 일정 크기·포인터 비가로채기를 적용한다.
- 적용/유지 범위와 현재 실행은 [제목·설명 압축 보고](compact-headings-report.md)를 따른다.

## 공통 페이지 폭과 지도 팔레트
- 상단과 본문·그래프의 바깥 여백·시작/끝선을 같은 기준으로 쓴다. 다른 목적의 내부 조건창·보조창 너비까지 같게 강제하지 않는다. 메뉴 위치는 별도 요청 없이 이동하지 않는다.
- 지도 그라데이션은 기존 표시 설정에서 선택하고, 기본/선택 색상표는 작은 미리보기로 비교한다. 일반·상권·두시점·증감과 범례가 같은 선택을 공유한다.
- 색상표는 원값·수치 범위·분류 기준을 바꾸지 않는다. 증감의0중심·중립색·부호를 보존하고 설명에 특정색을 고정하지 않는다. 결측은 색상표와 별개 상태다.
- [현재 색상·폭 실행](palette-and-alignment-report.md)과 [조회 옵션 참고 설계](tableau-query-options-plan.md)의 구현/제안 구분을 따른다.
- 단일 상단 입력·관련 검색·부가 조건 팝오버의 설계는 [조회 옵션 현행 설계](tableau-query-options-plan.md)를 따른다. 이전 조건 칩·독립 조회창·자석 배치의 [수용 기준](tableau-query-acceptance.md)과 과거 실행 보고는 해당 버전의 이력이며 새 통합의 검수 증거로 소급하지 않는다.


## 2026-11-17 상세·공통 도구 추가 기준

- 공통 화면 전환·정보창 열기/닫기·배치 설정은 최상단 한 곳에서 제공한다. 정보창 안에 같은 접기/배치 버튼을 반복하지 않는다. 배치 초기화는 열기/닫기와 다른 행동이므로 상단 배치 메뉴 안에서 명확히 구분한다.
- 상권 지도와 지역 분석 지도 전환은 목적지를 버튼명으로 표시하고 현재 모드·조회 상태를 보존한다. 단순 ‘이전 화면’으로 시작 화면이나 브라우저 방문 이력에 의존하지 않는다.
- 지도 내부의 범위 맞춤·지역 필터 해제는 지도 도구로 묶고, 구 경로·단위·관측 상태·상세 선택은 한 행을 우선한다. 무결과 복구와 필수 결측 의미를 삭제하지 않는다.
- 상세의 화면 제목·비교 기준·선택값·도구를 압축하되 차트 공간이 실제 늘었는지 측정한다. 분포지도는 지도와 범례·핵심 주의가 함께 들어가야 하며, 공통 display/height 규칙 때문에 SVG가0이 되지 않는지 실제 화면으로 확인한다. 긴Y축 눈금은 폰트·범위에 맞춰 여백을 확보한다.
- 이번 적용·검수 범위는 [11/17 상세 실행](detail-compact-execution-2026-11-17.md)과 [독립 감사](detail-compact-audit-2026-11-17.md)를 따른다. 과거/중간 이미지의 실패와 최종 재검수를 구분한다.
