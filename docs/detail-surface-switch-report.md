# 상세 조회의 팝업·본문 전환

2026-11-16. R05 공간, R06 역할 구분, R20 실제 실행 기준을 적용했다.

## 동작 계약

- 상세 종류는 기존 콤보에서 고른다. 팝업의 `본문에서 보기`, 본문의 `팝업으로 보기`는 같은 상세 컴포넌트 한 벌을 옮기며, 조회·선택·그래프 상태를 새로 만들지 않는다.
- 일반 분석은 중앙 작업 영역을, 상권 지도는 좌우 조건·정보창 사이 중앙 영역을 교체한다. 아래에 새 내용을 추가하거나 지도 컴포넌트를 없애고 다시 만들지 않는다. 원래 지도는 가려진 채 유지한다.
- 본문 제목·전환·`← 지도로 돌아가기`는 내부 스크롤 바깥에 두어 계속 보인다. 팝업은 닫기/Esc로 복귀한다. 처음 진입한 위치와 초점을 공통 관리해, 다른 상세를 거친 뒤에도 숨겨진 버튼으로 초점을 돌리지 않는다.
- 표시 방식만 바꾸면 모든 조건을 유지한다. 그래프 시점 선택 등 기존에 지도 조건을 바꾸는 동작은 그대로 공유한다. 지도 복귀는 현재 조건을 유지한다는 설명을 붙인다. 진입 전 조회를 별도로 복원하는 스냅샷이나 미적용 초안은 이번에 만들지 않았다.
- 그래프 옵션이 열린 상태에서 화면을 옮겨도 옵션의 포털 대상·조상 관찰을 다시 연결한다. 원래 지도는 마운트 상태로 유지하여 확대·이동 위치를 보존한다.
- 적용 대상은 분석용 생활인구·생활이동·전입전출·행정구역 매출·상권 지도다. 시연용 기존 장면 방식은 변경하지 않는다. 화면별 표시 선호는 해당 실행 세션에서 유지하며 새로고침 저장은 하지 않는다.

## 영향 범위

| 대상 | 변경 | 보존 |
|---|---|---|
| 공통 상세창 | 중앙 본문 호스트·전환·복귀·처음 진입 위치/초점 | 기존 하위 컴포넌트·콜백·데이터 상태 |
| 공통 플로팅 옵션 | 본문/팝업 이동 후 포털 재연결 | 그래프 값/기준시점/축설정 |
| 일반 분석·상권 조회 | 공통창의 중앙 호스트 위치 검토 | 별도 페이지별 구현·산식 수정 없음 |
| 과거 시안·보고 | 구현 전 이력으로 보존 | 기존 검수 결과를 이번 전환에 소급하지 않음 |

조회 상태의 범위를 별도로 정하는 근거로 [Power BI 드릴스루](https://learn.microsoft.com/en-us/power-bi/create-reports/desktop-drillthrough)와 [Tableau 필터 액션](https://help.tableau.com/current/pro/desktop/en-us/actions_filter.htm)을 확인했다. 제품별 방식을 그대로 복제하지 않고 현재 대시보드의 공유 조건 동작을 유지했다.
