# 시연용 그래프 집중 화면 — 독립 소스 검토·수용 기준

2026-11-15 · R01/R03/R05/R06/R07/R19/R20. 이 문서는 변경 전 소스 검토와 실행 수용 기준이다. 브라우저를 실행한 통과 보고가 아니며 최종 구현·공개 검수는 부모 실행 보고에서 별도로 기록한다.

## 판단 목적

광고주가 선택 지역의 시간·기간 변화를 한눈에 읽는 것이 주목적이다. 주정보는 추세선·현재값·축·기준 시점이고, 두 시점의 정확한 차이는 질문이 나왔을 때 여는 보조 분석이다. 그래프가 화면을 채운다는 뜻은 패널의 빈 바탕을 늘리는 것이 아니라 실제 도표의 가로·세로 작업 영역이 남은 화면을 사용하는 것이다.

## 변경 전 확인한 원인

- `layout-standard.css`는 시연 `.trendSvgWrap svg`를 260px 높이로 정한다. `.compact-trend-controls.css`는 패널 최소 높이만 해제하므로 화면이 커져도 실제 도표는 커지지 않는다.
- 시연 `.analysisView`는 `interaction-contrast.css`에서 가용 화면 높이를 받지만 `.dashboardContent`는 스크롤 부모다. 그 안의 활성 자료 묶음·추세 패널이 남은 높이를 이어받는 연결은 없다.
- `TrendExplorer.tsx`의 고정 `viewBox="0 0 1000 260"`은 CSS 높이만 늘리면 기본 `preserveAspectRatio`에 의해 위아래 빈 공간이 생긴다. `preserveAspectRatio="none"`만으로 채우면 글자·원도 왜곡된다.
- `TimeComparison`은 4자료 모두 본문 전체 패널로 항상 렌더링된다. 선택 지역 안내도 추세 제목 바로 앞에 반복된다. 여러 보조 분석이 남아 있어 시연 상세 화면에서 세로 스크롤과 주의 분산이 생긴다.

## 자료별 추가 영향

| 자료 | 추세 옆·아래의 보조 정보 | 필요한 보존 경로 |
|---|---|---|
| 생활인구 | 요일·월 구간 특성, 체류·거주 기반, 연령·성별 비교, 두 시점 분포 지도, 두 시점 수치 | 현재 조건을 유지한 명시적 보조 분석 진입. 단순 CSS 숨김으로 유일한 진입 버튼을 없애지 않음 |
| 생활이동 | 상대 지역 연결·출발지/도착지, 두 시점 수치, 일계→시간대 설명 | 연결 분석·두 시점 수치의 선택 진입. 일계 지도와 시간 추이의 의미는 제목·축 가까이에 남김 |
| 거주지 이동 | 연령·성별 구성, 두 시점 수치, 연령별 1개년 한계 | 2025 연령별 자료를 장기 추세처럼 해석하지 않게 한계 유지. 구성 분석의 기존 명시적 상세 경로 보존 |
| 추정매출 | 두 시점 수치·분기 비교 | 비교 기준·정확 금액·차이·증감률·해석 주의를 보조 화면 안에 함께 유지 |

## 구현 판단

1. 시연 상세에서 활성 자료 묶음과 추세 패널은 가용 높이를 연결해서 받는다. 추세 패널 내부는 제목/현재값, 해석 기준, 가변 도표, 작은 재생 도구로 배치한다. 고정 헤더·메뉴를 제외한 남은 화면이 도표에 배정되어야 한다.
2. SVG는 측정된 도표 작업 영역의 비율을 따라 좌표를 계산한다. 글자 크기·원형 마커·선 굵기는 읽기 규격을 유지하며 패널만 커지고 선은 중앙에 작게 남는 경우를 피한다. 축·첫/마지막 점·긴 분기 이름을 위한 여백은 남긴다.
3. ‘두 시점 비교’는 그래프 가까이 있는 하나의 진입 버튼으로 제공한다. 시연 기본은 닫힘, 열기/접기 상태를 표시한다. 열어도 주 그래프 높이와 데이터가 변하지 않는 보조 창이 적절하다. 기본 분석용의 상세 도구는 같은 계산을 사용한다.
4. 비교창에는 현재 지역·지표·기간 조건을 명시한다. 비교 기준 선택·정확값·차이·비율은 기존 원값 계산을 유지하며 축을 조정했다고 비교 원값이 바뀌면 안 된다.
5. 선택 지역 안내의 반복 영역을 정리하더라도 지역·조건이 추세 제목과 현재값에서 읽혀야 한다. 지도 복귀와 후보 비교 경로를 유지한다. 보조 분석의 유일한 경로를 숨기는 방식은 허용하지 않는다.

## 실제 실행 수용 기준

- PC 1800×961 및 1366×768에서 시연 상세의 주 그래프가 남은 콘텐츠 높이를 사용하고 기본 상태의 불필요한 세로 스크롤이 없다. 도표 바탕과 실제 플롯 양쪽의 경계를 측정한다. 짧은 화면은 필수 축·조작을 잘라 숨기기보다 안전한 스크롤을 허용하며 해당 한계를 기록한다.
- 4자료를 바꿔도 현재 보기 선택이 유지된다. 시연→분석→시연, 지도→상세→후보→상세에서 주그래프 크기가 회복되고 현재 조건·값이 유지된다.
- 두 시점 비교 기본 닫힘, 열기/닫기/재열기/키보드 Esc/초점 복귀를 검사한다. 열기 전후 주그래프 높이·추세선 값·현재값은 동일하다.
- 기준 분기를 바꾸면 두 카드의 기준·선택 값, 차이, 비율이 같은 자료·지역으로 계산된다. 예: 서울 2025년3분기 매출 26,105,709,261,054원 →4분기27,216,323,031,204원, 차이+1,110,613,770,150원, 약+4.3%.
- 양수가 아닌 기준·결측·단일 연도에서는 미지원·계산 불가 이유를 보존한다. 결측을0으로 만들지 않는다.
- 비교창을 연 뒤 그래프 시점을 바꾸거나 지역·연령/성별·지표를 바꾸면 보조창도 같은 조건으로 갱신된다. 비활성 자료·시작 화면·전체화면 지도에서 이전 보조창이 남아 덮지 않는다.
- 옵션창과 비교창이 함께 열릴 때 Esc 한 번은 한 창만 닫는다. 비교창 이동·크기 조절·좁은 화면 경계와 긴 금액·제목 잘림을 검사한다.
- 시연 실제 글자 크기는 기존4종(14/18/24/36px) 이내이며 그래프의 실화면 SVG 변환까지 고려한다. 분석용6종 규칙도 유지한다.
- 재생·이전/다음·수동 축·100지수·차이·툴팁·지도 복귀를 변경 영향 경로에서 다시 검사한다. 과거 전체 E2E를 이번 검증으로 표기하지 않는다.

## 검토 범위의 한계

독립 검토자는 소스와 개발 규칙만 읽었고 화면을 조작하지 않았다. 위 수치는 기존 원값 대조 기준이며 이번 변경 결과값이나 실제 화면 치수 통과 증거를 대신하지 않는다. 새 소스 반영 후 부모가 실제 Chrome과 공개 화면에서 기록해야 한다.

## 명시적 화면 전환 보완 — 추가 소스 반영

추가 지시에 따라 시연 상세는 아래로 이어 읽는 방식 대신 선택한 분석 화면 하나를 표시한다. `usePresentationDetail`이 `analysis-section` 이벤트의 대상ID를 받아 활성 자료 묶음의 직접 자식 하나에 `data-detail-active`를 부여한다. `presentation-detail-views.css`는 나머지 형제를 숨기며 선택한 패널만 가용 높이를 받게 한다. 상세가 접힌 `details`이면 기존 `navigateSection`이 열고 초점을 옮긴다. 자료·모드·시작 화면 전환은 기본 추세로 초기화하고 분석용에서는 표식을 해제한다. 지연 자료가 대상 패널을 나중에 마운트하는 경우 자식 관찰로 연결한다.

이 코드 반영은 실제 Chrome 통과를 뜻하지 않는다. 부모가 통합할 때 `usePresentationDetail({tab,mode,presentationStep,view})` 반환값의 `isSupplementary`와 `detailLabel`을 사용해 현재 보조 화면 이름과 추세 복귀를 제공해야 한다. 이동 상대지역에는 명시적 대상ID가 필요하고, 기본 그래프의 ‘보조 분석’ 메뉴에서 각 대상ID로 진입해야 한다. CSS 표식 변화로 그래프가 숨겨질 때 기존 그래프/비교 플로팅창도 함께 숨겨지는지 별도 검사한다.

화면 전환 기준의 추가 검수: 생활인구의 요일·월중/체류·거주/연령·성별/분포지도, 이동의 상대지역, 거주지 이동의 집단 구성 각각을 메뉴로 열고 추세로 돌아간다. 콘텐츠 부모의 스크롤을 이용해 다음 분석을 발견하도록 요구하지 않는다. 선택된 보조 분석이 긴 경우 그 패널 내부 스크롤은 허용하며 다음 분석으로 이어지는 스크롤과 구분한다.
