## 현행 구조
공통 탐색, 현재 화면의 조회, 그래프의 표시 도구를 나눈다. 최신 사용자 요구에 따라 PC의 제품 헤더와 자료/보기 메뉴는 한 행으로 합치고, 상단·본문·그래프의 바깥 시작·끝선을 맞춘다. 기능 역할은 다음과 같다.

| 층 | 주로 볼 것 | 여는 방식 |
|---|---|---|
| 공통 메뉴 | 자료 공간, 분석/시연, 시작 복귀 | 화면 전역에서 같은 위치 |
| 현재 결과의 조회 | 자료·기간·지역·상권 검색·현재 분석 기준 | 기본은 공통 메뉴 아래의 실제 입력. 필요하면 같은 호스트를 플로팅/우측 도킹으로 이동. 현재값 표시와 수정을 한 곳에서 수행하며 읽기 전용 요약을 반복하지 않음 |
| 분석 대상·기준 | 제공되는 연령·성별·업종·요일·시간 기준 | 같은 상단 바에서 기간 → 지역 → 대상/기준의 의미·키보드 순서 유지. 부가 입력은 작은 설명 가능한 아이콘의 팝오버. 지원 범위는 입력 가까이에 유지 |
| 표시 설정 | 색상 범위·분위/등간격·축 | 지도/그래프 가까운 별도 표시 메뉴. 원자료나 후보를 바꾸지 않음 |
| 창 설정 | 선택 정보·순위·서식 창의 좌우 고정·떼기·배경·위치/크기 초기화 | 해당 창 제목의 메뉴 하나. 상단 기본 조회 입력과 구분 |
| 결과 작업 | 표 내려받기·후보 추가 | 결과 제목/선택 결과 가까이. 조회 순서에서 분리 |

시연과 분석은 단일 조회 입력·상세 콤보·팝업/본문 전환·지도 복귀를 공유한다. 차이는 정보 밀도와 강조·글자 크기이며 시연 네 단계/분석 여섯 단계 이하를 유지한다. 시연에만 별도 후보 버튼이나 아래로 이동하는 상세 경로를 남기지 않는다.

## 현재 유지할 여섯 가지 데이터·입력 계약
1. **현재 조건을 읽고 해제하는 경로**: 지역/유형/검색을 각각 짧게 표시하고 해당 조건만 해제한다. 후보·기간·표시 범위를 우연히 지우지 않는다. 작은 상태 버튼을 또 큰 안내 상자로 만들지 않는다.
2. **관련 선택지만 제공**: 구를 바꾸면 그 구의 동, 자료를 바꾸면 확보된 기간·분석 기준을 제공한다. 상권 선택지 건수는 나머지 조건의 교집합 기준이다.0건 선택지는 비활성으로 보이되 현재 선택은 해제할 수 있게 남긴다. 인구 비공개·미지원과 상권 검색의 실제0건을 구분한다.
3. **조회 범위와 지도 선택 구분**: ‘조회 범위 서울 전체’와 ‘선택 상권 종로·청계’를 다른 상태로 읽는다. 클릭은 상세 값·추이 연동, ‘이 지역만’은 명시적 공간 필터, 후보는 기존처럼 공간 조회를 바꿔도 유지한다.
4. **입력의 반응 원칙**: 드롭다운·시간·지도 클릭은 즉시 반영. 상권 이름·유형 검색은 카메라를 자동 초기화하지 않는다. 상권 도형·순위 항목 선택은 해당 경계로 확대하며, 상위 지도 복귀는 이전 범위를 복원한다. 조회 결과 전체 범위 맞춤은 별도 버튼으로 실행한다. 짧은 지연은 측정 후 도입하며 적용 결과 수를 알린다. 복수 조건의 임시 편집을 넣는 경우에만 ‘적용 전’과 현재 결과를 분리한다.
5. **초기화 범위 명시**: 배치 초기화/지도 원래 범위/지역·검색·유형 해제/색상 초기화는 별개의 행동이다. 포괄적인 ‘초기화’로 기간·후보까지 지우지 않는다. 기존 조건 저장 작업대와 별도 저장 메뉴를 중복 생성하지 않는다.
6. **지원하지 않는 조합을 만들지 않기**: 생활인구 연령×성별은 실제 교차 자료를 사용한다. 상권의 시간·성별·연령·요일은 서로 별도 주변분포이므로 ‘분석 기준 한 가지’로 제공한다. 전출입의 성별×연령 교차나 직업은 확보되지 않은 상태로 표시한다.

## 실제 사용 시나리오
광고주가 ‘홍대 주변의 저녁 수요’를 묻는다. 상단 조회 바에서 상권 유동인구와 확보 분기 선택→이름 검색→동명 검색결과가 여러 구면 지역을 좁힘→부가 분석 기준에서17–21시 선택→상권 선택으로 값 확인→상세 콤보에서 추이 또는 후보 비교. 성별을 보려면 시간대와 교차한 숫자로 계산하지 않고 분석 기준을 성별로 바꾼다. 두 모드 모두 팝업↔본문은 같은 내용과 설정을 유지하고, 지도 복귀는 현재 공유 조건과 선택·확대 위치를 유지한다.

## 수용 기준
- 상단 입력 자체에서 현재 적용값을 읽고 직접 수정한다. 같은 내용의 왼쪽 조회 옵션·읽기 전용 조건 칩·본문 요약을 반복하지 않는다. 부가 입력 팝오버를 닫아도 해당 조건과 실제 결과는 유지된다.
- 구 변경 후 다른 구의 동·미지원 기간·이전 응답 값이 남지 않는다.
- 검색·구·동·상권유형 교집합의 결과 수·지도·순위·CSV가 같다.
- 선택지0건·자료 없음·비공개·미지원은 구분하고 가능한 해제 행동을 제공한다.
- 지도 호버가 영구 선택을 바꾸지 않고 클릭은 값·추이와 동기화한다.
- 후보 유지, 범위별 초기화, 표시 설정의 원값 불변을 독립 대조한다.
- 분석↔시연·지도↔본문·팝업↔본문·전체화면 전환에서 입력은 한 벌이며 중복ID와 이전 창이 남지 않는다. 원래 지도나 비활성 자료의 숨김이 현재 입력·검색 팝오버를 가리지 않는다.
- 상단 조회를 바꿔 본문 그래프를 확인한 뒤 지도로 돌아오면 같은 조건·값·선택 지역이 연결된다. 표시 방식만 바꿀 때는 그래프 표시·축·기준 시점·지도 확대/이동 위치를 유지한다. 복귀 버튼은 내부 스크롤 뒤에도 읽고 사용할 수 있다.
- 조회 배치를 상단→플로팅→우측 도킹→상단으로 바꿔도 같은 입력 ID·조회 상태·선택·후보·원값이 유지된다. 우측은 지도540px 이상을 남길 때만 고정하고, 부족하면 플로팅으로 남긴다. 드래그 취소와 버튼/키보드 대안도 확인한다. 상권은 기존 정보 패널·상세창과의 충돌 검토 뒤 적용 범위와 실행 관문을 따로 기록한다.
- 새로운 적용 버튼은 실제 필요성이 입증될 때만 추가하고 변경 대기/적용 상태 및 취소를 검사한다.

[이전 소스 감사](query-options-strategy-audit.md)와 [이전 조회 수용 기준](tableau-query-acceptance.md)의 독립 조회창/칩 경로는 해당 버전의 이력이다. 새 상단 통합 수용 판정은 [개발 규칙 R20](DASHBOARD_DEVELOPMENT_RULES.md)과 [공통 실행 기록](shared-query-presentation-report.md)을 따른다. 독립 원자료의 모집단·기준값은 변경하지 않는다. 범례·도표 공식 참고와 후순위 기능은 [인포그래픽 참고 검토](tableau-infographic-reference.md)를 따른다. 공식 기능 참고·설계 계약·소스 반영·실행 통과를 구분한다.

## 배치·색상에 대한 사용자 추가 확인
상단과 본문·그래프는 공통 페이지 여백과 시작·끝선으로 맞춘다. 메뉴의 업무 역할은 유지하되 최신 요구인 PC 한 행 공통 헤더를 적용 대상으로 삼는다. 이전의 ‘메뉴 위치를 그대로 유지한다’는 전제로 중복된 제품 헤더·자료/보기 행을 남기지 않는다. 자료4개는 동위 폭을 유지하고, 모드·부가 도구는 더보기로 묶되 현재 상태를 식별할 수 있게 한다. 좁은 화면에서 글자를 줄여 한 행을 강제하지 않는다.

색상 요구는 기본 눈금과 적용 눈금의 비교가 아니라, 여러 그라데이션 중 선택하는 기능이다. 기본과 현재 선택 팔레트 미리보기를 제공하고 지도 채움·범례를 같이 바꾸되 원값·현재 눈금은 유지한다. 증감/순이동은0중심·부호·중립색을 유지한다.

## 단일 상단 조회와 현재 조건

- 실제 입력이 현재 조건 표시를 겸한다. 해제 가능한 조건은 그 항목만 해제하고, 필수 기간·자료에는 의미 없는 해제 버튼을 만들지 않는다. 부가 조건은 같은 바의 작은 아이콘과 툴팁이 있는 비모달 팝오버에서 편집한다. 별도의 큰 왼쪽 조회창이나 같은 값의 읽기 전용 조건 줄을 다시 만들지 않는다.
- 생활인구·생활이동·거주지 이동·행정구역 매출·상권의 본문 상세/후보 비교에서도 상단 입력 한 벌을 유지한다. 숨겨진 지도 화면으로 이동하거나 입력을 복제하지 않는다. 팝업에서는 배경 입력을 비활성화하고 모달 안의 기존 옵션·명시적 적용 행동을 유지한다. 부가 팝오버의 Esc는 해당 창만 먼저 닫고 원래 입력으로 초점을 돌린다.
- 생활인구 기본 입력은 기준일·조회 시각·자치구·행정동·연령·성별 여섯 가지다. 기준일 달력에서 제공 기간 전체를 선택하며 별도 월 선택을 반복하지 않는다. 시간 슬라이더·이전/다음은 부가 팝오버의 ‘시간 빠르게 이동’을 펼쳤을 때만 제공한다. 지도 아래 전체폭 행이나 같은 현재 시각 조건 칩은 반복하지 않는다.
- 검색과 선택은 하나의 입력으로 제공한다. 별도 검색 버튼과 native 선택기를 병치하지 않는다. 같은 상태를 쓰며 검색·방향키·Home/End·Enter·Esc를 제공한다. 상권 관련 선택지 건수는 나머지 조건의 교집합이다. 구 선택은 종속 동을 함께 해제하므로 구·동을 제외한 조건으로 구별 건수를 계산한다. 현재 선택한0건 항목은 해제할 수 있게 남긴다.
- 거주지 이동 연령별은2025년 자치구, 성별은2021–2025년 구·동만 제공한다. 지원 범위 변경 시 가장 가까운 지원 연도(동률이면 이전 연도)로 조정하고 이유를 표시한다. 연령×성별 교차 자료를 만들지 않는다.

## 조회 영역의 공간과 역할

현재값을 직접 편집하는 단일 조회 바는 기본적으로 공통 메뉴 아래에 고정한다. 사용자가 원하면 같은 입력 호스트를 플로팅/우측 도킹으로 이동하고 상단 복원 경로를 제공한다. 기간 → 지역 → 분석 대상/기준의 의미와 키보드 순서를 유지하되 관련 입력을 한 행에 압축하고, 폭이 부족하면 필요한 줄바꿈 또는 부가 팝오버를 사용한다. 양쪽 끝·글자 규격은 상단·지도·그래프와 같은 토큰을 쓴다. 한 행을 고집해 글자를 줄이거나 모든 보조 기능을 상시 노출하지 않는다.

이전 `queryLayout="focused"` 조회창의280px·260–360px 조절·360×560px 플로팅·한 열 배치는 레거시 회귀 자료다. 현행 일반·상권 화면에 왼쪽 조회 패널을 남기는 근거가 아니다. 같은 입력 호스트를 활성 지도/본문/전체화면으로 옮길 때 실제 ID·값·조회 이벤트를 보존하고, 원래 지도 DOM의 숨김이 활성 바의 가시성을 지배하지 않게 한다.

지도 확대·구/동 전환은 지도 옆 조작, 색상·범위는 지도 표시 메뉴, 축은 그래프 옵션, 내려받기는 결과 도구로 둔다. 조회 바에는 결과를 바꾸는 입력만 두며 필요한 미지원 이유는 해당 입력 가까이 남긴다. ‘조회 옵션’, ‘자료·지역·시간·지표’ 같은 큰 제목이나 설명 전용 행은 실제 입력과 기능을 반복하면 제거한다.

## 자석 배치와 투명도 계약

최신 사용자 요구는 **기본 상단 조회 바도 필요하면 동일 호스트를 플로팅/우측 자석 도킹으로 옮기는 선택형 배치**다. 이전의 ‘상단 기본 조회 바는 이동 대상이 아니다’라는 전제는 폐기한다. 이는 여러 위치에 입력을 복제하라는 뜻이 아니다. 상단/띄우기/우측 고정/상단 복원을 명시적으로 제공하고 드래그와 키보드 대안을 함께 둔다. 제목을 끌어 가장자리56px 구간에 두면 붙을 위치를 예고하며 놓을 때만 확정한다. 취소된 드래그는 고정을 확정하지 않는다. 선택 지역 정보·순위·부가 작업창은 별도 업무 역할을 유지한다.

조회 호스트와 남아 있는 정보·작업창의 도킹은 다른 고정 창을 제외하고 지도540px 이상을 남길 수 있을 때만 허용한다. 공간이 부족하거나 소유 화면에 고정할 자리가 없으면 플로팅을 유지한다. 같은 쪽 창이 겹치지 않도록 명시적 충돌 처리를 한다. 고정 창은 폭, 플로팅은 위치와 가로·세로 크기를 조절하고 복원·배치 초기화를 제공한다. 이전 조회창을 별도로 되살리는 구현과 현행 단일 조회 호스트의 이동을 혼동하지 않는다.

플로팅 배경 불투명도는50–100%(기본100%)를 선택한다. 글자·버튼 전체에 opacity를 적용하지 않는다. 좌우에 붙으면 배경은100%로 표시하고 다시 떼면 앞서 고른 값을 복원한다. 배치·투명도 변경은 조회 조건·선택·후보·지도 색상·통계 원값을 바꾸지 않는다. 범례·의미 설명은 읽기용 툴팁이므로 자석 창으로 일괄 확대하지 않는다.

## 상권 작업공간의 압축과 적용 경계

- 제품 root 헤더와 상권 작업공간 제목·주요 action을 PC 한 행으로 묶어 중복 큰 제목·부제·context를 줄인다. 작업공간 복귀·상세 선택·모드/부가 도구의 발견성은 유지하고, 좁은 화면에서는 한 행을 강제하지 않는다.
- 지도 지표, 조회/관측/자료 없음 개수, 서울→구→상권 경로, 범위 맞춤·지역 해제·내려받기·지도 표시 도구는 업무 목적이 다르다. 의미가 같은 제목·조건은 합치되 이 정보들을 무조건 삭제하거나 작은 도구 하나에 전부 숨기지 않는다. 공간 탐색과 결과 해석에 필요한 현재 범위·단위·무결과 복구는 남긴다.
- 상권 조회의 선택형 이동은 일반4자료의 동일 호스트 이동 구조와 상권의 정보 패널·상세 팝업·본문 호스트·우측 도킹이 충돌하지 않는지 먼저 검토한다. 최소 지도540px·좁으면 플로팅·상단 복원·포털/초점·같은 상태 보존을 상권에서 따로 확인한 범위만 지원 완료로 판정한다. 현재 구현 중인 범위를 전면 지원이나 공개 검수 완료로 표현하지 않는다.
