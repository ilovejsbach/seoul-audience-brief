## 현행 구조
공통 탐색, 현재 화면의 조회, 그래프의 표시 도구를 나눈다. 메뉴 위치는 유지하고 상단·본문·그래프의 바깥 시작·끝선을 맞춘다. 기능 역할은 다음과 같다.

| 층 | 주로 볼 것 | 여는 방식 |
|---|---|---|
| 공통 메뉴 | 자료 공간, 분석/시연, 시작 복귀 | 화면 전역에서 같은 위치 |
| 현재 결과의 조회 | 자료·기간·지역·상권 검색·현재 분석 기준 | 짧은 현재값 버튼. 값이 많은 조건은 검색 드롭다운/한 묶음 팝오버 |
| 분석 대상·기준 | 제공되는 연령·성별·업종·요일·시간 기준 | 같은 조회 편집기의 기간 → 지역 → 대상/기준 순서. 필수 현재값·지원 범위는 유지 |
| 표시 설정 | 색상 범위·분위/등간격·축 | 지도/그래프 가까운 별도 표시 메뉴. 원자료나 후보를 바꾸지 않음 |
| 창 설정 | 좌우 고정·떼기·배경·위치/크기 초기화 | 창 제목의 메뉴 하나. 조회 입력과 구분 |
| 결과 작업 | 표 내려받기·후보 추가 | 결과 제목/선택 결과 가까이. 조회 순서에서 분리 |

시연: 현재값이 보이는 짧은 조작과 한 결과. 분석: 여러 조건을 비교할 수 있는 고정 조회창을 선택적으로 유지한다. 둘은 같은 선택 상태와 계산을 공유한다.

## 소스에 반영한6가지 계약
1. **현재 조건을 읽고 해제하는 경로**: 지역/유형/검색을 각각 짧게 표시하고 해당 조건만 해제한다. 후보·기간·표시 범위를 우연히 지우지 않는다. 작은 상태 버튼을 또 큰 안내 상자로 만들지 않는다.
2. **관련 선택지만 제공**: 구를 바꾸면 그 구의 동, 자료를 바꾸면 확보된 기간·분석 기준을 제공한다. 상권 선택지 건수는 나머지 조건의 교집합 기준이다.0건 선택지는 비활성으로 보이되 현재 선택은 해제할 수 있게 남긴다. 인구 비공개·미지원과 상권 검색의 실제0건을 구분한다.
3. **조회 범위와 지도 선택 구분**: ‘조회 범위 서울 전체’와 ‘선택 상권 종로·청계’를 다른 상태로 읽는다. 클릭은 상세 값·추이 연동, ‘이 지역만’은 명시적 공간 필터, 후보는 기존처럼 공간 조회를 바꿔도 유지한다.
4. **입력의 반응 원칙**: 드롭다운·시간·지도 클릭은 즉시 반영. 상권 이름·유형 검색과 상권 선택은 카메라를 자동 초기화하지 않는다. 조회 범위 맞춤은 명시적 버튼으로 실행한다. 짧은 지연은 측정 후 도입하며 적용 결과 수를 알린다. 복수 조건의 임시 편집을 넣는 경우에만 ‘적용 전’과 현재 결과를 분리한다.
5. **초기화 범위 명시**: 배치 초기화/지도 원래 범위/지역·검색·유형 해제/색상 초기화는 별개의 행동이다. 포괄적인 ‘초기화’로 기간·후보까지 지우지 않는다. 기존 조건 저장 작업대와 별도 저장 메뉴를 중복 생성하지 않는다.
6. **지원하지 않는 조합을 만들지 않기**: 생활인구 연령×성별은 실제 교차 자료를 사용한다. 상권의 시간·성별·연령·요일은 서로 별도 주변분포이므로 ‘분석 기준 한 가지’로 제공한다. 전출입의 성별×연령 교차나 직업은 확보되지 않은 상태로 표시한다.

## 실제 사용 시나리오
광고주가 ‘홍대 주변의 저녁 수요’를 묻는다. 상권 유동인구와 확보 분기 선택→이름 검색→동명 검색결과가 여러 구면 지역을 좁힘→시간대 기준17–21시 선택→상권 선택으로 값/분기 추이 확인→후보 담기. 성별을 보려면 시간대와 교차한 숫자로 계산하지 않고 분석 기준을 성별로 바꾼다. 시연에서 보조 분석을 열면 해당 화면으로 교체하고 같은 조건으로 돌아온다.

## 수용 기준
- 조건창을 닫아도 실제 적용 조건은 현재 결과 옆에서 읽힌다.
- 구 변경 후 다른 구의 동·미지원 기간·이전 응답 값이 남지 않는다.
- 검색·구·동·상권유형 교집합의 결과 수·지도·순위·CSV가 같다.
- 선택지0건·자료 없음·비공개·미지원은 구분하고 가능한 해제 행동을 제공한다.
- 지도 호버가 영구 선택을 바꾸지 않고 클릭은 값·추이와 동기화한다.
- 후보 유지, 범위별 초기화, 표시 설정의 원값 불변을 독립 대조한다.
- 시연/분석·띄움/고정·전체화면 전환에서 중복 입력과 이전 창이 남지 않는다.
- 새로운 적용 버튼은 실제 필요성이 입증될 때만 추가하고 변경 대기/적용 상태 및 취소를 검사한다.

[이전 소스 감사](query-options-strategy-audit.md)는 변경 전 문제의 이력이다. 현재 수용 시나리오와 독립 원자료 기대값은 [조회 수용 기준](tableau-query-acceptance.md), 범례·도표 공식 참고와 후순위 기능은 [인포그래픽 참고 검토](tableau-infographic-reference.md)를 따른다. 공식 기능 참고·설계 계약·소스 반영·실행 통과를 구분한다.

## 배치·색상에 대한 사용자 추가 확인
메뉴 위치는 현행을 유지한다. 상단과 본문·그래프가 서로 다른 바깥 폭을 갖는 이유가 없다는 지시이므로, 공통 페이지 여백과 시작·끝선으로 맞춘다. 우측/중앙/좌측으로 메뉴를 재배치하는 제안은 적용하지 않는다.

색상 요구는 기본 눈금과 적용 눈금의 비교가 아니라, 여러 그라데이션 중 선택하는 기능이다. 기본과 현재 선택 팔레트 미리보기를 제공하고 지도 채움·범례를 같이 바꾸되 원값·현재 눈금은 유지한다. 증감/순이동은0중심·부호·중립색을 유지한다.

## 단일 조회창과 현재 조건

- 현재 조건 칩은 해당 입력을 열고, 해제 가능한 조건은 그 항목만 해제한다. 필수 기간·자료 조건에는 의미 없는 해제 버튼을 만들지 않는다. 넘치는 조건은 ‘나머지 조건’ 비모달 팝오버로 읽는다.
- 생활인구·생활이동·거주지 이동·행정동 매출의 상세 분석/후보 비교에서도 기존 입력 하나를 외부 조회창으로 열어 현재 보기를 유지한다. 숨겨진 지도 화면으로 이동하거나 입력을 복제하지 않는다. 닫기/Esc 후 원래 진입점으로 돌아간다.
- 생활인구 기본 입력은 기준일·조회 시각·자치구·행정동·연령·성별 여섯 가지다. 기준일 달력에서 제공 기간 전체를 선택하며 별도 월 선택을 반복하지 않는다. 시간 슬라이더·이전/다음 시간은 기간 안의 ‘시간 빠르게 이동’을 펼쳤을 때만 제공한다. 지도 아래 전체폭 행은 없애고 정확 시각 선택과 현재 시각 조건 칩은 유지한다.
- 검색과 선택은 하나의 입력으로 제공한다. 별도 검색 버튼과 native 선택기를 병치하지 않는다. 같은 상태를 쓰며 검색·방향키·Home/End·Enter·Esc를 제공한다. 상권 관련 선택지 건수는 나머지 조건의 교집합이다. 구 선택은 종속 동을 함께 해제하므로 구·동을 제외한 조건으로 구별 건수를 계산한다. 현재 선택한0건 항목은 해제할 수 있게 남긴다.
- 거주지 이동 연령별은2025년 자치구, 성별은2021–2025년 구·동만 제공한다. 지원 범위 변경 시 가장 가까운 지원 연도(동률이면 이전 연도)로 조정하고 이유를 표시한다. 연령×성별 교차 자료를 만들지 않는다.

## 조회 영역의 공간과 역할

일반 지도는 `queryLayout="focused"`를 사용한다. 기본 폭280px·조절260–360px, 플로팅 기본360×560px이며 **기간 → 지역 → 분석 대상/기준 한 열**을 유지한다. 창을 넓혔다고 의미 묶음을 자동2·3열로 재배치하지 않는다. 상권 작업공간도 기간 → 지역·상권 → 분석 대상의 한 열을 유지하되 전용 좌우 패널의 폭 계약을 따른다. 이전220px/자동 다중 열은 과거 셸 이력이며 현행 조회 기본값이 아니다.

지도 확대·구/동 전환은 지도 옆 조작, 색상·범위는 지도 표시 메뉴, 축은 그래프 옵션, 내려받기는 결과 도구로 둔다. 조회창 내부에는 결과를 바꾸는 입력만 두며 필요한 미지원 이유는 해당 입력 가까이 남긴다. 제목은 조회 옵션·창 설정·접기의 간결한 한 행을 기본으로 한다.

## 자석 배치와 투명도 계약

조회 옵션·선택 지역 정보·순위는 업무 역할을 합치지 않으면서 같은 배치 조작을 사용한다. 제목을 끌어 좌우 가장자리56px 구간에 두면 붙을 위치를 예고하고, 놓을 때만 고정한다. 취소된 드래그는 고정을 확정하지 않는다. 좌측/우측/띄우기 버튼도 제공한다.

도킹은 다른 고정 창을 제외하고 지도540px 이상을 남길 수 있을 때만 허용한다. 공간이 부족하거나 전체화면/외부 상세 편집 등 소유 화면에 고정할 자리가 없으면 플로팅을 유지한다. 같은 쪽 창이 겹치지 않도록 기존 창을 플로팅으로 돌리는 등 명시적 충돌 처리를 한다. 고정 창은 폭, 플로팅은 위치와 가로·세로 크기를 조절하고 접기·복원·배치 초기화를 제공한다.

플로팅 배경 불투명도는50–100%(기본100%)를 선택한다. 글자·버튼 전체에 opacity를 적용하지 않는다. 좌우에 붙으면 배경은100%로 표시하고 다시 떼면 앞서 고른 값을 복원한다. 배치·투명도 변경은 조회 조건·선택·후보·지도 색상·통계 원값을 바꾸지 않는다. 범례·의미 설명은 읽기용 툴팁이므로 자석 창으로 일괄 확대하지 않는다.
