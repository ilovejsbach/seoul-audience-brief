# 태블로·Power BI를 참고한 조회 옵션 적용안

2026-11-15. 공식 설명과 공식 예시 이미지를 검토하고 현재 소스에 대조한 설계안이다. 아래의 새 조회 기능은 구현 완료 보고가 아니다. 앞서 배포한 제목·단위 압축과 구 라벨 개선은 별도 실행 보고를 따른다.

## 참고한 기능과 적용 판단

|---|---|---|

공식 이미지의 필터 창과 여닫기 예시는 실제로 살펴봤다. 작성 도구의 모든 메뉴를 광고주용 화면에 복제하는 것은 권하지 않는다. 위 적용 판단은 해당 제품의 의무 규칙이 아니라 우리 과제에 맞춘 설계 판단이다.

## 권장 구조
공통 탐색, 현재 화면의 조회, 그래프의 표시 도구를 나눈다. 공간 배치는 사용자 확인 중인3단계 위계에 맞춰 확정하되 기능 역할은 다음과 같다.

| 층 | 주로 볼 것 | 여는 방식 |
|---|---|---|
| 공통 메뉴 | 자료 공간, 분석/시연, 시작 복귀 | 화면 전역에서 같은 위치 |
| 현재 결과의 조회 | 자료·기간·지역·상권 검색·현재 분석 기준 | 짧은 현재값 버튼. 값이 많은 조건은 검색 드롭다운/한 묶음 팝오버 |
| 상세 조건 | 업종, 제공되는 연령·성별·요일·시간 기준 | 필요할 때만 여는 창. 지원 범위를 보며 선택 |
| 표시 설정 | 색상 범위·분위/등간격·축·배치 | 조회와 분리. 원자료나 후보를 바꾸지 않음 |

시연: 현재값이 보이는 짧은 조작과 한 결과. 분석: 여러 조건을 비교할 수 있는 고정 조회창을 선택적으로 유지한다. 둘은 같은 선택 상태와 계산을 공유한다.

## 우선 적용할6가지
1. **현재 조건을 읽고 해제하는 경로**: 지역/유형/검색을 각각 짧게 표시하고 해당 조건만 해제한다. 후보·기간·표시 범위를 우연히 지우지 않는다. 작은 상태 버튼을 또 큰 안내 상자로 만들지 않는다.
2. **관련 선택지만 제공**: 구를 바꾸면 그 구의 동, 자료를 바꾸면 확보된 기간·분석 기준을 제공한다. 선택지 건수는 나머지 조건의 교집합 기준이다.0건 항목을 숨길지 비활성으로 보일지 정하고 기존 선택은 해제할 수 있어야 한다. 비공개·미지원과 실제0을 구분한다.
3. **조회 범위와 지도 선택 구분**: ‘조회 범위 서울 전체’와 ‘선택 상권 종로·청계’를 다른 상태로 읽는다. 클릭은 상세 값·추이 연동, ‘이 지역만’은 명시적 공간 필터, 후보는 기존처럼 공간 조회를 바꿔도 유지한다.
4. **입력의 반응 원칙**: 드롭다운·시간·지도 클릭은 즉시 반영. 상권 검색은 타이핑 중 카메라가 계속 초기화되는 현상을 줄일 방안을 우선 검토한다. 짧은 지연은 측정 후 도입하며 적용 결과 수를 알린다. 복수 조건의 임시 편집을 넣는 경우에만 ‘적용 전’과 현재 결과를 분리한다.
5. **초기화 범위 명시**: 배치 초기화/지도 원래 범위/지역·검색·유형 해제/색상 초기화는 별개의 행동이다. 포괄적인 ‘초기화’로 기간·후보까지 지우지 않는다. 기존 조건 저장 작업대와 별도 저장 메뉴를 중복 생성하지 않는다.
6. **지원하지 않는 조합을 만들지 않기**: 생활인구 연령×성별은 실제 교차 자료를 사용한다. 상권의 시간·성별·연령·요일은 서로 별도 주변분포이므로 ‘분석 기준 한 가지’로 제공한다. 전출입의 성별×연령 교차나 직업은 확보되지 않은 상태로 표시한다.

## 실제 사용 시나리오
광고주가 ‘홍대 주변의 저녁 수요’를 묻는다. 상권 유동인구와 확보 분기 선택→이름 검색→동명 검색결과가 여러 구면 지역을 좁힘→시간대 기준17–21시 선택→상권 선택으로 값/분기 추이 확인→후보 담기. 성별을 보려면 시간대와 교차한 숫자로 계산하지 않고 분석 기준을 성별로 바꾼다. 시연에서 보조 분석을 열면 해당 화면으로 교체하고 같은 조건으로 돌아온다.

## 수용 기준
- 조건창을 닫아도 실제 적용 조건은 현재 결과 옆에서 읽힌다.
- 구 변경 후 다른 구의 동·미지원 기간·이전 응답 값이 남지 않는다.
- 검색·구·동·상권유형 교집합의 결과 수·지도·순위·CSV가 같다.
- 선택지0건·자료 없음·비공개·미지원은 구분하고 가능한 해제 행동을 제공한다.
- 지도 호버가 영구 선택을 바꾸지 않고 클릭은 값·추이와 동기화한다.
- 후보 유지, 범위별 초기화, 표시 설정의 원값 불변을 독립 대조한다.
- 시연/분석·띄움/고정·전체화면 전환에서 중복 입력과 이전 창이 남지 않는다.
- 새로운 적용 버튼은 실제 필요성이 입증될 때만 추가하고 변경 대기/적용 상태 및 취소를 검사한다.

[현재 소스 감사](query-options-strategy-audit.md)를 함께 따른다. 공식 기능 참고, 우리 적용 제안, 이미 구현된 기능을 구분한다.

## 배치·색상에 대한 사용자 추가 확인
메뉴 위치는 현행을 유지한다. 상단과 본문·그래프가 서로 다른 바깥 폭을 갖는 이유가 없다는 지시이므로, 공통 페이지 여백과 시작·끝선으로 맞춘다. 우측/중앙/좌측으로 메뉴를 재배치하는 제안은 적용하지 않는다.

색상 요구는 기본 눈금과 적용 눈금의 비교가 아니라, 여러 그라데이션 중 선택하는 기능이다. 기본과 현재 선택 팔레트 미리보기를 제공하고 지도 채움·범례를 같이 바꾸되 원값·현재 눈금은 유지한다. 증감/순이동은0중심·부호·중립색을 유지한다.
