숫자 축약은 표시용이다. 원자료·집계·색상 분류·CSV 계산에는 적용하지 않는다. 금액 표시는 소수 둘째 자리까지 반올림한다. title/접힘 상세에서 정확한 원 단위 금액을 확인한다.

## 실제 데이터와 검사

Chrome 실제1800×961에서 분석4자료, 각각 시연3장, 두시점·KPI·후보·팝업·집단구성·거주기반·이동 연결·전체화면 구→동→추이 복귀·최대지도비중을 검사했다. `long-content-results.json`은20기록/시연을 풀어28장면이며, 검사 대상 텍스트·카드에서 가로 넘침이 없었다. 별도 `market-layout-results.json`에서 최대상권매출·최장상권명·후보/추이·그룹·범례 연동과 실제 마우스 분할 조절을 확인했다.

- 가장 큰 상권매출(노량진역/2025Q4)1,261,630,232,011원. ‘1.26조 원’과 정확값title 일치.

기존 회귀: 자료별 조회·집계·전체화면5경로, 상권지도7경로, 중요 여정5경로 통과. 독립 원자료 의미 검사5경로(선택금액·매출교차조건·상권인구·순위·해석 범위) 통과. 축/표시 단위검사11개 통과. 정확값 검사기는 축약문자열 대신title·지도 접근성 값·정확 상세를 원자료 기대값과 대조하도록 갱신했다.

## 실화면에서 추가 발견해 수정한 것

- CSS 글자 규칙이 지도 줌 보정을 덮어 상권 배경 구 이름이 커지던 문제: 줌과 글자 크기 보정을 연결.
- 숨긴 지도 크기0으로 옵션 초기 크기가240×180까지 축소되던 문제: 숨김 측정 무시.
- 이동/포커스 스크롤 뒤 창이 화면 밖으로 나가던 문제: 지도와 뷰포트의 교집합으로 위치·크기를 제한하고 스크롤 때 재계산.
- 상권 순위의 긴 이름이 숫자 옆 좁은 열에서 여러 줄로 찢어지던 문제: 이름 전체 폭, 금액 다음 행 정렬.
- 보조 헤더가 전역 상단 메뉴의 고정 높이·안쪽 여백을 물려받던 문제: 비교 제목·옵션·범례 헤더의 내용 높이와 정렬을 따로 지정. 창 조절2경로 재검사 통과.
- 새 상세 토글의 자식 글자 대비: 아이콘·글자를 흰색으로 통일.

자동화 중 지역 선택의 두 프레임 화면 이동이 끝나기 전에 다음 버튼을 눌러 생긴 선택자 대기 실패는 도착 포커스를 기다리도록 고친 뒤 중요 여정5개를 다시 통과했다. 제품 오류 수정과 자동화 안정화를 구분한다.
