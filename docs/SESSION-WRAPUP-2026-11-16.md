## 최신 실제 실행과 공개 회귀 범위

2026 매출 로컬 Chrome 1365×768 에서 두 모드의 6분기 전환, 두 분기 비교, 현재/기준 분기 변경, 추이 점·후보·실제 내려받은 CSV, 결측, 긴 명칭, 출처와 카메라 복귀를 검사했다. 독립 UI 감사는 로컬 6장+공개 3장을 열람해 제공 사례에 새 P0/P1 없음으로 판정했다. [UI 감사](market-sales-2026-ui-audit.md)는 원자료 재계산/실제 조작을 대신하지 않는다.

최신 공개 JS/CSS·데이터 해시를 확인한 뒤 다음을 실제 검수했다:

- 종로3가역 2026Q2 **319,445,468,035원**, 기준 2025Q2 **298,030,034,019원**, 차 **+21,415,434,016원**을 분석·시연 비교에서 각각 확인.
- 본문에서 2026Q1 로 바꾸고 기준 2025Q4 와 비교하면 **−17,604,534,413원**. 여섯 분기 추이Q2 점→지도 복귀 때 2026Q2·선택경로·140% 확대 유지.
- 충신시장Q1 자료없음/회색→Q2 **1,303,350원**/분포색. 기준 없음은 0/증감으로 채우지 않음. 확인 여정의 서비스 오류 0개.
