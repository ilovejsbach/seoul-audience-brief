## 남은 실행 순서

1. D10 일반 추이를 같은1365×768에서 실제로 열어 시간축·재생줄·툴팁·선택값을 확인한다. 특성 비교도 같은 크기로 다시 확인한다.
2. 두 모드×생활인구/이동/전입전출/매출/상권에서 단일 입력, 종속 선택, 지도·순위·상세·그래프·CSV의 의미 연결을 점검한다. 현재 raw fixtures와 독립 자료를 사용한다.
3. 모든 상세 콤보 순회, 팝업↔본문↔지도, 후보/저장조건, 다른 지역·기간 변경 후 복귀를 확인한다. 축/기준/카메라와 현재 조건이 유지되어야 한다.
4. 일반/동 지도, 상권 서울→구→상권, 내부 집중 보기와 실제 Chrome 자체 전체화면을 별도로 검사한다. 플로팅 잔류·닫기/초점도 확인한다.
5. 긴 제목·14자리 매출·음수·0·결측·미지원·0건에서 잘림과 복구를 확인한다. 폰트 종류 상한과 대비를 실제 계산값으로 측정한다.
6. 독립 감사 P0/P1을 처리하고 영향 범위 재검사 후 변경 파일만 묶어 커밋한다. Pages 배포 뒤 공개 URL에서도 같은 여정을 검사해 보고서를 갱신한다.

사용자가 모든 화면의 실제 검사를 요구했으므로 대표 여정만으로 전수 완료라고 표현하지 않는다. 불가한 범위는 화면·조건·이유를 목록으로 남긴다.
