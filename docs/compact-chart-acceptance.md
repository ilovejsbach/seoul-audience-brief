# 그래프 옵션 압축 — 독립 수용 기준

2026-11-15. R03·R05·R06·R07·R13–15·R17·R19–21. 이 문서는 독립 소스 감사와 수용 기준이다. 실제 브라우저 실행 통과나 개선 효과 측정을 대신하지 않는다.

## 판단 질문과 의도
광고주가 그래프의 변화 추이를 보면서 필요할 때 표시·축·재생 조건을 조정하고, 원래 지역 지도나 후보 비교로 돌아갈 수 있는가? 그래프 하단의 큰 재생 버튼·속도 선택·별도 복귀 행이 도표를 밀어내는 문제를 줄인다. 분석용 계산·시연용 계산은 분리하지 않는다.

- 주정보: 선택 지역/조건·현재 값·추세선·현재 표시 방식/단위·축 범위 및 해석상 경고.
- 보조 조작: 이전/재생/다음·선택 순번은 작은 한 줄에 유지한다.
- 고급 조작: 실제값/증감/기준100·비교 기준·축 모드/범위/여유·속도·계산/결측 설명은 가까운 ‘그래프 옵션’ 진입점에서 연다.
- 다음 행동: 지도 복귀·후보 비교는 그래프 헤더의 작은 액션으로 제공한다. 하단에 같은 목적의 큰 행을 추가하지 않는다.

## 소스 감사에서 확정한 변경 영향

1. 기존 TrendExplorer는 하단 재생 그룹·속도·선택 순번 다음에 chartNextActions라는 별도 행을 만든다. 기존 CSS의 padding/min-width와 시연 글자 확대가 결합돼 두꺼운 조작 영역이 된다.
2. 다섯 소비자 계열은 같은 TrendExplorer를 사용한다. 한 컴포넌트의 개선은 모두에 전파되며 상권은 특히 좁은 호스트를 가진다.
3. layout-standard.css의 `.app .dashboardContent .trendExplorer`는 최소 높이460px다. 컨트롤을 외부로 빼도 이 최소 높이가 유지되면 빈공간이 남을 수 있으므로 실제 높이와 새 CSS 우선순위를 검사해야 한다.
4. R19 현행 문장은 실제값/증감/기준100 선택을 그래프 가까이에 남기도록 한다. 최신 요구에서는 **현재 선택된 표시 방식·현재 축과 경고를 본문에 유지하고 선택 도구는 그래프 옵션에서 접근**하는 계약으로 본문을 명확히 바꿔야 한다. 단순 추가 문단으로 모순을 덮지 않는다.
5. tests/critical-journeys.mjs·semantic-e2e.mjs·market-map-e2e.mjs의 축 열기와 long-content-e2e.mjs의 기준100 조작은 새 옵션 진입을 먼저 실행해야 한다. 접근 경로의 변경과 수치 판정의 완화는 구분한다.

## 수용 기준

1. 기본 그래프 하단은 PC에서 약32–36px의 한 줄 재생 도구로 유지한다. 폰트를 임의 축소하거나 터치/클릭 영역을 지나치게 줄이지 않는다. 좁은 호스트에서는 필요할 때만 자연스럽게 줄바꿈한다.
2. 속도 선택·축 입력·긴 계산 설명·별도 복귀 행이 기본 그래프 아래에 상시 자리 잡지 않는다.
3. 옵션 열기/닫기 전후 도표 SVG와 소유 그래프 높이가 변하지 않는다. 기본 최소 높이가 불필요한 흰 공간을 만들지 않는지 화면으로 확인한다.
4. 현재 실제/증감/100 보기, 단위, 기준100의 기준시점, 현재 축·0 제외/범위 밖·비양수 기준 경고는 옵션을 닫아도 해석할 수 있다. 축을 자른 그래프를 원점 포함으로 오인하게 하지 않는다.
5. 재생은 다음 시점으로 실제 값/선택 표시를 갱신한다. 끝에서 정지하고 처음부터 다시 재생할 수 있다. 이전/다음의 양끝 비활성 상태도 일치한다.
6. 속도를 바꾸면 실제 간격이 달라지되 원값·기준·축·조회 조건을 바꾸지 않는다. 다른 장면/탭으로 이동하면 재생 타이머가 정지한다.
7. 표시·기준·축 모드/수동 범위/여유·오류·적용·초기화의 모든 경로가 옵션 안에서 접근 가능하다. 수동 오류가 기존 선을 NaN으로 만들지 않는다.
8. 옵션은 화면 전역 이동·가로세로 조절·화면 경계 제한·위치 초기화를 제공한다. 닫기/Esc 후 옵션 버튼에 초점이 돌아온다. 제목 이동 키가 자식 선택기의 방향키를 가로채지 않는다.
9. 옵션은 비모달이며 도표 점이나 지도 조작을 막지 않는다. 실제 선택과 모드 변경을 한 뒤 설정 상태가 유지된다.
10. 비활성 그래프·상권 추이 닫힘·다른 탭·시연 다른 장면의 옵션은 이전 화면 위에 남지 않는다. 숨은 창의 Esc 처리기가 현재 화면의 초점을 빼앗지 않는다.
11. 그래프 옵션의 글자·색상은 소유 분석/시연 모드의 토큰과 같고 시연4종/분석6종의 크기 계약을 넘지 않는다. 포털 내부도 포함해 실측한다.
12. 복귀/후보 액션은 제목을 밀거나 긴 지역명·큰 금액을 자르지 않는다. 짧은 시각 라벨을 쓰더라도 접근 가능한 이름/의미는 분명히 남긴다. 후보 상한·이미 담김 상태를 단순 ‘추가’처럼 오인시키지 않는다.
13. 좁은 상권 상세·추이창에서 재생 도구·단위·선택 값·옵션 진입점이 가로로 넘치거나 겹치지 않는다. 화면 너비가 커도 호스트가 좁을 수 있으므로 컨테이너 실측으로 검사한다.
14. 설명 툴팁은 옵션보다 위에 보이고 내부를 읽을 수 있으며 Esc 한 번은 가장 안쪽 설명만 닫는다. 전체화면 경로가 있으면 올바른 전체화면 요소에 표시한다.
15. 실제 수치·지도 연결·CSV·후보·시나리오 저장을 레이아웃 편의로 바꾸지 않는다. 옵션 창을 움직이거나 닫는 행위가 값/조건을 변경하지 않는다.

## 실행 기록의 구분
구현 담당의 빌드/타입 검사와 부모의 실제 Chrome/공개 실행을 별도 기록한다. 이 문서 작성 단계에서는 브라우저를 실행하지 않았다. 당시의 과거 보고서 통과를 이번 컴포넌트 변경에 소급하지 않는다. 기존 자료의 독립 기대값과 정상/오류/복귀 경로를 유지한 채 새 진입점을 검사한다.

## 구현 후 독립 소스 검토 — 1차

실제 브라우저를 실행하지 않고 현재 TrendExplorer.tsx/compact-trend-controls.css를 다시 읽었다.

- 기본 그래프 최소 높이0, 헤더의 작은 옵션/복귀/후보 액션, 하단32px 재생 버튼,440×390px 전역옵션창, 내부스크롤·이동·크기조절·닫기/Esc·초점복귀가 소스에 반영됐다.
- 실제/차이/지수 계산·축 계산·재생 interval과마지막시점정지의원래알고리즘은유지됐다. 옵션 개폐 자체가 계산 상태를 초기화하지 않는다.
- 현재 보기·축 범위·0 제외·범위 밖·비양수 기준 경고는 그래프 본문에 남았다. 긴 계산 설명·속도·최대/직전차이는 옵션창으로 이동했다.
- 보완 요청1: 지수/증감의현재선택기준시각/연도가본문요약에서빠져있다. 옵션을닫은상태에서도정확한chosenBaseline을읽을수있어야한다.
- 보완 요청2: 후보버튼의접근가능이름과title에는이미담김/상한상태가보존되지만시각라벨은항상‘후보 비교 +’다. 추가되지않는상태에더하기기호를보여오인시키지않도록상태별시각문구를구분한다.

두 보완 요청의 소스 반영 여부와 실제 레이아웃/동작은 후속 검수에서 판정한다. 소스 확인만으로 실제32px 한 줄·높이불변·폰트집합·가독성이 통과했다고 주장하지 않는다.

## 독립 소스 재확인 — 2차

두 보완 요청은 소스에서 반영됐다. 지수/증감 본문에실제기준시각/연도가추가됐고, 후보버튼은추가/보기/이미담김/상한의시각문구와상태를구분한다. 새 floating-window-escape.ts는동일키이벤트를WeakSet으로한번만처리하고, 초점창또는마지막보이는창하나를선택하며, 설명툴팁/미리보기닫기를우선한다. MapPanel은다른전역창이있을때배경전체화면을동시에닫지않는다. 이는소스재확인이며실제키동작/레이아웃통과는부모실행기록에따른다.

추가 검토 위험: 공유 FloatingQueryLayer가 전체화면에 진입할 때 소유 host와의 관계를 확인하지 않고 모든 열린 창을 새 전체화면 요소로 옮길 수 있다. 그래프 옵션을 연 채 다른 지도 전체화면으로 진입하면 소유 그래프가 display:none은 아니므로 getClientRects가 남을 수 있다. 전체화면/대체전체화면과 소유 host가 서로 포함관계인 경우에만 창을 유지할지 판단하고, 포함관계가 없는 창의 숨김/복귀를 실제 화면에서 확인한다.
