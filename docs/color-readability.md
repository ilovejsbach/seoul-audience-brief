# 색상과 가독성 개선

2026-11-14. 어두운 카드와 밝은 작은 글자가 반복되면서 읽을 대상과 배경의 구분이 약해진 문제를 우선 해결한다. IBM Plex Sans KR의 크기·굵기·기능·배치는 유지하고 색상만 바꾼다.

## 적용 원칙

- 페이지는 연회색 `#f3f5f7`, 읽을 카드·조건·표는 흰색으로 통일한다. 제목은 짙은 남색, 본문은 중성 남색, 보조 글자도 충분히 진하게 둔다.
- 클릭·선택·주요 실행은 남색 `#24558b` 하나로 표현한다. 활성 버튼의 글자는 흰색이다. 주황은 차트 축 밖 값·음수 등 의미 있는 예외에만 제한한다.
- 지도의 단계 구분 색은 실제 값에 대응하므로 유지한다. 지도 배경은 연하게, 도형 경계는 흰색, 지도 글자는 진한 글자와 흰 윤곽으로 구분한다.
- 툴팁·팝업·조건 요약·후보·자료 설명도 같은 흰 배경 체계를 사용한다.
- 활성 버튼 내부 글자·아이콘과 시연용 모드의 명시적 흰 글자까지 덮어써 흰 배경에 흰 글자가 남지 않도록 한다.
- 상권 지도 자체 색은 담당 컴포넌트가 관리하고, 공통 작업 공간의 테두리·패널·텍스트만 맞춘다.

## 기계 계산한 대비

목표는 보통 크기의 16px 본문 대비 4.5:1 이상이다. 아래 값은 sRGB 채널을 선형화한 상대휘도와 대비 공식을 직접 계산한 결과다. 눈으로 추정한 수치가 아니다.

선형화: 채널이 0.04045 이하이면 `c/12.92`, 그 외에는 `((c+0.055)/1.055)^2.4`.

상대휘도: `0.2126R + 0.7152G + 0.0722B`.

대비: `(밝은 휘도 + 0.05) / (어두운 휘도 + 0.05)`.

표의 용도: Heading=제목, Body=본문, Secondary=보조, Page=페이지, Hero=히어로, Active button=활성 버튼, Input=입력값, Axis=차트 축, Negative=음수 안내.

| 용도 | 글자 | 배경 | 계산 대비 | 4.5:1 |
|---|---|---|---:|---|
| Heading | `#152b43` | `#ffffff` | 14.40:1 | PASS |
| Body | `#33465c` | `#ffffff` | 9.67:1 | PASS |
| Secondary | `#536477` | `#ffffff` | 6.07:1 | PASS |
| Body/Page | `#33465c` | `#f3f5f7` | 8.85:1 | PASS |
| Secondary/Hero | `#536477` | `#f7f9fb` | 5.76:1 | PASS |
| Active button | `#ffffff` | `#24558b` | 7.64:1 | PASS |
| Input | `#1f3045` | `#ffffff` | 13.40:1 | PASS |
| Axis | `#43566e` | `#ffffff` | 7.51:1 | PASS |
| Negative | `#92501f` | `#ffffff` | 6.20:1 | PASS |

구분선 `#c8d3df`와 차트 격자 `#d5dfe8`는 본문이 아닌 보조선이다. 위 글자 대비 기준을 충족한다고 주장하지 않는다. 실제 화면에서 작은 글자의 크기·중첩·선택 상태와 그래프 도형도 별도로 확인해야 한다.

## 검증 범위

이번 파일은 색상 오버라이드다. 자료 계산, 필터 상태, 재생, 패널 크기, 글꼴 크기는 변경하지 않았다. 최종 Chrome 확인에서는 분석·시연 히어로, 네 자료 화면, 지도 툴팁과 팝업, 후보 비교, 시간 추이, 조건 저장, 표, 인쇄를 각각 확인한다. 본 문서 작성 시점에 실제 화면 검증까지 완료했다고 주장하지 않는다.
