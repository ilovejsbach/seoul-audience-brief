# Seoul Audience Atlas

광고주 브리핑을 위한 서울 인구·이동·상권 지도 대시보드. React/TypeScript/Vite로 제작한 정적 웹이며, 서버·인증키 없이 배포된 실제 JSON을 읽습니다.

## 실행

```sh
npm ci
npm run dev
npm run build
```

## 데이터

- 생활인구: 서울시 OA-23016, 2026-10-01~31, 427개 행정동×24시간. 특정 시점의 내국인 추계 인원이며 방문객·광고 노출 수가 아닙니다.
- 생활이동: 서울시 OA-22300, 2026-10-31. 원본 6,317,901행을 서울 구별 출발·도착×출발시간으로 집계. 내외국인·모든 이동목적 합계. 구내 이동은 경계 유입·유출에서 제외합니다. 고유 방문자 수가 아닙니다.
- 거주지 전입·전출: 서울통계 공식 전출입 공개 서비스. 연간 주민등록 거주지 이동이며 생활이동과 다릅니다. 확보 기간과 공간 단위는 화면과 JSON 메타데이터를 따릅니다.
- 상권 추정매출: 서울시 OA-22175, 2025년 분기별 행정동 제공 업종 합계. 원본 시간 구간별 금액이며 개별 시간으로 분할하지 않습니다.
- 지도: 서울시 공식 250m 격자 선택기에서 제공하는 2025-06-30 기준 25구·426동 경계. 2026년 생활인구 427동 중 425동에 연결됩니다. 용두동·신설동은 과거 용신동 경계를 임의로 나누지 않으며 통계 목록에서 확인합니다. 매체 위치는 포함하지 않습니다.

공식 출처:

- https://data.seoul.go.kr/dataList/OA-22300/F/1/datasetView.do

`public/data`만 화면에 배포합니다. 대용량 원본은 `data/raw`에 로컬 보관하며 Git에서 제외됩니다. 재수집·정제 스크립트는 `scripts`에 있습니다. 화면용 날짜별 인구 JSON을 원본에서 다시 만들려면 `prepare-population.py` 실행 후 생성한 파일을 `public/data/population`에 복사하고 index 경로를 화면 상대경로로 맞춥니다.

## 해석 범위

데이터셋별 연도·주기·대상 인구가 다르므로 직접 나누어 광고 전환율이나 노출 수로 해석할 수 없습니다. 결측은 0과 구분합니다. 시계열의 행정구역 변경은 개별 검토가 필요하며, 과거 거주지 이동을 현재 동 구역으로 소급 재배분하지 않습니다. 파일 수집은 실시간 자동 갱신을 의미하지 않습니다.

## 배포

소스는 main에, 빌드한 정적 파일은 gh-pages 브랜치에 보관합니다. `python3 scripts/publish-pages.py`로 dist만 배포하며 원본 데이터는 제외합니다. Pages 설정은 gh-pages 브랜치의 루트를 사용합니다. Vite base는 상대경로이므로 저장소 하위 URL에서도 데이터가 로드됩니다. 자동화로 전환할 때 사용할 Actions 예시는 docs/pages-workflow-example.yml에 있습니다.

## 화면 여정과 비교

히어로 개요에서 분석 목적을 선택하고, 지역 퍼널(서울→구→동→후보)과 시간 퍼널(제공기간→날짜·시간)로 탐색합니다. 지도 팝업은 수치와 출처를 보여주고 상세 분석 또는 후보 비교로 연결합니다. 분석/시연 모드는 같은 실제 자료를 사용합니다. 두 시점 비교는 같은 지표·조건의 차이이며 광고 효과나 전환율이 아닙니다.

거주지 이동은 구 2001~2025년, 동 2015~2025년을 확보했습니다. 2015년 이후 구·동은 동일 서울 허브 자료를 사용합니다. 2023년은 두 공식 제공처의 구 값이 서로 달라 교차검증 미완료 안내가 있습니다. 둔촌1동의 2022·2023년 전입과 순이동은 원본 결측을 유지했습니다.
