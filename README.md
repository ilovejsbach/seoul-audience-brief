광고주 브리핑을 위한 서울 인구·이동·상권 지도 대시보드. React/TypeScript/Vite로 제작한 정적 웹이며, 서버·인증키 없이 배포된 실제 JSON을 읽습니다.

## 해석 범위

데이터셋별 연도·주기·대상 인구가 다르므로 직접 나누어 광고 전환율이나 노출 수로 해석할 수 없습니다. 결측은 0과 구분합니다. 시계열의 행정구역 변경은 개별 검토가 필요하며, 과거 거주지 이동을 현재 동 구역으로 소급 재배분하지 않습니다. 파일 수집은 실시간 자동 갱신을 의미하지 않습니다.

## 배포

소스는 main에, 빌드한 정적 파일은 gh-pages 브랜치에 보관합니다. `python3 scripts/publish-pages.py`로 dist만 배포하며 원본 데이터는 제외합니다. Pages 설정은 gh-pages 브랜치의 루트를 사용합니다. Vite base는 상대경로이므로 저장소 하위 URL에서도 데이터가 로드됩니다. 자동화로 전환할 때 사용할 Actions 예시는 docs/pages-workflow-example.yml에 있습니다.

## 화면 여정과 비교

현재 개선 기준은 [디자인·사용성 우선 단계별 설계 v2](docs/expansion-workspace-design.md)입니다. 공간·가독성·동작을 함께 고치며 실무 작업·조회와 광고주 현장 비교·결론 도출을 병렬 설계·검증합니다. [기존 화면 구조 분석](docs/expansion-ia-audit.md)과 표본 동작 모형은 후순위 확장 참고안·초기 설명 시안이며 운영 화면 적용·사용성 검증 완료와 구분합니다.

[생활인구·상권 실제 재점검과 네 조합 전후 시안](docs/paired-design-review.md)은 현재 배포 화면의 캡처와 별도 동작 모형을 함께 제공합니다. 운영 코드·배포에는 적용하지 않았습니다.

상단의 지도 중심 조회에서 상권 자료와 조건을 선택해 지도를 유지하며 상세·추이·후보를 비교합니다. 기존 히어로에서는 구·동 분석과 시연을 시작할 수 있습니다. 지도 팝업은 수치와 출처를 보여주고 상세 분석 또는 후보 비교로 연결합니다. 분석/시연 모드는 같은 실제 자료를 사용합니다. 두 시점 비교는 같은 지표·조건의 차이이며 광고 효과나 전환율이 아닙니다.

거주지 이동은 구 2001~2025년, 동 2015~2025년을 확보했습니다. 2015년 이후 구·동은 동일 서울 허브 자료를 사용합니다. 2023년은 두 공식 제공처의 구 값이 서로 달라 교차검증 미완료 안내가 있습니다. 둔촌1동의 2022·2023년 전입과 순이동은 원본 결측을 유지했습니다.

## 분석용과 시연용

기기별 글자 크기와 정보량은 [반응형 타이포그래피 기준](docs/responsive-typography.md)을 따릅니다. 모바일·태블릿·PC의 역할 크기를 구분하고, 시연 네 단계·분석 여섯 단계 상한을 유지합니다.

분석용은 자료·조건 선택, 상세 수치, 조회 조건 저장·복원(최대 3안), 선형 추이와 지도 연동을 제공합니다. 시연용은 같은 데이터·상태·계산을 사용하며 지도/상세 분석/후보 비교를 순서 없이 선택해 필요한 정보만 표시합니다. 시작 화면도 분석용 자료 선택 화면과 시연용 보고서 표지로 구분됩니다.

시간 재생은 관측된 시점을 순서대로 조회하는 기능입니다. 실제값·기준 대비 증감·기준 100 지수를 볼 수 있고, 결측은 보간하지 않습니다. 조건별 비교안은 현재 브라우저 세션 내에서만 유지됩니다.

생활이동은 도착 시각이 기본이며 출발 시각으로 전환할 수 있습니다. 시간대별/선택 시간까지 누적/원본 자료일 전체 이동량을 구분합니다. 도착 시각 자료의 날짜는 원본 ETL_YMD 기준이며 자정을 넘긴 실제 달력 도착일을 검증한 것은 아닙니다. 이동 건수와 고유 방문자 수를 혼동하지 않아야 합니다.

## 상권 지도와 세로축 조정

2026년 매출의 확보·코드 연결·실제 화면과 배포 검수는 [2026 상권 매출 실행 기록](docs/market-sales-2026-execution.md)에서 확인합니다. 수치는 공식 전체 CSV 기준이며 표 미리보기와의 일부 차이, 2023 경계와의 시점 차이는 [독립 감사](docs/market-sales-2026-audit.md)에 구분했습니다.

상단 `상권 지도`는 실제 상권 경계 1,650개, 2025Q1–2026Q2 상권 추정매출 128,053행·62업종, 2021Q1–2026Q2 상권 유동인구 지표 36,281행을 제공합니다. 기존 2025년 85,732행을 보존하고 2026Q1 21,188행·Q2 21,133행을 추가했습니다. `두 분기 비교`에서 같은 상권·업종·세부 항목의 2025년과 2026년을 비교합니다. 분기·지역·상권·업종 및 시간/성별/연령/요일 중 한 가지 주변분포를 선택합니다. 인구의 일평균 환산은 확정하지 않았고 원본 지표로 표시합니다. 경계 코드 연결과 형상의 기준 시점 일치는 구분합니다.

## 감사 결과를 적용한 조회 옵션

참고 대시보드와 전체 옵션 구조의 감사 결과를 바탕으로 생활인구부터 개편했습니다. 기본은 기간 → 지역 → 분석 대상 한 열이며 날짜·시각·구·동·연령·성별을 선택합니다. 검색은 하나의 선택기에 내장하고, 지도 탐색·색상은 지도 가까이, 내려받기는 결과 도구로 분리합니다. [통합 감사 이력](docs/query-options-audit-report.md) · [공식 참고 비교](docs/query-reference-audit.md) · [독립 감사 이력](docs/query-options-independent-audit.md).

현재 조건 칩에서 해당 입력을 열거나 조건 하나만 해제합니다. 지역·상권 선택지는 검색과 관련 결과 건수를 제공하고, 상세/후보 화면에서도 같은 조회 입력을 띄워 현재 보기를 유지합니다. 거주지 이동은 실제 확보한 성별2021–2025년 구·동, 연령2025년 구의 지원 범위를 따릅니다.

조회 옵션·선택 정보·순위 창은 좌우 고정/떼기·이동·크기 조절을 같은 원칙으로 통합 중입니다. 지도540px를 남길 공간이 있을 때 가장자리56px에서 고정을 예고합니다. 플로팅 배경은50–100%로 조절하고 도킹 시100%, 다시 떼면 이전 설정을 복원하며 글자·버튼은 흐리게 하지 않습니다. 조회창 제목에는 창 설정·접기만 두고 배치·투명도는 창 설정 안에서 조절합니다. 일반 지도 조회창은 기본280px·조절260–360px, 플로팅360×560px이며 넓혀도 한 열 순서를 유지합니다. 생활인구 빠른 시간 이동은 기간 묶음의 접힌 보조 조작입니다.

생활인구의13개 조회 여정을 Chrome1800×905와1366×768에서 각각 확인했고 전체화면 대체 화면의 단일 입력도 확인했습니다. 다른 자료도 같은 구조로 확장하고 전출입 지표·생활이동 집계·상권 필터와 단일 입력의 대표 여정을 확인했습니다. 2026-11-16 GitHub Pages에 배포했고 공개 조회·지도·그래프 연동을 확인했습니다. [공개 배포·실행 기록](docs/public-query-deployment-report.md). 최종 범위와 제한은 [조회 개선 실행 보고](docs/focused-query-report.md), 원자료 기대값은 [생활인구 독립 수용 기준](docs/population-query-acceptance.md)을 따릅니다. 과거 실행 통과를 현재 모든 기능에 소급하지 않습니다.
