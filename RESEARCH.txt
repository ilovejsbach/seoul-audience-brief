서울 유동인구 지도 — 기술·UX 설계 (2026-11-14)

1. 자료 취득
권장 주자료: 서울 열린데이터광장 250m 기반 행정동별 생활인구.
내국인 OA-23016, 장기외국인 OA-23017, 단기외국인 OA-23018.
자치구 내국인 OA-23019. 각 데이터셋의 FILE에서 과거 자료를 받고 OPEN API에서 지원 기간과 필드를 확인한 뒤 인증키를 신청한다.
https://data.seoul.go.kr/dataList/OA-23016/S/1/datasetView.do
https://data.seoul.go.kr/dataList/OA-23017/S/1/datasetView.do
https://data.seoul.go.kr/dataList/OA-23018/S/1/datasetView.do
기존 OA-14991 등은 과거 분석용으로 분리한다. 2026년 250m 기준 전환 전후 수치를 동일 기준이라고 가정하지 않는다.
실시간 도시데이터는 주요 장소 혼잡 확인용으로 분리하며 모든 행정동을 대표하지 않는다.
https://data.seoul.go.kr/dataVisual/seoul/guide.do
생활인구는 특정 시점에 존재하는 추계 인구이다. 하루 시간별 값을 합쳐 고유 방문자 수로 표시하면 안 된다.

2. 추천 기술
GitHub Pages 정적 웹 + 정제 JSON + GitHub Actions 수집 작업.
실서비스 화면: TypeScript/Vite, MapLibre GL JS, ECharts. 지도 경계는 기준일이 맞는 행정동/자치구 GeoJSON을 별도 관리한다.
원본 수집→형식 검사→행정동코드 연결→같은 시각의 구별 합계→일자별 JSON 생성→배포.
인증키는 GitHub Secrets에 저장하고 브라우저에는 전달하지 않는다. 원본 대용량 CSV 전체를 브라우저에서 읽지 않는다.
데이터에는 기준일, 공개일, 수집일, 단위, 대상 인구, 결측 및 비식별 여부, 행정구역 버전을 기록한다.
결측은 0으로 바꾸지 않는다. 전일 비교는 같은 시각끼리, 평일/주말 비교는 같은 집계 방식끼리 한다.
2026-11-09 공식 공지의 격자 누락 소급 대상 기간은 재수집이 필요하다.
https://data.seoul.go.kr/together/notice/datasetNoticeView.do?bbsCd=10008&seq=1b68433233ce9c1df838a4f63df84ca0

3. 대표 UX
서울 전체→구 선택→행정동 선택→시간·성별·연령 조건→비교·내려받기 순서.
데스크톱은 왼쪽 조건, 가운데 단계구분도, 오른쪽 상세 패널. 모바일은 지도 아래 상세 패널.
인구수와 면적당 밀도를 구분하고 현재 선택한 단위와 색상 범례를 항상 표시한다.
시간 슬라이더를 움직이면 지도·순위·추이가 함께 갱신된다.
세부 내역에는 24시간 추이, 연령 구성, 선택 지역 비교, CSV 내보내기 및 출처를 둔다.
현재 index.html은 가상 예시를 사용하는 대표 시안이다. 2013년 구 경계는 디자인 검토용이며 서비스용 최신 경계가 아니다.
실자료 연결, 최신 동 경계 확보, 집계 대조 및 공개 검증 후 통계 서비스로 전환한다.

4. 추가 조사: 데이터 확보 우선
입출입은 OA-22300 수도권 생활이동(출발-도착지 기준)을 우선한다.
https://data.seoul.go.kr/dataList/OA-22300/F/1/datasetView.do
출근·등교·쇼핑·관광·병원·귀가·기타의 추정 이동목적을 제공한다. 이동목적은 실제 결제나 방문 설문 결과가 아니다. 내부 이동은 구 경계 유입/유출에서 제외하며 구 집계 전 동 간 이동을 구분한다. 반복 통행을 고유 방문자로 단정하지 않는다.
수단별 OD 보완: OA-22657. 도착지 성연령: OA-22298. 내국인 도착지 수단별: OA-22655.
길단위인구 행정동: OA-22178 / 상권: OA-15568. 이름만 보고 보행 센서 실측 통행량이라고 단정하지 않는다.
추정매출 상권: OA-15572 / 상권배후지: OA-15573. 점포 상권: OA-15577. 실제 개별 점포 매출과 구분한다.
https://data.seoul.go.kr/dataList/OA-15572/F/1/datasetView.do
https://data.seoul.go.kr/dataList/OA-15577/S/1/datasetView.do
직장인구 배후지: OA-15570. 메타 갱신주기와 본문 갱신 설명이 다르므로 실제 기준분기 확인이 필요하다.
지하철 시간대별 승하차: OA-12252. 월별 시간대 합계이며 일별 시계열과 혼동하지 않는다.
버스 정류장·노선·시간대별 승하차: OA-12913. 월별 CSV, 매월 5일 전월 갱신 안내.

확보 상태: 공식 데이터셋 및 파일 목록/제공 수단 확인. 원본 통계 파일 다운로드 및 인증키 실호출은 아직 수행하지 않음.
